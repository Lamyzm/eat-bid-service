## 🔴 A. 먼저 — 검정 설계를 고쳐야 한다. **짝지은 비교다**

**문서의 표본 크기 우려는 *짝지어지지 않은* 이항검정에서 나왔다:**
```
아버지 187투찰 6낙찰 → P(X≥6 | 무작위) = 0.1425  ⟹ 아무것도 못 말했다
```
🔴 **그런데 대결은 *같은 회차·같은 `R`·같은 경쟁자 벡터*다. 짝지은 설계다.**
```
회차마다 네 칸 중 하나:
   (모델 승, 사람 패)  = b        ← 정보를 가진 칸
   (모델 패, 사람 승)  = c        ← 정보를 가진 칸
   (둘 다 패)                     ← 정보 없음
   (둘 다 승)                     ← 불가능.  회차당 낙찰자 1명 (x_model = x_human 일 때만)

귀무가설: b/(b+c) = 0.5      ⟹ McNemar
```
**⟹ 일치하는 회차는 검정력에 기여하지 않는다. `b+c` 만 세면 된다.**
**⟹ 187 회차라도 불일치가 충분하면 판정이 선다. 187·6 계산은 틀린 검정이었다.**

**필요 표본 (McNemar, α=0.05 양측, 검정력 80%):**
```
불일치 비율 60:40 을 탐지 →  b+c ≈ **194**
불일치 비율 55:45 을 탐지 →  b+c ≈ 783
```
⚠ **`b+c` 를 얻으려면 전체 회차 수 = `194 / 불일치율` 이다. 불일치율은 아직 모른다.**
**⟹ 🔴 표본 추출 전에 `TUNE` 에서 *불일치율만* 먼저 잰다. 그게 필요한 회차 수를 정한다.**

## 🔴 B. 그리고 승패 기준에 **공정성 문제**가 있다

**문서: *"원가 대리값이 없으므로 지금은 낙찰 수."*  ⟹ 이대로는 우리가 이기게 되어 있다:**
```
모델이 P(승) 을 최대화하면  →  승률 최적 x 로 간다 (N=3 에서 1.0143)
사람은 마진을 함께 본다      →  더 낮은 x 로 간다

⟹ 낙찰 수만 세면 모델이 이긴다.  그런데 그건 **더 나쁜 가격에 더 자주 이긴 것**이다
⟹ "이겼다"가 목적함수 차이의 산물이 된다.  판정이 아니라 인공물
```
🔴 **이건 오늘 다섯 번 겪은 "무엇으로도 기각/기각 불가능" 과 같은 계열이다 — 우리가 이기게 설계된 검정.**

### ✅ 처방 — **가격을 맞추고 겨룬다.** 프론티어로 낸다

```
모델을 단일 정책이 아니라 **정책 족**으로 만든다.  공격성 파라미터 λ 하나
   λ 를 훑으면 (평균 x,  낙찰률) 곡선이 나온다   ← 우리 프론티어
사람의 (평균 x, 낙찰률) 을 그 위에 찍는다

🔴 판정:  **사람의 평균 x 와 같은 지점**에서 우리 낙찰률이 더 높은가
```
**⟹ 이게 "같은 가격이면 누가 더 자주 이기나"이고, 목적함수 차이에 안 걸린다.**
**⟹ 그리고 제품 문구가 바로 나온다: *"지금 가격대 그대로, 낙찰을 X% 더 가져갈 수 있습니다."***
⚠ **낙찰 수 단독 비교도 같이 낸다. 다만 `평균 x` 를 반드시 옆에 적는다 — 그거 없이는 못 읽는다.**

## 🔴 C. 정보 규율 — 결정과 채점을 가른다

```
✅ 채점에 쓴다      실현 R · 실현 경쟁자 벡터        (사람도 우리도 같은 걸 마주했다)
🔴 결정에 못 쓴다   실현 R · 경쟁자 벡터 · 사후 필드(rnk · wd · N_live)
✅ 결정에 쓴다      마감 전 관측:  BID_CNT(=N_pool) · 품목 · 지역 · 기초금액 · 하한율 · 기관
```
**⟹ 이 선을 넘으면 오라클이고 결과가 무의미하다. 코드에서 두 함수로 분리한다:**
```
decide(pre_bid_features) -> x_model        # 사후 필드에 접근 자체가 없다
score(x_model, R_real, competitors)        # 산술
```

## D. 사전 등록하는 셋

### D-1. 승패 기준
```
🔴 주 지표   사람의 평균 x 와 **같은 가격 지점**에서의 낙찰률 차 (프론티어 대조)
   부 지표   낙찰 수 차 (McNemar b:c).  **평균 x 를 반드시 병기**
⚠ 한계 명시  원가 대리값이 없어 마진을 못 잰다.  "낙찰 × 마진"은 지금 계산 불가
```

### D-2. 반증 — **먼저 적는다**
```
모델이 사람과 같거나 못하면 그렇게 보고한다.  구체적으로:
   McNemar 95% CI 가 0.5 를 덮으면        → "판정 불가".  이겼다고 안 적는다
   같은 가격에서 낙찰률 차 CI 가 0 을 덮으면 → "차이 없음"
   b/(b+c) < 0.5 이고 유의하면            → **사람이 낫다**.  그대로 적는다
🔴 그리고 층별로 낸다 — 전체에서 이겨도 저N 에서 지면 그건 지는 것이다
```

### D-3. 표본
```
1. TUNE 에서 **불일치율만** 먼저 잰다 (결과 아님. 검정력 계산용)
2. 필요 회차 = 194 / 불일치율
3. 지역 층화.  🔴 투찰자를 뽑고 낙찰 여부는 사후 층으로 (문서 §3-2)
```
