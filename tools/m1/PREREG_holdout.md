## 🔴 두 경로가 서로 다른 답을 준다 — 그래서 *수준*은 좁게 못 건다

```
경로 A (철회 공변량)   β = −3.26 %p / 0.1152 = −28.3 %p per 1.0 철회율
                       Δwd(TUNE 0.86% − HOLD_A ~0.14%) = 0.0072
                       ⟹ 예측 효과 **−0.20 %p**.  무시할 크기

경로 B (시간 추세)     −1.438 %p/월 × 6~7개월 외삽 ⟹ **−2 ~ −3 %p**
                       ⚠ 기울기 SE 가 1.08 이라 외삽 불확실성이 ±6 %p 를 넘는다
```
⚠ **경로 B 의 기울기는 5점에서 나왔고 유의하지 않다. 좁은 밴드를 만들 근거가 없다.**
🔴 **없는 정밀도를 지어내지 않는다. 수준 예측은 넓게 걸고, 그 검정이 약하다고 적는다.**

## 예측 1 — 수준 `[약한 검정]`

```
HOLD_A 원 미보정 점추정      **−1 %**   (경로 A·B 평균, TUNE +2.69% 에서 하락)
반증 밴드                     [−9 %, +7 %]
   근거: 월간 실제 변동 sd 3.4 %p / √3개월 = 2.0,  기울기 외삽 불확실성 ±6
```
⚠ **이 밴드는 넓다. 벗어나면 진짜 신호이고, 안에 들면 아무것도 배우지 못한다.**
**⟹ 통과를 근거로 쓰지 않는다.**

## 🔴 예측 2 — **모양** `[좁은 검정. 이게 진짜 시험이다]`

**수준은 못 맞혀도 *구조*는 맞혀야 한다. `N` 대역 격차(007 바닥 대비)의 모양:**

```
① 단조성:  격차가 N 에 **단조 감소**한다.  3-4 > 5-9 > 10-29 > (30-59, 60-99, 100+)
           ⟹ 어긋나면 잔차의 원인 진단이 틀린 것이다

② N=3-4 격차가  **[+5, +14] %p**       (TUNE +9.46 ± 0.54, 월간 변동 포함)
③ N≥30 세 대역이 전부 **|격차| < 3 %p**  (TUNE +0.21 / +0.15 / +0.84)
④ 부호:  N<10 에서 **양수**(과대예측).  음수로 뒤집히면 예측 실패
```
🔴 **①③④ 중 하나라도 깨지면 `HOLD_A` 가 `TUNE` 과 다른 것을 재고 있다는 뜻이고, 그건 낙관이 아니라 모형 실패다.**

## 예측 3 — `HOLD_B` (신규 지역) `[사전 상한 없음]`

**`TUNE` 에 신규 지역이 `n=438`(1.2%) 뿐이라 상한을 못 만든다.**
🔴 **점추정도 밴드도 걸지 않는다. 순수 외삽으로 *보고만* 한다.** (team-lead 지시)
