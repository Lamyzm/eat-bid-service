# 사전 등록 — `ACT` 를 `is_recorded_winner` 로 바꿀 때의 방향과 크기

**작성 시각: 돌리기 전.** team-lead 지시: *"부호와 대략 크기를 적어라. 결과를 보고 '그럴 줄 알았다'가 되면 아무것도 못 배운다."*

## 무엇을 바꾸나 (이번 단계에서만)

`ACT` : 규칙 유도 `min{x ≥ R}` (관측 투찰 중)  →  `is_recorded_winner` (BID_STT=002)
**다른 것은 안 바꾼다** — `F_X` 표본·경쟁자 벡터·지수·층 모두 현 상태(철회 제외 `xcap`) 유지.

## 기제

```
7.09% 회차(16,517)에서 낙찰자 본인이 철회했다
xcap 은 철회 제외 ⟹ 그 낙찰자의 행이 **내 자료에 아예 없다**
⟹ 지금 내 규칙은 그 다음(= 더 높은 x) 투찰자에게 낙찰을 붙이고 있다
   (data-inventory 표: 그 모집단의 95.611% 가 "규칙 높음" — 한 방향)
⟹ 고치면 그 양성이 **사라진다**.  그 회차는 내 자료에서 양성이 0 이 된다
```
🔴 **그 회차를 버리지 않는다.** 버리면 결과에 조건을 건 표본이 된다(collider). 실제로 진 사람들의 관측이다.

## 사전 등록하는 수치

```
① 관측 낙찰률이 약 7.09% 떨어진다        0.02558 → ≈ 0.02377
② 예측 p 는 안 바뀐다
⟹ 모든 p/ACT 비가 1/(1−0.0709) = **×1.076** 된다
```

| | 지금 | **예측** |
|---|---:|---:|
| 원 미보정 `N=3-4` | +3.6% | **≈ +11.4%** |
| 007 기준선 `N=3-4` | −4.75% | **≈ +2.5%** |
| 🔴 **격차 `N=3-4`** | **+8.32 %p** | **≈ +8.95 %p** |

## 🔴 핵심 주장 — **격차는 거의 안 움직인다**

모형과 `(a)` 천장이 **같은 분모**(줄어든 `ACT`)로 나뉘므로 둘 다 같은 배율로 올라간다.
**⟹ 라벨 수정은 잔차를 *줄이지 않는다*. 방향은 "더 나빠 보인다" 쪽이고, 격차는 +0.6 %p 만 는다.**

## 반증 조건

```
격차가 +8.95 ±1.5 %p 밖으로 나가면 내 추론이 틀린 것이다
특히 격차가 **줄면** → 제거되는 양성이 x 에 대해 무작위가 아니어서
                      대역 집계에까지 영향을 준다는 뜻 (내 계산은 개수만 봤다)
```

## ⚠ 이 단계 뒤에 별도로 할 것 (섞지 않는다)

`bidlevel.npz` 에 철회 투찰의 `x` 가 있다 (10,586,962 행 vs `xcap` 9,667,069).
⟹ `F_X` 표본 · `(a)` 경쟁자 벡터 · 지수를 **전부** 철회 포함으로 재구축할 수 있다.
**그건 다음 단계다. 이번 표에 섞으면 어느 변경의 효과인지 못 가른다.**
