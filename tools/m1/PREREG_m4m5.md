# 사전 등록 — M4(GBDT) · M5(신경망) 대결

**작성 시각: 적합 전.** team-lead 지시 *"이번엔 사전 등록해라 — 무엇을 이기면 성공인지 결과 전에."*

## 1. 정보 대칭 — 사장 지시의 핵심

**모든 방법이 같은 것만 받는다. `M1` 의 `decide()` 규율을 그대로 적용한다.**
```
✅ 준다    n_pool(BID_CNT · 마감 전 관측) · 기초금액 · 하한율 · 품목 · 지역 · 기관 · ym
❌ 안 준다  실현 R · 실현 경쟁자 x 벡터 · nbid_live · wd · rnk · 낙찰 결과
```
🔴 **구현으로 강제한다: 특징 행렬을 만드는 함수가 금지 열에 *접근 자체를 안 한다*.**

## 2. 🔴 누출 차단 — 아버지 행을 학습에서 뺀다

```
아버지 투찰이 학습 표본에 있으면 그를 상대로 한 평가가 표본 내가 된다
⟹ 학습에서 **아버지 biz_no 두 개의 행 전부 제외**
⟹ 그의 회차는 남는다 (다른 투찰자를 통해).  그의 행만 뺀다
```

## 3. 창

```
적합    학습기 (ym ≤ 202512), 아버지 행 제외
조율    TUNE (202601~202605)
평가    아버지 투찰 3,926건 — 창별로 따로 낸다
🔴 표본 외 검증 수단이 없다.  HOLD 는 소진됐다.  결과에 반드시 적는다
```

## 4. 성공 기준 — **결과 전에 못박는다**

**비교 대상 넷을 같은 자리에:**
```
아버지 실제  1.91%   ·   제비뽑기 1.87%   ·   M1 구조 2.11% (p=0.575, 구분 안 됨)
```

**M4/M5 가 성공이라고 부르려면 셋을 **동시에** 만족해야 한다:**
```
① 아버지보다 높다.  그리고 McNemar p < 0.05      ← M1 이 못 넘은 문턱
② M1(2.11%) 보다 높다
③ 낙찰 시 평균 x 가 아버지 대비 −1.21%(M1 값)보다 **덜 싸다**
   ⟹ 더 싸게 사서 이긴 거면 성공으로 안 친다
```

**반증 — 먼저 적는다:**
```
M4 ≤ M1              →  "표 형태에서 GBDT 가 구조 모형을 못 이긴다" 로 보고
McNemar p ≥ 0.05     →  "아버지와 구분 안 됨".  이겼다고 안 적는다
M5 ≤ M4              →  "신경망이 GBDT 를 못 이긴다" 로 보고.  그것도 결과다
셋 다 아버지 이하      →  🔴 "세 방법 모두 사람을 못 이긴다" 로 보고
```

## 6. 채점

```

투찰 하나씩 대체.  그의 다른 투찰은 경쟁자로 남는다

```
