# 0030 — 화면의 주인공을 **경쟁자 수와 승률 곡선**으로 옮긴다

- Status: Accepted
- Date: 2026-09-02
- 관계: `0027`(예측 승률을 경계 안으로)이 *허용*한 것을 이 문서가 *우선순위*로 정한다. `0027` 의 세 조건은 그대로 구속한다.
- 근거: `docs/experiments/2026-09-02-STATE.md` 및 그 안의 측정들

## Context

`PLAN-MATERIALS` 는 질문→재료 대조로 화면을 짰고, 사장 기획에 **학교별 낙찰률 추이**가 앞자리에 있다.
2026-09-02 측정으로 **무엇이 낙찰을 가르는지**가 정량으로 나왔고, 그 순위가 현재 화면 순위와 다르다.

### 측정된 사실 넷

```
① 위치가 승률을 5배까지 가른다
   같은 금액을 항상 넣는다고 할 때  0.980 → 0.60%  ·  0.995 → 2.95%  ·  1.030 → 1.48%

② 그 최적 위치는 **경쟁자 수가 정한다**
   경쟁 11-20 → 0.9950   21-40 → 0.9925   41-80 → 0.9880   (앞 기간에서 고르고 뒤 기간 채점)

③ 경쟁자 수는 **마감 전에 대부분 보인다**
   마감 전 관측/최종 중앙:  경쟁 3-20 에서 100% · 41-80 에서 94% · 151+ 에서 89%

④ 🔴 그런데 사람들이 그걸 잘 못 쓰고 있다
   정보를 하나도 안 쓰는 **고정 숫자**가 사람 평균을 이긴다 (2.89% vs 2.24%)
   그리고 "어느 회차를 고르나"는 나중 성적을 **예측하지 못한다** (p=0.40)
   반면 "금액을 어디 놓나"는 예측한다 (p=1e−30)
```

## Decision

**화면 우선순위를 이렇게 정한다.**

```
1순위   이 회차의 **경쟁자 수** + **승률 곡선**
2순위   이 회차(또는 같은 조건)의 **투찰 분포** — 사람들이 어디 서 있나
3순위   내 성적표를 **위치 중심**으로 (회차 내 백분위)
4순위   사업자 여러 개를 쓰는 사용자용 — 두 자리가 겹치나
5순위   학교·기관별 추이 — **내리지 않는다.** 자리만 뒤로
```

### 🔴 그리고 내리지 않는 이유를 규약으로 박는다

> **분석적 가치가 낮다는 우리 판단으로 사용자가 보는 재료를 화면에서 제거하지 않는다.**
> **판단 재료의 값은 우리 통계가 아니라 사용자의 결정 시간으로 잰다.**
> **⟹ 할 일은 "치우는 것"이 아니라 *"옆에 사실을 같이 놓는 것"* 이다.**

`학교별 추이` 옆에 붙일 사실: *"이 차이는 대부분 회차별 경쟁자 수로 설명됩니다."*

## Consequences

- **`PLAN-MATERIALS` 의 배치가 바뀐다.** 질문→재료 대조 자체는 유효하고, *순서*만 이 문서가 덮는다.
- **승률을 내는 모든 화면은 `0027` 조건 2에 따라 보정 상태를 병기한다.** 수치는 §"화면에 박을 숫자".
- **경쟁자 수는 "현재값 + 늘어날 수 있음"으로 낸다.** 확정값으로 내면 안 된다(§③).
- **입력 금액 범위를 제한한다.** 사람이 안 넣는 구간은 우리 추정이 무너지는 곳이다(신경망이 거기서 퇴화했다).

## 🔴 만들지 않는 것

```
❌ 추천가 — "이 금액을 넣으세요"
   0027 이 경계 밖에 뒀고, 우리가 가진 건 상관이지 인과가 아니다
   (낮게 놓으면 이긴다 vs 이길 수 있는 사람이 낮게 놓는다 — 자료로 못 가른다)

❌ "사업자를 하나 더 만드세요"
   측정은 했다(아버지 낙찰의 46%가 두 자리에서 나온다).
   그러나 같은 주체의 복수 응찰이 eaT 규정상 허용되는지 **확인하지 않았다**
   ⟹ 재료로도 안 올린다.  규정 확인이 선행 조건

❌ 자동 투찰 — 0027 그대로
```

## ⚠ 이 결정이 안고 있는 것

```
🔴 균형이 아니다.  현 인구가 1.000 근처에 몰려 있어서 성립한다
   제품이 퍼지면 그 자리가 이동하고 이득이 줄어든다.  **성공이 값어치를 깎는다**
   ⟹ 화면 문구가 "확실한 우위"를 암시하면 안 된다

⚠ 우리가 파는 건 "1% 싸게"다.  낙찰 1.4배 ↔ 건당 약 1% 하락
   사용자 마진을 모르면 이득인지 말할 수 없다  ⟹ 마진 입력을 받거나, 판단을 사용자에게 남긴다

⚠ 자료가 전수가 아니다.  17개 지역 중 6개가 96% · 2025-02~08 학습 구간에 구멍
   ⟹ 지역별 수치는 크롤 완결 뒤 재계산한다.  그전엔 **전국값**으로만 낸다
```

## Rejected alternatives

- **학교별 추이를 내린다** — 규약 위반. 사용자 니즈와 분석 가치는 다른 축이고, 우리 판단으로 지우면 사용자가 결정할 재료를 잃는다.
- **최적 금액을 한 점으로 찍는다** — `0027` 경계이자, 인과 근거가 없다.
- **크롤 완결까지 화면 결정을 미룬다** — 위 ①~④는 지역 편향에 크게 안 흔들리는 성질(기전·순위)이다. 흔들리는 것은 *수치*이고, 그건 재계산 항목으로 분리했다.
