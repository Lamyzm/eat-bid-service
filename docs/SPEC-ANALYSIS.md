## B. 우리만 가능 (비드큐에 없음 — 630만 투찰 원장)
- 회차별 **2등가·무효 확정 상한** → 승부 회랑 차트
- **개찰 리플레이**: 전 참여자 투찰 사다리 + 1–2등 간격
- **리허설 정확 재생**: 예정가 보유 회차는 낙찰확정/밀림/무효 3분류가 수학적으로 확정
- 학교 발주 예보(주기), 자격 필터 내장(allowedRegions)

## C. UI 기획

### C1. 분석판(학교 워크벤치) 레이아웃
```
┌ 헤더: 학교명 · 하한 탭 · 기간 프리셋(3/6/12개월/전체) · [리포트 인쇄]
├ 좌 레일(렌즈): ①흐름 ②분포 ③리허설 ④리플레이 ⑤참여업체 ⑥추첨(예정가율)
├ 중앙: lightweight-charts (줌·팬·크로스헤어·호버값)
├ 우 고정: 투찰금액 산출기 — 기초금액 × 값 ↔ 금액, 하한 미달 경고, 투찰함 저장
└ 하단: 렌즈 연동 근거 표 (+ 엑셀 저장)
```

### C2. 상호작용 문법 (전 화면 공통 — 비드큐 문법 채택)
1. **모든 차트 요소·표 행 클릭 = 산출기에 값 주입** (흐름 점, 히스토 막대, 칩, 사다리 행)
2. 히스토그램 더블클릭 = 드릴다운 (0.1 → 0.01 자리)
3. 차트 ↔ 표 상호 하이라이트, 주목 요소는 빨강
4. 차트마다 값 라벨·n 명시, 표가 근거로 동반
5. 인쇄/엑셀 = 산출물 격상

### C3. 렌즈 정의
- **흐름**: 낙찰률 라인 + 2등가·무효상한 점선(회랑) + 참여수 볼륨 + 하한/구간/내값 기준선 + 내 투찰 마커
- **분포**: 하한 마진 히스토그램(0.1 자리) → 더블클릭 0.01 드릴다운, 잘 나온 구간 빨강 강조
- **리허설**: 내 값 입력/차트 클릭 → 회차별 밀림/기회/무효 재생 + 집계 3카드 + 회차별 판정 표
- **리플레이**: 회차 선택 → 전 투찰 사다리(낙찰·밀림·하한미달 색), 1–2등 간격, 무효 경계
- **참여업체**: 로스터 표 + 업체 클릭 → 그 업체 투찰 위치 차트에 오버레이 (경쟁사 비교 흐름의 축소판)
- **추첨**: 예정가율(예정가/기초) 분포 히스토그램 = 추첨의 폭 시각화, 이번 기초금액 기준 하한금액 분포 환산
- ②(공고 상세)는 결정 화면으로 유지, "분석판 →"으로 연결. 공고 리포트 = 분석판의 인쇄 뷰.

### C4. 내 성적 개편
행당 3단 스택: `낙찰 90.006 / 2등 90.012 / 내 값 90.055 (+0.049)` + 진 이유 컬럼 + 기간·품목 필터 + 엑셀.

## D. 데이터 검증 필요 (구현 전)
1. `planned_price` 커버리지 스캔 (레이크) → 리허설 정밀도(3분류 확정 비율) 결정
2. 복수예가 15개 리스트: 컬럼 부재 확인됨 → 조합 다운로드 제외 확정
3. 2등가·무효상한: firm_bids 전량 보유로 가능 확인됨 (서버 엔드포인트 구현 완료)

## E. 구현 순서
1. planned_price 검증 → schema(school_auctions.plannedPrice) 반영
2. 분석판 워크벤치 재편 (렌즈 레일 + 상시 산출기 + 클릭 배선)
3. 분포/추첨 렌즈 (히스토그램+드릴다운)
4. 공고 리포트(인쇄 뷰)
5. 내 성적 3단 스택 + 엑셀
6. 참여업체 렌즈 오버레이 · 경쟁사 즐겨찾기
7. ④⑥⑦ 백로그 계속
