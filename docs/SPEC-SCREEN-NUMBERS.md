### 입력 범위 제한 — **반드시 건다**

```
허용   투찰률 0.984 ~ 1.10   (학습기 투찰의 1%~99% 분위)
🔴 그 밖은 사람이 거의 안 넣는 구간이라 우리 추정이 무너진다
   근거: 신경망이 이 구간 밖에서 퇴화했다 (고른 값의 60%가 격자 최저점에 몰림)
```

### 경쟁자 수 표기 — **확정값으로 내면 안 된다**

**마감 전 관측 수 ÷ 최종 수 (중앙값) · 완전일치 비율**

| 최종 경쟁자 | 마감 전 비율 | 완전일치 | 화면 문구 |
|---|---:|---:|---|
| 3–10명 | 100% | 68.9% | "현재 N명" |
| 11–20명 | 100% | 50.3% | "현재 N명" |

## 2. 투찰 분포 화면 — "사람들이 어디 서 있나"

```

   그 구간 안에서 승률은 2.60% ~ 3.01%   → **거의 평평하다**
   그 밖으로 나가면 5배까지 차이난다 (0.980 → 0.60%)
```

**⟹ 화면에서 말할 수 있는 사실:** *"이 회차 투찰의 대부분이 좁은 구간에 몰려 있습니다. 그 안에서는 서로 비슷합니다."*

## 3. 내 성적표 — **위치 중심**

```
🔴 크게 보여줄 것   "내 투찰이 회차 안에서 몇 번째로 낮았나" (백분위)
                   근거: 나중 성적을 예측한다.  rho = −0.24, p = 1e−30

⚠ 작게 둘 것       "어느 회차를 골랐나" (경쟁 규모·품목·지역 선택)
                   근거: 나중 성적을 **예측하지 못한다**.  p = 0.40
```

**5분위 대조표 — 사용자 위치를 여기에 얹는다**

| 회차 내 위치 | 나중 성적(배수) |
|---|---:|
| 가장 낮은 20% | 1.137 |
| | 0.979 |
| 가운데 | 0.981 |
| | 0.911 |
| 가장 높은 20% | 0.846 |

⚠ **문구 주의: "낮게 넣으면 이깁니다"로 쓰면 안 된다.** 상관이고 인과가 아니다. *"낮게 넣던 업체가 이후에도 더 낙찰했습니다"* 가 정확한 표현이다.

## 4. 사업자 여러 개 쓰는 사용자 화면

```
🔴 보여줄 것   이 회차에서 내 두 투찰이 얼마나 떨어져 있나
              겹치면: "이 회차는 사실상 한 번 넣으신 것과 같습니다"

근거   기준 사용자(사업자 2개) 낙찰의 **46%** 가 두 자리에서 나온다
       두 자리를 같은 값으로 모으면 1년 낙찰 25건 → **14건**
       한 사업자는 한 회차에 정확히 1건만 넣을 수 있다 (전수 확인, 예외 0)
```

⚠ **"사업자를 하나 더 만드세요"는 쓰지 않는다. 규정 미확인 (`ADR 0030`).**
