## 0-R. 15차 — **VoI 분위 읽기: 리더 직감이 맞다. 그 읽기는 동어반복이다.**

### 0-R-1. 왜 "너무 매끄러워서 의심스럽다" 가 정확한 직감인가

리더 읽기: *"손실을 만드는 건 `N` 을 틀리는 것이 아니라 셀 간 최적 x 차이다. 큰 금액 회차는 최적 x 곡선이 평평해서 `N` 을 틀려도 대가가 없다."*

**앞 문장은 참이지만 아무것도 말하지 않는다. 뒷 문장은 셋 중 하나를 근거 없이 고른 것이다.**

```
손실 ≈ P(오분류) × E[후회 | 오분류]
오분류율이 층마다 같다(6.6/7.1/7.6%)  ⟹  차이는 후회 항에 있다   ← 산술적으로 강제된다
```
> **"손실은 결정이 바뀌는 정도다" 는 VoI 의 정의다. 항상 참이고, 그래서 설명이 아니다.**
> **설명은 "왜 결정이 안 바뀌나" 에 있고, 그건 아직 안 쟀다.**

### 0-R-2. `VoI(Q5) = 0` 을 만드는 설명이 셋 있다. 셋이 다른 제품 결론을 낸다.

| | 설명 | 제품 결론 |
|---|---|---|
| **A** | `w(x)` 곡선이 **평평하다** — 어디에 넣든 같다 | **큰 금액 회차엔 위치 조언을 아예 안 보여준다** |
| **B** | 곡선은 **뾰족한데 `x*` 가 `N` 에 따라 안 움직인다** | **위치 조언을 보여주되 `N` 조건화를 뺀다** |
| **C** | Q5 의 `N` 분포가 **좁아서** 오분류가 비슷한 `N` 사이에서만 난다 | 둘 다 유효하고, `N` 변동이 적을 뿐 |

> **A 와 B 는 정반대 제품 결론이다. 같은 `VoI = 0` 에서 나온다.**

### 0-R-3. C 는 내가 직접 재서 기각했다

| 기초금액 분위 | n | N 중앙 | N p10 | N p90 | **log N 의 sd** |
|---|---|---|---|---|---|
| Q1 | 46,641 | 12 | 2 | 102 | 1.397 |
| Q2 | 46,641 | 17 | 3 | 135 | 1.373 |
| Q3 | 46,640 | 19 | 4 | 149 | 1.379 |
| Q4 | 46,641 | 15 | 3 | 148 | 1.364 |
| **Q5** | 46,641 | 13 | 4 | 149 | **1.317** |

**Q5 의 `N` 산포가 다른 분위와 사실상 같다**(log N sd 1.317 vs 1.36~1.40). 사전 등록 층 분포도 고르다
(Q5: S1 24.4% · S2 29.8% · S3 17.4% · S4 25.0%).

> **⟹ C 기각. "Q5 는 `N` 이 안 변해서 VoI 가 0" 은 아니다.**
> **A 와 B 가 남고, 지금 데이터는 둘을 못 가른다.**

### 0-R-4. 가르는 방법 — 그림 하나

```
Q5 안에서 N 버킷별로  w(x)  곡선을 겹쳐 그린다

곡선들이 전부 평평           →  A.  위치 조언을 큰 금액에서 뺀다
곡선이 뾰족한데 봉우리가 겹침  →  B.  위치 조언은 살리고 N 조건화만 뺀다
```
**보조 수치 둘:** ① 층별 `max w − median w` (곡선의 뾰족함) ② 층별 `x*(N)` 의 산포(봉우리 이동폭).
**①이 작으면 A, ①은 큰데 ②가 작으면 B.**

⚠ **`max w` 는 max 통계량이다 — G1 시간분할 밖 값으로 재라.** 안 그러면 A/B 판정 자체가 커스를 탄다.

### 0-R-5. ⚠ 화면 함의를 지금 확정하면 이르다

리더가 *"참여자 수가 불확실하다 경고를 `작은 금액 × N=5-9` 한 곳에만 붙인다"* 고 했다.

**두 가지가 걸린다:**
1. **그 배치는 §8-A3 에서 "층 선택에 못 쓴다" 고 방금 격리한 바로 그 사후 관찰(VoI 층별 분해)에서 나온다.** 화면 설계에 쓰는 건 추론 주장이 아니니 허용 범위이긴 하다 — **다만 held-out 에서 같은 자리에 나오는지 확인하고 붙여라.** 비용이 거의 없다
2. **A 냐 B 냐에 따라 경고의 의미가 달라진다.** A 면 큰 금액에서 경고를 뺄 게 아니라 **위치 조언 자체를 빼야** 하고, B 면 조언은 두고 경고만 빼는 게 맞다

> **⟹ §0-R-4 그림 하나를 먼저 그려라. 그 다음에 화면을 정해도 늦지 않다.**

### 0-R-6. VoI held-out — 받는다. 내 권고의 목적만 바뀐다

**`data-inventory` 가 이미 G1 을 적용했다는 것(정책을 2023~2025 에서 고르고 2026 에서 평가)을 확인했다.**
`0.199 %p` 는 안쪽 max 가 학습기간 안에서 끝난 값이라 커스에 안 물렸다. **내 우려("3~4배가 커스였다")는 일어나지 않았다 — 실제 1.30 배다.**

**`in-sample` 대조는 그대로 권한다. 다만 판정용이 아니라 눈금용이다** — `in-sample − held-out` 이 이 데이터에서 max 기반 통계량이 얼마나 부푸는지의 실측값이고, **VoI·최적 x·T1 의 모든 max 에 같은 눈금이 적용된다.** 한 번만 재면 된다.

## 0-Q. 14차 — **T1 `N` 층 사전 등록. 그리고 「≥2 통과」 규칙에 문제가 있다.**

### 0-Q-1. 🔴 먼저 경고 — **「≥2 of K」 는 지금 증거가 보이는 모양을 기각하도록 설계돼 있다**

계산했다. 각 층 `α=0.025` (95% CI 하한이 문턱을 넘음 = 단측 0.025):

| 효과가 **모든 층**에 있을 때 | | 효과가 **한 층**에만 있을 때 |
|---|---|---|
| 층별 검정력 30% → `P(≥2 통과)` **0.348** | | **0.022** |
| 층별 검정력 50% → **0.688** | | **0.037** |
| 층별 검정력 70% → **0.916** | | **0.051** |
| 층별 검정력 90% → **0.996** | | **0.066** |

> **효과가 한 층에만 있으면 「≥2 통과」의 검정력이 2~7% 다. 사실상 항상 실패한다.**
> **그리고 `data-inventory` 의 지금 결과가 정확히 그 모양이다 — 이득이 `N≤29` 에만 있고 `N=100+` 에서는 해롭다.**

**⟹ 지금 T1 을 그대로 등록하면, "국소적으로 진짜인 효과" 를 "전역적으로 없음" 으로 판정하게 된다.**
**이건 내가 §0-K 에서 경고한 것("한 층이 전체를 끌고 간다")의 반대 방향 실패이고, 내가 제안한 규칙이 만든다.**

### 0-Q-2. 대체안 — **「≥2 통과」 를 「사전 등록된 방향의 단조 추세」 로 바꿔라**

**우연한 한 층은 기울기를 안 만든다. 진짜지만 국소적인 효과는 만든다.** 그게 둘을 가르는 신호다.

**그리고 방향은 데이터를 보기 전에 이미 정해져 있다 — §4-2 가 예측한다:**
```
P(낙찰|x) = 내 영토의 f_R 질량 ≈ f_R(x) / (N·g(x))
  N 이 크면  영토가 얇아지고, 어디에 서든 몫이 1/N 로 눌린다
        ⟹ 위치 선택의 이득은 N 에 대해 감소해야 한다
```
> **이건 사후 관찰이 아니라 `f_R/g` 구조에서 나온 사전 예측이고, `기초금액` 결과보다 먼저 문서에 있다(§4-2, 1차).**

**등록할 형태:**
```
T1 (개정)
  ① 층별로 B1 대비 상대 개선의 95% CI 를 낸다 (G1 시간분할 · 회차 블록 부트스트랩)
  ② 🔴 추세 요건:  효과가 N 에 대해 단조 비증가 (Jonckheere–Terpstra 등 순서 대립 검정, 단측)
  ③ 수준 요건:  적어도 한 층에서 CI 하한 > +10%
  ④ 🔴 T4 무해 요건:  어느 층에서도 유의한 손해가 없을 것
        ← N=100+ 의 −0.29%p (z=−2.03) 가 정확히 이 게이트에 걸린다. 각주가 아니라 게이트다
  ⑤ 통과 시 제품 주장은 통과한 층으로 범위를 한정한다 ("N ≤ X 에서")
```
**②가 ①~③보다 강력하다** — 모든 층의 정보와 순서를 다 쓰고, **우연한 한 층으로는 못 만든다.**

⚠ **그래도 「≥2 통과」를 유지하고 싶다면 실효 유의수준을 알고 써라:**

| K | P(≥1 우연 통과) | **P(≥2 우연 통과) = T1 실효 α** |
|---|---|---|
| 3 | 0.073 | **0.0018** |
| **4** | 0.096 | **0.0036** |
| 5 | 0.119 | 0.0059 |
| 6 | 0.141 | 0.0088 |

**보수적인 건 좋은데, 위 검정력 표와 같이 보면 "보수적"이 아니라 "거의 항상 기각"이다.**

### 0-Q-3. 등록할 `N` 층 — **투표 메커니즘의 구조 경계. `기초금액` 결과와 무관하다.**

**근거는 `2N` 표가 `15` 슬롯을 어떻게 덮느냐 하나다 — 신호가 어디 있는지와 아무 상관이 없고, §0-K/§0-L(기초금액 결과 이전)에서 나왔다.**

| 층 | N | 표/슬롯 `2N/15` | n | 비율 | 구조적 의미 |
|---|---|---|---|---|---|
| **제외** | **1–2** | ≤0.27 | 16,112 | 6.9% | **마스크가 표로 결정된다. 무작위성 0** |
| **S1** | 3–7 | 0.4~0.93 | 51,157 | 21.9% | 표 < 슬롯. 무득표 슬롯 다수 · 서버 채움 · tie-break 지배 |

### 0-Q-4. `N≤2` 제외 근거 — **문서에 인용할 형태**

> **`N≤2` 에서는 예비가격 선택에 무작위성이 없다. 마스크는 뽑히는 게 아니라 계산된다.**
>
> - **`N=1`**: 표 2개 → 득표 슬롯 2개 → **서버가 2개를 채운다.** 채움 규칙은 결정론적이다(낮은 번호 3배 선호, 전수 실측).
> - **`N=2`**: 표 4개 → 득표 슬롯이 4개이면 **마스크 = 득표 집합. 선택 단계가 존재하지 않는다.**
> - **`N=3`** 부터 `2N=6 > 4` 가 되어 비로소 "고르는" 일이 생긴다.
>
> **따라서 "선택이 가격과 독립인가" 라는 귀무가설은 `N≤2` 에서 정의되지 않는다.**
> 순열 검정은 마스크를 교환 가능한 대상으로 다루는데, 거기서는 교환할 무작위성이 없다.
>
> **실측이 이를 뒷받침한다:** `N≤2` 는 회차의 6.9% 인데 선택보정 후 결합 `z` 의 거의 전부를 낸다
> (`N≤2` z=+6.44 vs `N≥3` z≈+0.6~1.3, §0-K-1). **잔여 이상 현상이 정확히 귀무가 성립 안 하는 곳에 몰려 있다.**

### 0-Q-5. ⑤ VoI 해석 — **해석은 안 바뀐다. 그러나 값은 바뀌고, 커지는 쪽이다.**

리더 논리: *"기초금액은 as-of 불확실성 0 이므로 VoI 가 순수하게 `N` 불확실성만 재는 게 유지된다."*

**전반부는 맞다. 후반부("그래서 값이 유지된다")는 안 따라온다.**

```
VoI(N | Z) = E_N[ max_x E[보상 | N, Z] ] − max_x E[보상 | Z]
                                    ↑                    ↑
                           Z 가 세밀해지면 두 항이 다 커진다
```
**해소되는 불확실성은 여전히 `N` 하나다 — 해석은 그대로.** 그러나 **조건집합 `Z` 가 세밀해지면 안쪽 `max` 가 더 많이 착취할 수 있고, `E[max] ≥ max[E]` (Jensen) 이므로 첫 항이 더 빨리 커진다.**

> **⟹ 리더 직감("셀이 늘고 셀 간 최적 x 차이가 커져서 N 오분류 손실이 커진다")이 맞다.**
> **그게 정확히 이 Jensen 메커니즘이고, `기초금액 × N` 상호작용이 유의하므로(z=+5.18) 실제로 커질 것이다.**

**🔴 그런데 여기에 리더가 아직 안 이은 게 있다 — VoI 는 max 기반 통계량이다.**
```
셀이 늘어난다  →  안쪽 max 가 고르는 후보가 늘어난다  →  Optimizer's Curse 가 커진다
                  (Smith–Winkler: 후보 k=30 이면 실망폭 ≈ 2sd)
```
> **∴ 재계산된 VoI 의 증가분은 "진짜 증가" 와 "커스" 가 섞여 있다.**
> **G1(시간분할 밖 보고)을 `최적 x` 뿐 아니라 `VoI` 계산에도 그대로 적용해야 한다.**
> **안 하면 "VoI 가 3~4배 커졌으니 `N` 예측 모델을 다시 연다" 가 커스에 속아서 내려질 수 있다.**

**권고: VoI 를 두 벌로 내라 — `in-sample VoI` 와 `held-out VoI`. 둘의 차이가 §0-M-2 G1 이 말한 커스 실측값이고, 그게 그대로 "EIV 재개 문턱" 의 잡음 하한이 된다.**

## 0-P. 13차 — **「개수로 추정하지 마라」 의 더 나은 형태: 영향함수**

리더 질문: *"'개수로 영향을 추정하지 마라 — 통계량의 성질이 정한다' 를 다른 형태로 더 잘 쓸 수 있나?"*

**쓸 수 있다. 그리고 그게 중요하다 — 지금 형태는 옳지만 "그럼 어떻게 아느냐" 에 답을 안 준다.**
*"통계량의 성질이 정한다"* 는 **"계산하지 말고 생각해라"** 로 읽힐 위험이 있다. 반대여야 한다.

### 0-P-1. 이름이 있다 — **영향함수(influence function)**

**오염의 영향은 개수가 아니라 `ε × (그 통계량의 영향함수 크기)` 다. 그리고 그건 한 줄로 계산된다.**

| 통계량 | 영향함수 | 오염의 영향 |
|---|---|---|
| **비율 (0/1 평균)** | **유계**, `\|IF\| ≤ 1` | `\|Δ\| ≤ ε` — **개수가 곧 상한** |
| **평균** | `IF ∝ (x − μ)` | `Δ ≈ ε·δ̄` — 편차에 **선형** |
| **분산 · sd** | `IF ∝ (x − μ)²` | `Δ ≈ ε·(δ² − σ²)` — 편차의 **제곱** |
| 상관 · 회귀계수 | 무계, 지렛대까지 곱해짐 | 더 나쁘다 |

### 0-P-2. 우리 90 행으로 검증했다 — 예측이 소수 셋째 자리까지 맞는다

```

| | 영향함수 예측 | 실측 | |
|---|---|---|---|
| **sd** | `√(σ² + ε(δ²−σ²))` = **0.021031** | **0.021028** | 비 **1.000** ✅ |

```

### 0-N-1. ① `f_R` 의 축 — **리샘플하지 마라. `f_R` 은 α 하나짜리 모수족이다**

리더 질문: *"같은 하한율의 과거 회차 후보에서 리샘플 하나면 충분한가? 전 기간을 쓰나, 최근 N개월로 자르나?"*

**리샘플이 필요 없다. 규칙이 확정됐기 때문이다(§0-L-2):**
```
후보 15개 = 아래 8개 IID U(1−α, 1)  +  위 7개 IID U(1, 1+α)
R         = 그중 4개의 평균 (슬롯 무작위 대응 → 균등 4-부분집합과 동치)
      ↓
f_R 은 α 만 정해지면 완전히 결정된다.   ← 미지수가 하나뿐이다
```

> **∴ `f_R(·|α)` 를 α 격자(2.0%~3.0%, 0.05% 간격)에 대해 한 번 미리 계산해 두고 끝낸다.**
> **화면의 문제는 "`f_R` 을 어떻게 만드나" 가 아니라 "이 회차의 α 가 얼마인가" 하나로 줄어든다.**

**리샘플 대비 이점 셋:**
1. **표본잡음 0** — 작은 셀(하한율 84, n=1,995)에서도 매끄럽다
2. **as-of 문제가 깨끗해진다** — α 예측은 공고 특징만 쓰면 되고(§0-M-1), 과거 후보값을 안 만진다
3. **꼬리가 정확하다** — 리샘플은 꼬리를 못 채운다. `f_R` 의 꼬리가 위치 계산에서 중요하다(§4-2)

**전 기간이냐 최근이냐:** **전 기간을 써라.** α 는 **규칙 모수**지 행동이 아니고, 연도 추이가 안정적이다(§0-M-3).
자르면 표본만 잃는다. ⚠ **대신 α 의 월별 관리도(control chart)를 붙여라** — 제도가 바뀌면 그때 다시 적합한다.

|---|---|

### 0-N-2. ② `g` 의 조건화 — **as-of 변수에 직접 조건화하라. 적분은 자동으로 된다.**

리더 질문: *"`g` 도 `N(T−1h)` 조건부여야 하나, 최종 N 의 사후분포로 적분해야 하나? 후자가 정확한데 전자가 단순하다."*

**둘이 대립 관계가 아니다. 셋째 선택지가 정확하면서 더 단순하다.**

```
❌ 틀린 방법 :  g(·| N_final = n) 을 과거에서 추정  →  n 자리에 N(T−1h) 를 대입
✅ 옳은 방법 :  g(·| N(T−1h) = n) 을 과거 회차의 「최종 투찰 분포」에서 직접 추정
```

> **✅ 쪽은 이미 최종 N 의 사후분포로 적분돼 있다.**
> 과거에 `N(T−1h)=n` 이었던 회차들은 각자 다른 최종 N 으로 끝났고, **그 최종 분포들의 평균이 곧 적분이다.**
> **명시적 적분을 코딩할 필요가 없다. 조건화 변수를 as-of 것으로 바꾸기만 하면 된다.**

**❌ 방법의 오차가 크다 — 재 봤다.** `P(낙찰|x) ≈ f_R/(N·g)` 이므로 `1/N` 의 기대값이 문제이고, Jensen 부등식으로 `E[1/N] > 1/E[N]`:

| N(T−1h) | 최종 N 평균 | **평균 대입 시 승률 과소평가** |
|---|---|---|
| 5 | 9 | **−49.5%** |
| 10 | 18 | **−58.5%** |
| 20 | 36 | −41.8% |
| 40 | 72 | −15.9% |
| 80 | 144 | −8.5% |

> **경쟁이 적은 회차에서 승률을 절반 가까이 과소평가한다.**
> **이건 우리가 지금까지 쫓던 어떤 효과보다 크다. 그리고 고치는 비용이 0 이다.**

⚠ **다만 뒤집힘(argmax) 판정에는 영향이 작을 수 있다.** 이 편향이 `x` 에 대해 대체로 **곱셈 상수**로 작동하므로 곡선의 **모양·봉우리 위치**는 덜 흔들린다.
**→ `data-inventory` 의 "최적 x 가 N 에 따라 뒤집힌다" 는 정성적 결론은 견고할 것이다. 보고되는 승률 수치는 아니다.**

### 0-M-2. 🔴 Optimizer's Curse 게이트 — **계획 문서에 그대로 넣을 절차**

`data-inventory` 의 `최적 x: 1.011 → 0.983` 은 **추정된 승률의 argmax** 라 Smith–Winkler 편향의 정확한 표적이다.
아래 5단계를 **순서대로, 전부** 통과해야 화면에 숫자를 올린다.

---

**G1. 시간분할 밖에서 값을 보고한다 — 이게 제일 중요하고 제일 싸다**

```
학습기간에서 x*(N) 을 고른다  →  평가기간에서 "그 x*" 의 승률을 잰다
```
**보고하는 숫자는 반드시 평가기간 값이다. 학습기간 최댓값은 절대 보고하지 않는다.**
argmax 선택 자체가 학습기간 안에서 끝나므로 **편향이 구조적으로 제거된다. 축소 수식이 필요 없다.**

> **부수 효과 — 커스의 크기가 측정된다:**
> `학습기간 max ŵ(x*) − 평가기간 ŵ(x*)` = **커스의 실측값.**
> **이 값을 문서에 남겨라.** 다른 모든 max 기반 지표(VoI 포함)의 편향 규모를 가늠하는 눈금이 된다.

**G2. max 전에 곡선을 매끄럽게 한다**

`ŵ(x)` 는 이론상 `x` 에 대해 **매끄럽다** — 영토의 `f_R` 질량이라 연속이다(§4-2).
따라서 **격자별 원시 추정치의 max 를 쓰지 마라.** 단조/평활 적합(예: 국소 다항, 또는 `f_R/(N·g)` 형태 적합) 후 그 곡선의 max.
**평활 = 이 상황의 축소(shrink-then-max)다.** Smith–Winkler 의 처방을 곡선 형태로 실행하는 것.

**G3. "뒤집힘" 을 순열 귀무와 대 본다**

주장은 *"최적 x 가 N 에 따라 다르다"* 이므로 귀무는 *"곡선이 N 과 무관하다"* 다.
```
회차의 N 라벨을 셀(연월 × 하한율 × 품목) 안에서 순열 →  N 구간별 x*(N) 재계산
→  통계량 = spread(x*) = max_N x*(N) − min_N x*(N)
→  관측 spread(=0.028) 가 순열 분포의 95 분위를 넘는가
```
⚠ **순열은 반드시 회차 블록 단위**(§5-3). 투찰 단위로 섞으면 귀무가 과도하게 좁아진다.
⚠ **N 을 셀 안에서만 섞어라.** 전역으로 섞으면 시기·품목 효과가 N 효과로 새어 든다.

**G4. argmax 가 아니라 곡선을 보고한다**

`x*` 는 평평한 봉우리 위에서 크게 흔들린다. **`x*` 하나를 화면에 박지 마라.**
```
보고 = ŵ(x) 곡선 + 블록 부트스트랩 신뢰띠   (회차 클러스터, 재입찰은 UP_ELCTRN_BID_ID 로 묶음)
화면 = "이 구간이 평평하다 / 이쪽이 낫다" 이지 "1.011 을 넣어라" 가 아니다
```
**제품에 필요한 건 봉우리의 위치가 아니라 곡선이 평평한지 여부다**(§4-3).

**G5. 효과 크기 게이트 — 유의성과 별개로**

`ŵ(x*) − ŵ(B1)` 의 **블록 부트스트랩 CI 하한**이 사전 등록한 문턱을 넘어야 한다.
⚠ **문턱을 지금, 숫자를 보기 전에 정하라**(설계문서 §7 의 규율). 안 정하면 결과를 보고 움직인다.

## 0-K. 8차 — **`+2.80` 은 `N≤3` 에서만 나온다. 그리고 거기가 귀무가 가장 약한 곳이다.**

### 0-K-1. 🔴 판정의 출처를 셀 간 결합으로 다시 읽었다

`mechanism-verdict.md` §4-1 의 N 구간표를 결합 z (`Σz_i√n_i / √Σn_i`) 로 묶으면:

| | n | 결합 z |
|---|---|---|
| 전체 7셀 | 233,114 | **+2.72** (리더의 +2.80 과 일치) |

| **`N≤3` 두 셀만** | 26,779 | **+6.44** ← 전체 유의성의 출처 |

> **회차의 11.5% 가 결합 z 의 거의 전부를 낸다.**

**그리고 하필 `N≤3` 이 귀무가 가장 못 믿을 구간이다:**

| N | 표 수 | mask 의 무작위성 |
|---|---|---|
| 1 | 2 | 득표 슬롯 2개 → **서버 채움 2개(결정론적, 낮은 번호 3배 선호)** |

| 3 | 6 | 득표 6 > 4 → **동점 tie-break(낮은 번호, 결정론적)가 지배** |

> **`N≤3` 에서 mask 는 뽑히는 게 아니라 계산된다.**

### 0-K-2. 그래서 판정 문장을 바꾸는 게 낫다 — **더 안전하고 더 강하다**

```
❌ 지금  "관측이 영분포보다 위다 (z=+2.80)"        ← N≤3 두 셀이 만든 값
✅ 대안  "N≥4 (회차의 88.5%) 에서 관측이 선택편향-only 영분포와
          구분되지 않는다 (결합 z=+0.57, 셀별 |z| ≤ 1.03)"
```

**두 번째가 "가격 가시성 없음" 의 증거로 더 낫다.** *"영분포보다 위"* 는 방어할 필요도 없는 잉여 주장이고 — 위에 있을 이유가 없다 — **오히려 "왜 위인가" 라는 질문을 자초한다.** *"영분포와 일치한다"* 가 정확히 우리가 주장하려는 것이다.

**권고: `N≥4` 를 주 판정으로 올리고, `N≤3` 은 "귀무가 성립하지 않는 구간" 으로 따로 적어라.**

### 0-K-3. 그리고 이게 §4-4 의 미해결 모순을 푼다

리더가 남긴 것:
> *"채움은 낮은 슬롯을 3배 선호하고 낮은 슬롯은 미세하게 싸므로 채움 회차의 D 는 음수여야 한다. 그런데 +4.12 bp 다."*

**채움이 필요한 회차 = 득표 슬롯 < 4 = `N≤2` 다.** 리더 본인이 *"`N=1` 785 회차는 전부 득표 슬롯이 정확히 2개"* 라고 적었다.
그리고 §4-1 표에서 **`N=01` 의 영평균이 −2.95 bp** 다 — 그 구간은 절단이 극심하다.

**∴ `+4.12 bp` 를 `0` 과 비교한 게 문제다. 그 구간의 귀무는 크게 음수다.**
`+4.12` 대 `−2.95` 는 §4-1 의 `N=01` 행(`+6.35` 대 `−2.95`)과 같은 이야기이고, **모순이 아니라 같은 현상 하나다.**

> **미해결 항목이 아니라, `N≤3` 에서 순열 귀무가 안 통한다는 하나의 사실이 두 군데로 나타난 것이다.**
> **§4-4 의 🔴 를 내려도 된다 — 단, "N≤3 은 별도 취급" 을 문서에 남기는 조건으로.**

### 0-K-4. Q③ `M` 분위 축 — **넣지 마라. 상한이 0.015 bp 다.**

## 0-J. 7차 — **재입찰은 안 넣어도 된다(증명). 안전집합 +0.56 bp 는 `M` 을 의심하라.**

### 0-J-1. Q1 재입찰 — **"보수적 추정" 이 아니라 "정확히 무관" 이다. 넣지 마라.**

리더는 *"재입찰이면 절단보다 강한 편향 → 내 영분포는 과소추정 → 결론 방향은 안전"* 이라 봤다.

P(mask | 관측됨, r, M)  =  P(mask)·1{통과} / Σ_{mask'} P(mask')·1{통과}

**앞선 시도 횟수는 분자·분모에 같은 상수로 들어가 약분된다.** 관측된 `(r, M)` 으로 조건화하는 순간
**시도 횟수는 보조통계량(ancillary)이 되어 귀무분포에서 사라진다.**

|---|---|---|

### 0-J-2. Q2 안전집합 +0.56 bp — **리더 가설은 항등식으로 반증된다**

리더 가설: *"safe 조건이 `Rmax` 에 의존하므로 후보 분산이 큰 회차를 덜 담고, 그게 D 와 상관된다."*

**틀렸다. 항등식이 막는다:**
```
E[D | r] = (1/4)·Σ_s (p_s − 4/15)·r_s        ← r 과 슬롯확률 p_s 에만 의존
```
> **`r` 만의 함수로 회차를 골라도 `E[D|r]` 은 그 회차에서 이미 정해진 값이고, 그 평균은 안 움직인다.**
> **`Rmax` 든 후보분산이든 `r` 만의 함수다. ∴ 편향을 만들 수 없다.**

수치 확인 (진짜 효과 0인 세계): 후보분산 하위 50% 만 남겨도 `mean(D) = +0.17 bp` (잡음). ✅

**내 대안 가설도 틀렸다 — 정직하게 적는다.** *"`p_s` 가 `N` 에 의존하는데 안전집합이 `N` 을 치우치게 고른다"* 를 시뮬로 걸어 봤다. `p_s` 를 안전집합 안에서 / `N`-층 안에서 다시 추정해도 **잔차가 안 줄었다**(−0.276 → −0.278 → −0.282 bp). **재현 실패.**

**이유가 명확하다:** 슬롯→가격 대응이 회차마다 무작위 순열이면, **mask 분포가 무엇이든 `E[D]=0` 이다.**
`p_s` 를 아무리 비틀어도 무작위 순열과 곱해지면 0 이 된다. **∴ `p_s` 오보정으로는 이 신호를 만들 수 없다.**

### 0-J-3. 🔴 그래서 남는 답 — **`M` 이 `R` 에 오염됐을 가능성**

논리를 끝까지 밀면 답이 좁혀진다:

```
safe 조건 = f(r, M)
  · r 만의 함수로 자르면        → 편향 0  (§0-J-2 항등식)
  · mask 로 자르면              → 편향 발생하지만, safe 는 mask 를 안 본다
  ∴ 편향이 생겼다면 반드시 M 을 통해서다
```

**`M` 이 `R` 에 의존하면 즉시 오염된다. 그리고 그 부호가 관측과 같다.**

**시뮬 (진짜 효과 0, 동일 세계, `M` 정의만 바꿈):**

| `M` 의 정의 | 안전집합 | mean(D) | z |
|---|---|---|---|
| **`max_j x_j` (전원 최고 투찰)** — 올바름 | 10.9% | +0.31 bp | **+0.86** (잡음) ✅ |
| **낙찰자의 `x`** — 오염 | 0.3% | **+148.8 bp** | **+106** ❌ |

**왜:** 낙찰자의 `x` 는 정의상 **`R` 이상 최저 투찰** — `R` 의 함수다. 그걸로 자르면 **`R` 이 높은 회차를 고르게 되고, `D` 가 위로 끌려 올라간다.** **부호가 리더의 +0.56 bp 와 같다.**

**⚠ 확인할 것 셋 — 전부 값이 아니라 "어떤 행이 들어갔나" 의 문제다:**

1. **`M` 이 전원의 최고 투찰인가.** 낙찰자만, 또는 상위 몇 명만 들어가 있지 않은가
2. **`R` 을 참조하는 필터가 걸려 있지 않은가.** `유효투찰 여부`·`낙찰하한금액 이상`·`사정률 범위` — **이런 조건은 전부 `R` 의 함수다.** 하나라도 걸려 있으면 `M` 이 오염된다
3. ⚠ **`SAJEONG_PCT` 경로를 특히 보라.** 사정률은 통상 `투찰금액 / 예정가격` 이라 **분모에 `R` 이 있다.** 두 경로가 99.98% 일치한 건 **값**이 맞다는 뜻이지 **행 선택**이 맞다는 뜻이 아니다

**🔴 그리고 이걸 가르는 한 줄짜리 진단이 있다:**
```
corr(M, R)  을 재라.
```
> **투찰은 `R` 이 뽑히기 전에 정해진다. ∴ 올바른 `M` 은 `R` 과 거의 독립이어야 한다.**
> **양의 상관이 유의하게 나오면 `M` 이 오염된 것이고, +0.56 bp 는 그 산물이다.**
> **거의 0 이면 `M` 은 깨끗하고, +0.56 bp 는 진짜 잔여 신호다 — 그때는 그게 "선택 편향이 없는 곳에서 잰 유일한 깨끗한 추정치" 가 된다.**

### 0-J-4. 만약 `M` 이 깨끗하다면 — **+0.56 bp 가 정답이고, 결론이 더 강해진다**

그 경우 읽는 법:
- **전수 −2.00 bp = 선택 편향.** 리더 판정 그대로 유지
- **+0.56 bp = 선택 편향이 원리적으로 불가능한 곳에서 잰 가격 가시성의 상한**
- **부호가 반대**라 "업체가 싼 후보를 골라낸다" 는 이야기는 **어느 쪽으로도 성립 안 한다**
- 크기: **0.56 bp / 승부 창문 5.8 bp = 창문의 10%**

**→ 프론트엔드 문장이 오히려 더 단단해진다:** §0-I-6 의 상한 주장(창문의 6%)과 같은 자릿수이고, **서로 다른 두 경로가 같은 크기로 수렴한다.**

### 0-J-5. 받는 것 · 갱신하는 것

**✅ 동수 tie-break 확정 — `§9-8` 을 닫는다.** 낮은 번호 우선 93.4%(재추첨 귀무 26.1%). 내가 "이 문서 최대의 단일 미확인 사항"이라 했던 항목이다.

## 0-I. 6차 — **콜라이더가 결정적이다. 그리고 칼보다 나은 게 있다.**

> **결론 먼저: 제안한 칼(`max x ≥ max(후보)`)은 논리적으로 타당하지만 쓰지 마라.**
> **전수를 그대로 쓰면서 콜라이더를 정확히 제거하는 방법이 있고, 내가 시뮬로 검증했다.**
> **그리고 그 전에 — 프론트엔드에 내보낼 문장은 "0 이다" 가 아니라 크기의 상한이어야 한다(§0-I-6).**

### 0-I-1. 🔴 콜라이더는 미묘하지 않다. **검정 대상을 직접 자른다.**

```
낙찰 ⟺ max_j x_j ≥ R
R = mean(선택4),   D = R − mean(r)
      ↓
낙찰 ⟺ D ≤ M − mean(r)          (M = max_j x_j)
```

> **007 조건부 표집은 `D` 를 위에서 절단하는 것과 정확히 같다.**
> **∴ `P(낙찰) < 1` 이면 `E[D | 낙찰] < 0` 이 가격 가시성 없이도 반드시 나온다.**

**크기를 재 봤다.** `D ~ N(0, 0.00743)` 절단만으로:

| 유찰률 | 순수 절단이 만드는 mean(D) |
|---|---|
| 0.5% | −1.08 bp |
| **1.0%** | **−2.00 bp** |
| 2.0% | −3.67 bp |
| 7.0% | −10.73 bp |

> **관측 −2.00 bp 는 "유찰률 1%" 의 순수 절단과 소수점까지 같다.**
> 설계문서 §8-5 가 *"공고의 92.9% 만 갖고 있다 — 유찰·취소가 빠졌다"* 고 적어 뒀다.
> **그 7.1% 중 R 초과가 원인인 게 1/7 만 돼도 관측치가 전부 설명된다.**

**→ 지금 데이터는 "가격 가시성" 과 "절단" 을 전혀 못 가른다. z=−12.96 은 둘 중 무엇에 대한 증거도 아니다.**

### 0-I-2. 🔴 그리고 순열검정은 이걸 **안 잡아준다**

```
순열이 하는 일: mask 를 다른 회차 가격판에 붙여  「회차 안 mask↔가격 상관」 을 끊는다
콜라이더가 만드는 것:                          「회차 안 mask↔가격 상관」
```

**같은 것이다. ∴ 콜라이더 효과는 100% 신호 쪽에 남는다.**
영분포 −0.6303 bp 는 (슬롯 쏠림) × (평균적 슬롯↔가격 구조)만 담고, **절단은 하나도 안 뺐다.**

**설계는 훌륭하다 — 귀무를 "균등 4-부분집합" 에서 "슬롯 집합 ⊥ 슬롯→가격 배정" 으로 고친 것은 정확한 수정이다. 다만 그 귀무가 여전히 절단을 포함하지 않는다.** 층화 5단계가 안정적인 것도 절단을 못 가른다(절단은 층 안에서도 똑같이 작동한다).

### 0-I-3. ✅ 칼은 타당하다 — 그러나 필요 없다

**논리는 맞다.** `M ≥ max(r)` 이면 `R = mean(4개) ≤ max(r) ≤ M` 이므로 **어떤 mask 든 낙찰**이다.
그리고 **조건식이 `(r, M)` 만의 함수라 mask 를 조건화하지 않는다.** 그게 핵심 성질이고 정확하다.

**리더가 든 구멍 1(경쟁 센 회차로 치우침)은 유효하다.** 다만 그건 **내적 타당성이 아니라 외적 타당성** 문제다 — 그 부분집합 안에서 추정은 불편이고, 다른 회차로 일반화가 안 될 뿐이다. **그리고 아래 방법이 그 손실 없이 같은 일을 한다.**

### 0-I-4. 🔴 더 나은 설계 — **낙찰 조건부 귀무를 회차마다 정확히 계산한다**

`C(15,4) = 1365`. **전부 열거하면 된다.**

```
회차 i 마다:
  1) 1365개 부분집합 각각의 D 를 계산                    → allD (n × 1365)
  2) 낙찰이 가능했던 것만 남긴다:  allD ≤ M_i − mean(r_i)
  3) 남은 것들의 평균 = 그 회차의 「낙찰 조건부 귀무 평균」
  4) 검정통계량 =  Σ(D_i − 귀무_i) / √(Σ 조건부분산_i)
```

**전수를 그대로 쓴다. 칼이 없다. 콜라이더가 정확히 빠진다.**

**시뮬로 검증했다 (4만 회차, 8/7 층화 후보판, N 에 따라 M 이 오르는 현실적 설정):**

| | 진짜 효과 **없음** | 진짜 효과 **있음** |
|---|---|---|
| 관측 mean(D) | −28.55 bp | −30.35 bp |
| **순진한 귀무(0) 대비** | **z = −64.6** ❌ 거짓 양성 | z = −69.2 |
| 낙찰조건부 귀무 평균 | −28.54 bp | −28.87 bp |
| **보정 후** | **−0.02 bp, z = −0.05** ✅ | **−1.48 bp, z = −4.38** ✅ |

> **효과가 없을 때 z 가 −64.6 에서 −0.05 로 죽고, 있을 때는 −4.38 로 살아남는다.**
> **정확히 원하는 성질이다.**

**⚠ 실전에서는 한 가지를 더 해야 한다.** 위 시뮬은 귀무 mask 를 **균등 4-부분집합**으로 놨다. 실제 mask 는 투표라 슬롯 쏠림이 심하다(seq3 0.732 vs seq14 0.013). **리더의 순열과 합쳐라:**

```
회차 i 의 귀무 = 「같은 셀 동료 회차들의 mask 풀」 중
                 회차 i 의 가격판에 붙였을 때 낙찰됐을 것들만 남긴 평균
```
**쏠림은 순열이 보존하고, 절단은 필터가 제거한다. 이게 확정판이다.**

| **화면의 `f_R`** | ❌ **그 회차 것은 못 쓴다.** 같은 규칙 과거 회차에서 학습한 투표 분포를 써라 |

`plist.npz` 로 굳힌 것 받았다. **§0-I-4 는 그 판만으로 돌아간다** — 필요한 게 가격 15개·선택 마스크·N 이고 전부 들어 있다. **`M = max_j x_j` 만 추가로 필요하다**(철회 포함, §0-I-5 구멍 3).

### 0-H-1. ✅ 리더의 귀무분산 공식은 정확하다 — 검증했다

```
Var[mean(선택4) | r] = (v/4)·(11/14),   v = 15개 모분산(divisor N)
```
몬테카를로 40만 회로 대조: **실측/공식 = 0.99903**, `E[D] = +0.19 bp`(0 이어야 함). **맞다.**
`(11/14) = (N−n)/(N−1)` 유한모집단 보정도 정확하다.

**그리고 리더 말이 맞다 — 이 검정은 후보 생성 분포가 무엇이든 유효하다.** 회차별 조건부화가 생성 단계를 통째로 지운다. **§0-G-3 의 미해결(꼬리 얇음)이 이 검정을 건드리지 못한다.** 설계가 옳다.

**⚠ 다만 가중 방식에 선택지가 있다.** `z = ΣD/√(ΣVar)` 는 **비가중 합** 검정이고, 이건 *"편향이 회차의 분산에 비례한다"* 는 대립가설에 최적이다. 다른 대립가설엔 다른 통계량이 낫다:

| 대립가설 | 최적 통계량 |
|---|---|
| 편향이 **일정 bp** | **역분산 가중** `Σ(D/Var) / √(Σ1/Var)` |
| 편향이 **회차 spread 에 비례** | 표준화 평균 `Σ(D/sd)/√n` |
| 편향이 **분산에 비례** | 현재 것 |

**α 가 회차마다 다르면(§0-G-3) 비가중 합은 폭 넓은 회차에 지배된다.** 셋 다 내라 — 한 줄이고, 셋이 갈리면 그 자체가 이질성의 증거다.

### 0-H-2. ⚠ N 구간 6개 — **"기대되는 잡음" 이 아니다. 셋이 같은 방향을 가리킨다.**

리더가 *"다중비교 안에서 기대되는 수준이라 아무 말도 하면 안 된다"* 고 했다. **행동(판단 보류)은 옳고, 성격 규정은 정정이 필요하다.** 6개 구간을 따로 보는 대신 **이질성·추세**로 묶어 재면:

| 검정 | 값 | p |
|---|---|---|
| 가중 전체 평균 | **−0.85 bp** (z = −0.62) | 0.54 — **전체 편향 없음. 리더 결론 확인** ✅ |
| **이질성 Q** (df=5) | **11.54** | **0.042** |
| **log(N) 추세 기울기** | **+2.47 bp / ln(N)** (z = +2.18) | **0.029** |
| "6개 중 \|z\|>2 가 둘" | — | **0.028** |

> **셋이 전부 경계선이고, 셋이 같은 것을 읽고 있다 — `D` 가 `N` 에 의존한다.**
> **"무시" 가 아니라 "주시" 다. 전수에서 SE 가 8배 줄면 결판난다.**

**그리고 방향이 해석 가능하다 — 이게 중요하다.**

추세가 **양(+)** 이다: N 이 크면 `D` 가 0 쪽으로 올라간다. 즉 **N 이 작을 때 `D` 가 음(−)** 이다.
**이걸 만드는 메커니즘이 하나 있고, 이미 관측된 것으로 만들어진다:**

```
ml-expert 실측:  corr(seq, 가격) = +0.0124   (SE 0.0043, 2.9σ — 0 은 아니다)
동수 tie-break:  낮은 seq 우선
        ↓
낮은 seq → (아주 약하게) 낮은 가격  →  D 가 음(−)
N 이 작다 → 동수가 흔하다 → tie-break 자주 발동 → D 더 음(−)
N 이 크다 → 동수가 드물다 → 효과 소멸 → D → 0
        ↓
∴ D 는 N 에 대해 증가한다.   ← 관측된 부호와 일치
```

**크기도 맞는다.** 완전 단조(corr=1)일 때 tie-break 효과가 N=5 에서 대략 −50 bp 규모이므로, `corr = 0.0124` 면 **약 −0.6 bp**. 관측 최저 구간이 −3.7 ± 4.0 bp — **부호 같고 크기가 잡음 안에 들어간다.**

> **가설이지 결론이 아니다. 그러나 예측이 뾰족하다:**
> **전수에서 `D` 대 `N` 이 단조 증가하고 큰 `N` 에서 0 으로 수렴하면 이 설명이 맞다.**
> **혹(hump)이 나오거나 부호가 뒤집히면 다른 것이다.**

⚠ **맞더라도 레버가 아니다.** 이용하려면 seq↔가격 대응을 알아야 하는데, **그 대응의 세기가 곧 0.0124 다.**
74 bp × 0.0124 ≈ **1 bp** — 승부 창문 5.8 bp 의 6분의 1. **§0-G-1 의 결론은 그대로다.**

### 0-H-3. 🔴 `sd(D) ≠ sd(R)` — 리더 메시지에 정정 하나. 그리고 새 측정 하나.

리더가 *"α 를 역산하려면 이 값(`귀무 sd(D)=0.0074286`)을 쓰면 된다"* 고 했다. **그건 안 된다.** 둘은 다른 물건이다:

```
Var(R) = E[ Var(R | r) ]  +  Var( mean(r) )
         └ sd(D) 가 재는 것    └ 회차마다 15개 후보의 평균이 다른 몫
```

**`sd(D)` 는 회차 안 선택 잡음이고, `sd(R)` 은 거기에 회차 간 변동이 더해진 것이다.** α 역산에 `sd(D)` 를 쓰면 두 번째 항을 통째로 빠뜨린다.

**그리고 이 항등식에서 새 모멘트가 하나 떨어진다:**
```
Var(mean(r)) = 0.007544² − 0.0073864² = 2.353e−6
sd( 회차별 15개 후보의 평균 ) = 0.001534
```

**이 값이 층화 깊이를 직접 잰다:**

| 규칙 | sd(mean of 15) | sd(width) |
|---|---|---|
| 15개 IID 균등 ±3% | 0.004464 | 0.004829 |
| 아래8/위7 IID | 0.002238 | 0.004456 |
| 15등분 층화 ±3% | 0.000298 | 0.001628 |
| 8/7 층화 ±3% | 0.000299 | 0.001643 |
| **함의된 실측** | **0.001534** | ? |

> **8/7 IID 와 완전층화 사이다 — 부분 층화.** §0-G-3 의 모순("sd 는 ±3% 를 요구하는데 폭은 더 좁은 걸 요구")과 **같은 방향**이다.

**⚠ 그런데 이 유도는 쓰지 마라. 직접 재라.** 이유:
1. `0.007544² − 0.0073864²` 는 **거의 같은 두 수의 차**다. 전체 분산의 **4%** 만 남는다. **`sd(R)` 이 2% 만 틀려도 결과가 100% 바뀐다.**
2. 두 값이 **같은 표본**에서 나왔는지 모른다. `sd(R)=0.007544` 와 `sd(D)` 의 2,997 회차가 같은 집합이 아니면 뺄셈이 무효다.

> **→ `sd(mean(r))` 을 직접 재라. 한 줄이다. 그러면 위 표에서 규칙이 바로 정해진다.**

### 0-H-4. `data-inventory` 에 필요한 것 — **세 줄이면 규칙이 닫힌다**

```
① sd( max − min )  와 그 히스토그램            → α 가 고정인가 가변인가   (§0-G-4)
② sd( mean(15개 후보) )   ← 새로 추가            → 층화 깊이               (§0-H-3)

**①과 ②는 직교한다** — ①은 회차 간 폭 변동, ②는 회차 안 분산 구조. **둘이 있으면 §0-G-3 의 11개 실패한 규칙군 문제가 닫힌다.**

> **화면에 놓을 `f_R` 은 "같은 규칙을 쓰는 과거 회차들의 후보"에서 만들어야 한다.**
> **이 둘을 섞으면 §3 의 정보집합 동등성이 깨진다.** 리더 메시지의 *"as-of 안전한 인자"* 는 **규칙에 대해서만 참이다.**

### 0-G-6. Q3 — **비균등이 승부 창문 계산을 바꾸나. 바꾼다. 그리고 크기가 결정적이다.**

**위치 이동이 먼저다.** `f_R` 의 중심이 1.00000 이 아니라 **0.99872** 다.

```
f_R 중심 이동   = −12.8 bp
승부 창문 폭    =   5.8 bp
                 ─────────
                  2.2 창문
```

> **`R` 이 1.0 중심이라고 가정하고 투찰 위치를 잡으면 창문 2개만큼 어긋난다.**
> **§4 의 `P(낙찰|x) = f_R(x)/(N·g(x))` 에서 분자를 통째로 잘못 읽는다는 뜻이다.**
> **이건 우리가 지금까지 낸 어떤 위치 관련 수치보다 큰 단일 오차원이다.**

**모양(봉우리·꼬리)의 영향은 그보다 작다.** `R` 은 후보 4개의 **평균**이라 후보 밀도의 비균등이 상당히 씻긴다
(후보 sd 0.0169 → R sd 0.0075). **위치 이동은 그대로 통과하고, 모양은 절반쯤만 통과한다.**
**→ 우선순위: 중심 이동을 먼저 고치고, 모양은 실측 후보 재추출로 자동 처리한다(§0-G-5).**

### 0-G-7. Q2 — **품목·기관·시기별로 모양이 다른가**

측정 못 했다. **다만 다를 것이라고 볼 근거가 있다:** Kang & Riew Table 1 이 **기관마다 α 가 다르다**고 명시한다(±2%/±2.5%/±3%/−5~0%/−6~0%). eaT 안에서도 발주 유형별로 갈릴 수 있고, **§0-G-3 의 모멘트 모순이 정확히 그 이질성의 증상**이다.

**측정 방법:** `α 역산 = (max−min)/2` 를 회차별로 내고 **발주기관 × 품목 × 연월**로 교차표. **다봉이면 층이다.**
⚠ **그리고 §0-G-5 의 as-of 규율을 잊지 마라** — 층 자체는 공고 시점에 알 수 있으니 인자로 써도 되지만, **α 를 그 회차의 후보에서 역산한 값은 개찰 후 정보다.** 과거 회차에서 학습한 "이 기관은 α=3%" 를 써야 한다.

### 0-G-8. Q4 — **sd 두 값의 불일치. 우리 기록 쪽을 의심하는 리더 판단에 동의한다**

```
ml-expert 실측   0.007544
우리 기록        0.00781      ← 3.4% 큼
8/7 층화 예측    0.00766
8/7 IID 예측     0.00792
```

**3.4% 차이는 수천 회차 표본에서 우연이 아니다. 표본 정의 차이다.** 의심 순서:
1. **재입찰·유찰·취소 포함 여부** — 재입찰은 규칙이 다를 수 있다
2. **α 층 혼입** — ±2% 회차가 섞이면 sd 가 내려가고, 반대면 올라간다
3. **기간** — `sd(R)` 의 월별 시계열을 그리면 즉시 보인다 (§0-E 에 이미 있는 항목)
4. **`기초가격` 정의** — 분모가 다르면 전부 어긋난다

**⚠ 그리고 이건 §0-F-0-b 에 직접 걸린다.** 나는 *"관측 0.00781 이 비전략 예측치에 붙어 있다 → 전략투표 없다"* 고 했는데, **Case A 가 확정된 지금 그 추론은 필요 없어졌다** — 무작위 대응이면 전략투표가 애초에 불가능하다. **§0-F-0-b 의 결론(전략투표 없음)은 유지되지만, 근거가 sd 대조가 아니라 §0-G-1 의 corr 실측으로 바뀐다.** 더 강한 근거다.

### 0-G-9. Q2(2차) — 남은 −3.8 bp. **`mean(R)|N` 곡선은 여전히 필요하다. 다만 기대는 낮춰라**

배경 −9.4 bp 를 빼면 남는 건 −3.8 bp 다. **Case A 에서 투표가 R 의 평균을 옮길 수 없으므로**(§0-F-1 증명),
투표 가설은 **이미 배제돼 있다.** 남는 후보는:

| 후보 | `N` 의존성 | 크기가 맞나 |
|---|---|---|
| **tie-break 가 낮은 seq 우선** | **N 에 따른 혹** | ⚠ seq 가 금액과 무관하므로 **이것도 금액 편향을 못 만든다.** 배제 |
| **α·규칙 이질성의 2차 효과** | 상수 | 가능. §0-G-3 의 미해결과 같은 뿌리 |
| **후보 생성 자체의 추가 비대칭** | 상수 | 가능 (8/7 만으로 −10.0 bp 인데 실측 −9.4 bp 라 이미 0.6 bp 어긋나 있다) |
| **표본 잡음** | — | `ml-expert` 대조군 차이 3.9 bp 에 대한 SE 를 안 봤다. **먼저 SE 를 내라** |

> **∴ `mean(R)|N` 이 평평할 것이라고 예상한다.** 혹이 나오면 그게 진짜 놀라운 일이고, 그때 `seq` 무작위성을 다시 의심해야 한다.
> **⚠ 그리고 먼저 할 일은 곡선이 아니라 `−3.8 bp` 의 표준오차다.** 잡음이면 곡선을 그릴 이유가 없다.

**→ §9-8(tie-break 미확인)의 위험 등급을 내린다.** seq 가 금액과 무관하므로 tie-break 규칙이 무엇이든 **`R` 의 금액 분포를 못 바꾼다.** 다만 **§0-F-5 의 반사실 재생에서는 여전히 정확히 재현해야 한다**(어느 후보가 뽑히는지는 바꾸니까).

### 0-F-1. Q1 — 레버인가. **조건부로 그렇다. 그리고 조건을 증명으로 닫았다.**

**Case A (번호↔금액 대응이 매 회차 무작위) → 레버가 정확히 0 이다. 시뮬이 아니라 증명이다:**

> 가격이 번호에 **투표와 독립인 균등 무작위 순열**로 배정된다고 하자.
> 표는 선택 집합 `S`(크기 4)를 정한다. `S` 는 순열과 독립이다.
> 따라서 `S` 의 가격들은 **15개 가격의 균등 무작위 4-부분집합**이다 — `S` 가 어떻게 정해졌든 무관하게.
> **∴ `R` 의 분포는 균등 4-of-15 추첨과 정확히 같다. 내 표가 무엇이든.** ∎

**따름정리 두 개 — 리더가 물은 것에 직접 답한다:**
1. **"해석해를 투표식으로 다시 낼 수 있나?"** → **Case A 에서는 다시 낼 필요가 없다. `sd(R) = 0.256039·α` 가 그대로 정확히 성립한다.** 투표가 아무리 쏠려도. Case B 에서는 닫힌형이 없고, **`ds_pList` + `DRAW_NO` 로 회차별 시뮬레이션**해야 한다(그게 더 정확하다).
2. **"투표식이면 인기 번호로 쏠려 분산이 달라진다"** 는 리더 가설 → **Case A 에서는 틀렸다(위 증명). Case B 에서만 맞다.** 그리고 §0-F-0 이 보이듯 **맞을 때는 엄청나게 맞는다(3~4배).**

**Case B (대응이 금액순) → 레버가 크다. 실측:**

경쟁자 `x ~ N(1.000, 0.004)`, 경쟁자는 무작위 투표. 105개 번호쌍 전수 탐색.

| 내 x | N=5 | N=12 | N=30 | 최적 번호쌍(N=30) |
|---|---|---|---|---|
| 0.994 | 1.36x | 1.38x | 1.22x | (1, 2) |
| 0.998 | 1.04x | 1.05x | 1.04x | (9, 11) |
| 1.000 | 1.19x | 1.19x | 1.11x | (6, 14) |
| 1.004 | **2.13x** | 1.40x | 1.23x | (11, 14) |
| 1.008 | **2.65x** | **1.63x** | **1.35x** | (14, 15) |

**⚠ 귀무 수준을 반드시 같이 봐라.** Case A 에서 같은 절차를 돌리면 **모든 `x` 에서 1.03~1.05x** 가 나온다 —
**105개 중 최대를 고른 표본잡음일 뿐이다. 진짜 이득이 0 인데 4% 로 보인다.**
> **이게 §0-C(a) 에서 경고한 Optimizer's Curse 의 실물 시연이다.**
> **1.05x 이하는 우리 시뮬 해상도에서 잡음과 구별되지 않는다.** 위 표의 `0.998` 행은 전부 잡음이다.

**최적 번호쌍이 `x` 에 대해 단조**다 — `x` 가 낮으면 (1,2), 높으면 (14,15). **이론이 예측한 그대로**(아래 Q3)라서, 이건 잡음이 아니라 신호다. **내부 타당성 검사 통과.**

### 0-F-2. Q2 — N 별 크기. **N ≤ 30 이면 의미가 있다. N ≤ 12 면 크다.**

두 가지가 N 과 함께 죽는다: **피벗 확률**(내 2표 / 총 2N표)과 **낙찰확률 이득**.

| N | 내 2표가 최다득표 4개를 바꿀 확률 | 최적표 이득 (x=1.008) |
|---|---|---|
| 5 | 63% | **2.65x** |
| 12 | 45% | 1.63x |
| 30 | 30% | 1.35x |
| 100 | 17% | (미측정, 1.1x 대로 추정) |

**실무 문턱:** `N ≲ 30` 에서 이득이 잡음(1.05x)의 4배 이상. **eaT 회차의 N 분포를 보고 몇 %가 이 구간인지 세라 — 그게 이 기능의 시장 크기다.**

### 0-F-3. Q3 — 최적 표 전략. **있다. 그리고 모두가 하면 상쇄가 아니라 붕괴다.**

**최적 전략은 한 줄이고, 시뮬이 독립적으로 재발견했다:**
> **내 `x` 바로 아래 가격의 번호에 투표하라.**

**왜:** `R` 은 내 매출을 안 바꾼다(투찰금액이 곧 매출이고 이미 고정). `R` 은 **누가 이기는지만** 정한다.
나는 `R ∈ (내 아래 이웃, 내 x]` 일 때 이긴다. **∴ `R` 을 내 바로 아래로 끌어오는 표가 최적이다.**
→ `x` 가 높은 자는 높은 번호, 낮은 자는 낮은 번호. **표는 `x` 의 단조 함수여야 한다** — §0-B-4 에서 예측한 상관이 여기서 나온다.

**"모두가 하면 상쇄되나" → 상쇄가 아니다. 더 나쁘고 더 흥미롭다.**

모두의 `x` 가 뭉쳐 있으므로 **모두의 최적 표도 뭉친다.** 표가 쏠리면 `R` 이 **군중 한가운데에 고정**된다(§0-F-0).
그러면:
- **군중 안에 있는 사람들**: `R` 이 자기들 사이에 오지만 간격이 촘촘해 각자의 몫은 여전히 작다
- **군중 위에 있는 사람들**: **낙찰확률이 0 이 된다.** `R` 이 절대 거기까지 안 온다
- **군중 아래에 있는 사람들**: `R ≤ x` 가 거의 확실해지고 아래에 아무도 없어 **크게 유리해진다** (표에서 0.994 가 9.1%→18.6%)

> **집단 전략투표는 상쇄되는 게 아니라 `R` 의 무작위성을 죽이고, 그러면 게임이 "누가 R 바로 위에 서느냐" 로 바뀐다.**
> **이건 혼합전략 균형의 붕괴이고, LUBA 문헌이 다루는 구조와 같은 종류다** — 다만 **우리 규칙에 대한 균형 해는 문헌에 없고 나도 안 풀었다.**

⚠ **내 "전략적 경쟁자" 모형은 근시안적 최적대응이지 균형이 아니다.** 균형에서는 이 붕괴를 예상해 섞을 것이다.
**균형 계산은 안 했다. 여기서 하는 주장은 "붕괴 방향이 있다"까지지 "균형이 이렇다"가 아니다.**

**제품 함의 (불편하지만 적어야 한다):** 이 기능을 널리 팔면 **우리가 sd(R) 을 죽여서 시장을 바꾼다.**
그게 §3-2 의 루카스 비판이 실물로 나타나는 자리다. **채택률 상한을 미리 정해 두는 게 맞다.**

### 0-F-4. Q4 — 문헌. **없다. §0-B-2 에서 이미 답했고, 다시 찾아도 없다.**

서구 경매 문헌의 random/secret reserve 는 **전부 판매자가 정한다.** 가장 가까운 게 **"random price setter mechanism"**(참가자 한 명을 뽑아 그의 분위를 유보가로) 인데 다르다 — 우리는 **전원이 2표씩 내고 최다득표**다.
**"입찰자가 투표로 유보가격을 형성하는" 메커니즘의 이론·실증 문헌을 나는 못 찾았다.** 국문·영문 모두.

### 0-F-5. Q5 — replay 설계. **표까지 재생하라. 그러면 P2 가 가정에서 사라진다.**

**리더가 준 두 선택지 중 후자가 가능하고, 가능하면 그게 맞다.**

```
경쟁자 DRAW_NO 전원 관측  +  ds_pList 15개 금액 관측
   → 내 표만 바꿔 최다득표 4개를 다시 세면  →  반사실 R 이 정확히 계산된다
```

`data-inventory` 의 대조가 이걸 이미 증명했다 — **철회 표 포함 시 99.31% 재현.**
**즉 재구성 함수가 작동한다. 그러면 반사실도 작동한다.**

**그래서 P2 를 지운다:**

| | 1차 문서에서 | **지금** |
|---|---|---|
| P1 경쟁자 `x` 무반응 | 가정 (검정 불가) | **가정 그대로** |
| **P2 내 `x`·표가 R 을 안 바꿈** | **가정 (엄밀히 거짓)** | **🔴 삭제. 가정이 아니라 계산한다** |
| P3 참여 집합 불변 | E4 참 · E5 거짓 | 그대로 |

> **행동 공간을 `x` 에서 `(x, 표)` 로 넓히고, replay 를 그 공간 위에서 돌려라.**
> **정확도가 올라가는 게 아니라 — 안 그러면 지금 replay 는 틀린 R 을 쓴다.**

**구현 주의 셋:**
1. **표 재생은 `DRAW_NO` 디코딩에 달렸다.** 고유값 105 = C(15,2) 이므로 코드↔번호쌍 대응을 먼저 확정하라. 틀리면 조용히 다 틀린다
2. **동수 tie-break 를 정확히 재현해야 한다.** 반사실은 대부분 **동수 경계**에서 갈린다 — tie-break 를 틀리면 반사실만 골라서 틀린다. **§9-8 이 여기서 1급 위험이 된다**
3. **철회 표를 포함**하라(99.31% vs 87.64%)

### 0-F-6. 화면 함의

리더 말이 맞다 — **사실이면 사장이 고를 게 하나 더 있고, 지금 화면에 그 축이 없다.**
다만 **순서를 지켜라:**

seq 판정(§0-A) → Case B 확정 →  N 분포로 시장 크기 산정(§0-F-2) →  그 다음에 화면
```

**Case A 로 판명되면 이 축은 정확히 0 의 가치다**(증명 §0-F-1). **확정 전에 화면에 올리면 사장에게 없는 레버를 판다.**

## 0-B. 리더가 물은 5가지 — 답

**1. `R ⊥ N` 이 깨진 게 얼마나 아픈가 → 아프지 않다. 오히려 이득이다. 단 한 군데만 아프다.**

- **예측에는 무해하다.** 우리는 `(R, {x_j})` 의 **결합 예측분포**가 필요할 뿐이고, 둘 다 관측한다. 내생성은 **인과 식별**의 문제지 **예측**의 문제가 아니다. M1 은 애초에 예측분포 모형이지 구조 모형이 아니었다(§3-1) — 그래서 이 소식에 안 무너진다.
- **미지수가 는 게 아니라 줄었다.** 계획은 `N`·`X` 둘을 추정하려 했는데, `N` 은 마감 전 관측(`BID_CNT`)되고 `R` 은 표를 알면 결정론적이다. **남는 건 "경쟁자들이 어떻게 투표하나" + "경쟁자들이 어디에 넣나" 인데, 이 둘은 같은 대상의 두 좌표다** — 같은 사람이 같은 순간에 `(DRAW_NO, x)` 를 함께 낸다. **결합 모형 하나로 간다.** §0-B-4.
- **딱 한 군데 아프다:** §2 의 **해석해가 죽는다.** `sd(R)=0.256·α` 는 균등 4-of-15 전제였다. 투표식이면 `f_R` 은 **투표 분포에 의존**하므로 해석적으로 못 닫는다.
  **→ 대체안: `f_R` 을 회차별로 `ds_pList` 에서 직접 재구성하라.** 15개 후보 금액이 다 있으므로, **경쟁자 투표만 시뮬레이션하면 그 회차의 `f_R` 이 정확히 나온다.** 해석해보다 낫다. 이게 R 을 관측하는 진짜 이득이다.

**2. 투표 행동을 모델링하는 문헌 → 🔴 없다.**

찾아봤고 **없다.** 서구 경매 문헌의 random/secret reserve 는 **전부 판매자가 정한다**(Li–Perrigne, Elyakime 외). **입찰자가 유보가 형성에 투표로 참여하는 메커니즘의 이론·실증 문헌을 나는 못 찾았다.**
가장 가까운 것 하나: **"random price setter mechanism"** — 참가자 한 명을 무작위로 뽑아 그 사람의 분위를 유보가로 쓰고 나머지끼리 경매. 근사 최적임이 알려져 있다. **다르다** — 우리는 전원이 2표씩 내고 최다득표로 정한다.
**→ 이건 문헌 공백이다. 그 사실 자체를 기록해 둔다.** 우리가 하는 게 문헌에 없는 일이라는 뜻이고, **인용할 선행이 없으니 우리가 유도한 것을 유도과정과 함께 써야 한다**는 뜻이다.

**3. `BID_CNT` 가 마감 전에 보인다 → 게임을 바꾼다. 그리고 문헌이 이걸 다룬다.**

- **먼저 계획 정정:** 방법론 계획 §1 표의 *"경쟁자 수 ⚠ 개찰 후 관측 → 투찰 시점 특징으로 추정해야 함"* 은 **틀렸다.** 관측된다(진행중 442행 중 76.9%). **M1 의 추정 대상 하나가 통째로 사라진다.**
- **⚠ 그런데 곧바로 쓰면 안 된다. 세 가지를 먼저 확인하라:**
  1. **`BID_CNT` 가 마감 시점 최종값과 얼마나 다른가.** 마감 직전 몰림이 있으면 조기 관측값은 편향된 신호다. **마감 전 스냅샷과 최종값의 차이 분포**를 내라
  2. **언제 0 이 아니게 되나.** 76.9% 는 "마감 전 어느 시점"이고, **우리가 실제로 투찰하는 시점**에 보였는지는 다른 문제다. as-of 절단 안에서 다시 세라
  3. **누출 검사에 새 항목이다.** `BID_CNT` 를 특징으로 넣으려면 **"이 값이 그 시각에 실제로 조회 가능했다"** 를 증명해야 한다. 스냅샷 타임스탬프가 없으면 못 쓴다
- **문헌:** 참여자 수 실시간 공개가 입찰 행동을 바꾼다는 건 확립돼 있다(정보공개 설계 문헌). 그러나 **우리 규칙(무작위 문턱 + 문턱 이상 최저가) 하에서의 분석은 못 찾았다.** 직관적으로는 강하다 — §4 의 공식이 `1/N` 로 스케일하므로 **N 을 보고 참여 여부를 정하는 것 자체가 커버리지 전략의 핵심 도구**가 된다. **E5 가 여기서 실질을 얻는다.**
- ⚠ **동시에 전략적 상호작용이 생긴다.** 모두가 N 을 보고 반응하면 참여가 균형화되고, replay 의 P1(무반응) 가정이 **참여 차원에서** 약해진다. §5-4 의 E5 경고가 더 강해진다.

**4. `DRAW_NO` 와 `x` 가 같이 제출된다 → 상관되면 결합. 식별에 두 가지 뜻이 있다.**

**왜 상관될 이유가 있나 (이론):** 내 낙찰조건은 `R ≤ x` 이고 **내가 받는 돈은 `x` 로 이미 고정이다 — R 은 내 매출을 안 바꾼다.** R 은 **누가 이기는지만** 정한다. 그러므로:
> **낮게 넣은 자는 낮은 R 을 원하고, 높게 넣은 자는 높은 R 을 원한다.**
> **대응이 금액순이라면 `DRAW_NO` 와 `x` 는 이론적으로 양의 상관이어야 한다.**

**→ 이게 §0-A 의 `seq` 질문에 대한 독립적인 두 번째 검정이다.** `corr(DRAW_NO 가 가리키는 금액순위, x)`:
- **0 이면** 대응이 무작위이거나 아무도 전략적으로 투표하지 않는다
- **양수이면** 대응이 금액순이고 **일부는 이미 전략적으로 투표하고 있다** — 그리고 그건 **우리가 팔 수 있는 것**이다

**식별에 무슨 뜻인가:**
- **나쁜 뜻:** `R` 과 `X` 가 결합되면 "R 을 고정하고 x 를 옮기는" 반사실이 순수하지 않다. 다만 **replay 는 여전히 정확하다** — 남들의 `(DRAW_NO, x)` 를 다 관측하고 고정하면 내 `x` 변경의 결과가 계산된다. **결합은 replay 를 안 깬다. 깨는 건 반응이지 상관이 아니다.**
- **좋은 뜻 (더 크다):** `(DRAW_NO, x)` 쌍은 **행동 지문**이다. 같은 업체는 번호 습관이 있다. **업체 식별자가 없어도 `DRAW_NO` 패턴으로 "이 회차에 어떤 유형이 몇 명 왔나" 를 추론할 수 있다.** 그게 `g(x)` 의 조성이고, §4 공식의 유일한 미지수다. **`DRAW_NO` 를 R 의 부속물이 아니라 경쟁자 조성 추정의 도구로 써라.**

**5. 철회자의 표가 집계된다 (99.31% vs 87.64%) → 규정 근거를 못 찾았다. 그러나 통계적으로는 오히려 좋다.**

- **규정 확인 실패.** 조달청·나라장터·eaT 어느 규정 원문에서도 "철회 시 표 처리" 조항을 못 찾았다. **모른다고 적는다.**
- **그럴듯한 이유:** 표는 **투찰 시점**에 집계되고 철회는 **개찰 후**에 일어난다. 시간 순서상 철회가 표를 되돌릴 수 없다. 자연스럽다.
- **⚠ 그런데 87.64% 도 12%가 안 맞는다는 뜻이다.** 99.31%도 0.69%가 안 맞는다. **그 불일치 회차들을 따로 봐라** — 규칙 예외(다른 α, 다른 tie-break, 재입찰)가 거기 숨어 있을 가능성이 높고, **§0-A 의 층 구분이 거기서 나온다.**
- **통계적으로 좋은 소식:** `R` 재구성에 철회자를 포함해야 한다는 건 **`R` 이 "최종 참여자 집합"이 아니라 "투찰한 모든 자"의 함수**라는 뜻이고, 그건 **as-of 시점에 더 잘 정의된다.** 누출 위험이 준다.

## 0-C. `ml-expert` 의 두 판정에 대한 내 의견

### (a) "VoI 에 OPE 불필요 / EVPI max 편향이 위험 / 판정을 영점 분포 95분위로" → **방향은 맞다. 두 군데 고쳐야 한다.**

- **"OPE 불필요"** — 동의한다. 나도 독립적으로 같은 결론에 왔다(§5-5). 보상함수가 알려져 있고 결정론적이며 `R`·`{x_j}` 를 전부 관측하므로 positivity/중요도가중이 필요 없다. **이름은 replay 다.**
- **"max 편향"** — **맞고, 문헌 이름이 있다: Smith & Winkler (2006), *The Optimizer's Curse*, Management Science 52(3):311–322.**
  > *"we should expect the value of the chosen alternative to be less than its estimate, even if the value estimates are unbiased … because of the optimization-based selection process."*
  > *"for k = 30, the disappointment will be around twice the standard deviation in the estimates."*
  VoI 정의 `E_S[max_x E[보상|S]] − max_x E[보상]` 에 **max 가 둘 다 들어 있고, 안쪽 max 가 더 많은 후보 위에서 돌면 편향이 더 크다.** 그래서 **재료를 넣으면 VoI 가 항상 양수로 나오는 경향**이 있다. 정확한 지적이다.
- **"판정을 '신뢰구간이 0 을 안 넘는다' → '영점 재료 분포의 95분위를 넘는다'"** — **동의한다.** 편향된 추정량은 0 을 기준으로 못 쓴다. **같은 편향을 가진 귀무분포**를 만들어 거기에 대야 한다. 이건 순열검정이다.
- **⚠ 고칠 것 두 가지:**
  1. **순열을 아무렇게나 하면 귀무분포가 틀린다.** 재료 열을 통째로 섞으면 **그 재료가 다른 재료들과 갖던 상관까지 깨져서**, 귀무 하의 max 편향 크기가 실제와 달라진다. → **다른 재료의 층(strata) 안에서 순열**하거나 **knockoff** 로 만들어라. 그리고 **순열은 반드시 회차(또는 학교×날짜) 블록 단위**로 — 투찰 단위로 섞으면 귀무분포가 과도하게 좁아져 **거의 모든 재료가 유의하게 나온다.**
  2. **더 나은 대안이 있다 — 원천에서 고쳐라.** Smith–Winkler 의 처방은 검정 보정이 아니라 **max 를 취하기 전에 추정치를 축소(shrink)하는 것**이다. §6-5 의 경험적 베이즈를 여기에 그대로 재사용하면 **편향이 애초에 안 생기고, 순열 귀무분포는 확인용 2차 방어로 남는다.** 계산도 더 싸다.
  → **권고: shrink-then-max 를 1차, 블록 순열 귀무분포를 2차.** 둘이 같은 답을 내면 확정.

### (b) "1.9% 불균형은 우리가 만든 것 / 조건부 밀도로 재구성하면 1,058만 · 불균형 없음 / 검정력을 그 축으로" → **핵심은 맞다. 한 단계가 빠졌고, 그걸 채우면 숫자가 나온다.**

- **맞는 부분 (그리고 중요하다):** 목표를 "낙찰 0/1" 에서 **"경쟁자 입찰 밀도 `g(x|Z)`"** 로 바꾸면 1,058만 투찰이 **전부 양의 관측**이 된다. 불균형이 사라지는 게 아니라 **불균형이라는 개념이 없어진다.** 나도 §6-3 에서 점과정 `λ(x|Z)` 로 같은 제안을 했다 — **독립적으로 같은 곳에 도착했다. 이 방향이 맞다고 본다.**
- **빠진 한 단계:** *"불균형이 없다"* 에서 *"검정력 문제가 없다"* 로 곧장 못 간다. **정밀도의 출처가 바뀐 것**이지 자동으로 좋아진 게 아니다:
  - **결과 기반(outcome-based) 비교**는 여전히 1.9% 베르누이 잡음에 묶인다. 내가 낸 표(+20% 검출에 팔당 22,244 투찰)는 **그 추정량에 대해서는 그대로 유효하다.**
  - **모형 기반(model-based) 비교**는 그 잡음을 안 낸다. 대신 **`g` 추정오차**만 낸다. **그게 훨씬 작다.**
- **그래서 그 축으로 다시 계산했다:**
  두 위치 `x₁`·`x₂` 의 낙찰확률 비는 `[f_R(x₁)/g(x₁)] ÷ [f_R(x₂)/g(x₂)]`. `f_R` 은 (메커니즘이 확정되면) 알려져 있으므로 불확실성은 `g(x₁)/g(x₂)` 뿐이다. 두 구간의 투찰 개수를 `n₁`·`n₂` 라 하면
  ```
  se( log(g₁/g₂) ) = √(1/n₁ + 1/n₂)
  20% 차이(log 0.18)를 2σ 로 잡으려면 →  구간당 n ≈ 250
  ```

  | | 필요 표본 |
  |---|---|
  | **결과 기반** (+20% 상대 개선 검출, 낙찰률 1.9%) | 팔당 **22,244 투찰** |
  | **밀도 기반** (같은 20% 차이, 위치 두 구간 비교) | 구간당 약 **250 투찰** |

  > **약 90배 효율.** 1,058만 투찰이면 폭 5.8bp 짜리 구간 하나에 수만 건이 들어간다. **모집단 축에서 위치 비교는 통계적으로 풍족하다.**
  > 개인 축(투찰 2,000)도 **자기 회차들의 경쟁자 밀도를 모집단에서 빌려 오면** 결과 기반의 "상대 +74% 이상만 검출" 벽을 넘는다.
- **⚠ 대신 새 위험이 생긴다 — 이걸 반드시 같이 적어야 한다.** 모형 기반은 **정밀하지만 `g` 가 틀리면 편향되고, 그 편향은 표본을 늘려도 안 준다.** 결과 기반은 **잡음이 크지만 (고정-경쟁자 반사실에 대해) 불편이다.**
  → **둘 다 내라.** 같은 답이면 확정. **다르면 `g` 모형이 틀린 것이고, 그게 발견이다.** 이건 §3-1 의 M1↔M4 대조와 같은 구실을 하고, 훨씬 싸다.

**요약: `ml-expert` 의 두 판정 모두 방향이 옳다. (a)는 순열 설계와 shrink-then-max 를 보태야 하고, (b)는 "모형 기반이 편향 위험을 새로 진다"를 보태야 완결된다.**

## 0-D. 제도 문헌 — 찾은 것과 못 찾은 것

**⚠ 규정 원문(법령·예규·고시 급)은 끝내 못 찾았다.** 찾은 건 아래가 전부다.

**① 두 개의 서로 다른 규칙이 공존한다 — 이게 혼선의 원인으로 보인다:**

| | 규칙 | 출처 |
|---|---|---|
| **오프라인/구제도** | **입찰자 중 4인을 임의 선정 → 1인 1개씩 추첨 → 4개 평균** | 「조달청 시설공사 계약업무 처리규정」 조문 인용 (2차 출처) |
| **현행 전자입찰** | **전 입찰자가 2개씩 선택 → 최다득표 4개 평균** | 나라장터·국방전자조달 실무 설명, 언론 |

> **Kang & Riew (2015) 가 모형화한 "무작위 4개 추첨" 은 전자가 아니라 오프라인 규칙에 대응한다.**
> **그래서 그 논문의 시뮬레이션이 우리 데이터와 안 맞는 게 당연하다.** §2 의 해석해도 같은 운명이다 — **눈금으로는 유효하되, 현행 규칙의 예측치는 아니다.**

**② 번호↔금액 대응은 "입찰자에게 비공개" 라고 실무 자료가 일관되게 말한다.**
> *"입찰 참여업체들은 예정 가격 2개를 선택할 때 체크박스를 선택할 뿐 그 뒤에 있는 금액은 알 수 없다"* (소셜타임스)
> *"어떤 번호에 어떤 금액이 들어있는지는 비공개 … 사실상 무작위 추첨"* (실무 블로그)

**⚠ 그런데 "비공개" 와 "무작위 배열" 은 다른 말이다.** 금액순으로 정렬해 놓고 안 보여줘도 "비공개"다. **그리고 우리 `mean(R) = 0.99868` 은 무작위 배열과 양립하지 않는다**(§0-A). **실무 설명이 이 지점에서 부정확할 가능성이 높다.**

**③ eaT 가 나라장터와 같은 규칙을 쓰는지 — 여전히 확인 못 했다.**
aT 공공급식 통합플랫폼의 예비가격 추첨 규정 문서를 못 찾았다. **`DRAW_NO` 고유값이 정확히 105 = C(15,2) 라는 사실이 "2개 선택" 을 증명하고, 그게 현재 우리가 가진 가장 강한 증거다.** 학술·규정 문헌은 없다.

**④ 동수 처리 규칙:** 실무 자료 한 곳만 *"번호가 빠른 순서 또는 추가 무작위 추첨"* 이라 한다. **규정 근거 없음. 그리고 §0-A 의 시뮬레이션은 이 규칙에 민감하다** — "낮은 번호 우선" 이면 편향이 생기고 "추가 무작위 추첨" 이면 안 생긴다. **`ds_pList` 에서 동수 발생 회차를 뽑아 실제로 어느 쪽인지 확인할 수 있다.**

## 0. 세 줄 요약 (1차 · 여전히 유효)

1. **우리가 발명하려던 게 이미 학문으로 있다 — 단, 우리에게 필요한 부분은 아니다.**
   구조적 입찰 계량경제(GPV / Li–Perrigne)는 *관측된 입찰에서 숨은 가치를 복원*하는 기계다.
   우리는 **R 도 경쟁자 입찰도 전부 관측한다.** 그 기계의 어려운 절반이 우리에겐 필요 없다.
   M1 을 "구조 모형"이라 부르면 **문헌이 안 푼 문제를 문헌의 이름으로 부르게 된다.**

2. **한국 제도(복수예비가격)에 대한 서구 문헌은 없다. 한국어 문헌은 있고, 결정적이다.**
   Kang & Riew (2015) 가 15개 생성·4개 추첨의 예정가격 분포를 시뮬레이션으로 낸다.
   **내가 그 해석해를 닫아서 우리 `sd 0.00781` 과 대조했다. 안 맞는다.** → §2

3. **`13배` 논증은 성립하지 않는다.** 단위는 같아서 비교 자체는 정당한데, **거기서 나오는 결론이 틀렸다.**
   낙찰확률은 `sd(R)` 이 아니라 **`f_R(x) / (N·g(x))`** 로 정해진다 — 내 자리 위 R 밀도를 경쟁자 밀도로 나눈 값.
   **"위치가 안 먹힌다" 는 `g ∝ f_R` 일 때만 참이고, 그건 데이터로 하루면 확인된다.** → §4

## 1-1. 구조적 입찰 계량경제

### Guerre, Perrigne & Vuong (2000), *Optimal Nonparametric Estimation of First-Price Auctions*, Econometrica 68(3):525–574 — **초록 + 2차 문헌**

- **푼 것:** 1차가격 밀봉입찰 IPV 에서, 관측된 **입찰**과 **입찰자 수**만으로 숨은 **사적가치 분포 F** 를 비모수 식별. 균형전략 역산 없이 두 단계 커널 추정으로 최적 수렴률 달성.
- **같은 곳:** 밀봉·1회·입찰 전량 관측.
- **다른 곳 (결정적):** GPV 의 목표는 **F(가치)** 다. 우리 제품이 답할 질문에 F 는 안 들어간다. 사장이 묻는 건 "얼마 넣으면 딴다" 이지 "경쟁자의 원가 분포는 무엇인가" 가 아니다.
- **우리가 쓸 것:** **거의 없다.** 단 하나 — **역산 없이 관측분포에서 직접 간다**는 방법론적 태도. 그리고 §3-1 의 "언제 F 가 필요해지는가" 판정 기준.
- 출처: <https://onlinelibrary.wiley.com/doi/abs/10.1111/1468-0262.00123>, PDF <http://www.its.caltech.edu/~mshum/gradio/papers/gpv.pdf>

### Li & Perrigne (2003), *Timber Sale Auctions with Random Reserve Prices*, REStat 85(1):189–200 — **전문 파싱해 읽음**

- **푼 것:** 프랑스 산림청(ONF) 1차가격 밀봉입찰. **유보가격이 무작위**이고 입찰 시점에 알 수 없다. 이 모형의 식별을 세우고 GPV 를 확장해 F 를 추정, 최적 유보가격을 계산·시뮬레이션.
- **우리 문제와 가장 가까운 서구 논문이다.** 무작위 유보가격 + 밀봉 + 구조 접근.
- **결정적 인용 (본문 그대로):**
  > "In the present case, the econometrician **observes the number of potential bidders, the seller's random reserve price, and the bids**. The question is whether these observations are sufficient to recover the two distributions H(·) and F(·)."
  > "the identification problem of the IPV model with a random reserve price **reduces to whether bidders' private-value distribution is uniquely determined from observed bids**."
- **⚠ 정정:** 내가 처음 WebFetch 로 받은 요약은 "유보가격이 관측되지 않을 때…" 라고 썼는데 **틀렸다.** 원문을 직접 파싱해 보니 Li–Perrigne 은 **유보가격을 관측한다.** 우리와 같은 조건이다. (요약 모델이 지어냈다. 그 요약은 폐기.)
- **같은 곳:** 유보가격이 확률변수 · 관측됨 · 입찰자 수 관측 · 입찰 전량 관측.
- **다른 곳 (셋):**
  1. **방향.** 저들은 정방향 경매(최고가 낙찰), 우리는 역경매(**커트라인 이상 중 최저가**).
  2. **유보가격의 성격.** 저들의 R 은 **판매자의 사적가치**다 — 판매자가 전략적으로 정한다. 우리 R 은 **제도가 만든 난수**다. 아무의 가치도 아니다. 그래서 저들이 힘들여 식별하는 `H(판매자 가치 분포)` 가 우리에겐 **기계적으로 계산되는 알려진 분포**다. (§2)
  3. **연구 목적.** 저들은 판매자를 위해 최적 유보가격을 설계한다. 우리는 **입찰자를 위해 위치를 고른다.** 발주처가 규칙을 바꾸는 반사실은 우리 질문이 아니다.
- **우리가 쓸 것:** ① "무작위 유보가 관측되면 식별이 쉬워진다" 는 것의 **근거로 인용 가능**. ② **더 중요한 것 — 저들조차 R 이 관측되는 상황에서 F 를 식별하려고 두 단계 비모수를 돌렸다는 사실.** 우리는 F 가 필요 없으므로 그 비용을 안 낸다. **M1 이 GPV/Li–Perrigne 라인이라고 자칭하면 안 되는 이유가 여기 있다.**
- 출처: <https://direct.mit.edu/rest/article-abstract/85/1/189/57377/>, PDF <https://spot.colorado.edu/~martinsc/li-perrigne(2003).pdf>

### 경쟁자 수의 내생성 — Athey, Levin & Seira (2011, QJE 126:207–257); Einav 외 highway procurement; An 외 (미관측 경쟁) — **초록만**

- **푼 것:** 참여(entry)가 내생일 때 입찰 모형의 식별. 잠재 입찰자 수가 미관측일 때의 비모수 복원(오분류 문헌 응용).
- **우리와 같은 곳:** M1 이 추정하려는 "경쟁자 수 분포 N | 회차특징" 이 정확히 이 문제다.
- **다른 곳:** 저들은 **N 을 못 본다.** 우리는 **개찰 후 N 을 전부 본다.** 우리 문제는 식별이 아니라 **예측**이다 (as-of 시점에 N 의 예측분포).
- **우리가 쓸 것:** **경고로 쓴다.** Athey–Levin–Seira 의 핵심 메시지는 *"형식이 바뀌면 참여가 바뀐다"* 다. 우리 E5(커버리지 재배분)가 정확히 그 함정이다 — **내가 안 들어가던 학교에 들어가면 그 회차의 N 과 R 추첨이 바뀐다.** §5-4 에서 다시 때린다.
- 출처: <https://academic.oup.com/qje/article-abstract/126/1/207/1900787>, <https://web.stanford.edu/~leinav/pubs/Auctions.pdf>, <https://arxiv.org/pdf/1908.05476>

### Kang, Minseok & Riew, Moon Charn (2015), 「복수예비가격 생성 및 추첨방법이 예정가격에 미치는 영향」, 한국건축시공학회 논문집 15(1):89–97 — **전문 파싱해 읽음**

**우리 문제에 직결되는 유일한 논문이다.** 우리 데이터의 R 분포를 대조할 눈금을 준다.

  | 수자원공사, 한전 | −2.5% ~ +2.5% |
  | **조달청, 코레일, 농어촌공사, 인천공항** | **−2% ~ +2%** |
  | 철도시설공단, 가스공사 | **−5% ~ 0%** |
  | 도로공사, LH | **−6% ~ 0%** |

  → **범위가 기관마다 다르고, 일부는 비대칭(위쪽이 없다).** 이것 하나만으로도 §2 의 결론이 나온다.
- **생성 방식:** 대부분 기관이 **생성범위를 15개 구간으로 나누고 각 구간에서 균등난수 1개씩** 뽑아 15개를 만든다.

  - **비균등분할-A** — 100% 아래 8구간 / 위 7구간. (지자체, 안전행정부 예규 74호)
  - **비분할** — 전 구간에서 바로 4개.

  | 비분할 ±3% (이론) | 100,000,000 | 866,025 | 0.866% |

### 🔴 추첨은 "무작위 4개" 가 아닐 수 있다 — 실무 자료 — **웹페이지 읽음**

Kang & Riew 는 **"무작위 4개 추첨"** 으로 모형을 세운다. 그런데 실제 나라장터 절차 설명은 다르다:

> "15개 생성된 가격에는 1번부터 15번까지 번호가 부여된다. 각 입찰 참여 업체는 **이 15개 번호 중 2개를 고른다.** … 추첨 종료 후 **가장 많이 선택된 상위 4개 번호**에 해당하는 예비가격의 산술평균이 최종 예정가격이 된다."

→ **선택은 입찰자가 한다. 뽑히는 4개는 최다득표 4개다.**

**이게 왜 중요한가:**
- 입찰자의 번호 선택이 **균등·독립**이고 번호↔금액 대응이 **감춰져 있으면**, 최다득표 4개 집합은 라벨에 대해 교환가능(exchangeable)해서 **결과적으로 균등 4-of-15 와 같은 분포**가 된다. Kang & Riew 모형이 그대로 맞다.
- 그러나 **번호↔금액 대응이 단조**(1번=최저가)이고 입찰자에게 **번호 선호**(1·7·15 같은 습관, 소프트웨어 기본값, 담합 시 지정번호)가 있으면 — **R 의 분포가 균등추첨과 달라진다.** 평균도 분산도 움직인다.
- **우리는 이걸 데이터로 직접 검정할 수 있다.** `ds_pList` 에 15개 후보와 `CHC_YN` 이 다 있다. → §2-3

⚠ **모른다고 적는다:** eaT(학교급식)가 나라장터와 **같은 규칙**인지 나는 확인하지 못했다. eaT 는 aT(한국농수산식품유통공사) 시스템이고 별도 규정을 쓴다. **eaT 의 복수예가 생성범위·구간분할·추첨방식을 다룬 학술 문헌은 검색으로 찾지 못했다.** 우리 `ds_pList` 가 사실상 유일한 1차 자료다.

### 엄상훈·조인휘 (2022), 「국가종합전자조달시스템 복수예비가격에서 다중선형회귀 및 정규화 모델 기반의 예정가격 예측」, 한국통신학회논문지 47(10):1576–1585 — **초록만**

- **푼 것:** KONEPS 복수예가 데이터로 예정가격을 다중선형회귀·리지/라소/엘라스틱넷으로 예측. **R² 99% 이상, MAE 1%.**
- **우리와 같은 곳:** 목표 변수가 같다.
- **⚠ 이 논문은 우리 경고 사례로 쓴다. 두 가지 이유로:**
  1. **성능이 사실은 나쁘다.** 예정가격은 기초금액에서 ±3% 안에 있으므로 `R²` 를 **원 금액**에 대해 재면 기초금액 하나만 넣어도 99.9% 가 나온다. **R² 99% 는 정보가 있다는 증거가 아니다.** 그리고 MAE 1% 는 — 우리 sd 0.78% 짜리 분포에서 **"항상 기초금액"** 이라고 답하는 상수 예측기의 MAE(정규 근사로 ≈ 0.8×sd ≈ 0.62%) **보다 나쁘다.** (⚠ 논문이 MAE 를 무엇 대비 %로 쟀는지 초록만으론 확정 못 한다. 확인 전엔 단정하지 않는다. 그러나 **"R² 99%" 를 성능 근거로 읽으면 안 된다**는 건 확정이다.)
  2. **투찰 시점에 없는 값을 썼을 가능성이 높다.** 15개 후보를 독립변수로 쓰면 예정가격은 그중 4개의 평균이므로 **당연히 맞는다.** 그리고 15개는 **개찰 때 공개된다.** 우리 설계문서 §3-2 의 누출 목록에 `예비가격 15개` 가 들어 있는 건 정확한 판단이다.
- **우리가 쓸 것:** **선행연구 대조군.** "한국에서도 이걸 해봤고, 이렇게 하면 안 된다" 의 근거. 우리 §3(정보집합 동등성)이 이 논문과 우리를 가르는 지점이다.
- 출처: <https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002887161>

### 황대현, 「전자 입찰에서 딥러닝을 이용한 입찰가격 예측」, 전남대학교 — **검색 스니펫만**

KNNR·MLR·MLP·ANFIS 비교, 딥러닝 우세. **MSE/RMSE/MAPE/MAE 로만 평가.** 낙찰 여부·의사결정 개선은 안 잰다. **우리 설계문서 §6("정확도가 아니라 결정 개선")이 이 문헌군 전체와 갈라지는 지점이다 — 그 판단은 옳다.**

## 1-3. 문턱 근접형 낙찰 규칙 — **우리 규칙과 구조가 같은 문헌군**

우리 규칙 "커트라인 이상 중 최저가" 는 서구의 표준 1차가격 경매가 **아니다.** 가장 가까운 건 **average bid auction(평균가 낙찰제)** 계열이다.

### Decarolis (2018), *Comparing Public Procurement Auctions*, International Economic Review 59(4) — **초록 + 요약**

- **푼 것:** 이탈리아 공공조달. 1차가격(+사후 이상저가 심사) vs **평균가 낙찰제**를 비교. 평균가 낙찰제의 규칙: 상·하위 10% 를 잘라낸 평균 A1 → A1 초과 입찰의 평균 A2 → **A2 에 아래에서 가장 가까운 입찰이 낙찰.**
- **우리와 같은 곳 (여기가 핵심):** **"문턱에 아래에서 가장 가까운 자가 이긴다."** 우리 규칙 "R 이상 중 최저가" 와 **위상이 같다.** 위치 게임이지 가격 게임이 아니다.
- **다른 곳:** 이탈리아의 문턱 A2 는 **입찰들로부터 내생적으로 계산된다.** 우리 R 은 **외생 난수**다. → 이탈리아는 담합 유인이 훨씬 강하고(입찰을 몰아 문턱을 옮길 수 있다), 우리는 그게 원리적으로 약하다.
- **문헌의 결과 중 우리가 쓸 것:**
  - 평균가 낙찰제에선 **낙찰 할인율이 훨씬 낮다** (36.67% → 13.75%). **문턱형 규칙은 가격경쟁을 죽이고 위치경쟁으로 바꾼다.** 우리 판(하한율 근처에 몰림)과 정확히 같은 현상.
  - Decarolis (2011) — **평균가 낙찰제는 담합 유인을 특별히 키운다.** → §5-6 의 위협.
- ⚠ **원문 PDF 접근 실패** (eief.it 500, Wiley 403). **초록·2차 요약만 봤다.** 인용 수치는 검색 요약 출처다.
- 출처: <https://onlinelibrary.wiley.com/doi/abs/10.1111/iere.12274>, <https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3533352>

### Chang, Chen & Salmon, *An Investigation of the Average Bid Mechanism for Procurement Auctions*, Management Science 60(6) — **초록만**

- **푼 것:** 평균가 낙찰제의 이론·실험. **"3인 이상에서 순증가 전략의 대칭 베이지안 내시균형이 존재하지 않는다."** 기존 균형분석은 **"모두가 동일하게 투찰하고, 배분이 경매보다 추첨에 가까워진다"** 고 예측하는데, **실험에서는 그렇게 안 나온다.**
- **우리와 같은 곳:** *"이 규칙에선 배분이 추첨에 가까워진다"* — 우리 `13배` 논증의 이론적 사촌이다. **문헌은 이 예측이 실험에서 깨진다고 보고한다.**
- **우리가 쓸 것:** **`13배` 논증을 문헌이 지지하지 않는다는 근거.** 이론적 "추첨화" 예측과 실제 행동은 갈린다.
- 출처: <https://pubsonline.informs.org/doi/10.1287/mnsc.2013.1893>, PDF <https://cpb-us-w2.wpmucdn.com/people.smu.edu/dist/8/1647/files/2022/03/CCS_AvgBid.pdf>

### Scarsini, Solan & Vieille (2010/2014), *Lowest Unique Bid Auctions* — **전문 파싱해 읽음**

- **푼 것:** 최저유일가 경매(LUBA)의 정적 게임 분석. 순수전략 균형 없음, 혼합전략 균형. 그리고 **실증 관찰.**
- **본문 초록 그대로:**
  > "We show that the **observed behavior in these auctions differs considerably from what theory would prescribe if all bidders were fully rational.** We show that the seller makes money, which would not be the case with rational bidders, and **some bidders win the auctions quite often. We describe a possible strategy for these bidders.**"
- **우리와 같은 곳:** ① 이산 격자 위의 **위치 게임**. ② 균형이 **"모든 위치에서 기대보수가 같다"** 는 무차별 조건으로 정해진다 — **우리 §4 의 `g ∝ f_R` 이 그것이다.** ③ **시장이 균형에서 벗어나 있으면 일부 참가자가 계속 이긴다.**
- **다른 곳:** 승리 조건이 "유일성"이지 "무작위 문턱 넘기"가 아니다. 지불 구조도 다르다(입찰마다 고정비용).
- **우리가 쓸 것:** **우리 제품의 존재 근거가 이 문장이다.** *균형이면 위치는 무의미하고, 균형이 아니면 위치에 돈이 있다.* 그리고 **균형인지 아닌지는 검정 가능한 명제다.** → §4-3

## 1-4. 분위 회귀 · 구간 · 계층 모형

### Romano, Patterson & Candès (2019), *Conformalized Quantile Regression*, NeurIPS — **초록 + 저장소**

- **푼 것:** 분위 회귀 + 컨포멀 예측. **분포 가정 없이 유한표본에서 주변 커버리지(marginal coverage)를 보장**하면서, 구간 폭이 x 에 따라 적응.
- **우리와 같은 곳:** **M2 가 하려는 것이 정확히 이거다.** 그리고 설계문서 §6 이 *"구간 커버리지가 명목치를 지키는가"* 를 판정 기준으로 걸었다.
- **다른 곳 (반드시 알아야 한다):** **핀볼 손실만 최소화한 분위 회귀는 커버리지를 보장하지 않는다.** CQR 의 캘리브레이션 단계(별도 홀드아웃으로 분위 예측을 사후 보정)가 있어야 보장이 붙는다. 그리고 보장되는 건 **주변** 커버리지지 **조건부**가 아니다 — *"품목·지역별로도 80%가 지켜지나"* 는 별도 문제이고, Gibbs·Cherian·Candès (2023) 가 그 확장을 다룬다.
- **우리가 쓸 것:** **M2 를 CQR 로 바꾼다.** 화면에 구간을 놓겠다면 **커버리지 보장이 붙은 구간**이어야 한다. 추가 구현비가 작다(홀드아웃 + 분위수 하나).
- **⚠ 우리 데이터의 함정:** CQR 의 보장은 **교환가능성(exchangeability)** 을 전제한다. 우리는 **시간분할**을 쓰고(설계문서 §3-3), 그건 교환가능이 아니다. → 시간 이동이 있으면 커버리지가 깨진다. **"평가 구간에서 커버리지를 실측한다"** 를 판정에 반드시 남겨야 한다(설계문서가 이미 그렇게 써 뒀다 — 옳다).
- 출처: <https://arxiv.org/abs/1905.03222>, 코드 <https://github.com/yromano/cqr>, 조건부 확장 <https://arxiv.org/pdf/2305.12616>

### 계층 모형 / 축소 — Efron–Morris, James–Stein, Gelman & Hill — **초록·교재 수준**

- **푼 것:** 표본이 적은 단위의 추정치를 전체 평균 쪽으로 끌어당기면 **전체 제곱오차가 줄어든다**(James–Stein). 경험적 베이즈로 축소량이 데이터에서 정해진다.
- **우리와 같은 곳:** M3 이 정확히 이것. `1회 중 100%` 문제의 정석 해법이 맞다. **문헌이 우리 판단을 지지한다.**
- **우리가 쓸 것 (구현 조언):** **MCMC 계층 모형을 먼저 세우지 마라.** 회차 233k · 학교 수천 규모에서 **경험적 베이즈 축소(Efron–Morris 닫힌형)** 로 시작하면 몇 초에 끝나고, 축소량이 해석 가능한 한 숫자(`τ²`)로 나온다. 그게 안 통할 때 계층 모형으로 간다.
- **⚠ 우리 계획이 안 적은 것:** M3 의 축소 대상이 **무엇인가**가 안 정해져 있다. "낙찰 x 의 학교별 중앙값"인가, "학교별 낙찰확률"인가, "학교별 경쟁자 수"인가. **셋의 계층 구조가 다르다.** 특히 경쟁자 수는 학교보다 **지역×품목**에 붙을 가능성이 크다 — 그러면 학교 계층은 헛 계층이다.
- 출처: <https://arxiv.org/pdf/1203.4664>, <https://www.pymc.io/projects/examples/en/latest/generalized_linear_models/multilevel_modeling.html>

### 희소사건 로지스틱 — King & Zeng (2001) — **초록 + 해설**

- **푼 것:** 사건이 드물 때 ML 로지스틱의 **소표본 편향**. 보정 추정량 제안. Firth 벌점우도가 사실상 같은 일을 하고 더 널리 구현돼 있다.
- **우리와 같은 곳:** 낙찰률 1.9%.
- **다른 곳 (중요):** **문제는 "비율이 낮은 것" 이 아니라 "드문 쪽의 사건 수가 적은 것" 이다.** 해설 원문:
  > "If you have a sample size of 1000 but only 20 events, you have a problem. If you have a sample size of 10,000 with 200 events, you may be OK. If your sample has **100,000 cases with 2000 events, you're golden.**"
- **→ 모집단 축(투찰 1,058만 · 낙찰 약 20만)은 희소사건 문제가 아니다. 전혀.** 설계문서 §6 의 *"AUC 를 주 지표로 안 쓴다"* 는 판단은 **다른 이유(실무 의미)로는 옳지만, "1.9% 라서 통계가 안 된다" 는 이유로는 틀렸다.**
- **개인 축(낙찰 38~75건)은 진짜로 문제다.** → §5-3 에서 검정력으로 수치화.
- 출처: <https://gking.harvard.edu/files/0s.pdf>, <https://statisticalhorizons.com/logistic-regression-for-rare-events/>

## 1-5. 정보의 값어치 · 정책 평가

### VoI — EVPI / EVPPI / EVSI (의사결정분석·보건경제 계열) — **초록·튜토리얼**

- **푼 것:** *"이 불확실성을 없애면 최적 결정이 바뀌고, 그 결과가 얼마나 나아지나"* 를 계산하는 표준 틀. **EVPPI**(부분 완전정보의 값)가 우리 설계문서 §6 의 "한계 VoI" 와 **정확히 같은 대상**이다. 중첩 몬테카를로, 회귀 기반 근사(GAM/GP) 등 계산법이 정리돼 있다.
- **우리와 같은 곳:** 개념·계산법 그대로 쓸 수 있다. **"설명력 대신 VoI" 라는 우리 척도 전환은 문헌이 이미 40년 쓴 것이고, 이름이 EVPPI 다.** 우리 문서에 그 이름을 박아 두면 나중 사람이 바퀴를 다시 안 만든다.
- **다른 곳:** 보건경제 EVPPI 는 **베이즈 모형의 파라미터 불확실성**에 대해 잰다. 우리는 **관측 가능한 재료 하나를 화면에서 뺐다 넣었다** 하는 것에 대해 잰다. 후자가 더 쉽다 — 사후분포가 필요 없다.
- **우리가 쓸 것:** ① 용어(EVPPI)와 정의를 그대로. ② 계산 구조: `E_재료값[ max_행동 E[결과 | 재료값] ] − max_행동 E[결과]`. **바깥 max 가 안쪽에 있어야 VoI 다.** 우리 문서의 "한계 VoI" 서술이 이 구조를 명시하지 않았다 — 명시해야 한다.
- 출처: <https://pmc.ncbi.nlm.nih.gov/articles/PMC8183576/>, <https://en.wikipedia.org/wiki/Expected_value_of_sample_information>

### Off-policy evaluation (OPE) — **초록 다수**

- **푼 것:** 로그로만 새 정책의 가치를 추정. IPS / DR / self-normalized. **핵심 가정: positivity(overlap)** — 새 정책이 고를 수 있는 모든 행동에 로깅 정책이 양의 확률을 줬어야 한다.
- **결정적 사실:** **"OPE is difficult with a deterministic logging policy, since its log data contain no information about the reward from actions never chosen."**
- **우리와 다른 곳 — 그리고 이게 좋은 소식이다:** §5-5 에서 자세히. 요약하면 **우리는 OPE 가 필요 없다.** 보상함수가 **알려져 있고 결정론적**이기 때문이다.
- 출처: <https://arxiv.org/html/2603.21485v1>, <https://arxiv.org/pdf/2010.11002>, <https://arxiv.org/pdf/1907.09623>

### 반사실 리플레이 (광고 경매 실무 문헌) — **초록**

- **푼 것:** 로그된 경매에서 **경쟁 입찰·참여를 고정**한 채 내 입찰만 바꿔 결과를 다시 계산.
- **인용:** *"Replay evaluation holds the opportunity set, bids, and bidder participation fixed, which is useful for offline screening but **is not a live causal effect.**"*
- **우리가 쓸 것:** **M6/E4/E5 의 정확한 이름이 이것이다 — replay(반사실 재생)이지 OPE 가 아니다.** 그리고 그 한계("생방송 인과효과가 아니다")를 문헌 문장 그대로 우리 §8 에 박아 둘 것.
- 출처: <https://arxiv.org/pdf/2605.12840>, <https://arxiv.org/pdf/2605.21736>

## 2. 🔴 `sd 0.00781` — 메커니즘과 대조했다. 안 맞는다.

> **⚠ 2차 개정 주석.** 아래 해석해는 **"균등 4-of-15 무작위 추첨"** 전제다. `data-inventory` 확정으로
> **현행 규칙은 투표식**임이 밝혀졌으므로, 이 해석해는 **현행 규칙의 예측치가 아니라 비교 눈금**이다.
> 다만 **§0-A 에서 확인했듯 투표식은 sd 를 거의 안 바꾼다(0.0077 근처 유지).**
> **→ sd 이상(+1.7%)에 대한 아래 진단은 그대로 유효하다. mean 이상은 §0-A 로 이관됐다.**

### 2-1. 해석해를 닫았다

15개 구간 균등분할, 각 구간에서 균등난수 1개, **균등 4-of-15 비복원 추첨**, R = 4개 평균일 때:

```
w = 2α/15                                     구간 폭
Var(R) = w²/48  +  (σ_m²/4)·(11/14)           within + between
         σ_m² = w²·(15²−1)/12 = 18.667 w²
       = w²·(0.020833 + 3.666667) = 3.6875 w²
sd(R)  = 1.92029 · w = 1.92029 · (2α/15) = 0.256039 · α
```

`between` 항의 `(11/14)` 는 **비복원 추출의 유한모집단 보정** `(N−n)/(N−1) = 11/14` 다.

**검증 (둘 다 통과):**
- 내 몬테카를로 40만 회: ±3% → sd **0.7674%** (해석해 0.7681%)
- **Kang & Riew 의 독립 시뮬레이션 20,000회: 767,369 / 1억 = 0.7674%** ✅

|---|---|---|
| ±2% | **0.512%** | 0.577% |
| ±2.5% | **0.640%** | 0.722% |
| ±3% | **0.768%** | 0.866% |

### 2-3. 그래서 무엇을 해야 하나 — **회차별로 규칙을 추정하라. 풀링하지 마라.**

가장 가능성 높은 설명 셋:

1. **규칙이 회차마다 다르다.** Kang & Riew Table 1 이 보여주듯 기관마다 생성범위가 다르고 일부는 **비대칭(−5%~0%, −6%~0%)** 이다. eaT 도 발주 유형·시기별로 다를 수 있다. **규칙이 섞이면 풀링한 평균은 아래로, 풀링한 sd 는 넓어진다.** 이 조합만이 관측된 방향을 낸다.
2. **추첨이 균등 4-of-15 가 아니다.** 실제 규칙은 **최다득표 4개**다(§1-2). 번호↔금액 대응이 단조이고 입찰자에게 번호 선호가 있으면 균등추첨과 달라진다.
3. **선행 분석의 표본이 오염됐다.** 재입찰·유찰·취소 섞임, `기초가격` 정의 불일치.

**하루 안에 끝나는 검정 (전부 `ds_pList` 만으로):**

| # | 검정 | 어떻게 | 결과가 말하는 것 |
|---|---|---|---|
| **T1** | **생성범위 α 를 회차별로 추출** | `(max−min)/기초가` · 15개의 최소·최대 | α 가 상수인가? 몇 종인가? **여기서 층이 갈리면 아래 전부 층별로 다시 낸다** |
| **T2** | **구간 분할 방식** | 15개를 정렬해 인접 간격 분포 · 100% 위/아래 개수 | 균등분할인가 8/7 인가. **회차마다 위/아래 개수를 세면 즉시 나온다** |
| **T3** | **🔴 추첨이 순위에 대해 균등한가** | `P(CHC_YN=Y \| 후보의 가격순위 r)`, r=1..15 를 세어 15개 비율을 낸다. 균등이면 전부 4/15=0.2667. **χ² 적합도 검정** | **깨지면 R 은 순수 난수가 아니다.** 그러면 R 에 예측 가능한 성분이 있고, **이 프로젝트의 결론이 통째로 바뀐다** |
| **T4** | **추첨이 번호(라벨)에 대해 균등한가** | 같은 것을 `번호`로 | T3 은 균등한데 T4 가 깨지면 → 번호↔금액이 **매 회차 무작위 순열**이라는 뜻 (좋은 소식, 모형이 단순해짐) |
| **T5** | **뽑힌 4개가 교환가능한가** | 4개 순위의 공동분포를 균등 4-subset 과 비교 (예: 4개 순위합의 분포) | 최다득표 방식의 실제 효과 |
| **T6** | **T1·T2·T3 로 층을 갈라 층별 mean/sd 재산출** | | **해석해와 층별로 맞으면 메커니즘 이해 확정. 안 맞으면 그 층이 발견이다** |

> **방법론 계획 §4 의 "1. R 분포 (관측 + 해석 유도 대조) ← 안 맞으면 여기서 멈추고 원인부터" 는 옳은 순서다.**
> **이 문서는 그 대조를 미리 한 번 돌렸고, 이미 안 맞는다는 것을 알린다.** T1~T6 이 1번 항목의 구체 명세다.

## 3. M1 "구조 모형" — 식별은 문제가 아니다. **이름이 문제다.**

### 3-1. 우리에게 식별 문제는 없다

구조적 입찰 계량경제의 식별 문제는 **"관측된 입찰에서 미관측 가치를 복원할 수 있는가"** 다. GPV·Li–Perrigne 이 푸는 건 그거다.

**우리는 가치를 복원할 필요가 없다.** 우리 질문은:

> 이 회차에서 내가 x 를 고르면 딸 확률이 얼마인가.

이 확률은 **R 의 분포**와 **경쟁자 x 들의 분포**만 있으면 계산된다. 둘 다 관측된다 — 사후에, 233,336 회차 · 1,058만 투찰에서. **필요한 건 그 둘의 as-of 예측분포지, 아무의 사적가치도 아니다.**

→ **M1 은 구조 모형이 아니라 조건부 예측분포 모형이다.** 이름을 정확히 부르면:
- GPV 의 비모수 역산 · 커널 대역폭 · 경계보정 같은 비용을 **안 낸다**
- 대신 **예측 문제의 규율**(시간분할, 보정, 커버리지)이 전부 적용된다
- **M4(GBDT)와의 대조가 무의미해진다** — 둘이 같은 것을 다르게 추정할 뿐이다. 우리 계획은 M1 을 "구조", M4 를 "비구조" 로 대립시키는데, 실제 차이는 **"낙찰규칙을 모형에 넣었는가"** 하나다. 그게 좋은 대조지만, 그렇게 불러야 정확하다.

### 3-2. 그런데 **진짜 식별 문제가 하나 있다 — 우리 계획이 안 적은 것**

**언제 구조(가치)가 필요해지는가:** 제품이 실제로 사장들의 투찰을 바꾸면, **경쟁자 분포 g 자체가 바뀐다.** 그때 과거 g 로 추정한 낙찰확률은 무효다. 루카스 비판.

- **사용자 한 명(아버지)** → 안전. g 를 고정으로 봐도 된다.
- **엔터프라이즈** (설계문서 §1 이 명시한 목표) → **위험.** 같은 판의 여러 업체가 같은 화면을 보면 g 가 화면 쪽으로 몰리고, **그 순간 화면이 알려준 자리가 가장 붐비는 자리가 된다.**
- **문헌이 이걸 다룬다:** 이럴 때 필요한 게 균형 개념이고, 균형을 계산하려면 **가치 분포 F 가 필요하다.** 그러니까 **GPV/Li–Perrigne 이 필요해지는 조건이 정확히 "제품이 성공하는 것" 이다.**

**→ 계획에 추가 권고:** M1 을 지금은 예측분포로 두되, **"채택률이 시장의 몇 %를 넘으면 g 고정 가정이 깨지는가"** 를 replay 로 미리 재 둘 것. 계산은 쉽다 — 사용자 비율 k 를 넣고 그들이 화면 추천으로 이동한 g' 를 만들어 낙찰률이 어디서 무너지는지 본다. **이건 제품 로드맵 결정이지 학술 문제가 아니다.**

### 3-3. 경쟁자 수·위치 분포를 투찰 시점 특징으로 추정하는 게 가능한가 — **가능하다. 필요한 가정은 셋.**

| 가정 | 내용 | 검정 가능? |
|---|---|---|
| **A1. as-of 충분성** | 투찰 시점 특징 Z 가 주어지면, N 과 g 의 조건부 분포가 미관측 요인에 의존하지 않는다 | ❌ 직접 검정 불가. **하지만 보정(calibration)으로 간접 검정된다** — 이게 M1 의 1차 지표를 보정으로 잡은 판단이 옳은 이유다 |
| **A2. 시간 안정성** | 학습기간의 `g(·\|Z)` 가 평가기간에도 유효 | ✅ 시간분할 평가로 검정 |
| **A3. 무반응** | 내 x 가 경쟁자 x_j 를 안 바꾼다 | ⚠ 부분적. §5-5 |

**A1 에 대한 실질적 위협 하나 — 우리 계획이 안 적었다:**
경쟁자 수와 경쟁자 위치는 **독립이 아니다.** 경쟁이 붐비는 회차는 (a) 이문이 좋아서고 (b) 그런 회차에선 경쟁자들이 더 공격적으로(하한 가까이) 넣는다. **N 과 g 를 따로 추정해 곱하면 이 상관을 잃는다.** → 결합으로 모형화하거나, **점과정(point process)** 으로 한 번에: 경쟁자 입찰을 x 축 위의 **비동차 포아송 과정** `λ(x|Z)` 로 보면 N 은 `∫λ` 로 자동으로 나오고 상관이 보존된다. **권고: M1 의 (N, X) 2분해를 `λ(x|Z)` 1개로 바꿔라.** 파라미터가 줄고 상관이 살고, §4 의 낙찰확률 공식에 그대로 들어간다.

## 4. 🔴 `13배` 논증 — 단위는 맞다. **결론이 틀렸다.**

### 4-1. 단위는 같다 (이건 통과)

```
x = 투찰금액 / (기초가 × h),  h = 하한율/100
R = 예정가 / 기초가

낙찰 조건: 투찰금액 ≥ 예정가 × h
        ⟺ x·기초가·h ≥ R·기초가·h
        ⟺ x ≥ R                      ✅ 무차원, 직접 비교 가능
```

**따라서 `sd(R)=0.781%` 와 `창문 0.058%` 를 같은 자에 놓는 것 자체는 정당하다.** 비율 13.5배도 맞게 계산됐다.

**그리고 내부 정합성도 통과한다:**
```
f_R 최빈값 = 1/(0.00781·√2π) = 51.1
폭 0.058% 짜리 영역의 R 확률질량 = 51.1 × 0.00058 = 2.96%
관측 낙찰률 1.9%                                    ← 같은 자릿수. 앞뒤가 맞는다
```

### 4-2. 그런데 `13배` 에서 `"위치 조절 몫이 작다"` 는 안 나온다

**낙찰확률의 정확한 형태를 쓰면 왜인지 즉시 보인다.**

내가 x 에 넣고, 나보다 **아래에 있는 가장 가까운 경쟁자**를 `m(x) = max{x_j : x_j < x}` 라 하자.
낙찰 조건 "x ≥ R 이고 [R, x) 에 경쟁자 없음" 은 다음과 동치다:

```
낙찰  ⟺  R ∈ ( m(x), x ]
```

> **내 낙찰확률 = 내 아래 이웃과 나 사이 구간에 R 이 떨어질 확률.**
> **낙찰확률 = 내가 차지한 영토의 f_R 질량.**

즉시 따라오는 것들:

- **모두의 낙찰확률 합 = F_R(x_max) ≈ 1.** 영토는 분할이다. **제로섬이다.**
- 경쟁자가 밀도 `g` 로 흩어져 있고 N 명이면 내 아래 이웃까지 평균 간격 ≈ `1/(N·g(x))`. 따라서

```
        ┌─────────────────────────────┐
        │   P(낙찰 | x)  ≈  f_R(x)    │
        │                ─────────    │
        │                 N · g(x)    │
        └─────────────────────────────┘
```

(정합성: `∫ g·f_R/(N g) dx · N = ∫f_R = 1` ✅)

**이 공식이 말하는 것:**

| 조건 | 결과 |
|---|---|
| `g(x) ∝ f_R(x)` (경쟁자들이 이미 R 분포 모양대로 퍼져 있음) | **P(낙찰) = 1/N 이 모든 x 에서 같다. 위치가 진짜로 무의미하다** |
| `g` 가 `f_R` 보다 **뾰족**하다 (하한 근처에 뭉침) | **뭉침 밖 자리가 배로 유리하다** |
| `g` 가 `f_R` 보다 **평평**하다 | 중앙이 유리 |

> **`13배` 는 `sd(R)` 하나만 보고 `g` 를 안 봤다.**
> **진짜 질문은 "커트라인이 얼마나 흔들리나" 가 아니라 "`f_R(x)/g(x)` 가 평평한가" 다.**

**수치로 확인 (내가 시뮬레이션):** R ~ N(1, 0.0078), 경쟁자 30명이 N(1, 0.004) 로 뭉쳤을 때

| x | 낙찰확률(시뮬) | `f_R/(N g)` |
|---|---|---|
| 0.9940 | **5.75%** | 3.92% |
| 0.9980 | 1.82% | 1.87% |
| **1.0000** (뭉침 한가운데) | **1.69%** | 1.71% |
| 1.0020 | 1.76% | 1.87% |
| 1.0060 | 3.17% | 3.92% |
| **1.0100** | **7.21%** | 17.1% |

**같은 회차 안에서 위치만 바꿔 낙찰확률이 1.69% → 7.21%, 4.3배.** 그리고 x 가 높으면 **투찰금액도 크다 = 마진도 크다.** 이 설정에서 위치는 결정적이다.

⚠ **이건 예시지 우리 판이 아니다.** 경쟁자가 `sd 0.004` 로 뭉쳐 있다는 건 내가 넣은 가정이다. **근사식은 뭉침 중심 ±1σ 안에서 잘 맞고 꼬리에서 깨진다**(위 표 마지막 줄: 7.2% vs 17.1%). 꼬리에선 "내 아래에 아무도 없음" 항이 지배해서 포아송 간격 근사가 무너진다. **실제 계산은 근사식이 아니라 §4-4 의 정확 replay 로 한다.**

### 4-3. **하루짜리 실험이 이 프로젝트 전체를 판정한다**

```
1. f_R(x)  ← §2 에서 회차별로 확정 (해석 or 경험)
2. g(x)    ← 1,058만 투찰의 x 히스토그램. 회차 정규화 후 커널/히스토그램
3. 비 f_R(x)/g(x) 를 그린다.  평평한가?
```

- **평평하다** → **`13배` 결론이 옳다. 시장이 균형에 가깝고, 위치로 얻을 게 없다.**
  **그러면 우리 제품의 축은 커버리지·티켓 배치로 확정되고, M1·M2·M4·M5 를 다 접어도 된다.**
  → **연구비 대부분이 절약된다. 이게 이 실험의 가장 큰 값어치다.**
- **평평하지 않다** → **위치에 돈이 있다.** 그 편차의 크기가 곧 상한이고,
  Scarsini–Solan–Vieille 의 *"some bidders win the auctions quite often"* 이 우리 판에서도 참이라는 뜻이다.

**요약 통계 하나로 축약:** `f_R/g` 의 (투찰 밀도 가중) **변동계수**, 그리고 `max_x (f_R/g) ÷ 중앙값`. 이 숫자 하나가 **"위치 레버의 크기"** 다. `13배` 를 이걸로 교체할 것을 권고한다.

**⚠ g 추정의 실무 함정 — 반드시 처리해야 한다:**
- **뭉침(heaping).** 투찰액은 원 단위 반올림·소프트웨어 기본값·심리적 라운드에 몰린다. 그러면 g 는 **연속밀도가 아니라 이산 원자 + 연속** 혼합이다. **원자 위에 정확히 겹치면 낙찰이 아니라 동점 처리 규칙이 걸린다.** 커널로 뭉개면 이 구조가 지워진다.
  → **격자(grid) 위 이산 확률질량으로 g 를 추정하라.** 커널 밀도로 시작하지 마라. (문헌: NBER "Round Bidding in Auctions" <https://www.nber.org/system/files/working_papers/w34564/w34564.pdf> — 초록만 봄)
- **x 의 정의가 회차마다 하한율에 의존**한다. 하한율이 다른 회차를 같은 축에 겹치기 전에 하한율 층을 갈라 확인할 것.

### 4-4. E1·E3 의 "상한" 은 지금 정의로는 계산되지 않는다

설계문서 §2-1 은 상한을 *"R 을 못 맞추니 낮다"* 는 논리로 서술한다. 상한은 셋으로 갈라야 한다:

| | 무엇을 안다고 가정 | 계산법 | 의미 |
|---|---|---|---|
| **C1 신탁(oracle)** | R 도 경쟁자도 다 안다 | replay: 이길 수 있으면 이긴다 | ≈100%. **쓸모없는 상한** |
| **C2 경쟁자 신탁** | **경쟁자 입찰은 알고 R 은 분포만** | replay: `max_x ∫_{m(x)}^{x} f_R` | **🔴 이게 진짜 상한이다.** 모형이 아무리 좋아도 못 넘는다 |
| **C3 실현 가능** | 투찰 시점 특징만 | 모형 | C2 대비 몇 %인가 |

**C2 는 모형 없이 계산된다.** 회차마다 관측된 경쟁자 x 들을 정렬 → 인접 간격마다 `F_R(위)−F_R(아래)` → 최대. 233k 회차 전부에 대해 몇 분이면 끝난다.

> **권고 — 순서를 바꿔라.**
> 방법론 계획 §4 의 순서는 `누출검사 → R분포 → M3 → M1 → M4 → M2 → M6 → M5` 다.
> **`R분포`(=§2 T1~T6) 다음에 `C2 replay` 를 넣어라.** 모형을 하나도 안 만들고, 재료 순위표를 안 만들고,
> **"이 판에 위치로 딸 수 있는 몫이 얼마인가" 를 확정한다.**
> C2 가 실제 낙찰률과 거의 같으면 → **M1~M5 를 전부 안 만들어도 된다.** 그게 결과다.

## 5. 나머지 지적

### 5-1. **R 이 관측되는 게 실제로 얼마나 큰 이점인가 — 크다. 그런데 우리가 생각한 이유는 아니다.**

우리 계획은 *"R 분포를 경험적으로 추정할 수 있다"* 를 이점으로 든다. **그건 작은 이점이다** — R 분포는 메커니즘에서 **해석적으로 나온다**(§2-1). 표본이 없어도 안다.

**진짜 이점은 셋이고, 우리 문서에 안 적혀 있다:**

1. **메커니즘 검정.** 우리가 규칙을 제대로 아는지 검정할 수 있다. **그리고 §2 에서 이미 안 맞는다.** 관측이 없으면 이 불일치를 영원히 못 봤을 것이고, 잘못된 f_R 위에 모든 모형을 세웠을 것이다.
2. **회차별 f_R.** 규칙이 회차마다 다르면(§2-3), 풀링 f_R 은 틀리다. **`ds_pList` 가 있으면 회차별로 정확한 f_R 을 쓸 수 있다.** §4 의 공식에 그대로 들어간다. 이게 가장 큰 실무적 이점이다.
3. **replay 가 정확해진다.** `x' > R` 인지 계산하려면 R 이 필요하다. R 을 관측하므로 **반사실이 추정이 아니라 계산이다.** → §5-5

**⚠ 그리고 한 가지 나쁜 소식:** `CHC_YN` 이 있다는 건 **입찰자가 R 생성에 참여한다**는 뜻이다. 그러면 **내 참여가 R 을 바꾼다.** replay 의 "R 고정" 가정이 엄밀히는 깨진다. → §5-5.

### 5-2. 정보집합 동등성(설계문서 §3) — **옳다. 그런데 as-of 절단만으로는 안 끝난다.**

`BID_END_DT` 기준 절단은 정확한 판단이고 **`OPNG_DT` 가 아니라는 지적은 특히 좋다.** 추가로 잡아야 할 셋:

| 누출 경로 | 왜 as-of 로 안 잡히나 |
|---|---|
| **정규화·전처리에 미래가 섞임** | 특징 표준화·구간화·인코딩의 통계량을 **전체 기간**에서 내면, as-of 를 지켜도 미래가 샌다. **모든 전처리 파라미터를 학습기간에서만.** |
| **학교/업체 식별자 자체** | 학교 ID 를 카테고리로 넣으면 모형이 **그 학교의 미래 평균**을 외운다(타깃 인코딩이 아니어도 트리는 한다). 시간분할이 있어도 학습기간 안에서 새어 평가기간 성능을 부풀린다. → **out-of-fold 타깃 인코딩 필수** |
| **동시 개찰 회차 간 의존** | 같은 날 같은 학교의 여러 품목 회차는 R 추첨·참여자가 공유될 수 있다. **분할 경계를 회차가 아니라 날짜(또는 학교×날짜)로 잘라라.** |

### 5-3. **검정력 — 무엇이 되고 무엇이 안 되나 (수치)**

⚠ 먼저: **낙찰률 1.9% 는 모집단 축에서 아무 문제가 아니다.** King–Zeng 기준으로 사건 수 약 20만은 "golden" 이다. 설계문서 §6 의 *"1.9% 에서 AUC 의 실무 의미가 얇다"* 는 **실무 해석의 문제로는 맞고, 통계적 가능성의 문제로는 틀렸다.**

**개인 축은 진짜 문제다.** 독립 두 팔 비교(α=0.05, power=0.80, 기저 1.9%):

| 검출하려는 상대 개선 | 팔당 필요 투찰 | 팔당 낙찰 |
|---|---|---|
| +10% | 85,000 | 1,615 |
| +20% | 22,200 | 423 |
| +30% | 10,300 | 196 |
| +50% | 4,000 | 77 |
| +100% | 1,200 | 23 |

> **투찰 2,000 · 낙찰 38 인 업체에서 80% 검정력으로 검출 가능한 최소 개선 = 상대 +74%.**
> **낙찰이 1.7배가 되지 않으면 개인 축에서는 안 보인다.**
> 설계문서 §4 의 *"낙찰 75건이 개인 축의 상한"* 판단은 **옳다. 이 표를 그 문서 옆에 붙여 둘 것을 권고한다.**

**그런데 짝지은(paired) 설계면 완전히 달라진다.** replay 는 **같은 회차에서** 두 정책을 비교할 수 있으므로 McNemar 로 간다 — 회차 수준 잡음이 상쇄된다:

| 두 정책이 결과가 갈리는 회차 비율 | 갈릴 때 새 정책이 이기는 비율 | 필요 회차 |
|---|---|---|
| 3% | 60% | 6,500 |
| 3% | 55% | 26,000 |
| 5% | 65% | 1,700 |

**→ 개인 축 2,000 투찰로도 짝지은 replay 면 "갈림 5% · 우세 65%" 급 효과는 검출된다.**
**독립 비교로 설계하면 못 하고, 짝지어 설계하면 된다. 이건 순전히 설계 선택이다.**

**⚠ 그리고 반드시: 회차 수준 군집(cluster) 표준오차.** 한 회차의 투찰들은 **R 을 공유**해서 독립이 아니다. 투찰 단위로 신뢰구간을 내면 **폭이 크게 과소평가된다.** 우리 계획 어디에도 군집 얘기가 없다. **모든 신뢰구간은 회차(또는 학교×날짜) 블록 부트스트랩으로.**

**⚠ 다중검정.** E6 의 축 후보가 11개다. 각각 "분포가 갈리나"를 α=0.05 로 검정하면 **다 무효여도 하나 이상 유의할 확률이 43%** 다. **BH(FDR) 통제 또는 사전 등록된 축 목록 중 하나.**

### 5-4. E5(커버리지 재배분) — **replay 로 평가할 수 없다.** 우리 계획이 이걸 E4 와 같은 급으로 놓았다.

| | 반사실 | replay 유효성 |
|---|---|---|
| **E4 위치** | 같은 회차, 다른 x | ✅ **거의 정확** (경쟁자·R 고정 가정만) |
| **E5 커버리지** | **안 들어간 회차에 들어감** | ❌ **약함** |

E5 가 왜 다른가:
1. **내가 들어가면 N 이 +1 된다.** 그 회차의 모든 사람의 낙찰확률이 바뀐다(제로섬).
2. **내가 들어가면 예비가격 번호 2개를 뽑는다. R 의 추첨이 바뀐다.** 참여자가 적은 회차일수록 **내 2표가 최다득표 4개를 실제로 옮긴다.** (참여 5명이면 총 10표로 4개를 정한다 — 내 2표는 20%다.)
3. **선택편의.** 내가 안 들어간 회차는 무작위 표본이 아니다. 안 들어간 이유(거리·품목·납품능력)가 결과와 상관된다. **이게 Athey–Levin–Seira 의 내생적 참여 문제 그대로다.**

**권고:**
- E5 를 **"평가"가 아니라 "탐색"** 으로 격하하고, 결과에 **위 셋을 한계로 명시**한다.
- N+1 효과는 **보정 가능하다** — 관측된 N 명의 위치를 그대로 두고 나를 하나 더 넣어 재계산하면 된다. **하되, 다른 사람들이 반응하지 않는다는 가정은 여전히 남는다.**
- **참여자 수가 적은 회차에서는 R 추첨 효과를 반드시 계산해 넣어라.** T3~T5 의 결과가 있으면 계산할 수 있다.

### 5-5. VoI 를 과거 로그로 평가 — **OPE 가 아니다. 우리는 그것보다 좋은 자리에 있다.**

**OPE 문헌의 표준 가정(positivity/overlap)이 우리에겐 필요 없다.** 이유:

OPE 가 어려운 건 **"고르지 않은 행동의 보상을 모르기" 때문**이다. 문헌 그대로:
> *"OPE is difficult with a deterministic logging policy, since its log data contain no information about the reward from actions never chosen."*

**우리는 안다.** 낙찰 함수가 **알려져 있고 결정론적**이다:
```
won(x) = 1{ x ≥ R }  ·  1{ ¬∃j : R ≤ xⱼ < x }
```
`R` 과 `{xⱼ}` 를 다 관측하므로, **아버지가 넣지 않은 x' 의 결과도 정확히 계산된다.** 중요도 가중도, 성향점수도, 겹침 가정도 없다. **이건 OPE 가 아니라 replay 다** (광고 경매 문헌의 용어). 우리 계획 M6 을 "off-policy evaluation" 으로 부르면 **없는 문제를 풀게 된다.**

**대신 필요한 가정은 정확히 셋이고, 셋 다 이름을 붙여 문서에 박아야 한다:**

| | 가정 | 강도 | 검정 |
|---|---|---|---|
| **P1** | 내 x 변경이 **경쟁자 x_j 를 안 바꾼다** | 1회차·1업체면 강함. **엔터프라이즈면 깨진다**(§3-2) | 직접 검정 불가. 채택률로 관리 |
| **P2** | 내 x 변경이 **R 을 안 바꾼다** | ⚠ **엄밀히는 거짓.** 내 예비가격 번호 2표가 R 에 들어간다. 참여자 많으면 무시 가능, 적으면 아니다 | ✅ T3~T5 + 참여자 수별로 크기 계산 가능 |
| **P3** | 내 x 변경이 **참여 집합을 안 바꾼다** | E4(위치)면 참 · **E5(커버리지)면 거짓** | §5-4 |

**그리고 문헌 문장을 그대로 §8 에 넣을 것:**
> *"Replay evaluation holds the opportunity set, bids, and bidder participation fixed, which is useful for offline screening but **is not a live causal effect.**"*

**VoI 계산 구조도 명시해야 한다.** 설계문서 §6 의 "한계 VoI" 서술에 **max 가 어디 있는지**가 없다. EVPPI 정의를 그대로:
```
VoI(재료 S)  =  E_S [ max_x  E[ 보상 | S, 기존재료 ] ]  −  max_x E[ 보상 | 기존재료 ]
                     └ 안쪽 max: S 를 보고 행동을 다시 고른다
```
**안쪽 max 가 없으면 그건 VoI 가 아니라 그냥 설명력이다.** 그리고 **VoI ≥ 0 이 항상 성립**한다(정의상) — 추정치가 음수면 그건 추정오차지 발견이 아니다. **음수 VoI 를 "그 재료는 해롭다"로 읽지 않도록 문서에 못 박아라.**

### 5-6. 안 쓰기로 한 방법 — **넷 중 둘은 판단이 맞고, 둘은 틀렸다**

| | 우리 판단 | 내 판정 |
|---|---|---|
| **시계열(ARIMA)** | *"회차는 시계열이 아니다"* | **부분적으로 틀렸다.** 개별 회차의 가격은 시계열이 아니다. 맞다. 그런데 **`g_t(x)`(경쟁자 밀도)와 `N_t`(참여 규모)는 시계열이다** — 학기·방학, 업체 진입·퇴출, 제도 변경. §4 의 공식이 `g` 에 통째로 의존하므로 **`g` 의 시간 드리프트는 1급 문제다.** ARIMA 를 쓰라는 게 아니라, **as-of 특징에 최근성 가중(exponential decay)을 넣고 드리프트를 명시적으로 재라.** 시간분할 평가에서 성능이 뒤로 갈수록 떨어지면 그게 드리프트다 |
| **협업 필터링** | *"희소하고, 질문이 추천이 아니다"* | **결론은 맞고 이유가 틀렸다.** 우리 질문은 추천이 아니다 — 맞다. **그러나 업체×학교 행렬의 저계수 구조는 "이 회차에 누가 나타날까" 를 예측한다.** 그게 `N` 과 `g` 의 조성이다. **행렬분해를 "추천"이 아니라 "참여 예측"으로 쓰면 M1 의 입력이 된다.** → §6-3 |
| **강화학습** | *"환경과 상호작용 불가, 탐색 불가"* | **지금은 맞다.** 다만 **미래엔 열린다** — 아버지의 투찰에 **작은 무작위 교란을 의도적으로 넣으면**(±0.02% 급) 탐색 로그가 쌓인다. 문헌: *logging policy design*. **비용이 낮고 정보 이득이 크다.** 다만 replay 로 이미 정확 계산이 되므로(§5-5) **탐색이 필요한 건 P1(경쟁자 반응)뿐이다.** 그건 탐색으로도 못 배운다(내 한 명의 교란으론 남이 안 움직인다). → **결론: RL 은 닫아 두는 게 맞다. 이유를 "탐색 불가"가 아니라 "replay 로 이미 정확하다"로 바꿔라.** 더 강한 이유다 |
| **딥러닝 표현학습** | *"인자가 구조화돼 있다"* | **맞다.** 다만 **품목명(`PDLC_NM`) 자유텍스트**가 있다면 거기엔 표현학습 여지가 있다. 설계문서 §1 이 `PDLC_NM` 커버리지 79.6% 를 문제로 든다 — **텍스트 임베딩이 그 21%를 메우는 도구가 될 수 있다.** 분류가 아니라 **결측 보완** 용도로만 |

### 5-7. M5(신경망) 게이트 — **조건 2 가 검정 불가능하다**

여는 조건 셋 중 **"M4 의 상호작용 진단에서 고차 상호작용이 검출된다"** 는 **잘 정의된 검정이 아니다.** H-statistic 은 임계값이 없고 표본에 민감하다. 그리고 실무적으로 **NN 을 한 번 돌리는 비용이 이 진단을 제대로 하는 비용보다 싸다.**

**권고:** 조건 2 를 빼고 **조건 1(M4 가 B1 을 이긴다) + 조건 3(M1–M4 격차가 설명 안 된다)** 만 남겨라. 게이트가 단순해지고 검정 가능해진다. 예산 동일 배정 규율(§2-M5 마지막)은 **매우 좋다 — 유지.**

# 제3부 · 우리가 놓친 것

## 6-1. 🔴 `f_R/(N·g)` 진단 — **§4. 가장 먼저 할 일.**

재론 안 한다. **하루. 모형 0개. 프로젝트 전체를 판정.**

## 6-2. 🔴 C2(경쟁자 신탁) replay 를 상한으로 — **§4-4. 두 번째.**

**모형 없이 계산되는 진짜 상한.** E3 을 이걸로 재정의할 것.

## 6-3. 점과정(point process)으로 경쟁자를 모형화

M1 의 `(N 분포) × (위치 분포)` 2분해 대신 **비동차 포아송 강도 `λ(x | Z)` 하나.** 이유: §3-3.
- N 과 위치의 상관이 자동 보존
- §4 공식에 그대로 들어간다: `P(낙찰|x) = E_R[ exp(−∫_R^x λ) · 1{x≥R} ]` — **이게 근사가 아니라 포아송 하에서 정확식이다**
- 파라미터가 준다 → 표본 효율이 는다 (우리 계획 §1 의 주장이 여기서 진짜로 실현된다)
- **이산 뭉침**은 `λ` 위에 원자를 얹어 처리(§4-3)

## 6-4. **CQR (conformalized quantile regression)** 로 M2 를 교체

핀볼 손실만으로는 커버리지 보장이 없다. CQR 은 몇 줄 추가로 유한표본 주변 커버리지를 준다.
**화면에 구간을 놓겠다는 판정 기준(설계문서 §6)이 이 도구를 요구한다.** 시간 이동 때문에 보장이 완전하진 않으니 **평가기간 실측 커버리지를 함께 보고.**

## 6-5. **경험적 베이즈 축소 먼저, 계층 모형은 나중에**

M3 을 MCMC 로 시작하지 마라. Efron–Morris 닫힌형이 몇 초에 돌고 `τ²` 하나로 축소량이 해석된다.
**그리고 축소 대상을 먼저 정하라** — 낙찰 x 중앙값 / 낙찰확률 / 경쟁자 수. **셋의 계층이 다르다.**

## 6-6. **투찰 격자 위 이산선택 모형** — g 를 "예측"이 아니라 "설명"하려면

경쟁자들이 왜 거기 넣는지 모르면 `g` 의 드리프트를 못 잡는다.
투찰을 **격자 위 선택**으로 놓고 조건부 로짓을 걸면 "하한 근처 선호 · 라운드 선호 · 학교별 관행" 이 계수로 나온다.
**→ `g` 의 구조적 예측기가 되고, 그게 §4 공식의 유일한 미지수다.**

## 6-7. **군집 부트스트랩 · FDR 통제** — §5-3. 인프라 항목.

**모든 신뢰구간을 회차 블록 부트스트랩으로.** E6 의 11개 축에 BH 절차.
**지금 계획대로 가면 나중에 전부 다시 계산해야 한다.**

## 6-8. **담합·들러리 오염을 §8 한계 목록에 추가**

문헌·언론이 보고하는 것: eaT 준수점검 대상 2,568곳 중 **813곳(31.6%)이 불공정행위 적발**(국회 제출 aT 자료, 5년간). 지역 단위 담합·유령업체 사례 다수.

**우리 분석에 직접 닿는다:**
- `g` 의 일부가 **들러리 입찰**이면 그건 경쟁이 아니라 **의도적으로 닫힌 간격**이다. §4 의 "빈 자리를 찾아라" 가 그 지역에서 통하지 않는다
- P1(무반응) 가정이 담합 지역에서 더 약하다 — 담합자들은 반응한다
- 설계문서 §8-4 의 **낙찰자 철회 6.5%** 와 얽힌다. 철회가 담합 신호일 수 있다
- Decarolis (2011): **문턱형 낙찰제는 담합 유인을 특별히 키운다** — 우리 판이 그 형식이다

**권고:** §8 에 항목 추가. 그리고 **지역×품목별 g 의 이상 뭉침**을 진단으로 내면 (a) 담합 탐지이자 (b) "여기선 위치 전략이 안 통한다" 는 실무 경고가 된다. **제품 기능이 될 수도 있다.**

## 6-9. 향후 로깅 설계 — **작은 무작위 교란**

지금은 필요 없다(replay 가 정확하니까). 그러나 **P1(경쟁자 반응)을 언젠가 재려면** 교란 로그가 유일한 길이다.
**비용이 거의 0 이므로 지금부터 넣어 두라**는 게 문헌의 조언(logging policy design). ±0.02% 급이면 기대손실이 무시할 수준이다.

# 7. 우선순위 — 우리 계획 §4 순서에 대한 반대 제안

```
현재 계획:  누출검사 → R분포 → M3 → M1 → M4 → M2 → M6 → M5

제안:      0. 누출검사                                    (그대로 — 옳다)
           1. T1~T6  회차별 메커니즘 추정 · 해석해 대조     (§2. 이미 안 맞는다)
           2. f_R/g 진단                                  (§4-3. 하루. 모형 0개)
           3. C2 replay 상한                              (§4-4. 모형 0개)
           ─────── 여기서 프로젝트가 갈린다 ───────
           2·3 이 "레버 없음" 이면 → M1·M2·M4·M5 를 전부 접고
                                    커버리지·티켓 배치로 간다 (E5·E6)
           레버가 있으면 →  4. λ(x|Z) 점과정  (M1 재정의)
                            5. M4 대조 · VoI(EVPPI)
                            6. CQR (M2)
                            7. 경험적 베이즈 축소 (M3 — 결과와 무관하게 화면에 쓰이므로 병렬 가능)
                            8. M5 (게이트 2개 충족 시)
```

**바뀌는 것 하나:** M3 이 3번에서 7번으로 갔다.
설계문서는 M3 을 *"결과와 무관하게 화면에 쓰인다"* 는 이유로 앞에 뒀는데, **맞는 말이지만 앞에 둘 이유는 아니다.** M3 은 다른 실험의 눈금이 아니고, 병렬로 돌려도 된다. **1~3 이 진짜 관문이다.**

# 9. 이 문서가 확신하지 못하는 것

1. **eaT 가 나라장터와 같은 복수예가 규칙을 쓰는지 확인하지 못했다.** eaT 전용 규정 문서를 못 찾았다. **§2 전체가 이 확인에 달려 있다.** `ds_pList` 실물이 유일한 답이다
2. **Decarolis(2018) 원문을 못 읽었다** (500/403). 인용한 수치(36.67% vs 13.75%)는 **검색 요약 출처**다. 우리 문서에 쓸 거면 원문 확인 필요
3. **엄상훈·조인휘(2022)의 MAE 1% 가 무엇 대비 %인지** 초록만으론 확정 못 한다. "상수 예측기보다 나쁘다"는 내 주장은 **그 해석에 의존**한다. 원문 확인 전엔 단정하지 말 것
4. **`창문 폭 0.058%` 가 어떻게 계산된 값인지 모른다.** 나는 "인접 투찰 간 평균 간격"으로 해석했고 그 해석에서 낙찰률 1.9% 와 앞뒤가 맞았다(§4-1). **다른 정의였다면 §4-1 의 정합성 확인은 무효다**
5. **`f_R/(N·g)` 는 내가 유도했고 문헌 출처가 없다.** 도출이 짧아서 논문거리가 아닐 뿐이라고 보지만, **어딘가 이미 있을 가능성**을 배제 못 한다
6. **선행 결론의 `sd 0.00781` 이 어떤 표본에서 어떻게 계산됐는지 모른다.** §2-2 의 불일치가 메커니즘 때문인지 표본 정의 때문인지 못 가른다 — **T1~T6 이 그걸 가른다**

**2차 개정에서 추가된 것:**

7. **`ds_pList` 의 seq 가 화면 번호인지 저장 정렬인지 모른다.** §0-A 전체가 여기 달렸고, **§0-A 의 시뮬레이션 결론은 이 확인 전에는 가설이다.** 확정 전에 "투표가 큰 레버다" 를 제품 판단으로 쓰지 마라
8. **동수 tie-break 가 "낮은 번호 우선"인지 "재추첨"인지 규정으로 확인 못 했다.** §0-A 의 mean 편향 시뮬은 전자를 가정했다. 후자면 편향이 없고 **§0-A 의 mean 진단이 통째로 무효**다
9. **`BID_CNT` 의 마감 전 관측이 "우리가 투찰하는 시점"에도 유효한지 모른다.** 스냅샷 타임스탬프가 없으면 as-of 특징으로 못 쓴다 (§0-B-3)
10. **`R` 재구성 대조의 불일치분(99.31% 에서 0.69%, 철회 제외 시 12.36%)이 무엇인지 모른다.** 규칙 예외가 거기 있을 수 있다
11. **조달청·aT 의 예비가격 추첨 규정 원문(법령·예규 급)을 끝내 못 찾았다.** 2차 출처와 데이터 관측만으로 서술했다

**3차(§0-F)에서 추가된 것:**

12. **§0-F 의 모든 수치는 시뮬레이션이지 우리 데이터가 아니다.** 경쟁자 `x ~ N(1.000, 0.004)` 는 **내가 넣은 가정**이다. 실제 `g` 로 다시 돌려야 크기가 확정된다 — **방향과 메커니즘은 견고하고, 배수는 아니다**
13. **"경쟁자 전략투표" 모형은 근시안적 최적대응이지 균형이 아니다.** 균형에서는 붕괴를 예상해 섞을 것이다. **균형 해는 안 풀었고 문헌에도 없다.** §0-F-3 의 주장은 "붕괴 방향이 있다"까지다
14. **`sd(R)` 붕괴 예측(0.0077 → 0.0021)은 반사실이다.** 관측된 적이 없다. **다만 "지금은 비전략 쪽에 붙어 있다"는 관측은 실측이다**
15. **동수 tie-break 규칙이 §0-A 의 mean 진단과 §0-F-5 의 반사실 재생 **둘 다**의 전제다.** 지금 이 문서에서 가장 큰 단일 미확인 사항이다
