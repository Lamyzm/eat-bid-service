# 목표 재설정 — **보정이 아니라 사람과의 대결**

> **2026-09-02 · 사장 지시 · team-lead 기록**
> **이 문서가 이전 평가 틀을 대체한다.** `2026-09-01-material-value-design.md` 의 VoI·문턱 계열은 아래 3번의 특수한 경우로 내려간다.

## 0. 무엇이 바뀌나

| | 지금까지 | 🔴 새 목표 |
|---|---|---|
| 재는 것 | 예측 승률 vs 관측 승률의 오차 `%p` | **같은 회차에서 모델이 그 사람보다 이겼나** |
| 답 | `+9.46 %p` 미보정 | *"이 사람 대신 우리가 넣었으면 몇 번 더 이겼나"* |
| 사용자에게 뜻 | 없다 | 그대로 뜻이 된다 |

> **⟹ 오늘 하루 판 잔차는 부차적이 된다. 보정이 완벽하지 않아도 *그 사람보다 자주 이기면* 값을 한다.**

## 1. 순서

```
0. 가진 걸로 먼저     raw 233,552 재파싱.  **네트워크 0**       ← 진행 중
1. 전국 수집          빈 지역·기간을 채운다
2. 표본 추출          각 지역에서 투찰자를 **무작위로 많이**
3. 🔴 1차 질문        우리 모델이 **그 사람보다 잘 낙찰하는가**
4.    2차 질문        그 범위를 **사용자한테 줄 수 있는가**
```

## 2. 🔴 왜 이게 정확히 계산되나 — 가정이 필요 없다

**밀봉 입찰이라 다른 사람 투찰이 고정이다. 우리가 다르게 넣어도 남들은 안 바뀐다.**

```
모델 낙찰  ⟺  x_model ≥ R   AND   대체한 사람을 뺀 나머지 중 [R, x_model) 에 아무도 없다
```
**⟹ 반사실이 *추정*이 아니라 *산술*이다.** `f_R` 도 `F_X` 도 필요 없다 — 실현된 `R` 과 실현된 경쟁자 벡터를 그대로 쓴다.
⚠ **`R` 은 실현값을 쓴다. 예측 시점엔 모르지만 *채점*에는 써도 된다** — 사람도 우리도 같은 `R` 을 마주했다.

## 3. ⚠ 설계 결정 둘

### 3-1. 어디까지 겨루나 — **`L1` 부터**

```
L1  위치만      그 사람이 들어간 회차 그대로, 금액만 우리가 정한다
L2  선택+위치   어느 회차에 들어갈지도 우리가 정한다 (연간 투찰 수는 동일하게 묶는다)
```
**⟹ `L1` 이 먼저다. 깨끗하게 분리되고, `L2` 는 `L1` 이 이긴 뒤에 의미가 생긴다.**
⚠ **`L2` 는 예산 제약이 필수다.** 무제한으로 넣게 하면 이기는 게 당연해서 비교가 무너진다.

### 3-2. 🔴 표본을 **"낙찰자"로 뽑으면 안 된다**

```
낙찰자만 뽑으면  →  이미 이긴 사람들과만 겨룬다  →  **결과에 조건 건 표본**
                    (007 collider · 낙찰자 철회 탈락과 같은 구조)
```
**⟹ *투찰자*를 뽑고 그 사람의 회차 전부를 본다. 낙찰 여부는 그 뒤 층으로 가른다.**
⚠ **지역별로 층화한다** — 지역마다 경쟁도가 다르고, 우리 코퍼스가 지역 편향돼 있다.

## 4. ⚠ 미리 정해야 할 것 — 결과 보기 전에

```
🔴 승패 기준     "더 많이 낙찰" 하나인가, "낙찰 × 마진" 인가
                 (원가 대리값이 없으므로 지금은 낙찰 수. 그 한계를 명시한다)
🔴 반증          모델이 사람과 **같거나 못하면** 그렇게 보고한다.  기준을 먼저 적는다
🔴 표본 크기      한 사람당 회차 수가 적으면 판정이 안 선다 —
                 아버지 187투찰 6낙찰에서 P(X≥6|무작위)=0.1425 로 아무것도 못 말한 게 그 사례다
```

## 5. ✅ 사용자 니즈 ≠ 사실 — 규율로 올린다

> 사장: *"학교별 낙찰률 추이 같은 건 우리가 의미없다 생각하지만 사용자는 보고 싶어하는 경우가 많다. 사용자 니즈랑 사실이 다른 거지."*

> 🔴 **규율(32): 분석적 가치가 낮다는 판단으로 사용자가 보는 재료를 화면에서 내리지 않는다.**
> **판단 재료의 값은 우리 통계가 아니라 사용자의 결정 시간으로 잰다.**
> **⟹ 우리가 할 일은 "치우는 것"이 아니라 *"옆에 사실을 같이 놓는 것"* 이다.**

⚠ **team-lead 가 오늘 그 반대로 굴었다** — `VoI(Q5)=0` 을 근거로 화면 항목을 내리려 했다. **VoI 는 *우리 모형의* 정보가치이지 *사용자의* 판단 재료 가치가 아니다.**
