## 2. 그가 서는 자리는 **고경쟁**이다

```
참여 회차 N:  중앙 **51** · 평균 59.8
전국:         중앙 15 · 평균 45.4
회차당 본인 투찰 k:  중앙 2 · 평균 1.90     ← 한 회차에 여러 건 넣는다
```
**⟹ 제품 함의: 우리가 판 저`N` 잔차(`+9.46 %p`)는 그가 서지 않는 자리다. `N≥30` 은 잔차 `~0.2 %p` 로 이미 잘 맞는다.**

## 3. 🔴 실력 — **무작위와 구분되지 않는다.** 그리고 크기까지 나온다

**기준선을 회차마다 정확히 계산한다** (`1/평균N` 으로 어림하지 않는다):
```
E[낙찰] = Σᵢ kᵢ/Nᵢ        kᵢ = 회차 i 에서 본인 투찰 수, Nᵢ = 그 회차 총 투찰
```

| | |
|---|---|
| 기대 | **73.26** |
| 실제 | **75** |
| sd | 8.39 |
| **z** | **+0.21** |
| 양측 `p` | **0.836** |
| 배수 | 1.024 |
| 기대 95% 범위 | **[57, 90]** — 실제 75 는 한가운데 |

> 🔴 **"모른다"가 아니라 "무작위와 구분되지 않는다"이고, 효과가 있더라도 무작위 대비 `±25%` 안이다.**
