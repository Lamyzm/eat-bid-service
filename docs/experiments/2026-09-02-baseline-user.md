```

## 🔴 3-2. 그리고 이게 "천장 0" 을 뜻하지 않는다 — 팀리드 틀 정정

**팀리드가 세운 이분법:**
```

```
🔴 **`data-inventory` 정정 — 세 번째 갈래가 있고 그게 가장 유리하다:**
```

재지 않는 것         "신호가 존재하나"              → 부록 F 가 잰다

부록 F:  같은 격자에서 최적 x 와 최악 x 의 낙찰률 비가 **399배**

⟹ "아무도 못 이긴다" 는 천장이 0 이 아니라 **바닥이 비어 있다**는 뜻이다
```
**⟹ 제품 근거는 "누가 하고 있다"가 아니라 *"부록 F 의 399배가 진짜인가"* 에 걸린다.**

## 🔴 3-4. 팀리드 직접 확인 — **`399배` 가 자료에서 재현되지 않는다**

**제품 근거로 계속 인용되던 *"최적 `x` 와 최악 `x` 의 낙찰률 비 399배"* 를 팀리드가 직접 셌다.**
**경쟁자 수를 좁게 고정하고, *실제로 넣은* 금액 위치별 실제 낙찰률:**

|---|---:|---:|---:|

| `N=10-12` | 12.8% | 0.84% | 15.2배 |
| `N=3-4` | 38.6% | 10.8% | 3.6배 |

🔴 **아버지 구간에서 관측된 위치 효과는 `1.9배`다. `399배` 는 *모형이 예측한 곡선의 양끝*이지 관측이 아니다.**

⚠ **다만 이걸로 `399배` 가 틀렸다고 확정할 수 없다:**
```
잰 것      "낮게 넣은 **사람들**이 더 이겼나"        ← 횡단면.  선택이 섞인다
필요한 것  "**같은 사람이** 같은 회차에서 낮췄으면"   ← 인과
```
**⟹ 그런데 3-3 의 대결이 정확히 그 인과 질문이고, 답이 "구분 안 됨"이었다. 두 독립 관측이 같은 방향이다.**
