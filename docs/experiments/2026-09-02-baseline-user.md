## 0. 왜 이게 결함이었나

`ADR 0002`·`PLAN-MATERIALS` 는 전부 **"사장"** 이라고만 쓴다. 메모리에도 결론(*"아버지 최적"*)만 있고 **누구 기준인지가 없었다.**

**⟹ 그래서 VoI·낙찰률 문턱·개선폭을 *분포에서 뽑은 가정*(중간값 투찰자 252.6건/년 등)으로 계산했다. 실제 기준점이 아니었다.**

## 2. 영업권 — 확정

```
그가 들어간 회차 99개:   김해시 95 · 통영시 4      (전부 경상남도)
```

## 3. 🔴 그가 서는 자리는 **고경쟁**이다 — 가정이 정반대였다

| | 중앙 `N` | 평균 `N` |
|---|---:|---:|
| **그의 회차** | **53** | 53.2 |
| 전국 코퍼스 | 15 | 45.4 |

```
N≤4      0 회차
5-9      0 회차
10-29    2 회차
🔴 30+   97 회차  (98%)
```

**⟹ 제품 함의:** 우리가 하루 종일 판 저`N` 잔차(`+8%p`)는 **그가 서지 않는 자리**다. `N≥30` 은 잔차 `~0` 으로 이미 잘 맞는다.

## 4. 🔴 성적 — **판정 불가. 표본 부족**

```
관측         187투찰 6낙찰 = 3.209%
무작위 기대   1/53.2 = 1.880%      (기대 낙찰 3.52건)

P(X≥6 | 무작위) = **0.1425**            ← 유의하지 않다
95% CI (Clopper-Pearson)  1.186% ~ 6.853%
무작위선 1.880% 가 CI **안에 있다**
모형 최적(N=30-99) 2.21% 도 CI **안에 있다**
```

> 🔴 **팀리드 자기 정정:** 처음에 *"무작위 대비 1.71배 · 우연으로 나오기 어려운 크기"* 라고 보고했다. **틀렸다.**
> **낙찰 6건으로는 실력·무능 어느 쪽도 말할 수 없다. 규율 18-b(차이의 `n` 을 보라)를 스스로 어겼다.**

## 5. 🔴 원인 — 아버지 행태가 아니라 **코퍼스 커버리지**

```
김해 회차 — 코퍼스에 있는 전부
  2024-12    3
  2025-01   30
  2025-02   12
  2025-06  273     ← 86% 가 한 달
  그 외 월   0

김해 = 전체 233,380 회차 중 **318 (0.14%)**
```
**⟹ 3개월만 입찰하신 게 아니라 3개월치만 갖고 있다.**
⚠ **계절성(신학기·2학기 발주)과 구분이 안 된다. 2025-06 한 달이 표본의 86% 다.**

## 6. ⟹ 수집의 성격이 바뀐다

> **전국 수집은 "사업 확장"이 아니라 *기준 사용자 한 명을 통계적으로 잴 수 있게 만드는 최소 조건*이다.**
> **지금 코퍼스로는 아버지에 대해 아무것도 확정할 수 없다.**
