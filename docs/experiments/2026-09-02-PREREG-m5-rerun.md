# 사전 등록 — `M5` 신경망 예산 맞춤 재실행

> **2026-09-02 · team-lead 작성 · 실행 전에 확정**
> 🔴 **우리는 이미 `M5` 의 불공정 실행 결과(1.25%)를 봤다. 그래서 이 문서가 유일한 보호막이다.**
> **이 문서를 고친 뒤에 돌리면 사전 등록이 아니다. 고칠 일이 생기면 새 문서를 만든다.**

## 0. 왜 다시 도나

```
1차 실행    M4 150만 행 · 300 반복      vs    M5 40만 행 · 7 에폭
⟹ ml-expert 본인의 리뷰 §2-4 가 "예산 불균형은 공정 비교가 아니다"라고 이미 적어둔 그 형태
⟹ 사장 첫 지시: "신경망에 표 2개 주고 아빠는 1개, 그 역도 안 된다"
```
**⟹ 1차 `M5` 수치(1.25% · p=0.023)는 인용 금지. 이 재실행이 대체한다.**

## 1. 🔴 그런데 예산이 원인이 아닐 수 있다 — 먼저 볼 것

`tools/m1/m5_nn.py` 를 읽었다.
```python
MLPClassifier(..., max_iter=40, early_stopping=True, n_iter_no_change=5)
# 실행 로그: 7 에폭에서 멈춤
```
⚠ **상한 40 인데 7 에서 멈췄다. 조기 종료가 걸린 것이지 예산 상한에 부딪힌 게 아니다.**
**⟹ "굶겼다"는 설명이 자료와 안 맞는다. 행 수는 적었지만 *수렴은 했다*.**

### 🔴 더 그럴듯한 가설 — 확률 곡면이 평평하다

```
decide() 는 x 격자 86점에서 p(낙찰 | 특징, x) 의 **argmax** 를 고른다
낙찰 라벨이 2% 로 극단 불균형 → MLP 가 매우 평평한 확률을 낸다
⟹ 평평한 곡면의 argmax 는 사실상 임의값이다.  단봉 구조를 못 잡는다
⟹ M1(구조식)은 그 봉우리를 식으로 박아넣었다.  그래서 이긴다
```

**⟹ 그러므로 재실행은 예산만 맞추면 안 되고 *진단*을 같이 내야 한다.**

## 2. 필수 진단 셋 — **성능 수치보다 먼저 낸다**

```
D1  선택된 x 의 분포.  격자 끝점(0.960 / 1.045)에 몰리는 비율
    🔴 한 점에 20% 이상 몰리면 퇴화다.  성능 수치를 해석하지 않는다
D2  표본 회차 20개에서 p(x) 곡선을 그대로 출력.  M1 의 곡선과 나란히
    🔴 M5 곡선의 (최대−최소)/최대 가 M1 의 1/5 미만이면 "평평함"으로 판정
D3  적합된 p 의 보정 — 예측 확률 십분위별 실제 낙찰률
```
**⟹ `D1`·`D2` 중 하나라도 걸리면 결론은 "예산이 아니라 *구성*이 문제"이고, 그때는 손실함수·불균형 처리·출력 파라미터화를 고치는 별도 작업이다.**

## 3. 예산 맞춤 규격

```
학습 행      **150만** (M4 와 동일).  같은 seed 로 같은 부표본
정보         features() 그대로.  실현 R · 경쟁자 벡터 · nbid_live · wd · rnk 접근 없음
누출         아버지 두 사업자 행 학습에서 제외 (그대로)
반복         조기 종료 유지하되 max_iter 200 · n_iter_no_change 15
             ⚠ 40 에서 7 로 멈췄으므로 상한이 구속하지 않았다.  여유를 더 준다
구조         (128,64) 그대로.  ⚠ 구조 탐색은 하지 않는다 — M4 도 한 구성만 썼다
```
🔴 **탐색을 더 하면 그건 `M5` 에 표를 더 주는 것이다. 한 구성으로 간다.**

## 4. 채점 — `M1`·`M4`·상수와 같은 자리

```
표본      TUNE + HOLD 20만 투찰 (적합 밖)
비교군    사람 · 제비뽑기(항등식이라고 병기) · **상수** · M4 · M1
상수      학습기 30만에서 x0 선택 → 평가 표본에서 채점  (창 안 최댓값 금지)
층        N 3-20 / 21-40 / 41+
병기      낙찰 시 평균 x · McNemar b·c·p · n
```

## 5. 🔴 판정 기준 — **결과 보기 전에 확정**

```
성공   M5 가 **상수**를 이기고(McNemar p<0.05) 그리고 M4 를 이긴다
부분   상수는 이기지만 M4 는 못 이긴다  →  "신경망이 되긴 하나 GBDT 아래"
실패   상수를 못 이긴다                →  "이 구성의 신경망은 값을 못 한다"
🔴 어느 경우든 D1·D2 를 같이 낸다.  퇴화면 성능 해석 자체를 하지 않는다
```
⚠ **`M1` 을 이기는 것은 성공 조건이 아니다.** `M1` 은 이 문제의 구조를 사람이 박아넣은 것이라, 신경망이 그걸 이기면 강한 결과이고 못 이겨도 실패가 아니다.
