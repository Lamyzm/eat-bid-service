## §2 메커니즘 — 전수 확정

### 2-1 계산식

```
기초가격        BGNG_PRC
예비가격 15개    ds_pList[k].CMNM_PLNPRC        비율 CMNM_PLNPRC_RT = CMNM_PLNPRC/BGNG_PRC
투표            ds_bidList[j].DRAW_NO           각 입찰자가 15개 중 2개
선택 4개        CHC_YN = 'Y'
예정가격        ELCTRN_BID_PLNPRC
R              = ELCTRN_BID_PLNPRC / BGNG_PRC
```

**`R = mean(CHC_YN='Y' 인 4개의 비율)`** — 233,204 회차 중 `|잔차| > 1e-4` 가 **95 건 (0.041%)**.

### 2-2 어느 4개가 뽑히는가 — 전수 재구성

`DRAW_NO` 로 슬롯별 득표를 세어 상위 4개를 재구성했다. **표 집계에 철회자를 넣는지가 갈랐다:**

| 집계 방식 | 동점 없는 회차 일치 | 전체 일치 |
|---|---|---|
| 철회자(`WITHDRAWAL_YN='Y'`) 표 **제외** | 83.918% | 86.461% |
| 철회자 표 **포함** | **99.006%** | **99.127%** |

**🔴 철회한 입찰자의 표도 예정가 결정에 들어간다. 그리고 회차의 52.67% 에 철회자가 있다.**
이건 잔재가 아니라 메커니즘의 일부다.

### 2-3 동점 — 회차의 절반이다

입찰자 수 중앙값이 14 명(=28 표)인데 슬롯이 15개다. **4위와 5위가 동점인 회차가 48.2%.**
동점이 이렇게 흔하면 tie-break 는 메커니즘의 절반이다.

| 규칙 | 실측 일치 |
|---|---|
| **낮은 번호 우선** | **93.432%** |
| 재추첨(균등) 귀무 기대 | 26.112% |

경계선 상황 분포: `(동점 2개 중 1개 뽑기) 24,466 · (3 중 2) 11,722 · (3 중 1) 11,422 · (4 중 3) 9,054`

낮은 번호 우선이 확정이다. **잔차 6.6% 는 미해결이다.**

## §3 실험 설계 — 사다리 셋

가설 하나를 세 번 다르게 검정했다. **매번 귀무가설을 더 정확하게 만들었고, 매번 답이 바뀌었다.**
이 사다리 자체가 이 문서의 방법론적 결론이다.

### 3-1 L1. 정확 조건부 검정 — `04_exact_conditional_selection_test.py`

회차 i 의 후보 15개 `r` 가 주어졌을 때, 4개가 균등 부분집합이면

```
E[mean(선택4) | r]  = mean(r)                            정확
Var[mean(선택4) | r] = (v/4)·(11/14),  v = 15개 모분산     정확 (유한모집단 보정)

D_i = mean(선택4)_i − mean(r)_i     →   E[D_i] = 0
z   = ΣD_i / √(ΣVar_i)
```

**모의 대조군이 필요 없다 — 대조군 분산이 0 이다.** 그리고 후보 생성 분포가 무엇이든
회차별 조건부화에서 지워진다.

> **왜 KS 가 아니라 이것인가.** 선행 검정은 같은 15개에서 4개를 뽑은 **모의** 대조군과
> KS 로 겨뤄 "구분 안 됨"(D=0.0287 < 0.0351, n=3,000)을 얻었다. KS 는 분포 **모양**의
> 통계량인데 실제 차이는 **위치 이동** 하나였다. 거기에 KS 는 검정력이 거의 없다.

**결과:**
```
표본 2,997 회차:  mean(D) = −0.889 bp   SE 1.357   z = −0.66     ← 못 잡는다
전수 233,204:     mean(D) = −2.000 bp   SE 0.154   z = −12.96    ← 잡힌다
```

**표본 3,000 은 이 크기의 효과를 볼 수 없는 표본이었다.** 표본에서 "차이 없음"을 결론으로
쓰면 안 된다는 것이 여기서 실측으로 나왔다.

### 3-2 L2. 순열 검정 — `07_price_visibility_test.py`

**L1 의 귀무가 틀렸다.** 투표가 슬롯에 심하게 쏠려 있으므로(seq3 0.732, seq14 0.013)
"균등 부분집합"은 애초에 참일 수 없다. 기각해도 아무 말이 안 된다.

옳은 귀무:

> **H0: 선택된 슬롯 집합 ⊥ 슬롯→가격 배정**

가격을 못 보면 무엇을 근거로 찍든 그 선택은 그 회차의 가격 배정과 독립이어야 한다.
**가격 배정 쪽에 구조가 있어도 H0 는 성립한다 — 독립이면 되지 무작위일 필요는 없다.**
이 아래 `E[D] = (1/4)Σ p_s·δ_s ≠ 0`.

셀(연도×N구간×하한율, 135개) 안에서 15칸 선택 마스크를 **통째로** 다른 회차의 가격판에
붙인다. 투표 쏠림은 쪼개지 않으므로 보존되고 가격 연결만 끊긴다.

```
영분포 평균 −0.6303 bp   sd 0.1298      관측 −1.9987 bp
z = −10.54       400회 중 관측 이하 0회      p < 0.0025
```

해석적 분해도 층화 5단계 전부 안정 — **Simpson 이 아니다:**

| 층화 | (A) 독립 하 기대값 | (B) 독립 위반 | z |
|---|---|---|---|
| 없음 | −0.584 bp | −1.414 bp | −10.99 |
| 연도 | −0.588 | −1.411 | −10.97 |
| N구간 | −0.602 | −1.396 | −11.12 |
| 연도×N구간 | −0.618 | −1.380 | −11.03 |
| 연도×N구간×하한율 | −0.634 | −1.366 | −10.95 |

### 3-3 L3. 기각표집 순열 — `09_selection_adjusted_null.py`

**L2 의 귀무도 틀렸다. 우리 코퍼스가 007 낙찰 전수다.**

```
낙찰 ⟺ max_j x_j ≥ R,       x = 투찰금액 / (기초가 · 하한율/100)
```

**`R` 이 낮게 나온 회차가 살아남는다.** 007 만 모은 것 자체가 낮은 `R` 을 고르는 것이고,
회차 **안**에서 봐도 콜라이더로 들어온다. L2 의 영분포는 이걸 안 넣었으므로 너무 높다.

그래서 선택 편향을 **귀무가설 안에 넣었다:**

> **H0: 선택 슬롯집합 ⊥ 슬롯→가격 배정, 단 관측되려면 `mean(뽑힌 4개) ≤ xmax` 를 통과해야 한다**

순열에서 기증 마스크를 뽑되 `mean(rate_i[donor]) ≤ xmax_i` 를 만족할 때까지 다시 뽑는다.
**이게 정확히 "가격을 못 보지만 낙찰된 회차만 관측된" 세계다.** `xmax` 는 H0 아래
보조통계량이므로 조건화가 유효하고, 표본을 안 버리므로 부분집합 절단의 치우침이 안 생긴다.

### 4-1 기각표집 순열

```

> ⚠ **이 표는 `xmax` 를 철회 포함으로 고친 뒤의 값이다(§7 #6).** 고치기 전에는 영평균 −2.56,

### 4-3 득표수와 가격의 상관

**세 갈래가 독립적으로 같은 말을 한다: −2.0 bp 는 "007 낙찰 회차만 모았다"는 표집이 만든
것이고, 투찰자는 개찰 전에 가격을 못 본다.**

### 4-4 네 번째 가설도 죽었다 — 서버 채움 규칙은 가격을 안 본다

`ml-expert` 가 세 번째 가설을 냈다: **서버가 무득표 슬롯을 채우는 규칙이 가격을 참조하면,
아무도 가격을 안 봐도 콜라이더가 없어도 `mean(D) < 0` 이 기계적으로 나온다.**

**검정할 게 아니라 읽으면 되는 것이었다.** 우리는 표(`DRAW_NO`)와 결과(`CHC_YN`)를 둘 다
갖고 있으므로 **채워진 슬롯이 직접 식별된다** — 득표 0 인데 `CHC_YN='Y'` 인 슬롯이다.

```

P(채움 | 무득표)  가격순위별 (0=가장 쌈, 균등 기대 0.008)
  0.008 0.008 0.008 0.008 0.008 0.008 0.008 0.009 0.008 0.008 0.009 0.008 0.009 0.008 0.008
  ↑ 완전히 평평하다

P(채움 | 무득표)  슬롯번호별
  1:0.014  2:0.014  3:0.016  4:0.013  5:0.013  6:0.012  7:0.012  8:0.009
  9:0.011  10:0.008  11:0.006  12:0.006  13:0.006  14:0.005  15:0.005
  ↑ 낮은 번호를 3배 선호한다
```

**채움은 슬롯 번호만 보고 가격은 안 본다.** D 에 닿는 경로가 슬롯↔가격 상관 하나뿐이고,
그건 이미 주변부 −0.584 bp 에 들어 있다. **그리고 규모가 애초에 안 된다 — 채움이 필요한
회차가 6,393 (2.742%) 뿐이다.**

부수로 나온 것:
```
득표 슬롯 2개 (채움 2개 필요)   회차  1,190   mean(D) = +4.120 bp
득표 슬롯 3개 (채움 1개)        회차  5,203   mean(D) = −0.101 bp
득표 슬롯 4개 (채움 0개)        회차 13,315   mean(D) = −2.830 bp
```
`N=1` 785 회차는 전부 득표 슬롯이 정확히 2개다.

🔴 **여기 모순이 하나 남는다.** 채움은 **낮은 슬롯을 3배 선호**하고 낮은 슬롯은 미세하게
**싸므로**(§5) 채움 회차의 D 는 **음수**여야 한다. 그런데 **+4.12 bp 다.** 두 사실이 같이
서려면 우리가 모르는 게 하나 더 있다. **미해결로 남긴다.**

⚠ 그리고 **무득표 슬롯이 뽑힌 회차 6,778 > 채움이 필요한 회차 6,393.** 차이 385 회차는
득표 슬롯이 4개 이상인데도 무득표 슬롯이 뽑힌 순수한 규칙 예외다.

## §5 그러나 "정확히 0" 은 아니다 — 아주 작은 진짜 지렛대

두 개가 겹친다.

**(a) 슬롯↔가격 무작위화가 완벽하지 않다.**
회차별 Spearman(슬롯번호, 가격) **전수 평균 +0.00488, SE 0.00055, z = +8.85.**
낮은 번호가 아주 살짝 싸다.
sd 는 0.26617 로 무작위 순열 이론값 `1/√14 = 0.26726` 과 그대로 맞는다 —
**sd 로는 절대 안 잡힌다.**

**(b) 동점은 낮은 번호가 이긴다** (§2-3, 93.4%).
그래서 낮은 번호를 찍으면 뽑힐 확률이 올라가고, (a) 때문에 그건 약간 더 싼 `R` 을 뜻한다.

**크기: 투표 쏠림 전체가 만드는 몫이 −0.63 bp 다.** 개인 두 표의 몫은 그보다 훨씬 작다.
**승부가 갈리는 창문이 5.8 bp 이므로 실무적으로는 0 이다.**

> 🔴 **화면 문구를 "증명"에서 "측정"으로 바꿔야 한다.**
> "번호 선택은 결과를 바꾸지 않는다"(거짓) 가 아니라
> **"번호 선택이 바꿀 수 있는 최대치는 0.63 bp 이고, 승부가 갈리는 폭은 5.8 bp 다"**(참).
> 후자가 참이면서 더 유용하다.

## §6 후보 15개의 분포 — `U(0.97, 1.03)` 이 아니다

전수 3,498,060 개:

```
mean 0.999067  (−9.33 bp)      sd 0.016943      균등이론 sd 0.017321
```

지지집합은 정확히 ±3% 이고 회차 내 순서통계(min·max·폭)도 균등과 맞는데 **모양이 다르다.**

```
[0.9700, 0.9800)   전 구간 −1 ~ −12%     아래쪽이 얇다
[0.9800, 0.9890)   전 구간  +5 ~ +22%    1.0 바로 아래가 두껍다
[1.0200, 1.0300)          −14 ~ −18%     위쪽 끝이 가장 얇다
```

**sd 차이는 2.4% 뿐이라 sd 로는 못 잡는다. 평균으로만 잡힌다.** 예비가격은 1원 단위라
반올림 효과도 아니다.

**귀결:**
- `f_R` 을 균등 가정으로 그리면 틀린다. **`plist.npz` 의 실측 후보에서 만들어야 한다**
- 합성 데이터 생성기에서 `u_k ~ U(0.97,1.03)` 을 빼야 한다. 안 그러면 **실제와 다른 세계를
  통과시켜 구현 검증(L1)을 무력화한다**
- `sd(R) = σ_within·√(¼·11/14)` 는 **구조가 후보 분포 모양에 의존하지 않으므로 살아남는다.**
  상수만 실측으로 바꾸면 된다 — 전수 실측 sd(D)/정확 귀무 sd(D) = **0.9831**

## §7 내가 틀린 것들 — 기록

이 실험에서 다섯 번 틀렸다. 전부 같은 모양이다: **재지 않고 추론했다.**

| # | 무엇 | 어떻게 드러났나 |
|---|---|---|
| 1 | "투표식이니 표가 조작 변수다 / 문제가 쉬워졌다" | 슬롯↔가격이 회차마다 새 순열이라 표로 `R` 을 못 움직인다 |
| 2 | "−13.2 bp = −9.4(생성) + −3.8(선택)" | 주변 평균 둘을 **짝짓지 않고** 뺐다. 짝지으면 −0.889 ± 1.357 bp |
| 3 | "선택은 균등 부분집합과 구분 안 된다" (표본 2,997, z=−0.66) | 전수에서 z=−12.96. **표본에서 얻은 '차이 없음'을 결론으로 썼다** |
| 4 | "선택이 균등이 아니다 → 가격을 본다" | 귀무가 틀렸다. 투표 쏠림이 있으니 균등일 리가 없다 |
| 5 | `xmax` 를 `BID_CALC_AMT` 로 만들었다 | 그 필드에 `10000000115368` 같은 10^13 오염값. `xmax−R` 중앙값이 **+560,048** 이 나왔다 |
| 6 | `xmax` 에서 **철회자를 뺐다** | `ml-expert`·`stats-expert` 가 각각 지적했다. 낙찰자는 개찰 시점에 정해지고 철회는 그 뒤다 |

**#6 이 #5 만큼 위험했다.** 철회를 빼면 `xmax` 가 과소평가되고, §3-3 의 기각표집 제약이
과도하게 빡빡해져 **영분포가 인위적으로 더 음수가 된다 — 즉 "선택 편향이 전부 설명한다"는
결론이 공짜로 나온다.** 판정을 **내가 원하는 쪽으로 미는 방향의 버그**였다.

**그리고 항등식이 그걸 잡아 줬다:**
```
                          수정 전       수정 후
xmax ≥ R      (100% 여야)  99.814%  →  100.000%
xmax < Rmin   (0% 여야)     0.005%  →    0.000%
```
철회를 빼면 785 회차에서 "낙찰됐는데 아무도 커트라인을 못 넘었다"가 나왔다. 이제 예외가 0 이다.
**판정 여유는 z=+5.09 에서 z=+2.80 으로 절반 아래로 줄었다.**

> **규칙으로 남긴다: 검정에 들어가는 조건은 그 조건이 만족돼야 하는 자명한 항등식을 같이
> 출력하라.** `xmax ≥ R` 이 100% 여야 한다는 건 007 전수라는 사실에서 공짜로 나오는데,
> 그걸 찍지 않았으면 0.186% 의 어긋남을 못 봤다.

**#5 가 가장 위험했다.** 그 판으로 낸 1차 결과는 "안전 부분집합에서 +2.34 bp" 라는 부호까지
틀린 답이었고, **그대로 판정으로 낼 뻔했다.** 같은 행의 `EFT_ALL_AMT`·`SAJEONG_PCT` 는 멀쩡했다.

> **규칙으로 남긴다: 판정을 세우는 양은 두 경로로 만들어 서로 대조한 뒤에 쓴다.**
> ```
> x_A = EFT_ALL_AMT / (기초가 · 하한율/100)
> x_B = (SAJEONG_PCT / 하한율) · R          ← 금액을 아예 안 지나간다
> |x_A − x_B| / x_B < 1e-3 인 회차 99.982%
> ```
> 대조가 없었으면 못 잡았다. **비율이어야 하는 값이 백만 단위인데도 코드는 조용히 돌았다.**

**#1~#4 의 공통 교훈:** 구조 주장에는 항상 대조군을 붙인다. 그리고 **귀무가설이 애초에
참일 수 없는 것이면 기각해도 아무 말이 아니다.**

## §8 프론트엔드 재료로 무엇이 나왔나

이 실험의 원래 목적은 예측이 아니라 **"사용자에게 무엇을 보여줄 근거"** 였다. 나온 것:

| 재료 | 근거 | 성격 |
|---|---|---|
| **"번호 선택이 바꾸는 최대치 0.63 bp / 승부 창문 5.8 bp"** | §5 | 미신을 끄는 **측정값**. 추천이 아니라 사실 |
| **"철회해도 당신 표는 예정가에 들어간다"** | §2-2 | 아무도 모르는 규칙. 회차의 52.67% 에 해당 |
| **"동점이면 낮은 번호가 이긴다 (48.2% 회차에서 발생)"** | §2-3 | 위와 같음 |
| **개찰 후 `R` 완전 분해** — 이 회차의 15개, 누가 뭘 찍었는지, 왜 그 4개인지 | §2 | **사후 설명은 100% 가능하다.** 사전 예측이 불가능한 것과 별개다 |
| **`R` 의 실측 분포** (품목·연도·하한율·N 별) | §6 + `plist.npz` | 사용자가 자기 판단의 눈금으로 쓸 배경분포 |
| **낙찰 여유 `xmax − R`** 중앙 0.065 · p10 0.011 · p90 0.120 | §3-3 | "얼마나 아슬아슬했나" 를 회차마다 보여줄 수 있다 |

**설계에 대한 함의 하나:** `R` 은 투찰 시점에 예측 불가이지만 **개찰 후에는 완전히 설명
가능**하다. 이 비대칭이 화면을 가른다 — **투찰 전 화면은 분포를, 개찰 후 화면은 분해를**
보여주는 것이 데이터가 실제로 지지하는 구성이다.
