## §2 메커니즘 — 전수 확정

### 2-1 계산식

```
기초가격        BGNG_PRC
예비가격 15개    ds_pList[k].CMNM_PLNPRC        비율 CMNM_PLNPRC_RT = CMNM_PLNPRC/BGNG_PRC
투표            ds_bidList[j].DRAW_NO           각 입찰자가 15개 중 2개
선택 4개        CHC_YN = 'Y'
예정가격        ELCTRN_BID_PLNPRC
R              = ELCTRN_BID_PLNPRC / BGNG_PRC
```

**`R = mean(CHC_YN='Y' 인 4개의 비율)`** — 233,204 회차 중 `|잔차| > 1e-4` 가 **95 건 (0.041%)**.

### 🔴 그 95 건은 잔차가 아니라 오염이다 — 그리고 오래 끌던 sd(R) 불일치의 정체다

`stats-expert` 가 `|plnprc/bgng − mean(선택4)| > 0.5` 인 행을 세니 **90 개**다. 값이 통째로
깨져 있고, **그 90 행이 전수 sd 를 2.8 배로 부풀린다:**

```
plnprc/bgng 원본        sd 0.021028
오염 90행 제거 후          0.007606
mean(선택4)               0.007605   <- 참값
```

**팀이 오래 끌던 불일치의 정체가 표본 정의가 아니라 이것이었다:**
```
팀 기록 0.00781   ·   표본 측정 0.007544   ·   참값 0.007605 (전수 · mean(선택4))
```

> **규칙: `R` 을 `ELCTRN_BID_PLNPRC / BGNG_PRC` 로 만들지 마라. `mean(CHC_YN='Y' 4개)` 를 써라.**
> 내가 이 95 건을 "0.041% 잔차"로 적고 넘긴 것이 잘못이다.
> **작은 개수가 작은 영향을 뜻하지 않는다 — 90 행이 sd 를 2.8 배로 만들었다.**

### 2-2 어느 4개가 뽑히는가 — 전수 재구성

`DRAW_NO` 로 슬롯별 득표를 세어 상위 4개를 재구성했다. **표 집계에 철회자를 넣는지가 갈랐다:**

| 집계 방식 | 동점 없는 회차 일치 | 전체 일치 |
|---|---|---|
| 철회자(`WITHDRAWAL_YN='Y'`) 표 **제외** | 83.918% | 86.461% |
| 철회자 표 **포함** | **99.006%** | **99.127%** |

**🔴 철회한 입찰자의 표도 예정가 결정에 들어간다. 그리고 회차의 52.67% 에 철회자가 있다.**
이건 잔재가 아니라 메커니즘의 일부다.

### 2-3 동점 — 회차의 절반이다

입찰자 수 중앙값이 14 명(=28 표)인데 슬롯이 15개다. **4위와 5위가 동점인 회차가 48.2%.**
동점이 이렇게 흔하면 tie-break 는 메커니즘의 절반이다.

| 규칙 | 실측 일치 |
|---|---|
| **낮은 번호 우선** | **93.432%** |
| 재추첨(균등) 귀무 기대 | 26.112% |

경계선 상황 분포: `(동점 2개 중 1개 뽑기) 24,466 · (3 중 2) 11,722 · (3 중 1) 11,422 · (4 중 3) 9,054`

낮은 번호 우선이 확정이다. **잔차 6.6% 는 미해결이다.**

## §3 실험 설계 — 사다리 셋

가설 하나를 세 번 다르게 검정했다. **매번 귀무가설을 더 정확하게 만들었고, 매번 답이 바뀌었다.**
이 사다리 자체가 이 문서의 방법론적 결론이다.

### 3-1 L1. 정확 조건부 검정 — `04_exact_conditional_selection_test.py`

회차 i 의 후보 15개 `r` 가 주어졌을 때, 4개가 균등 부분집합이면

```
E[mean(선택4) | r]  = mean(r)                            정확
Var[mean(선택4) | r] = (v/4)·(11/14),  v = 15개 모분산     정확 (유한모집단 보정)

D_i = mean(선택4)_i − mean(r)_i     →   E[D_i] = 0
z   = ΣD_i / √(ΣVar_i)
```

**모의 대조군이 필요 없다 — 대조군 분산이 0 이다.** 그리고 후보 생성 분포가 무엇이든
회차별 조건부화에서 지워진다.

> **왜 KS 가 아니라 이것인가.** 선행 검정은 같은 15개에서 4개를 뽑은 **모의** 대조군과
> KS 로 겨뤄 "구분 안 됨"(D=0.0287 < 0.0351, n=3,000)을 얻었다. KS 는 분포 **모양**의
> 통계량인데 실제 차이는 **위치 이동** 하나였다. 거기에 KS 는 검정력이 거의 없다.

**결과:**
```
표본 2,997 회차:  mean(D) = −0.889 bp   SE 1.357   z = −0.66     ← 못 잡는다
전수 233,204:     mean(D) = −2.000 bp   SE 0.154   z = −12.96    ← 잡힌다
```

**표본 3,000 은 이 크기의 효과를 볼 수 없는 표본이었다.** 표본에서 "차이 없음"을 결론으로
쓰면 안 된다는 것이 여기서 실측으로 나왔다.

### 3-2 L2. 순열 검정 — `07_price_visibility_test.py`

**L1 의 귀무가 틀렸다.** 투표가 슬롯에 심하게 쏠려 있으므로(seq3 0.732, seq14 0.013)
"균등 부분집합"은 애초에 참일 수 없다. 기각해도 아무 말이 안 된다.

옳은 귀무:

> **H0: 선택된 슬롯 집합 ⊥ 슬롯→가격 배정**

가격을 못 보면 무엇을 근거로 찍든 그 선택은 그 회차의 가격 배정과 독립이어야 한다.
**가격 배정 쪽에 구조가 있어도 H0 는 성립한다 — 독립이면 되지 무작위일 필요는 없다.**
이 아래 `E[D] = (1/4)Σ p_s·δ_s ≠ 0`.

셀(연도×N구간×하한율, 135개) 안에서 15칸 선택 마스크를 **통째로** 다른 회차의 가격판에
붙인다. 투표 쏠림은 쪼개지 않으므로 보존되고 가격 연결만 끊긴다.

```
영분포 평균 −0.6303 bp   sd 0.1298      관측 −1.9987 bp
z = −10.54       400회 중 관측 이하 0회      p < 0.0025
```

해석적 분해도 층화 5단계 전부 안정 — **Simpson 이 아니다:**

| 층화 | (A) 독립 하 기대값 | (B) 독립 위반 | z |
|---|---|---|---|
| 없음 | −0.584 bp | −1.414 bp | −10.99 |
| 연도 | −0.588 | −1.411 | −10.97 |
| N구간 | −0.602 | −1.396 | −11.12 |
| 연도×N구간 | −0.618 | −1.380 | −11.03 |
| 연도×N구간×하한율 | −0.634 | −1.366 | −10.95 |

### 3-3 L3. 기각표집 순열 — `09_selection_adjusted_null.py`

**L2 의 귀무도 틀렸다. 우리 코퍼스가 007 낙찰 전수다.**

```
낙찰 ⟺ max_j x_j ≥ R,       x = 투찰금액 / (기초가 · 하한율/100)
```

**`R` 이 낮게 나온 회차가 살아남는다.** 007 만 모은 것 자체가 낮은 `R` 을 고르는 것이고,
회차 **안**에서 봐도 콜라이더로 들어온다. L2 의 영분포는 이걸 안 넣었으므로 너무 높다.

그래서 선택 편향을 **귀무가설 안에 넣었다:**

> **H0: 선택 슬롯집합 ⊥ 슬롯→가격 배정, 단 관측되려면 `mean(뽑힌 4개) ≤ xmax` 를 통과해야 한다**

순열에서 기증 마스크를 뽑되 `mean(rate_i[donor]) ≤ xmax_i` 를 만족할 때까지 다시 뽑는다.
**이게 정확히 "가격을 못 보지만 낙찰된 회차만 관측된" 세계다.** `xmax` 는 H0 아래
보조통계량이므로 조건화가 유효하고, 표본을 안 버리므로 부분집합 절단의 치우침이 안 생긴다.

## §4 판정 — 세 갈래 독립 일치

### 4-1 기각표집 순열 — 그리고 닫힌 형태 열거

```
H0 (선택편향 미반영)   관측 −2.00 bp   영평균 −0.63   z = −10.26
H0 (선택편향 반영)     관측 −2.00 bp   영평균 −2.37   z =  +2.80
```

**`ml-expert` 가 이걸 닫힌 형태로 다시 냈다** — `C(15,4)=1,365` 를 회차마다 전부 열거하고
셀별 마스크 경험분포에 생존제약 `R(S) ≤ xmax` 를 걸었다. 몬테카를로 없음:

```
내 MC 영평균  −2.3691        열거 영평균  −2.375        → 교차검증 성립
```

### 🔴 판정 문장은 "영분포보다 위"가 아니다

`stats-expert` 가 셀 간 결합 z 로 다시 읽었고, 열거판이 같은 그림을 준다:

| 구간 | n | 잔차 (bp) | z |
|---|---|---|---|
| **N≤2** | 18,201 (7.8%) | **+3.411** | **+6.70** |
| N=3-4 | 24,327 | +0.158 | +0.39 |
| N=5-9 | 44,812 | +0.246 | +0.84 |
| N=10-29 | 67,063 | −0.081 | −0.34 |
| N=30-99 | 47,017 | +0.314 | +1.25 |
| N=100+ | 31,702 | +0.016 | +0.06 |
| **N≥3 결합** | **214,921 (92.2%)** | **+0.13** | **+0.93** |

**회차의 7.8% 가 전체 잔차의 71% 를 만든다. 나머지는 전부 0 과 구분되지 않는다.**

**그래서 판정은 이렇게 쓴다:**

> ❌ ~~"관측이 영분포보다 위다 (z=+2.80)"~~
> ✅ **"N≥3 (회차의 92.2%) 에서 관측이 선택편향-only 영분포와 구분되지 않는다 (결합 z=+0.93,
>    셀별 |z| ≤ 1.25). N≤2 는 별도 이상 현상으로 분리한다 (§8-C)."**

**두 번째가 우리가 주장하려는 것과 정확히 같고, 더 방어하기 쉽다.** "영분포보다 위"는
방어할 필요도 없는 잉여 주장이고 **오히려 "왜 위인가"를 자초한다.** 그리고 `xmax` 수정으로
여유가 절반으로 줄어든 것(z +5.09 → +2.80)이 이 틀에서는 문제가 아니게 된다 —
**우리가 원하는 답이 "0 과 구분 안 됨"이기 때문이다.**

### 4-2 순수 부분집합 칼

`xmax ≥ mean(상위 4개 후보)` 인 회차 **177,317 (76.1%)** — **어떤 4개가 뽑혔어도 낙찰됐으므로
선택 편향이 원리적으로 없다:**

```
mean(D) = +0.54 bp      영평균 −0.005 bp        [전체 −2.00 bp]
```

음수가 사라진다.

### 4-3 득표수와 가격의 상관

```
전체            회차별 corr(득표수, 중심화가격) 평균 −0.00553   z = −10.11
안전 부분집합    회차별 corr                      평균 +0.00152   z =  +2.39
```

부호가 뒤집힌다.

**세 갈래가 독립적으로 같은 말을 한다: −2.0 bp 는 "007 낙찰 회차만 모았다"는 표집이 만든
것이고, 투찰자는 개찰 전에 가격을 못 본다.**

### 4-3b 네 번째 갈래 — 슬롯↔가격 상관 **자체**가 007 인공물이다

`ml-expert` 가 쟀고 수정된 `M` 으로 재현했다:

```
                  n         Spearman(슬롯번호, 가격)        D (bp)
전체          233,155     +0.003857  (z = +6.99)         −1.9998
안전 부분집합  177,359     +0.000189  (z = +0.30)  ← 소멸   +0.5419
나머지         55,796     +0.015516  (z = +13.90)        −10.0791
```

**구조가 명확하다.** 007 필터는 `max_j x_j ≥ R` 이고 `R` 은 **뽑힌 슬롯**의 가격 평균이다.
투찰자가 낮은 슬롯을 찍으므로 **"낮은 슬롯이 마침 싼 판"이 살아남는다.** 그게 그 상관이다.

🔴 **이건 §5 의 숫자를 바꾼다.** "번호 선택의 최대치 0.63 bp" 는 전체 `rho = +0.00488` 에서
나왔는데 **그게 콜라이더 오염분이다.** 선택 편향이 원리적으로 없는 곳의 깨끗한 값은
`rho = +0.000189` — **20배 작다.** §5 의 결론(실무적으로 0)은 오히려 더 강해진다.

### 4-4 네 번째 가설도 죽었다 — 서버 채움 규칙은 가격을 안 본다

`ml-expert` 가 세 번째 가설을 냈다: **서버가 무득표 슬롯을 채우는 규칙이 가격을 참조하면,
아무도 가격을 안 봐도 콜라이더가 없어도 `mean(D) < 0` 이 기계적으로 나온다.**

**검정할 게 아니라 읽으면 되는 것이었다.** 우리는 표(`DRAW_NO`)와 결과(`CHC_YN`)를 둘 다
갖고 있으므로 **채워진 슬롯이 직접 식별된다** — 득표 0 인데 `CHC_YN='Y'` 인 슬롯이다.

```
채워진 슬롯 8,052 건 · 회차 6,778

P(채움 | 무득표)  가격순위별 (0=가장 쌈, 균등 기대 0.008)

## §5 번호 선택에 지렛대가 있는가 — **검출 한계 아래다**

이 절은 이 문서에서 **두 번 뒤집혔다.** 그 경로 자체가 결론의 일부다.

```
1차   "번호 선택은 결과를 바꾸지 않는다"     <- 교환가능성 정리. 슬롯-가격 완전독립 전제
2차   전수 Spearman +0.00488 (z=+8.85) 로 전제가 깨짐  ->  "최대 0.63 bp" 로 정정
3차   그 상관 자체가 007 인공물 (§4-3b)      ->  다시 계산해야 함
```

### 5-1 비례 축소는 틀린다

전체 `rho = +0.003857` 가 안전집합에서 `+0.000189` 로 **20배** 작아졌다. 그렇다고
`0.63 / 20` 으로 가면 안 된다 — **`rho` 는 단조 정렬을 재고, 지렛대는 delta_s 의 최대·최소를 쓴다.**
콜라이더가 빠지면 **정렬은 무너져도 delta 의 잡음 산포는 남는다.**

### 5-2 슬롯별 가격 편차에 콜라이더가 눈에 보인다

```
전체(오염) 폭 2.670   -1.12 -0.98 -1.17 -0.31 -0.12 … +1.50 +0.75 +0.62 +0.62 +0.22
                      깨끗한 단조 구조
안전집합   폭 1.284   -0.17 -0.00 +0.19 +0.24 +0.42 … +0.59 -0.10 +0.12 -0.23 -0.39
                      단조성이 사라졌다. 부호가 뒤죽박죽
나머지     폭 9.873   -4.14 -4.08 -5.48 -2.04 -1.83 … +4.40 +3.43 +2.20 +3.32 +2.17
                      콜라이더가 여기 농축돼 있다
```

### 5-3 순열 검정 — 지렛대는 잡음 아래다

회차 안에서 슬롯 라벨을 섞어 영분포를 만들었다 (400회):

| | delta 카이제곱(df=14) | 지렛대 관측 | 영분포 평균 | 영분포 p95 | |
|---|---|---|---|---|---|
| 전체(오염) | 69.32 | 1.1338 bp | 0.5278 | 0.7075 | 초과 |
| **안전집합(깨끗)** | **8.84 (p≈0.84)** | **0.5239 bp** | **0.6092** | 0.8256 | 🔴 **미달** |

**콜라이더를 빼면 슬롯-가격 구조가 통계적으로 존재하지 않는다.**
관측된 0.52 bp 는 **순수 잡음의 기대값 0.61 보다도 작다** (상위 25.8%).

### 5-4 🔴 인수분해로 계산하면 안 된다 — 직접 쟀다

한때 이 닫힌 형태를 쓰려 했다:
```
레버(N) = (1/4)·[(delta 상위2 합) − (delta 하위2 합)]·pi(N)
```
🔴 **`delta` 가 잡음일 때 `상위2 − 하위2` 는 max 통계량이라 위로 편향된다.**
그리고 아래에서 보듯 **`pi` 가 1 에 가깝기 때문에 그 편향이 감쇠 없이 그대로 레버로 넘어온다.**
깨끗한 `delta`(폭 1.28)를 넣어도 **0.32 bp 짜리 가짜 레버**가 나왔을 것이다.

**대신 직접 쟀다** — *"내가 항상 번호쌍 c 를 고른다면 기대 커트라인이 얼마나 달라지나."*
105쌍 전부에 `V_others + e_c` 를 넣고 득표를 재집계하고 동점을 낮은 슬롯 우선으로 깨서
`R_c` 를 다시 냈다. **안전집합 177,334 회차.**

| 구간 | n | 전략 레버 | 영분포 (슬롯-가격 독립) | 오라클 상한 | pi (내 표가 top-4 를 바꿈) |
|---|---|---|---|---|---|
| 전체 | 177,334 | 0.298 bp | 0.367 ± 0.082 | 88.98 bp | **0.717** |
| N≤2 | 14,832 | 1.457 | 2.224 ± 0.397 | 227.12 | **0.999** |
| N=3-4 | 18,132 | 1.266 | 1.396 ± 0.120 | 163.30 | 0.984 |
| N=5-9 | 34,943 | 0.884 | 0.823 ± 0.112 | 121.60 | 0.940 |
| N=10-29 | 49,432 | 0.380 | 0.513 ± 0.071 | 78.79 | 0.817 |
| N=30-99 | 33,724 | 0.380 | 0.464 ± 0.093 | 28.88 | 0.444 |
| N=100+ | 26,271 | 0.323 | 0.285 ± 0.080 | 13.32 | 0.234 |

### 5-5 🔴 `pi` 가 0.99 인데 레버가 0 이다 — 이게 결론이다

**내 두 표는 작은 판에서 거의 항상 최다득표 4개를 바꾼다** (N≤9 에서 94% 이상).
`stats-expert` 의 시뮬 추정치(0.63/0.45/0.30/0.17)보다 훨씬 크다.

**그런데 모든 N 구간에서 레버가 영분포 안이고, 전체는 오히려 영분포 평균보다 아래다**
(0.298 < 0.367).

> **"내 표가 결과를 바꾸는가"(예, 94%+)와 "그 변화가 나에게 유리한가"(아니오)는 다른 질문이다.**
> `pi ≈ 1` 인데 레버가 0 인 이유는 **`delta` 가 0** 이기 때문이다 (§5-3).

### 5-6 오라클 상한 — 제도가 무엇을 막고 있는가

가격을 볼 수 있다면 105쌍 중 최선을 고르는 값어치:
```
전체 88.98 bp   ·   N≤2 227.12 bp        vs   승부 창문 5.8 bp
                                          ->  창문의 15배 ~ 39배
```
**가격이 개찰 전에 공개됐다면 번호 선택이 압도적 레버였을 것이다.**
"개찰 전 `seq↔가격` 대응이 공개되나"가 왜 이 조사의 급소였는지를 이 숫자가 정량적으로
뒷받침한다. **그리고 제도가 정확히 그걸 막고 있다.**

### 5-7 화면 문구 — 최종

```
번호 선택이 커트라인을 바꾸는 비율    N≤9 에서 94% 이상 · N=100+ 에서도 23%
그 변화의 방향을 예측한 값어치        검출 안 됨 (0.30 bp < 영분포 0.37 bp)
가격을 볼 수 있었다면                 89 bp = 창문의 15배   <- 제도가 막는 것
승부 창문                            5.8 bp
```

> **"번호 선택은 거의 항상 커트라인을 바꿉니다. 그런데 어느 쪽으로 바뀔지는 알 수 없습니다."**

**이게 앞선 후보들보다 나은 이유 셋:**
1. **둘 다 측정됐다** — `pi` 도 레버도. 어느 쪽도 추정이 아니다
2. **사장이 모르던 것을 알려준다** — *"내 표가 실제로 결과를 움직인다"* 가 새 정보다
3. **동시에 행동으로 못 옮긴다는 것도 말한다** — 헛된 노력을 막는다

🔴 **"0 이다"로 쓰지 마라.** 이 문서에서 그걸로 이미 한 번 틀렸다. **"검출되지 않는다"** 가
참이고, 표본이 커지면 갱신 가능하다는 것까지 정직하게 전달한다.

## §6 후보 15개의 생성 규칙 — 아래 8개 · 위 7개 **IID**

전수 3,498,060 개:
```
mean 0.999067  (-9.33 bp)      sd 0.016943      균등 U(0.97,1.03) 이론 sd 0.017321
```
지지집합은 정확히 ±3% 인데 **모양이 다르다.** sd 차이는 2.4% 뿐이라 **sd 로는 못 잡는다.**

### 6-1 규정 원문이 있다

`stats-expert` 가 찾았다 — 「지방자치단체 입찰 및 계약집행기준」:

> **"0% ~ +3% 범위 안에서 7개, 0% ~ −3% 범위 안에서 8개의 복수예비가격을 작성해야 한다."**

| | 규정 예측 | 실측 |
|---|---|---|
| 후보 평균 | (8×0.985 + 7×1.015)/15 = **0.99900** | 0.999062 |
| 1.0 미만 비율 | 8/15 = **53.333%** | 53.00% |

**독립인 두 모멘트가 둘 다 맞는다.** 위쪽 끝이 얇은 것도 같은 원인이다 —
위쪽 3% 를 7개가, 아래쪽을 8개가 나누므로 위쪽 밀도가 7/8 배다.

### 6-2 🔴 그런데 층화가 아니다. 모멘트 하나만이 그걸 가른다

| 규칙 | 후보평균 | %<1.0 | **sd(15개 평균)** |
|---|---|---|---|
| **실측 전수** | **0.999067** | **53.00%** | **0.002166** |
| 15등분 층화 | 1.000000 | 49.99% | 0.000298 (**7.3배 틀림**) |
| 아래8/위7 **층화** | 0.999001 | 53.33% | 0.000299 (**7.3배 틀림**) |
| **아래8/위7 IID** | 0.998996 | 53.33% | **0.002236 (비 0.967)** |

**eaT 는 15구간으로 층화하지 않는다. 아래에서 8개, 위에서 7개를 독립 균등으로 뽑는다.**
8/7 규정은 맞았고 **층화 여부만 달랐다.**

🔴 **그리고 평균도 %<1.0 도 세 규칙을 전혀 못 가른다.** `sd(15개 평균)` 하나만이 가른다 —
**규칙을 정하는 모멘트를 안 재고 있었으면 우리는 틀린 생성기를 끝까지 몰랐을 것이다.**

### 6-3 그래서 sd(R) 분해가 닫힌다 — 미해결이 아니었다

```
Var(R) = E[sigma_within^2]·(1/4)(11/14)  +  Var(mean r)
         = sd 0.007447                      + sd 0.002166   ->  예측 sd 0.007756
                                                                실측    0.007605   비 0.9615
```
**분산에서 3.8% 안이고, 실측이 예측보다 낮은 방향이 정확히 007 절단과 부합한다**(절단은 분산을 줄인다).

### 6-4 🔴 alpha 는 회차마다 다르고, 하한율이 예측한다 — as-of 안전한 층화축

내재 `alpha = (max-min)/2` 산포가 고정 alpha 표집잡음의 **1.32 배**라 실제로 변한다. 그리고:

| 하한율 | n | 내재 alpha |
|---|---|---|
| 82 | 221 | 2.12% |
| 84 | 1,995 | 2.68% |
| 88 | 82,172 | 2.87% |
| 90 | 148,677 | **2.98%** |

**층 안에서 alpha 가 상수인지도 쟀다** — `관측 sd(â) / 고정 alpha 예측 sd` 비:

| 층 | n | 비 | |
|---|---|---|---|
| **하한율 90 (회차의 63.7%)** | 148,677 | **1.04~1.19** | ✅ **alpha = 3.0% 상수. 층화 끝** |
| 하한율 88 · 품목 3 / 6 | 736 / 1,044 | 1.04 / 1.03 | ✅ |
| 하한율 88 · 품목 4 / 5 / 7 | 2,747 / 1,333 / 3,551 | **2.20 / 1.94 / 1.88** | ❌ 갈라도 여전히 섞인다 |

⚠ `â = (max−min)/1.7639` 는 15개 뽑기의 범위통계라 **고정 alpha 라도 퍼진다.**
"퍼져 있다 = alpha 가 변한다"가 아니라 **고정 alpha 가 만드는 퍼짐과 대조해야** 나오는 판정이다.

🔴 **하한율 88 (35.2%) 에 숨은 축이 하나 더 있고, `발주기관` 일 가능성이 높다** — 어느 npz 에도 없다.

🔴 **하한율은 공고에 있다. as-of 안전한 층화 변수를 하나 얻었다.**
화면의 `f_R` 을 **같은 하한율의 과거 회차 후보**에서 만들면 정보집합 동등성(§3)을 지키면서 정확해진다.

**그리고 `sd(R)` 은 `N` 과 무관하다** (전 구간 0.00753~0.00768). 따라서 `f_R/g` 진단에서
**`f_R` 은 N 별로 다시 만들 필요가 없고 `g` 만 N 별로 가면 된다.**

**연도별로도 안정하다 — 좁아지지 않는다:**
```
2023  sd 0.007748  mean 0.998882  alpha 2.956%
2024     0.007546       0.998926        2.916%
2025     0.007571       0.998838        2.929%
2026     0.007695       0.998812        2.972%
```
**단조 축소가 없다. 규칙 변경도, 전략적 투표의 확산도 안 보인다.**
`sd(R)` 이 승부 창문의 13배라는 논증에 **유효기간이 붙지 않는다.**
(월 필드가 어느 npz 에도 없어 연 4점까지만 냈다.)

### 6-5 생성기 명세에 들어갈 것

```
후보    아래 8개 ~ U(0.97,1.00) · 위 7개 ~ U(1.00,1.03)   IID (층화 아님)
        -> 무작위 순열로 슬롯 1..15 에 배정
표      철회자 포함 전원 2표 · 슬롯별 실측 pi_k
선택    득표 상위 4 · 동점은 낮은 슬롯 우선 · 무득표 채움(가격 무관, 낮은 슬롯 3배 선호)
투찰    상한 = 기초가격 (xmax/R 이 1.30 을 넘는 회차 0 건)
관측    007 만 — R <= xmax 를 통과한 회차만 살아남는다   <- 이게 L1 의 진짜 시험이다

통과 기준  동점률 48.221% · 채움률 2.742% · 재구성 99.18%
          sd(R) 0.007605 · sd(mean r) 0.002166 · mean(D) 약 -2.0 bp
```
**마지막 줄이 핵심이다.** 생성기가 `mean(D)` 를 재현하면 우리 인과 이해가 맞은 것이고,
안 되면 아직 모르는 게 있다.

| 4 | "선택이 균등이 아니다 → 가격을 본다" | 귀무가 틀렸다. 투표 쏠림이 있으니 균등일 리가 없다 |

| 6 | `xmax` 에서 **철회자를 뺐다** | `ml-expert`·`stats-expert` 가 각각 지적했다. 낙찰자는 개찰 시점에 정해지고 철회는 그 뒤다 |

**#6 이 #5 만큼 위험했다.** 철회를 빼면 `xmax` 가 과소평가되고, §3-3 의 기각표집 제약이
과도하게 빡빡해져 **영분포가 인위적으로 더 음수가 된다 — 즉 "선택 편향이 전부 설명한다"는
결론이 공짜로 나온다.** 판정을 **내가 원하는 쪽으로 미는 방향의 버그**였다.

**그리고 항등식이 그걸 잡아 줬다:**
```
                          수정 전       수정 후
xmax ≥ R      (100% 여야)  99.814%  →  100.000%
xmax < Rmin   (0% 여야)     0.005%  →    0.000%
```
철회를 빼면 785 회차에서 "낙찰됐는데 아무도 커트라인을 못 넘었다"가 나왔다. 이제 예외가 0 이다.
**판정 여유는 z=+5.09 에서 z=+2.80 으로 절반 아래로 줄었다.**

> **규칙으로 남긴다: 검정에 들어가는 조건은 그 조건이 만족돼야 하는 자명한 항등식을 같이
> 출력하라.** `xmax ≥ R` 이 100% 여야 한다는 건 007 전수라는 사실에서 공짜로 나오는데,
> 그걸 찍지 않았으면 0.186% 의 어긋남을 못 봤다.

**#5 가 가장 위험했다.** 그 판으로 낸 1차 결과는 "안전 부분집합에서 +2.34 bp" 라는 부호까지
틀린 답이었고, **그대로 판정으로 낼 뻔했다.** 같은 행의 `EFT_ALL_AMT`·`SAJEONG_PCT` 는 멀쩡했다.

> **규칙으로 남긴다: 판정을 세우는 양은 두 경로로 만들어 서로 대조한 뒤에 쓴다.**
> ```
> x_A = EFT_ALL_AMT / (기초가 · 하한율/100)
> x_B = (SAJEONG_PCT / 하한율) · R          ← 금액을 아예 안 지나간다
> |x_A − x_B| / x_B < 1e-3 인 회차 99.982%
> ```
> 대조가 없었으면 못 잡았다. **비율이어야 하는 값이 백만 단위인데도 코드는 조용히 돌았다.**

**#1~#4 의 공통 교훈:** 구조 주장에는 항상 대조군을 붙인다. 그리고 **귀무가설이 애초에
참일 수 없는 것이면 기각해도 아무 말이 아니다.**

## §8 프론트엔드 재료로 무엇이 나왔나

이 실험의 원래 목적은 예측이 아니라 **"사용자에게 무엇을 보여줄 근거"** 였다. 나온 것:

| 재료 | 근거 | 성격 |
|---|---|---|
| **"번호 선택은 거의 항상 커트라인을 바꾼다. 그런데 어느 쪽인지는 알 수 없다"** | §5-7 | pi 94%+ 와 레버 검출 안 됨. **둘 다 측정값** |
| **"가격을 볼 수 있었다면 창문의 15배"** (오라클 89 bp) | §5-6 | 제도가 무엇을 막는지. 사장이 왜 이 게임을 하는지의 배경 |
| **`f_R` 중심 −11.3 bp = 승부 창문 1.95 개** | §6 | 🔴 **가장 큰 단일 오차원.** R 을 1.0 중심으로 놓고 위치를 잡으면 창문 2개만큼 어긋난다 |
| **`f_R` 층화축 = 하한율** (82 -> alpha 2.12% … 90 -> 2.98%) | §6-4 | **공고 시점에 알 수 있다.** as-of 안전 |
| **최적 x 가 N 에 따라 뒤집힌다** (1.019 -> 0.983) | 분기점 판정 | 안전집합에서도 서고 동적범위가 **35.9배**로 오히려 커진다 |
| **"철회해도 당신 표는 예정가에 들어간다"** | §2-2 | 아무도 모르는 규칙. 회차의 52.67% 에 해당 |
| **"동점이면 낮은 번호가 이긴다 (48.2% 회차에서 발생)"** | §2-3 | 위와 같음 |
| **개찰 후 `R` 완전 분해** — 이 회차의 15개, 누가 뭘 찍었는지, 왜 그 4개인지 | §2 | **사후 설명은 100% 가능하다.** 사전 예측이 불가능한 것과 별개다 |
| **`R` 의 실측 분포** (품목·연도·하한율·N 별) | §6 + `plist.npz` | 사용자가 자기 판단의 눈금으로 쓸 배경분포 |
| **낙찰 여유 `xmax − R`** 중앙 0.065 · p10 0.011 · p90 0.120 | §3-3 | "얼마나 아슬아슬했나" 를 회차마다 보여줄 수 있다 |

**낙찰률 편향의 방향을 정정한다.** 007 조건화가 낙찰률을 **위로** 올릴 것으로 예상했는데
반대였다 — 안전집합에서 오히려 **더 높다** (동적범위 28.2 -> 35.9배). 안전집합은 `xmax` 가 큰
회차라 경쟁자가 위쪽에 흩어져 **`R` 근처가 비고 위치의 값어치가 커진다.**

**설계에 대한 함의 하나:** `R` 은 투찰 시점에 예측 불가이지만 **개찰 후에는 완전히 설명
가능**하다. 이 비대칭이 화면을 가른다 — **투찰 전 화면은 분포를, 개찰 후 화면은 분해를**
보여주는 것이 데이터가 실제로 지지하는 구성이다.

## §8-B `M` 은 오염되지 않았다 — 행이 한 줄도 안 빠진다

`stats-expert` 가 정확한 진단을 냈다. H0 아래 `E[D|r] = (1/4)Σ_s (p_s − 4/15)·r_s` 이고
안전 부분집합은 `safe = 1{M ≥ Rmax}` 이므로, **편향이 생겼다면 `M` 을 통해서다.**
그리고 `ETC='낙찰 기준 미달'` 은 `bid < 하한율·예정가` 이므로 **`R` 의 함수다** —
그 행이 빠지면 `M` 이 오염된다.

**행 완전성 (n=233,155):**
```
투표자 수(철회 포함) == 공고의 BID_CNT      100.000%   예외 0 건
투찰 수(철회 포함)   == BID_CNT             98.519%   (평균차 −0.032, 금액 필터가 떤 것)
투찰 수(철회 제외)   == BID_CNT             46.883%
```
**`ds_bidList` 에 공고가 세는 입찰자가 한 명도 안 빠져 있고 우리 파싱도 한 명도 안 흘린다.**
`EFT_ALL_AMT` 를 쓰므로 `BID_CALC_AMT` 센티넬(= 낙찰 기준 미달, 투찰의 44.9%)도 안 잃는다.

**`corr(M, R)` 은 0 이 아니지만 그건 콜라이더 자체다:**
```
                  n        corr(M, R)   corr(M, mean r)
전체          233,155      +0.05589       +0.02855
안전(M≥Rmax)  177,359      +0.03231       +0.09602
나머지         55,796      +0.19217       +0.20326   ← 절단이 조이는 곳에 몰려 있다
```
007 표집이 `M ≥ R` 이므로 **`M` 과 `R` 이 독립이어도 살아남은 쌍에는 양의 상관이 생긴다.**
🔴 **이 진단은 우리가 연구 중인 바로 그것에 교란된다.** 행 완전성 쪽이 오염 가설을 직접 닫는다.

⚠ 다만 `stats-expert` 의 *"r 만의 함수로 골라도 평균은 안 움직인다"* 는 안 따라온다.
`E[D|r]` 이 **`r` 에 의존하므로** `r` 로 고르면 그 평균이 움직인다 — `safe` 는 `Rmax` 가 낮은
회차, 즉 **폭이 좁은 회차**를 더 담고, 폭이 좁으면 (A) 항이 0 쪽으로 줄어 `D` 가 위로 간다.
다만 순열 영분포가 이미 그걸 흡수한다(안전 부분집합 영평균 −0.005 bp).

## §8-C 🔴 `N≤2` 이상 현상 — 하나의 미해결. 두 군데로 나타났었다

§4-4 의 "채움 회차가 왜 +4.12 bp 인가"와 §4-2 의 "안전 부분집합이 왜 +0.54 bp 인가"는
**같은 하나다.** `ml-expert` 와 `stats-expert` 가 각각 같은 결론에 도달했다.

**질문이 잘못 놓여 있었다.** 채움 규칙의 낮은-슬롯 선호는 **이미 귀무 안에 있다**
(마스크 경험분포가 실제 채움 마스크를 담으니까). 물어야 할 건 "왜 양수냐"가 아니라
**"왜 귀무보다 위냐"** 였다. 그렇게 놓으면:

```
N≤2 · B-채움      n= 5,984   관측 +0.703   귀무 −3.830   차 +4.532 (z=+5.02)
N≤2 · A(규칙 미개입) n=10,588   관측 −2.189   귀무 −5.457   차 +3.268 (z=+4.92)
N≤2 · B-동점      n= 1,661                                차 +0.616 (z=+0.38)
N≥3 · A           n=110,137                               차 +0.183 (z=+1.06)
N≥3 · B-동점      n=104,375                               차 +0.012 (z=+0.07)
```
**규칙 그룹의 문제가 아니다. `N≤2` 의 문제다.**

### 배제한 설명 넷

| 후보 | 결과 |
|---|---|
| `xmax` 철회 제외 | ❌ 고쳐도 안 사라짐 (+0.564 → +0.542) |
| 철회 자체 | ❌ **반증.** `N≤2` 중 철회 0명인 회차(85.6%)에서 오히려 최대 (+4.381, z=+6.71) |
| 투찰행 손실 | ❌ `N≤2` 의 1.63% 뿐. 손실 없는 17,936 회차에서도 +3.331 (z=+6.49) |
| 서버 채움/동점 규칙 | ❌ 위 표 — A 그룹과 채움 그룹이 똑같이 크다 |

### 🔴 가장 유력한 설명: 귀무가 `N≤2` 에서 성립하지 않는다

**`N≤2` 에서 마스크는 뽑히는 게 아니라 계산된다.**
- `N=1` → 표 2개 → 득표 슬롯 2개 → **채움 2개가 결정론적**
- `N=2` → 표 4개 → 득표 슬롯이 4개면 **마스크가 표로 완전히 결정된다. 무작위성 0**

**마스크를 바꿔치기하는 순열 귀무는 "마스크에 무작위성이 있다"를 전제하는데 거기엔 없다.**
1~2명의 취향이 마스크를 결정하므로, 그 소수 업체가 비무작위면 기증자 풀이 안 맞는다.

**⟹ 이건 가격 가시성이 아니라 귀무 쪽 오설정일 가능성이 높다.** 확인 자리는 `BIZ_NO` 층화다.

### ⚠ 그리고 이건 판정을 안 바꾼다

`N≥3` (회차의 92.2%) 에서 잔차가 0 이다. **"투찰자는 가격을 못 본다"는 결론은 그대로이고,
`N≤2` 는 별도 이상 현상으로 분리해 적는다.** 크기가 승부 창문의 절반 이하이고 회차의
7.8% 에 몰려 있어 제품 판단을 안 바꾼다. **모른다고 적는다.**

## §8-C2 투찰금액에 상한이 있다

`ml-expert` 부수 발견:
```
xmax/R   p50 1.0588~1.0894   p99 1.145~1.149   🔴 1.30 초과 = 0 건
xmin < R 인 회차 69.3%   ← 커트라인 미달 투찰이 흔하다
```
`x/R = (투찰금액/예정가)·(100/하한율)` 이므로 상한 ≈ 1.145 는 **`투찰금액 ≤ 기초가격`** 과 맞는다.

**생성기의 투찰 분포에 이 상한을 넣어야 한다.** 생존 조건 자체는 여전히 한쪽(`R ≤ xmax`)이라
§3-3 의 귀무는 유효하다 — 상한은 `xmax` 의 분포를 제약할 뿐 조건을 양쪽으로 만들지 않는다.

## §8-D 동점 정의 — 하나로 박는다

세 좌석이 48.2% / 68.68% / 45.48% 로 달랐다. 전수로 갈랐다:

| 정의 | 비율 |
|---|---|

| C  득표 슬롯 < 4 (채움 필요) | 2.742% |
| D  B 또는 C | 48.221% |

**C ⊂ B 다** — 득표가 4개 미만이면 4위·5위가 둘 다 0 이라 자동으로 동점이다.
`득표≥4 AND 4위==5위` 는 48.221 − 2.742 = **45.479%**. **생성기 통과 기준은 B 를 쓴다.**
