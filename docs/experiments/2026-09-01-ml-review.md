## 0-✅. 개정 8 — 판정: **가격 가시성 기각. 보류를 해제한다** (단 "정확히 0"은 틀렸다)

**리더가 세 갈래로 독립 판정했고 전부 같은 답이다.**

```
① 기각표집 순열 (선택편향을 귀무 안에 넣음)
     H0 미반영   관측 −2.00 bp   영평균 −0.64   z = −10.06
     H0  반영    관측 −2.00 bp   영평균 −2.56   z = +5.09   ← 관측이 영분포보다 오히려 위
② 순수 부분집합 (xmax ≥ mean(가격 상위4) 인 174,228 회차 = 74.7%)
     mean(D) = +0.56 bp   영평균 −0.005      ← 음수가 사라진다
③ 득표수 × 가격 상관
     전체 −0.00553 (z=−10.11)  →  안전 부분집합 +0.00152 (z=+2.39)   ← 부호가 뒤집힘
```

## 0-⚠(기록). 개정 5 — §0-A 의 교환가능성 결론을 보류로 내렸던 기록

**리더의 전수 결과가 내 표본 결론을 뒤집었다. 내가 틀렸고, 틀린 방식이 중요하다.**

```
표본 3,000  (내 측정 5)      z = −0.66      "구분 안 됨"
전수 233,204 (리더)          z = −12.96     mean(D) = −2.00 bp, 귀무 SE 0.154 bp
올바른 귀무로 순열검정        z = −10.54     영분포 400회 중 관측 이하 0회
회차별 Spearman(슬롯,가격) 전수  +0.00488  SE 0.00055  z = +8.85   ← 0 이 아니다
```

### 🔴 내 잘못 — 신호가 내 데이터 안에 이미 있었고, 나는 검정을 안 했다

측정 1에서 나는 이렇게 적었다:
> *"평균 0.0124 · sd 0.2701 → sd 가 무작위 순열 이론값 0.267 과 일치한다. 균등 순열이다."*

**`sd` 가 맞는 것과 `평균` 이 0인 것은 다른 주장이다. 나는 후자를 검정하지 않았다.**
내 표본으로 지금 계산해 보면:
```
SE = 0.2701 / √3994 = 0.00427       z = 0.0124 / 0.00427 = 2.90     p ≈ 0.004
```
**내 자신의 표본에서 이미 유의했다.** 나는 산포 하나를 맞춰 보고 구조를 선언했다.

> 🔴 **이번 라운드에서 나는 같은 실수를 세 번 했다.**
> ① 후보 분포를 균등으로 가정 (sd 만 맞춰 보고) — 측정 7 에서 반증
> ② 풀링 리샘플로 정정 (주변분포만 맞춰 보고) — 측정 10 에서 반증
> ③ 순열 무작위성 선언 (sd 만 맞춰 보고) — 전수에서 반증
>
> **전부 "한 모먼트가 맞으니 구조가 맞다"였다.** 이건 우연이 아니라 **내 기본 실패 모드**다.
> §4-4 원칙에 규율로 박는다: **"분포 주장에는 검정을 붙여라. 모먼트 일치는 검정이 아니다."**

### 보류로 내리는 것 — 확정으로 두면 안 된다

| 항목 | 상태 | 이유 |
|---|---|---|

**🔴 화면 재료를 왜 특히 세게 내리는가.** 그건 *"이건 안 중요하다"* 를 사장에게 **증명으로** 제시하는 재료였다. 만약 실제로 조금이라도 중요하다면, 우리는 사장의 주의를 아껴 준 게 아니라 **레버를 뺏은 것**이 된다. 그리고 그 오류는 **사장이 스스로 발견할 수 없다** — 우리가 근거를 갖고 말했으니까. **비대칭이 최악이라 후보에서 뺀다.**

### ⚠ 그런데 아직 "가격을 본다"로 결론 내려서도 안 된다 — 대안 가설이 살아 있다

리더가 지목한 콜라이더가 실재한다: **우리 코퍼스는 007(낙찰) 전수**이고, `낙찰 ⟺ max_j x_j ≥ R` 이므로 **R 이 낮은 회차가 살아남기 쉽다.** 007 만 모은 것 자체가 `mean(D) < 0` 을 만든다.
N 구간별 z 가 큰 N 에서 사라지는 것(51+ 에서 z=−1.16)은 **두 가설이 똑같이 예측하는 모양**이다.

**§0-D 에 내가 제안하는 판별 절차를 적었다.**

> ⚠ **개정 5: 아래 측정 1·5·6 과 그에 딸린 결론은 §0-⚠ 에 따라 보류 상태다. 측정 2·3·4·7·8·9·10 은 유효하다.**

**재현 스크립트:** `docs/experiments/scripts/2026-09-01-mechanism-probe.py` · `2026-09-01-r-distribution-probe.py`
**표본:** 233,382 파일 중 무작위 4,000(측정 1~4) · 3,000(측정 5). `ds_pList` 15행 · `CHC_YN='Y'` 4개인 회차만.

### 측정 1 — 번호(seq)는 가격 정보를 담지 않는다

```
회차별 Spearman corr(CMNM_PLNPRC_SN, CMNM_PLNPRC_RT)
  평균 0.0124 · 중앙값 0.0107 · sd 0.2701 · |ρ|>0.5 비율 5.9%
```
**sd 0.2701 은 15개 무작위 순열의 이론값 1/√14 = 0.267 과 일치한다.**
→ **번호↔가격 배정은 회차마다 새로 뽑는 균등 순열이다.**

### 측정 2 — 투표는 극단적으로 비균등하다

```
P(선택 | seq)      순수추첨이면 4/15 = 0.267 이어야 한다
  seq 1  0.468   seq 2  0.634   seq 3  0.749   seq 4  0.392   seq 5  0.530
  seq 6  0.244   seq 7  0.427   seq 8  0.197   seq 9  0.173   seq10  0.072
  seq11  0.037   seq12  0.027   seq13  0.020   seq14  0.013   seq15  0.018
                                                          (합 = 4.000 ✅)

DRAW_NO 상위 (균등이면 각 1/105 = 0.95%)
  '1,2' 6.8% · '5,3' 4.9% · '2,3' 4.4% · '7,3' 4.2% · '4,3' 3.7%
  DRAW_NO 채움률 181,964/181,964 = 100% · 고유값 정확히 105 = C(15,2)
```

### 측정 3 — 그 편향은 N 이 커질수록 **더 날카로워진다**

```
                 seq1-5 평균   seq11-15 평균   차이
  N ≤ 3   471회      0.425         0.095      +0.330
  N 4-6   542회      0.572         0.031      +0.540
  N 7-12  783회      0.564         0.025      +0.539
  N > 12 2198회      0.575         0.005      +0.570      seq3 = 0.856
```
**N>12 에서는 최다득표 4개 집합이 사실상 결정론적이다** — 거의 항상 {1,2,3,4,5,7} 안에서 나온다.
**즉 "경쟁자들의 표"는 투찰 전에도 거의 맞출 수 있다.**

### 측정 4 — 그런데 R 분포는 N 과 무관하다

```
sd(R)   N≤3 0.00768 · N4-6 0.00753 · N7-12 0.00793 · N>12 0.00761
```

### 측정 5 — 🔴 결정적: 실제 R 은 순수추첨과 구별되지 않는다

같은 회차의 15개 비율에서 **4개를 균등 비복원 추출**한 대조군을 만들어 직접 대조했다.
```
  실제 R    n=2996  mean 0.998719  sd 0.007544  p5 0.98588  p95 1.01070
  대조군    n=2996  mean 0.999105  sd 0.007709  p5 0.98695  p95 1.01205
  sd 비 = 0.979
  2-표본 KS  D = 0.0287  <  임계값(5%) 0.0351   →  분포 구분 안 됨
```

### 🔴 귀결 — 두 무작위화가 상쇄된다

```
투표      최다득표 4개 슬롯    ← 강하게 편향돼 있고, 예측 가능하다
순열      슬롯 ↔ 가격 배정      ← 회차마다 균등 무작위

슬롯이 교환가능하므로, 어떤 규칙으로 4개 슬롯을 고르든
R = 15개 가격 중 4개를 균등 비복원 추출한 평균 이다.
```
**메커니즘은 투표식이 맞지만, R 의 분포는 계획이 원래 적은 "15개 중 4개 추첨 평균" 그대로다.**
설계자가 의도한 상쇄로 보인다. 그리고 이건 **가정이 아니라 측정 5로 확인된 사실**이다.

| **R** | 추정할 분포 | 표를 알면 결정론적 | ⚠ **투찰 시점엔 여전히 순수 난수.** 표를 다 알아도 무의미 |
| **경쟁자 수 N** | 추정 | as-of 관측 | ⚠ **미결 — §0-B 의 함정** |
| **경쟁자 위치 X** | 추정 | 미지수 | ✅ **미지수. 유일하게 남은 진짜 미지수** |
| **경쟁자들의 표** | 없던 개념 | 새 미지수 | ❌ **미지수가 아니다.** 예측 가능하고, 예측해도 값이 0 |

**→ 진짜 문제는 하나로 줄었다: 경쟁자가 어디에 넣나(X).**
그리고 그건 계획이 원래 잡은 그림이고, **판정 1(밀도 추정으로 재구성)이 정확히 그 자리다.**

### 측정 6 — 🔴 강한 교환가능성 검사: 내 표는 레버가 아니다 (개정 3)

리더가 *"경쟁자 표는 개찰 후지만 **내** 표는 내가 고른다 — 행동 공간이 `(x, 15개 중 2개)` 다"* 라고 제기했다. **제기 자체는 옳다.** 측정 1(순위상관)만으로는 이걸 못 닫는다 — 순위상관은 **꼬리·산포 의존을 못 잡는다.** 그래서 더 강한 검사를 돌렸다. 표본 6,000 회차.

```
기대: 각 슬롯이 최대/최소가 될 확률 = 1/15 = 0.0667

 seq   P(max)   P(min)   E|비율−중앙값|   평균비율
   1   0.0733   0.0629     0.014470      0.998828
   5   0.0706   0.0641     0.014238      0.999424
   6   0.0601   0.0701     0.014519      0.998799
  15   0.0652   0.0651     0.014303      0.998839          (15칸 전체는 스크립트 출력)

 P(max) 범위 0.0601~0.0733   ( 1/15 ± 2SE = 0.0602~0.0731 )
 P(min) 범위 0.0629~0.0719
 카이제곱 (df=14, 5% 임계 23.68)   P(max) 14.51   P(min) 10.72   → 둘 다 통과
 슬롯별 산포 E|비율−중앙값|  0.01420 ~ 0.01485  (균일)
 슬롯별 평균비율             0.99880 ~ 0.99942  (균일)
```

**순위·극단값·산포·평균 넷 모두에서 슬롯이 구별되지 않는다.** 교환가능성이 성립한다.

**그래서 정리가 성립한다 — 근사가 아니라 증명이다:**
```
S = g(내 표, 남의 표)        4개 슬롯 집합. 내 표가 S 를 바꾸는 것은 사실이다
P = (P₁ … P₁₅)              슬롯↔가격 배정. 표와 독립이고 슬롯에 대해 교환가능 (측정 1·6)
R = mean{ Pₖ : k ∈ S }

교환가능성 ⟹ 임의의 S 에 대해 {Pₖ : k∈S} 의 분포는 "15개 중 균등 비복원 4개"와 동일
        ⟹ R | 내 표  의 분포가 105가지 선택 전부에서 같다
```

> 🔴 **내 표는 조작 변수가 맞다. 그런데 보수와 독립인 조작 변수다.**
> `S` 를 바꾸는 것은 사실이고, `S` 를 바꿔도 `R` 의 분포가 안 바뀐다.
> 결정이론에서 이건 **행동 공간에서 제거해도 되는 차원**이다.

**`stats-expert` 의 지적("내 2표가 R 추첨에 들어가니 P2 는 엄밀히 거짓")도 같은 자리에 선다.** 그는 **의존성**을 지적했고 그건 맞다 — 하지만 그 의존성이 **보수에 전달되지 않는다.** 오염도 아니고 레버도 아니다. **엄밀히는 거짓이지만 결과적으로 무해한 가정**이다.

**⚠ 이 정리가 깨지는 조건은 정확히 하나다: 슬롯↔가격 상관 ≠ 0.**
측정 1·6이 그걸 4가지 방식으로 부정했다. 그리고 §4-4 생성기에 **그 손잡이를 이미 넣어 두었다**(L3) — 상관을 켠 세계에서는 표 예측이 레버가 되고, 그때의 증상을 미리 기록해 둔다.

### 측정 7 — ⚠ 후보 비율은 균등분포가 아니다 (개정 3, `stats-expert` 의 평균 불일치 해결)

```

**균등이 아니다.** 왼쪽으로 살짝 치우쳐 있고, 양 끝이 얇다(경계/격자 효과로 보인다).

**이게 `stats-expert` 의 "평균이 안 맞는다"의 원인이다.** 불일치는 R 이 아니라 **후보 생성 쪽**에 있다.
```
sd    이론(균등) 0.017321  ·  실측 0.016962   비 0.979   → sd 유도는 거의 그대로 유효
평균  이론(균등) 1.000000  ·  실측 0.999064   차 −0.000936
```
**커트라인 = 하한율 × R 이므로, 커트라인이 기초가 대비 체계적으로 0.094% 낮다.**
🔴 **승부 창문이 0.058% 다. 이 평균 편차가 창문의 1.6배다 — 무시하면 안 된다.**
(선행분석의 `R 평균 0.99868` 이 이미 이 값을 담고 있었다. 새로 밝혀진 것은 **그 원인**이다.)

**생성기 명세 수정 — 내 개정 2가 틀렸다.**
`u_k ~ U(0.97, 1.03)` 이라고 적었는데 **균등이 아니다.** 그리고 이건 내가 §4-4 에 스스로 적은 **원칙 1("특징 분포를 지어내지 않는다 — 경험분포에서 리샘플")을 예비가격에만 안 지킨 것**이다. 정정한다:
> **`u_k` 는 실측 경험분포에서 리샘플한다.** 균등 근사는 **sd 유도(§0-A ①)에만** 쓰고, **평균과 꼬리에는 쓰지 마라.**

### 측정 8 — ✅ `BID_DT` 확인: 투찰 정정에 의한 중복이 없다 (개정 3)

리더가 *"`BID_DT` 가 최초 제출인가 최종 수정인가 — 같은 `BIZ_NO` 가 여러 행인지 물어라"* 라고 했다. **직접 쟀다.** 표본 6,000 회차 · 투찰 276,425행.
```
BID_DT 채움                              276,425 / 276,425 = 100.00%
같은 회차에 같은 BIZ_NO 가 2행 이상인 회차       0 / 6,000 = 0.00%
BID_DT ≠ LAST_CHG_DT 인 투찰                276,425 / 276,425 = 100.00%
```
- **중복 행이 0건이다 → 도착 곡선이 정정으로 왜곡되지 않는다.** 리더의 우려는 해소된다.
- `LAST_CHG_DT` 는 전건이 `BID_DT` 와 다르다 → **레코드 최종 수정 시각(개찰 처리 등)이지 투찰 시각이 아니다.** `BID_DT` 를 써라.
- ⚠ **남은 미결 하나:** "중복 행 0건"은 *"정정이 없었다"* 가 아니라 *"정정하면 덮어쓴다"* 일 수도 있다. 덮어쓰기라면 `BID_DT` 는 최종 정정 시각이고 **실제 도착보다 늦다** → as-of N 이 **과소** 추정된다.
  🔴 **다행히 이 방향은 안전하다** — 과소 추정은 정보를 덜 주는 쪽이라 **누출을 만들지 않는다.** 도착 곡선 해석에만 주의를 달면 된다.

### 측정 9 — 🔴 분산 분해: `sd(D)` 는 `sd(R)` 이 아니다 (개정 4)

리더가 정확 조건부 검정으로 `귀무 sd(D) = 0.0074286` 을 내고 **"E3 의 σ 를 이 값으로 교체하라"** 고 했다. **검정은 옳다 — KS 보다 낫고, 후보 분포 가정 없이 성립한다. 받는다.** 다만 **그 값은 E3 이 필요로 하는 양이 아니다.** 표본 7,996 회차로 분해했다.

```
R_i = mean(r_i) + D_i           r_i = 그 회차 후보 15개

  sd(R)             0.0076051   ← 🔴 E3 이 필요한 값 (회차 간 R 의 산포)
  sd(mean(r_i))     0.0021294   ←    회차별 후보 평균의 산포
  sd(D)             0.0073454   ←    회차 내 선택 산포 (리더의 0.0074286)

분해 검산   Var(M) + Var(D) + 2Cov = 5.849e−5 − 6.5e−7 = 5.784e−5 = Var(R)   ✅ 정확히 닫힌다
            Cov(M,D) 상관 −0.0208  (n=7996 에서 SE 0.0112 → 유의하지 않음. 귀무와 일치)
```

**`sd(D)` 는 "후보 15개를 이미 안다고 할 때 남는 불확실성"이다.** 투찰 시점의 사장은 후보 15개를 모른다. **E3 = 0.00760 이지 0.00743 이 아니다.**

🔴 **그런데 이 둘의 차이 자체가 값진 VoI 계산이다 — 해석적으로 나온다:**
```
지금 사장의 커트라인 불확실성            sd 0.00760
후보 15개를 완벽히 알았을 때 남는 것      sd 0.00735       ← 3.3% 감소뿐
승부 창문                                 0.00058          ← 여전히 12.7배
```
> **후보 목록이 통째로 유출돼도 커트라인 불확실성이 3% 줄 뿐이다.**

**이건 §0-A 말미의 "급소"를 상당 부분 defuse 한다** — 그리고 급소를 더 날카롭게 만든다. §0-A 말미를 그에 맞춰 고쳤다.

### 측정 10 — 🔴 후보 15개는 iid 가 아니다. 8/7 층화다 (개정 4)

측정 9에서 `sd(mean(r_i))` 가 iid 예측의 **절반**(0.00213 vs 0.00434, 비 0.4911)이었다. 원인을 찾았다. 표본 7,996 회차.

```

   8개   7,601   0.9506      ← 🔴 95%의 회차에서 정확히 8개
   7개     394   0.0493         (반올림 경계로 보인다)
   6개       1   0.0001

정렬 후 인접 간격 평균
  0.00330 0.00325 0.00332 0.00333 0.00332 0.00327 0.00321 │ 0.00677 │ 0.00366 0.00373 0.00363 0.00358 0.00374 0.00370
                                                     8|9 자리만 2배 ↑ (그 간격만 cv 0.65, 나머지 0.87)

두 덩어리
  아래 8개   덩어리평균 0.985442   내부sd 0.007817   회차간 sd(평균) 0.003319

**생성 규칙은 대략 이것이다:**
```
8개 ~ U(0.97, 1.00)          7개 ~ U(1.00, 1.03)
```

```

🔴 **그리고 이것이 `stats-expert` 의 "평균이 1.0 이 아니다"의 최종 원인이다.** 균등분포의 비대칭이 아니라 **8:7 이라는 설계된 층화**다. 후보가 아래쪽에 하나 더 많다.

**⚠ 그래서 내 개정 3 생성기 명세도 아직 틀렸다.** 나는 *"경험분포에서 15개 iid 리샘플"* 로 고쳤는데, **그것도 틀렸다:**
```
풀링 경험분포에서 15개 iid 리샘플 →  sd(mean r) = 0.00447  (참값 0.00213 의 2.1배)
                                  →  sd(R)      = 0.0086   (참값 0.0076 보다 13% 과대)
```
**주변분포는 맞추지만 8/7 층화를 놓치기 때문**이다. 정정한다 — §4-4 에 반영했다.

> **교훈: 나는 "지어내지 마라, 경험분포를 써라"를 두 번 적용하고 두 번 틀렸다.**
> 첫 번째는 균등을 가정해서(측정 7), 두 번째는 **주변분포만 맞추고 결합 구조를 놓쳐서**(측정 10).
> **경험분포 리샘플은 독립을 가정한다.** 층화·제약이 있으면 주변분포가 맞아도 틀린 세계를 만든다.
> §4-4 원칙 1에 이 단서를 달았다.

### ⚠ 이 결론 전체가 기대는 가정 하나

> **개찰 전 응답이 `seq ↔ 가격` 대응을 노출하지 않는다.**

|---|---|---|
| 아무것도 | sd 0.00760 | 현 상태 |

### 그럼에도 얻은 것 넷 — 전부 값한다

**① E3(이론 상한)의 구조는 닫힌 형태다. 다만 상수는 유도하지 말고 실측하라.**

⚠ **개정 2에서 나는 `0.017321`(균등 가정)을 써서 `0.00768` 을 유도했다. 그 유도는 폐기한다** — 측정 7(균등 아님)과 측정 10(8/7 층화)이 그 입력을 부정했다.

**살아남는 것: 구조.** `sd(R) = σ·√(¼·11/14)` 의 계수 `0.4432` 는 **4-of-15 비복원 추출에서만 나오고 후보 분포 모양에 전혀 의존하지 않는다.** 리더의 지적이 옳다.
**바뀌는 것: σ.** 가정하지 말고 회차별 실측 분산을 쓴다.

```
E3 상한 (개정 4 확정)
  sd(R)  = 0.00760      ← 회차 간 R 의 산포. 투찰 시점 사장의 커트라인 불확실성
  sd(D)  = 0.00735      ← 후보 15개를 이미 안다고 할 때 남는 것
  창문     0.00058

  → 커트라인 불확실성이 승부 창문의 13.1배
  → 후보 목록이 통째로 유출돼도 12.7배 (3.3% 감소뿐)
```
🔴 **E3 을 실험으로 재지 말고 위 세 줄로 확정하라.** 계획 §4 순서 4번이 하루로 줄어든다. 그리고 **완벽한 정보로도 못 넘는 선이 확정**되므로 §4-3 의 오라클 눈금이 실데이터에서도 정확해진다.

**② 🔴 `DRAW_NO` 는 VoI 절차의 완벽한 양성 대조군(positive control)이다.**
- 중간변수(어느 슬롯이 뽑히나) 예측력이 **거의 완벽하다** — N>12 에서 seq3 는 85.6%

- **우리 VoI 코드가 여기에 양의 값을 주면 코드가 고장난 것이다**

내가 §2-6d 에 제안한 난수 영점 재료보다 **이쪽이 훨씬 강한 검사다 — 현실적인 0**이라서.
난수 재료는 예측력도 0이라 "예측력이 없어서 VoI 가 0"인지 "예측력은 있는데 결정과 무관해서 0"인지 못 가른다. **`DRAW_NO` 는 후자를 정확히 시험한다.** §2-6d 의 영점 검사에 추가하라.

**③ `DRAW_NO` 는 두 번째 선택 변수인데, 증명 가능하게 무의미하다 — 그리고 그게 화면 재료다.**
계획의 *"x = 내가 고르는 유일한 값"* 은 문자 그대로는 틀렸다. 번호도 고른다.
하지만 슬롯이 교환가능하므로 **105가지 선택이 전부 기댓값이 같다.**
**그런데 경쟁자들은 그렇게 안 믿는다** — 6.8%가 '1,2'를 찍고, seq 11~15 는 사실상 아무도 안 고른다.

> **화면에 놓을 실물 재료가 여기서 나온다: "번호 선택은 결과를 바꾸지 않는다."**

사장의 주의를 아끼게 해 주는 값이고, **헌법 1번(예측·추천가 금지)에 안 걸린다** — 추천이 아니라 **무의미함의 증명**이다. 그리고 이건 VoI 가 0 이어서 화면에서 빼는 재료가 아니라, **"VoI 가 0 이라는 사실 자체"가 값을 하는 드문 경우**다. 설계 문서 §0 의 세 칸(VoI=0 → 안 놓는다) 표에 **넷째 칸**이 필요하다.

**④ 합성 생성기 명세가 구체 숫자로 확정됐다** → §4-4 에 반영했다.

## 0-D2. 🔴 "가격 가시성" vs "007 선택 편향" 을 가르는 절차 (개정 5 제안)

리더가 `max_j x_j ≥ max(후보 15개)` 부분집합을 칼로 쓰고 있다. **논리는 맞다** — 그 부분집합에서는 어떤 4개가 뽑혔어도 낙찰되므로 007 조건부가 무정보다. 그리고 `max(후보)` 는 가격 벡터의 함수지만 **H0 아래 선택 마스크가 가격 벡터와 독립이므로 그 함수로 조건부해도 H0 가 보존된다.** 검정은 유효하다.

**⚠ 다만 두 가지를 미리 정해야 한다.**

**① 검정력을 먼저 보고하라.** `max_j x_j ≥ max(후보) ≈ 1.03` 을 만족하려면 누군가 하한의 3% 위로 넣어야 한다. **그 부분집합이 작으면 "효과가 사라졌다"가 아니라 "볼 수 없었다"가 된다** — 내가 표본 3,000 에서 겪은 것과 정확히 같은 실패다.
> **판정 전에 적어라: 이 부분집합의 `n` 과, 거기서 −1.37 bp 를 검출할 검정력.**
> **검정력이 80% 미만이면 음성 결과를 "편향이었다"로 읽지 마라. "결론 없음"이다.**

**② 그 부분집합은 무작위가 아니다.** 누군가 크게 위로 넣은 회차 = 경쟁이 특이한 회차다. 품목·N 구성이 전체와 다를 수 있다. **부분집합의 품목×N 분포를 전체와 대조해서 같이 보고하라.**

### 🔴 더 나은 칼 — 순열검정에 생존 제약을 넣어라

리더의 순열검정은 이미 옳은 귀무(`선택 마스크 ⊥ 가격 배정`)를 쓴다. **한 줄만 고치면 콜라이더가 귀무 안으로 흡수된다:**

```
현재      셀 안에서 다른 회차의 15칸 마스크를 이 회차 가격판에 붙인다
고침 🔴   붙인 마스크가 낙찰을 못 만들면 (R(m) > max_j x_j) 기각하고 다시 뽑는다
```

**근거.** 우리 코퍼스에 있는 회차는 전부 `max_j x_j ≥ R` 을 만족한 것이다. 그러니 **귀무 세계의 회차도 같은 필터를 통과해야 한다.** 지금 순열은 그 필터 없이 마스크를 붙이므로 **귀무가 관측보다 덜 편향돼 있고, 그 차이가 곧 콜라이더 몫**이다. 필터를 넣으면 영분포 평균이 `−0.6303 bp` 에서 더 내려가고, **남는 초과분만이 진짜 가격 가시성이다.**

**그리고 몬테카를로가 필요 없다 — 닫힌 형태로 정확히 계산된다:**
```
C(15,4) = 1,365 개 부분집합을 전부 열거한다  (233,204 × 1,365 = 3.2억, numpy 로 몇 분)

E_H0[D | 낙찰]  =  Σ_S p(S)·D(S)·1{max_j x_j ≥ R(S)}  /  Σ_S p(S)·1{max_j x_j ≥ R(S)}

p(S)  = 마스크 분포. 셀 안 다른 회차들의 실제 마스크 경험분포를 쓴다
        (투표 쏠림 구조를 보존한다 — 리더의 순열과 같은 원리)
```
`plist.npz` 에 판이 이미 굳어 있으니 **입력은 `max_j x_j` 하나만 더 있으면 된다.**
🔴 **이 값이 콜라이더 가설의 정확한 예측치다.** 관측 `−1.9987 bp` 가 이 값과 같으면 **전부 선택 편향**이고, 유의하게 아래면 **그 차이가 가격 가시성**이다. 부분집합으로 자를 필요가 없고 **전수를 다 쓴다.**

### 🔴 독립적인 두 번째 칼 — 업체 정체성으로 가른다

**두 가설이 다른 것을 예측한다:**

| | 가격 가시성 | 007 선택 편향 |
|---|---|---|
| 효과가 업체별로 다른가 | ✅ **다르다.** 가격을 보고 고르려면 **볼 줄 알아야** 한다 — 반복 참여·고빈도 업체에 몰린다 | ❌ **같다.** 콜라이더는 회차 수준 현상이고 업체와 무관하다 |
| 1회성 업체 | 효과 없거나 약함 | **전체와 같은 크기** |

```

       각 층에서 D 기여분을 따로 낸다   ← 마스크는 투찰자 단위라 분해가 자연스럽다

**전수를 쓰고, 부분집합 검정력 문제가 없다.** 그리고 `BIZ_NO` 가 `ds_bidList` 에 있으니 (측정 8) 바로 된다.

⚠ **교란 하나:** 고빈도 업체가 특정 품목·지역에 몰려 있으면 그게 섞인다. **품목×N 구간 안에서 층화해서 보라.**

### 🔴 그리고 이건 따로 물어야 한다 — 메커니즘 질문과 레버 질문은 다르다

**설령 가격 가시성이 확정돼도, 사장이 쓸 수 있느냐는 별개다.** 지금 숫자로 상한을 잡을 수 있다:

```
전체 효과            −1.37 bp   (순열 초과분 (B))
승부 창문             5.8 bp
개인 몫 상한          내 표는 2N 표 중 2표 → 대략 전체 효과의 1/N

  N = 3   →  약 0.5 bp   (창문의 8%)
  N = 10  →  약 0.14 bp  (창문의 2%)
  N = 50  →  약 0.03 bp  (창문의 0.5%)
```
> **가장 유리한 경우(N=3)에도 창문의 10% 미만이다.**

**그래서 화면 판정은 과학 결과와 거의 무관하게 안정적이다** — 다만 **문구가 달라진다:**
- ❌ ~~*"번호 선택은 결과를 바꾸지 않는다"*~~ — **증명이 아니므로 못 쓴다**
- ✅ 후보: *"번호 선택의 영향은 승부 창문의 N% 미만이다"* — **수치를 동반한 약한 주장.** 검정이 끝나야 숫자를 채울 수 있다

**⚠ 이 상한 계산 자체가 근사다.** `1/N` 은 표 수 비례를 가정한 것이고, 동점 처리와 비선형성이 있으면 틀린다. **위 열거 계산(`E_H0[D|낙찰]`)을 돌릴 때 "내 표 2개만 바꿨을 때 R 이 얼마나 움직이나"를 같은 코드로 같이 내라** — 그게 개인 레버의 정확한 값이고, 부수 비용이 0이다.

## 0-F. 🔴 개정 9 — 슬롯↔가격 상관은 007 인공물이다 (측정 11)

`data-inventory` 가 규칙을 읽어 와 **`mean(D)` 의 99.6% 를 재구성**했고(동점 = 낮은 슬롯 우선 98.1%, 채움·동점 모두 **가격 무관**), 동시에 §5 에 스스로 경고를 달았다:

**그 경고가 맞았다. 직접 쟀다** (`tools/mechanism/11_slot_price_corr_is_collider.py`, 전수 233,122):

전체         233,122   −2.0025 (z=−13.21)      +0.003860  (z = +7.00)

**구조적으로 명확하다.** 007 필터는 `max_j x_j ≥ R` 이고 `R` 은 **뽑힌 슬롯**의 가격 평균이다. 투찰자가 낮은 슬롯을 찍으므로 **"낮은 슬롯이 마침 싼 판"이 살아남기 쉽다** — 그게 양의 Spearman 이다.

### 인과 사슬에서 ②가 거짓이다

```

② 낮은 슬롯이 체계적으로 조금 싸다    ❌ 007 인공물. 안전 부분집합에서 0
③ 서버가 동점을 낮은 슬롯 우선        ✅ 참 (98.1%, 가격 무관 z=−0.11)

**①과 ③이 참이어도 ②가 없으면 D 가 안 나온다.** 슬롯이 가격 정보를 안 담으면 **어떤 슬롯 기반 규칙도 `E[D]=0`** 이다.

> 🔴 **⟹ 규칙 재구성이 99.6% 를 맞춘 것은 설명이 아니라 회계다.** 관측된 판을 그대로 쓰니 콜라이더를 같이 재생한 것이다.

### ⚠ 내 앞선 추정 둘을 정정한다

### 부수 발견 — 투찰금액에 상한이 있다
```
xmax/R   p50 1.0588~1.0894   p99 1.145~1.149   🔴 1.30 초과 0건

⚠ **생존 조건은 여전히 한쪽(`R ≤ xmax`)이라 귀무는 유효하다** — 상한은 `xmax` 분포를 제약할 뿐 조건을 양쪽으로 만들지 않는다. 다만 **생성기의 투찰 분포에 이 상한을 넣어야 한다.**

전체(오염)              69.32  구조 있음     1.1338 bp     0.5278       0.7075    → 초과
안전집합(깨끗)           8.84  🔴 0 과 구분 안 됨   0.5239 bp     0.6092       0.8256    → 🔴 미달
                                                        ↑ 관측이 영분포 평균보다 오히려 아래 (상위 25.8%)
```

> 🔴 **콜라이더를 제거하면 슬롯↔가격 구조가 통계적으로 존재하지 않는다**(χ²=8.84, p≈0.84).
> **관측된 0.52 bp 는 전부 추정 잡음이다** — 순수 잡음의 기대값 0.61 bp보다도 작다.

### ⚠ 단순 비례 축소를 하면 안 된다

리더가 *"rho 가 25.8배 작으니 0.63/25.8 = 0.024 bp"* 로 갈 수 있는데 **그건 틀린다.**
`rho` 는 **단조 정렬**을 재고 지렛대는 **δ 의 최대·최소**를 쓴다. 콜라이더가 빠지면 정렬은 무너져도 **δ 의 잡음 산포는 남는다.** 그래서 지렛대 추정치는 25.8배가 아니라 **잡음 바닥으로 내려앉는다.**

### ✅ 개정 12 — 레버를 **직접** 계산했다 (인수분해 안 함)

리더가 `레버(N) = (1/4)·[(δ상위2 합)−(δ하위2 합)]·π(N)` 로 인수분해하자고 했다.
🔴 **그 공식을 쓰면 안 된다** — `δ` 가 잡음일 때 `상위2−하위2` 는 **max 통계량이라 위로 편향**된다. 내가 §2-6d 에서 VoI 에 대해 경고한 바로 그 편향이다.

**대신 직접 계산했다:** *"내가 항상 번호쌍 `c` 를 고른다면 기대 커트라인이 얼마나 달라지나."*
105쌍 전부에 대해 `V_others + e_c` 로 득표 재집계 → 동점은 낮은 슬롯 우선 → `R_c`.
안전집합 177,334 회차. `tools/mechanism/17_vote_lever_direct.py` · `18_vote_lever_by_N.py`

```
구간          n        전략레버      영분포(슬롯↔가격 독립)   오라클 상한   π(내 표가 top-4 를 바꿈)
전체     177,334     0.298 bp     0.367 ± 0.082         88.98 bp     0.717
N<=2      14,832     1.457        2.224 ± 0.397        227.12        0.999
N=3-4     18,132     1.266        1.396 ± 0.120        163.30        0.984
N=5-9     34,943     0.884        0.823 ± 0.112        121.60        0.940
N=10-29   49,432     0.380        0.513 ± 0.071         78.79        0.817
N=30-99   33,724     0.380        0.464 ± 0.093         28.88        0.444
N=100+    26,271     0.323        0.285 ± 0.080         13.32        0.234
```

### 🔴 세 가지가 나온다

**① 모든 N 구간에서 레버가 영분포 안이다.** 전체는 오히려 영분포 평균보다 **아래**다(0.298 < 0.367). **어디서도 검출되지 않는다.**

**② `π` 는 매우 크다 — `stats-expert` 의 시뮬 추정치(0.63/0.45/0.30/0.17)보다 훨씬 크다.**
```
N≤2  0.999   N=3-4  0.984   N=5-9  0.940   N=10-29  0.817
```
**작은 판에서는 내 두 표가 거의 항상 최다득표 4개를 바꾼다.**

**③ 그런데 레버는 0이다. 그리고 이 둘이 같이 서는 것이 이 결과의 핵심이다.**
> **"내 표가 결과를 바꾸는가"(예, 94%+)와 "그 변화가 나에게 유리한가"(아니오)는 다른 질문이다.**
> `π ≈ 1` 인데 레버가 0 인 이유는 **`δ` 가 0** 이기 때문이다. **그래서 `δ·π` 인수분해가 위험하다** —
> `π` 가 1에 가까우니 `δ` 추정의 잡음이 그대로 레버로 넘어온다. **직접 계산이 유일하게 안전하다.**

### 🔴 오라클 상한 — 제도가 무엇을 막고 있는지 보여준다

**가격을 볼 수 있다면** 105쌍 중 최선을 고르는 값어치:
```
전체 88.98 bp  ·  N≤2 227.12 bp        승부 창문 5.8 bp
                                        → 창문의 15배 ~ 39배
```
**가격이 공개됐다면 번호 선택이 압도적 레버였을 것이다.** §0-A 의 "급소"(개찰 전 `seq↔가격` 공개 여부)가 왜 급소였는지 이 숫자가 정량적으로 뒷받침한다. **그리고 제도가 정확히 그것을 막고 있다.**

### ✅ 화면 문구용 최종 숫자와 문구

```
번호 선택이 커트라인을 바꾸는 비율   N≤9 에서 94% 이상  ·  N=100+ 에서도 23%
그 변화의 방향을 예측한 값어치        검출되지 않음 (전략레버 0.30 bp < 영분포 0.37 bp)

```
> **문구 후보:**
> ***"번호 선택은 거의 항상 커트라인을 바꿉니다. 그런데 어느 쪽으로 바뀔지는 알 수 없습니다."***

**이 문구가 앞선 후보들보다 나은 이유 셋:**
1. **참이고 둘 다 측정됐다** — `π` 도 레버도
2. **사장이 모르던 것을 알려준다** — "내 표가 실제로 결과를 움직인다"는 사실 자체가 새 정보다
3. **그런데 행동으로 옮길 수 없다는 것도 같이 말한다** — 헛된 노력을 막는다

⚠ **"0 이다"로 쓰지 마라.** 개정 5에서 그걸로 한 번 틀렸다. **"검출되지 않는다"가 참이고 갱신 가능하다.**

⚠ **"0 이다"가 아니라 "검출 한계 아래다"로 써라.** 전자는 다시 증명 주장이 되고, 우리는 개정 5에서 그걸로 한 번 틀렸다. **후자는 참이고, 표본이 커지면 갱신 가능하다는 것까지 정직하게 전달한다.**

## 0-I. 🔴 개정 14 — T3 앵커에 콜라이더가 섞여 있다

`stats-expert` 가 서명한 3중 게이트의 **T3(앵커)** 는 *"모형의 개선폭 > 「`f_R` 중심을 −11.3 bp 로 고치기만 한 것」의 개선폭"* 이다. **그 `−11.3` 이 007 조건부 값이다.**

```
007 전수    E[R]−1 = −11.332  =  후보생성 −9.332   +  선택 E[D] −2.000
안전집합    E[R]−1 =  −9.485  =  후보생성 −10.027  +  선택 E[D] +0.542
나머지      E[R]−1 = −17.202

앵커 후보 셋:  007 −11.33  ·  안전집합 −9.49  ·  🔴 해석적 −10.0
차이 1.85 bp = 승부 창문(5.8)의 0.32
```

### 왜 007 값을 앵커로 쓰면 안 되나

**007 = "누군가 낙찰됐다". 사장이 계산할 것은 "내가 낙찰된다".**
007 조건부 `R` 분포를 쓰면 **생존 사건을 두 번 세는 셈**이라 "낮은 투찰이 통과하는 빈도"를 과대평가하고 **사장을 필요 이상으로 낮게 넣도록 민다.**

⚠ **안전집합 값(−9.49)도 답이 아니다.** `xmax ≥ Rmax` 가 **가격이 낮은 회차를 골라내므로** 후보 생성 평균 자체가 조건부다(−10.027). `E[D]` 는 깨끗해도 `E[mean r]` 은 아니다.

### ✅ 정답은 해석적으로 나온다 — 추정이 필요 없다

```
E[mean r] = (8 × 0.985 + 7 × 1.015) / 15 = 0.99900     →  −10.00 bp
E[D]      = 0                (선택이 가격 무관 — §0-F 판정)
E[R] − 1  = −10.00 bp                                    ← 앵커는 이것
```
**안전집합 실측(−10.027)이 이 값과 0.03 bp 안에서 맞는다** — 독립 확인.

> **T3 앵커를 `−11.3` → `−10.0` 으로.** 차이 1.3 bp 는 창문의 0.22 이고,
> **앵커가 곧 게이트 문턱이므로 이 오차가 그대로 게이트 높이의 오차가 된다.**
> 앵커를 너무 높게 잡으면 **통과했어야 할 모형이 떨어진다.**

⚠ **이건 통계가 아니라 결정 문제 정의다** — *"사장의 결정이 007 조건부인가"* 가 전제이고 나는 아니라고 본다(이기려면 유찰이 아니어야 하지만 결정 시점에는 미정이다). **리더가 정할 일이고, 생성기가 숫자로 가른다** — 관측 필터를 켠 세계와 끈 세계 양쪽에서 앵커를 재면 어느 쪽이 사장이 마주하는 세계인지 보인다.

## 1. 문헌 — 무엇을 풀었나 / 우리와 어디가 같고 다른가 / 쓸 수 있는 결과

⚠ **읽은 수준을 각 항목에 표시했다.** 대부분 초록 + 논문 페이지 요약 수준이고, 본문까지 본 것은 표시했다.

### 1-1. 표 형태 데이터에서 GBDT vs 신경망 — 2022 이후 논쟁

| 문헌 | 읽은 수준 |
|---|---|
| Grinsztajn, Oyallon, Varoquaux, *Why do tree-based models still outperform deep learning on tabular data?* (NeurIPS 2022 D&B, arXiv 2207.08815) | 초록 + 페이지 |
| McElfresh et al., *When Do Neural Nets Outperform Boosted Trees on Tabular Data?* (NeurIPS 2023 D&B, arXiv 2305.02997) | 초록 + 페이지 |
| Erickson et al., *TabArena: A Living Benchmark for Machine Learning on Tabular Data* (NeurIPS 2025 D&B, arXiv 2506.16791) | 초록 + 논문 요약(alphaXiv) — 표는 못 봄 |
| Gorishniy et al., *TabM: Advancing tabular deep learning with parameter-efficient ensembling* (ICLR 2025, arXiv 2410.24210) | 초록 |
| Holzmüller et al., *Better by Default: Strong Pre-Tuned MLPs and Boosted Trees on Tabular Data* (RealMLP, NeurIPS 2024) | 초록 |
| Hollmann et al., *Accurate predictions on small data with a tabular foundation model* (TabPFN v2, Nature 637:319, 2025) + *A Closer Look at TabPFN v2* (arXiv 2502.17361) | 초록 |

**무엇을 풀었나.**
2022 년 Grinsztajn 은 45 개 데이터셋(주로 ~1만 행)에서 트리가 이긴다는 것을 보이고, **왜**인지를 셋으로 정리했다 — 신경망은 ① 무정보 특징에 약하고 ② 데이터의 축 방향(orientation)을 보존하지 않으며 ③ 불규칙한(irregular) 함수를 배우기 어렵다.
2023 년 McElfresh 는 176 개 데이터셋 · 19 개 알고리즘으로 다시 재고 **논쟁 자체가 과장됐다**고 결론냈다: 성능 차이는 대개 미미하고, **"GBDT 를 가볍게 튜닝하는 것이 GBDT 냐 NN 이냐를 고르는 것보다 중요"**하며, GBDT 의 실질 우위는 **치우친/두꺼운 꼬리 분포와 데이터 불규칙성**에서 온다.
2025 년 TabArena 는 51 개 데이터셋(500~25만 행) · 16 개 모델을 **200 회 무작위 탐색 + 8-fold 내부 CV**로 재고, 세 체제로 나눠 보고했다:

```
기본값(default)        CatBoost 계열이 앞선다
튜닝(tuned)            CatBoost 1위
튜닝 + 사후앙상블      TabM · RealMLP 가 GBDT 와 같거나 낫다
소규모(≤1만 행)        TabPFNv2 가 튜닝 없이도 앞선다
```
그리고 저자들의 결론 한 줄: **"GBDT 를 이기는 모델을 찾는 것보다 앙상블에서 잘 작동하는 모델을 찾는 것이 더 중요하다."**

**우리와 같은 점.** 우리 인자는 구조화된 표 형태다. 규모(회차 23만)가 TabArena 상단(25만)과 겹친다.
**우리와 다른 점 셋.**
1. **우리 목표는 점 예측이 아니라 조건부 분포다.** 위 벤치마크는 전부 분류/회귀 정확도다. 분포 추정에서의 순위는 저 표에 없다.
2. **우리는 고카디널리티 범주가 있다** — 학교 ID, 업체 ID, 시군구 51종+, 품목 세분류. 위 벤치마크 데이터셋에는 이런 축이 드물다. **여기가 신경망 임베딩이 전통적으로 이기는 곳이고, 위 결과가 그대로 이전되지 않는다.**
3. **우리는 구조를 안다.** 벤치마크의 모든 모델은 구조를 모르는 상태를 가정한다.

**쓸 수 있는 결과.**
- **"표 형태에서는 GBDT 가 정설"이라는 M5 의 전제는 2022 년 판이다.** 2025 년 판은 *"앙상블 예산을 주면 비긴다, 그리고 둘을 섞은 앙상블이 둘 다 이긴다"* 이다.
- 신경망 후보를 고를 때 **FT-Transformer · SAINT 계열은 후순위다.** TabM 논문은 attention/retrieval 계열의 복잡도가 값을 못 한다고 명시했고, TabArena 에서 실제로 앞선 것은 **TabM 과 RealMLP** — 둘 다 MLP 계열이다.
- TabPFN v2 는 **1만 행 상한**(v2.5 로 10만 근처까지)이라 우리 전체 코퍼스에는 못 쓴다. 하지만 **품목×지역으로 잘랐을 때 수천 행짜리 조각**에는 정확히 맞는 도구다 — 개인 축(투찰 3,926)과 희소 품목에 후보로 남긴다.

### 1-2. 구조를 아는 문제에 기계학습을 얹는 법

| 문헌 | 읽은 수준 |
|---|---|
| Wei & Jiang, *Estimating Parameters of Structural Models Using Neural Networks* (Marketing Science, arXiv 2502.04945) — 이하 **NNE** | 초록 + 페이지 |
| Zammit-Mangion et al., *Neural Methods for Amortized Inference* (arXiv 2404.12484) | 초록 |
| Philipp et al., *Robust parameter estimation and identifiability analysis with hybrid neural ODEs* (npj Syst Biol Appl, 2024) | 초록 + 페이지 |
| PIML 개관: Royal Society Phil. Trans. A, *Physics-informed ML and its structural integrity applications* (2023) | 초록 |

**무엇을 풀었나.**
PIML 개관은 구조 지식을 넣는 방식을 넷으로 정리한다 — **손실 함수 · 아키텍처 · 사전학습 · 하이브리드(물리 모형 + ML 부품)**. 우리에게 맞는 것은 넷째다.
NNE 가 훨씬 직접적이다: **구조 모형을 여러 파라미터 값으로 돌려 합성 데이터셋을 대량 생성하고, "데이터셋의 모먼트 → 파라미터"를 신경망에 학습시킨다.** 학습된 망은 새 데이터셋에 대해 즉시 추정치와 정확도를 낸다. 훈련 데이터셋 수가 늘면 **제한정보 베이즈 사후분포로 수렴**하고, 저자들은 시뮬레이션 비용이 큰 응용에서 SMM 보다 **더 정확한 추정을 더 싼 비용에** 낸다고 보고한다. 부수 성질로 **불필요한 모먼트 입력에 강건**하다.
하이브리드 신경 ODE 문헌은 반대편 경고를 준다: **신경망 부품을 넣으면 기계론적 파라미터의 식별 가능성이 깨질 수 있다.** 유연한 근사자가 구조 파라미터가 설명해야 할 몫을 먹는다.

**우리와 같은 점.** 우리도 "구조는 알고 두 미지수만 모른다"이고, **시뮬레이터를 쓸 수 있다**(§4 의 생성기). NNE 의 전제와 정확히 같다.
**우리와 다른 점.** NNE 는 관측이 적고 시뮬레이션이 비싼 상황을 겨눈다. 우리는 **관측이 많고 시뮬레이션이 싸다.** 그래서 NNE 를 그대로 쓸 필요는 없고, **NNE 의 학습 절차를 §3-1 의 합성 검증에 재사용**하는 쪽이 값이 크다.

**쓸 수 있는 결과.**
- **M1 안에 신경망을 넣는 것이 M5 를 따로 여는 것보다 낫다.** 경쟁자 위치 분포 `X | z` 와 경쟁자 수 `N | z` 를 신경망으로 파라미터화하면, 구조는 그대로 두고 유연성만 얻는다.
- 그때 **식별 가능성 경고를 반드시 붙여라.** `N | z` 와 `X | z` 를 둘 다 완전 자유롭게 두면 서로 몫을 뺏는다 — 실데이터에서는 N 이 개찰 후 관측되므로 **N 을 먼저 지도학습으로 고정하고, X 를 그 위에서 추정**하는 2단 절차가 안전하다.

### 1-3. 확률 보정 — 화면에 확률을 놓기 위한 전제

| 문헌 | 읽은 수준 |
|---|---|
| van den Goorbergh et al., *The harm of class imbalance corrections for risk prediction models* (JAMIA 29(9):1525, 2022) | 초록 + 요약 |
| *Challenges in the calibration of tree-based models for imbalanced classification* (arXiv 2412.16209) | 초록 |
| *Using Platt's scaling for calibration after undersampling — limitations* (arXiv 2410.18144) | 제목만 |
| Gruber & Buettner, *Better Uncertainty Calibration via Proper Scores* (OpenReview) / ECE 편향 문헌 | 초록 |

**무엇을 풀었나.**
van den Goorbergh 는 시뮬레이션과 난소암 사례로 **언더샘플링 · 오버샘플링 · SMOTE 가 전부 소수 클래스 확률을 강하게 과대추정**하고, **AUC 는 전혀 개선하지 않음**을 보였다. 결론이 강하다 — *"결과 불균형은 그 자체로 문제가 아니다. 불균형 보정이 오히려 성능을 나쁘게 할 수 있다."* 민감도/특이도 균형이 필요하면 **문턱을 옮기면 된다.**
트리 모델 쪽 후속(2412.16209)은 언더샘플링 후 **해석적 보정(샘플링 비율로 되돌리기)이 실패**함을 보인다 — 편향이 샘플링 비율뿐 아니라 **분할 시 고려하는 예측변수 개수에도 의존**하고, 통념과 달리 **결정 트리가 소수 클래스 쪽으로 편향될 수도** 있다. 처방은 **학습형 보정(beta calibration)**.
보정 지표 쪽: **ECE 는 proper scoring rule 이 아니다** — 균일 확률을 뱉는 자명한 예측기도 좋은 값을 받을 수 있고, **binning 경계에 민감**해 예측이 좋아져도 단조 감소하지 않는다.

**우리와 같은 점.** 낙찰률 1.9%, 화면에 확률을 놓으려는 목표, 그리고 계획이 이미 "보정 안 된 확률은 화면에 못 쓴다"를 못박은 것 — 방향이 맞다.
**우리와 다른 점.** 🔴 **우리 불균형은 진짜가 아니다.** 임상 예측은 사건이 실제로 드물지만, 우리는 **경쟁자의 x 를 전부 관측한다.** 낙찰 여부는 그 분포의 부산물이다(§2-2).

**쓸 수 있는 결과.**
- **리샘플링 · 클래스 가중치를 쓰지 마라. 설계 문서에 금지로 박아라.** 이건 "안 하는 게 낫다"가 아니라 **우리 목적(정직한 확률)에 정면으로 해롭다.**
- 주 지표를 **log loss / Brier(그리고 Brier 의 보정-분해능-불확실성 분해)** 로 하고, reliability curve 는 그림으로, **ECE 는 단독 판정 근거로 쓰지 마라.** 현재 §6 표는 "Brier · 보정"만 적혀 있어 이 구분이 없다.
- 보정을 하게 되면 **isotonic 또는 beta**. Platt 은 언더샘플링 뒤에 특히 위험하다.

### 1-6. 특징 중요도 vs 정보의 값어치 — SHAP 이 VoI 를 대신할 수 있나

> **답: 못 한다. 리더의 추측이 맞다.** 근거는 셋이고, 그중 하나는 문헌이 아니라 정의에서 바로 나온다.

| 문헌 | 읽은 수준 |
|---|---|
| Kumar, Venkatasubramanian, Scheidegger, Friedler, *Problems with Shapley-value-based explanations as feature importance measures* (ICML 2020, arXiv 2002.11097) | 초록 + 페이지 |
| *Feature Importance: A Closer Look at Shapley Values and LOCO* (arXiv 2303.05981) | 제목 + 검색 요약 |
| Brennan et al., *Calculating partial EVPI via Monte Carlo sampling algorithms* (Med Decis Making 27:448, 2007) | 초록 + 요약 |

**① 정의에서 나오는 이유 (문헌 없이 성립).**
SHAP 은 **모델의 예측값이 어떻게 분해되는가**를 잰다. VoI 는 **최적 행동의 argmax 가 바뀌는가**를 잰다. 예측값이 크게 움직여도 사장이 고르는 x 격자점이 안 바뀌면 **SHAP ≫ 0 이고 VoI = 0** 이다. 이건 설계 문서 §0 이 이미 옳게 적은 구분("맞추지만 행동과 무관한 값")이고, **SHAP 은 그 구분을 원리적으로 할 수 없다.**

**② Kumar 2020.** Shapley 값의 게임이론적 정식화가 실무의 설명 목적과 **맞지 않는다**고 주장한다. 수학적 문제들이 생기고, 그것을 완화하려면 **인과 추론 같은 추가 복잡도가 필연적으로 요구**된다. 저자들의 권고는 **해석이 명확한 좁은 상황 외에는 사용을 삼가라**는 것이다.

**③ 상관된 특징.** 우리 재료들은 서로 강하게 상관돼 있다(`최근 3회` · `잘 나온 구간` · `학교 중앙값`은 같은 이력에서 나온다). Shapley 값은 상관을 제거하지 않는다 — E7(재료 간 중복)의 답을 SHAP 으로 내려 하면 **중복이 값어치로 잘못 배분된다.**

**쓸 수 있는 결과.**
- **SHAP 을 순위표의 근거로 쓰지 마라.** 다만 **버려서도 안 된다** — 절제(ablation) 결과와 SHAP 이 **크게 어긋나면 그건 구현 버그의 신호**다. 진단 도구로만 쓰고, 그렇게 문서에 적어라.
- 대안으로 문헌이 주는 것은 **LOCO(leave-one-covariate-out)** 계열인데, 이것도 여전히 "예측력"이지 "결정 개선"이 아니다. **VoI 를 직접 계산하는 것 말고는 대체재가 없다.** 계산 절차는 §2-6.

### 1-7. 🔴 경쟁 상대 모델링 — 우리 문제와 가장 가까운 문헌은 경매경제학이 아니라 광고 실시간입찰(RTB)이다

| 문헌 | 읽은 수준 |
|---|---|
| Ren et al., *Deep Landscape Forecasting for Real-time Bidding Advertising* (KDD 2019, arXiv 1905.03028) | 초록 + 페이지 |
| Zhu et al., *An Efficient Deep Distribution Network for Bid Shading in First-Price Auctions* (KDD 2021, arXiv 2107.06650) | 초록 + 페이지 |
| Wu et al., *Predicting Winning Price in Real Time Bidding with Censored Data* (KDD 2015) | 초록 |
| *Deep Censored Learning of the Winning Price in RTB* (KDD 2018) / ADM(Arbitrary Distribution Modeling) | 검색 요약 |

**무엇을 풀었나.**
RTB 의 핵심 문제는 우리 문제의 **거울상**이다: *"내가 b 를 넣으면 이길 확률은 얼마인가"* 를 위해 **시장가(경쟁자 최고가)의 조건부 분포**를 예측한다. 그리고 그쪽은 **검열(censoring)** 을 안고 있다 — 지면 시장가를 못 보고 "내 입찰가보다 높다"만 안다.
DLF(KDD'19)는 이를 **생존분석 + RNN** 으로 푼다. 가격 격자를 따라 **조건부 승리 확률**을 RNN 으로 유연하게 모형화하고, 확률의 연쇄법칙으로 분포 전체를 유도한다. **분포 형태에 대한 사전 가정을 두지 않는 것**이 기여점이고, 검열/비검열 관측에 대한 **두 개의 음의 로그가능도 손실**을 end-to-end 로 최적화한다.
Deep Distribution Network(KDD'21)는 1가 경매에서 **비검열·검열 양쪽**을 다루며, 목적함수를 정확도가 아니라 **잉여(surplus)** 로 놓는다. 보고된 개선은 CPM +2.4% · CPC +2.4% · CPA +8.6%.

**우리와 같은 점 — 매우 많다.**
- 예측 대상이 점이 아니라 **분포**다.
- 최종 목적이 정확도가 아니라 **결정(얼마를 넣을까)** 이다. 설계 문서 §6 의 "정확도가 아니라 결정 개선"과 정확히 같은 자리에 서 있다.
- 특징이 표 형태 + 고카디널리티 범주(광고주·지면 ↔ 학교·업체)다.
- 신경망이 실제로 채택돼 있고, **그 이유가 "표 형태에서 NN 이 좋아서"가 아니라 "조건부 분포를 유연하게 짜야 해서"** 다.

**우리와 다른 점 — 그리고 그 차이가 우리에게 유리하다.**
| | RTB | 우리 |
|---|---|---|
| 경쟁자 관측 | **검열됨** (지면 상한만) | 🔴 **전수 관측** (개찰 후 전원의 투찰) |
| 커트라인 | 없음 | **있음** (R, 그리고 관측됨) |
| 경쟁자 수 | 모름 | 개찰 후 관측 |

**RTB 는 우리보다 어려운 문제를 신경망으로 풀고 있다.** 이건 "우리도 신경망 쓰자"가 아니라 **"우리 문제가 그 문헌의 축소판이고, 그쪽 도구가 초과 사양으로 들어맞는다"** 는 뜻이다.

**쓸 수 있는 결과.**
- **경쟁자 최소 x 의 조건부 분포를 직접 모형화하라.** 낙찰 이진 분류가 아니라. 이게 §0 판정 1의 실행형이다.
- 검열 처리 부분(생존분석 손실)은 우리에게 **필요 없다** — 그만큼 단순한 손실(그냥 조건부 밀도의 로그가능도)로 간다. 문헌보다 쉬운 길이 열려 있다.
- 목적함수를 **잉여/마진**으로 놓는 KDD'21 의 설계는 설계 문서의 "낙찰 수 · 기대 마진" 지표와 직결된다. 다만 원가 대리값이 없으면(설계 §11) 이 목적함수를 못 쓴다 — **원가 대리값 정의가 생각보다 앞 순서에 와야 한다.**

**무엇을 풀었나.** EVPPI(부분 완전정보의 기대값)는 **"불확실 파라미터의 어떤 부분집합을 알게 되면 얼마나 값이 있나"** 를 정확히 우리 VoI 와 같은 형태로 정의하고, **중첩 몬테카를로**(바깥 루프: 관심 파라미터, 안쪽 루프: 나머지)로 계산한다. 그리고 **핵심 경고**: 몬테카를로 추정치들의 **최대값은 위쪽으로 편향**되며, 표본이 작으면 EVPI 추정치가 편향된다.

**우리와 같은 점.** 정의가 같다. "재료 s 를 알면 최적 행동이 달라지고 결과가 나아지나."
**우리와 다른 점 — 그리고 이게 우리에게 유리하다.** 보건경제는 반사실 결과를 **모형으로만** 낼 수 있다. 우리는 **회차의 경쟁자 전원 투찰과 R 을 사후에 안다** — 다른 x 를 넣었을 때의 결과를 **정확히 재생**할 수 있다. 그래서 **OPE 의 IPS/DR 추정량이 필요 없다.**

**쓸 수 있는 결과.** §2-6 에 절차로 적었다. 특히 **max 편향 방어 장치**는 우리 계획에 없다.

## 2. 우리 계획을 때린다

### 2-1. M5 의 여는 조건 셋 — 하나는 유지, 하나는 삭제, 하나는 방향이 거꾸로다

```
1. M4 가 B1 을 유의미하게 이긴다
2. M4 의 상호작용 진단에서 고차 상호작용이 검출된다
3. M1 과 M4 의 차이가 설명 안 된다
```

**조건 1 — 유지.** 인자에 신호가 있어야 그 다음이 의미 있다. 옳다.

**조건 2 — 삭제하라. 근거가 없고, 진짜 기회를 막는다.**
- 문헌 어디에도 *"신경망이 GBDT 를 이기는 이유가 고차 상호작용"* 이라는 결과가 없다. Grinsztajn 이 든 세 이유는 **무정보 특징 · 축 방향 · 불규칙 함수**이고, 셋 다 **GBDT 에 유리한 방향**이다. TabArena 가 든 이유는 **앙상블**이다. 상호작용은 등장하지 않는다.
- 게다가 **GBDT 로 고차 상호작용을 진단하는 절차 자체가 신뢰할 수 없다.** Friedman H-통계량류는 상관된 특징에서 불안정하고, 우리 재료는 강하게 상관돼 있다(§1-6 ③).
- 🔴 **그리고 이 조건은 우리 문제에서 신경망이 이길 **실제** 자리를 정확히 비껴간다.** 그 자리는 **고카디널리티 범주 임베딩**(학교 ID · 업체 ID · 품목 세분류)이다. 이건 상호작용이 아니라 **표현(representation)** 문제이고, 상호작용 진단에 안 잡힌다.

**조건 3 — 방향이 거꾸로다.** *"M1 과 M4 의 차이가 설명 안 되면"* 열겠다는 것인데, 이건 **M1 과 M4 가 잘 맞을수록 M5 를 영영 안 열게 된다.** 그런데 둘이 잘 맞아도 셋째가 더 잘할 수 있다. 이건 **게이트가 아니라 결과**다 — 실험 뒤에 보고할 사실이지 실험 전에 거는 조건이 아니다.

### ✅ 개정 13 — 분기점 판정 이후에도 조건 셋을 그대로 둔다

`data-inventory` 가 *"평평하지 않다 · 최적 x 가 N 에 따라 1.019 → 0.983 으로 뒤집힌다 · 층화는 N 하나"* 를 냈다. 리더가 **M5 조건을 바꿀지** 물었다. **답: 바꾸지 않는다.**
- 조건 1·2 는 N 뒤집힘과 **무관**하다 (특히 조건 2 의 학교ID·업체ID 는 N 과 직교)
- **조건 3 은 오히려 더 유용해진다** — 최적 x 가 N 에서 부호를 뒤집으면 **그 상호작용을 못 잡는 모형은 특정 N 구간에 미보정이 몰린다.** 진단 장치가 설계대로 작동하는 자리다
- 그리고 **뒤집힘이 `g` 의 모양에서 나오고 N 하나로 설명된다면 그건 구조 모형이 유리하다는 근거이지 신경망 근거가 아니다** (§3-10 "잔차 출처가 X 하나로 좁혀진다"와 같은 방향)

**대신 인자 규율을 하나 추가한다** (§3-2 에):
> **`N` 과 `N × x` 상호작용은 M1·M2·M4·M5 전부에 들어간다. 어느 하나가 빠지면 비교가 무효다.**

### 🔴 그리고 "층화는 N 하나"에 경고 둘

**(a) 그 판정을 품목별로 냈나.** 풀링 코퍼스에서 나온 것이면 **품목은 여전히 N 층 *안에서* 갈릴 수 있다.** §2-5A 의 규율이 정확히 이 경우를 겨눈다. **품목×N 으로 다시 내라** — 안 갈리면 그때 확정이고 그것도 결과다.

**(b) 🔴 as-of N 은 정확하지 않고, 뒤집힘이 그 오차를 치명적으로 만든다.**
```
T−1h   중앙 99.3%   p10 84.0%     ← 회차의 10% 는 최종 N 의 84% 만 보인다
```
보통 측정오차는 추정치를 **감쇠**시키는 데 그친다. 그런데 **부호가 뒤집히는 구간에서는 N 을 조금만 틀려도 반대편으로 가므로 손실이 비대칭적으로 커진다.** 따라서:
1. **as-of N 정확도가 부차 사항이 아니라 1차 요구사항이다** — `T−1h` 권고(§0-B)의 근거가 여기서 더 강해진다
2. **모형이 N 을 점추정이 아니라 분포로 받아야 한다** (errors-in-variables). **M3(계층)이 그 자리**이거나 별도 측정오차 모형이 필요하다
3. **화면이 N 의 불확실성을 같이 보여야 한다.** 뒤집힘 지점 근처에서 *"지금 보이는 참여자 수로는 어느 쪽인지 모릅니다"* 가 정직한 표시이고, **그건 VoI 가 높은 재료다** — 정보가 결정을 실제로 바꾸는 지점이니까

⚠ **(b)는 내 추론이다.** 뒤집힘 지점 근처 회차 비율과 그 구간의 as-of N 오차를 안 쟀다. **재면 화면 설계가 바뀔 수 있는 크기라고 본다.**

---

**(개정 1의) 대신 제안하는 조건 셋:**
```
1. M4 가 B1 을 유의미하게 이긴다                        (유지)
2. 고카디널리티 범주 재료(학교ID·업체ID·품목세분류)의 절제 하락폭이 0 이 아니다
   → 임베딩으로 얻을 것이 있다는 직접 증거
3. M1 의 보정 곡선이 특정 구간(품목·경쟁밀도)에서 체계적으로 벗어난다
   → 구조가 못 잡는 이질성이 있고, 그 형태가 유연한 함수를 요구한다
```

**그리고 여는 방식을 바꿔라.**
- ❌ *"M5 = 낙찰 여부 신경망 분류기, M4 와 단독 대결"*
- ✅ **M5 = M1 의 `X|z`·`N|z` 를 신경망으로 파라미터화한 것.** 구조는 유지하고 유연성만 바꾼다. 그러면 M1 vs M5 가 **같은 축 위의 두 점**이 되고, 지면 "신경망이 안 된다"가 아니라 **"이 자리에는 이만큼의 유연성이면 충분하다"** 는 해석 가능한 결론이 나온다.
- 그리고 TabArena 의 결론대로 **단독 승부가 아니라 앙상블 구성원으로도 재라.** GBDT+NN 혼합 앙상블이 둘 다 이기는 것이 2025 년의 표준 결과다. 이걸 안 재면 우리는 **틀린 이분법을 검증하는 셈**이다.

**⚠ 한 가지는 계획이 옳다.** *"안 되면 그 사실을 결과로 적는다"* — 이건 유지하고, 조건을 바꾼 뒤에도 유지하라.

### 2-2. 🔴 표본 1,058만인데 신경망을 뺀 게 맞나 — 질문 자체가 틀렸다

계획의 자기 진단은 *"행 수는 많지만 회차 23만이고 낙찰은 회차당 1건"* 이다. 이건 **낙찰을 예측 대상으로 놓았을 때만** 맞다.

**우리가 실제로 추정해야 하는 것은 둘이고, 각각의 표본이 다르다:**

| 추정 대상 | 실효 표본 | 불균형 | 어디에 맞는 도구 |
|---|---|---|---|
| **R 분포** | 회차 23만 (회차당 1 실현) | 없음 | 경험분포 + 해석적 유도 |
| **N \| z** (경쟁자 수) | 회차 23만 (회차당 1 관측) | 없음 | 계수 회귀(음이항). GBDT 로 충분 |
| **X \| z** (경쟁자 위치) | 🔴 **투찰 1,058만** | **없음** | 조건부 밀도 추정 — **여기가 신경망 자리** |
| Y1 낙찰 이진 | 회차 23만 · 양성 1.9%/투찰 | 심함 | ← **이렇게 짜면 안 된다** |

**핵심.** 낙찰 여부를 이진 분류로 짜는 순간 우리는 **1,058만 개의 관측된 경쟁자 위치를 "0" 이라는 한 비트로 압축**한다. 같은 정보를 밀도 추정으로 쓰면 **표본이 1,058만이고 불균형이 없다.**

**그래서 실효 표본 판정은 이렇다:**
- **모집단 축에서 표본은 부족하지 않다.** 품목 5 × 연 3 으로 쪼개도 회차는 만 단위, 투찰은 수십만 단위다.
- **표본 부족이 결론이 될 수 있는 곳은 셋뿐이다** — ① 개인 축(낙찰 75), ② 희소 품목(수산·김치의 특정 지역), ③ `n=1` 학교. 셋 다 계획이 이미 지목했다.
- **신경망을 기본에서 뺀 결정 자체는 옳다.** 다만 이유가 계획에 적힌 이유("표본은 크지만 표 형태라서")가 아니라 **"구조 모형이 같은 표본을 훨씬 효율적으로 쓰기 때문"** 이어야 한다. 그리고 그 구조 모형 **안에서** 신경망이 다시 후보가 된다.

**⚠ 파생 결과 — 설계 문서 §6 을 손봐야 한다.** *"AUC 를 주 지표로 쓰지 않는다. 낙찰률 1.9% 에서 실무 의미가 얇다"* 는 옳지만, **밀도 추정으로 재구성하면 이 문장이 필요 없어진다.** 주 지표는 **조건부 로그가능도 / CRPS** 가 되고, 낙찰 확률의 보정은 그것의 **파생 지표**다.

### 2-3. M1 과 M4 를 "같은 인자"로 비교하는 설계는 공정하지 않다

계획 §3-2 는 *"M1·M2·M4·M5 가 같은 인자 집합을 쓴다. 다르면 비교가 성립하지 않는다"* 고 못박았다. **인자를 통일하는 것은 필요하지만 충분하지 않고, 이 문제에서는 오히려 오도한다.**

**이유.** M1 은 생성 모형이고 M4 는 판별 모형이다. 같은 인자를 줘도 **학습 신호가 다르다:**
```
M1 이 쓰는 것   회차별 경쟁자 전원의 x  +  15개 예비가격  +  R      (회차당 수십 개 실수)
M4 가 쓰는 것   won ∈ {0,1}                                       (회차당 1 비트)
```
같은 인자를 줘도 **M1 은 M4 보다 수십 배 많은 정보를 본다.** 그래서 "M1 이 M4 를 이겼다"는 **구조의 승리인지 라벨의 승리인지 갈리지 않는다.**

**제안 — 공정성의 단위를 바꿔라.**
| | 통일할 것 | 통일하지 말 것 |
|---|---|---|
| ✅ | **정보 집합** (as-of 절단 · 원본이 그 시점에 준 것 전부) | |
| ✅ | **평가 대상과 지표** (같은 예측 대상에 대한 같은 proper score) | |
| ✅ | **시간 분할** | |
| ❌ | | 인자 목록을 문자 그대로 동일하게 |
| ❌ | | 라벨 형식 |

그리고 **M4 를 두 판 돌려라:**
```
M4a  낙찰 이진 분류               ← 계획의 현재 형태. "라벨만 볼 때의 상한"
M4b  경쟁자 최소 x 회귀/분포 예측  ← M1 과 같은 라벨. 이게 진짜 대조군
```
**M1 vs M4b 가 공정한 비교이고, M4a vs M4b 의 격차가 "구조를 안 쓰고 라벨만 볼 때 얼마나 버리는가"를 수치로 준다.** 후자는 그 자체로 보고할 값어치가 있는 발견이다.

### 2-4. 탐색 예산을 같게 주는 것은 공정한 비교가 아니다

**문헌 근거 둘이 정면으로 충돌한다.**
- McElfresh: **"GBDT 를 가볍게 튜닝하는 것이 GBDT 냐 NN 이냐보다 중요"** → 탐색 횟수를 같게 하면 GBDT 가 먼저 포화한다.
- TabArena: **NN 은 사후 앙상블 없이는 못 이긴다.** 앙상블은 탐색 횟수가 아니라 **계산량**을 먹는다. "탐색 횟수 동일"은 NN 에서 앙상블 예산을 빼앗는다.
- 벤치마킹 방법론 문헌의 표준 처방은 **"같은 GPU-시간 / 같은 실행시간"**, 즉 **계산 예산 일치(compute-matched)** 다.

**제안 — 두 축으로 보고하라. 하나로 하면 어느 쪽이든 부당하다.**

| 축 | 규칙 | 답하는 것 |
|---|---|---|
| **A. 기본값(default)** | 각 방법의 **저자 권장 기본값 1회**. 탐색 0 | *"손을 안 대면 뭐가 낫나"* — 실무 판정에 가장 가깝다 |
| **B. 예산(budget)** | **동일 벽시계 시간**. 그 안에서 각자 자기 방식대로 쓴다 (GBDT 는 탐색에, NN 은 앙상블에) | *"끝까지 밀면 뭐가 낫나"* — 상한 판정 |

그리고 **예산을 구체 숫자로 못박아라.** 계획 §6 이 "예산 구체값 미정"으로 남겼는데, 이게 남아 있으면 §3-4 의 규율("예산을 안 정하면 '더 해보면 될지도'가 영원히 남는다")이 작동하지 않는다. 참고 눈금: **TabArena 는 200 회 무작위 탐색 + 8-fold 내부 CV** 를 썼다. 우리 데이터가 훨씬 크므로 그대로는 못 쓰지만, **회차 수를 층화 표본으로 줄인 개발용 부분집합**에서 그 예산을 쓰고 최종만 전체로 돌리는 게 현실적이다.

**⚠ 그리고 결과를 읽는 법을 미리 정하라.** 축 A 와 축 B 의 승자가 다르면 — 흔한 일이다 — **화면 판정은 축 A 를 따른다.** 우리는 매주 재학습할 팀이 아니다.

### 2-5. 품목별 분리 vs 조절변수 vs 계층 — 셋 다 돌려라. 순서와 판정이 있다

> 🔴 **개정 3 — 층화의 밑바닥이 바뀌었다.** `data-inventory` 전수 실측(n=233,380)으로 **우리가 쓰던 품목 어휘가 원본에 없다**는 것이 확인됐다. 아래 §2-5A 를 먼저 읽어라.

#### 2-5A. 🔴 층화 축을 다시 짠다 — 그리고 "결측"은 결측이 아니다

```
MAIN_ITEMS  닫힌 8원자:
  가공식품 38,109 · 육류 23,036 · 수산물 18,703 · 농산물 16,299
  김치류 9,791 · 가금류 7,953 · 곡류 1,818 · 우유류 1,470      (단일품목 계 117,179)
다품목 30,870 (2품목 20,002 이 지배)
품목 미표기 85,331 (36.6%)
```
**`축산`·`공산`은 우리가 만든 이름이다.** 원본에서는 `ds_itemList.MLFD_CLASS_NM` 의 값인데 자유 텍스트라 고유값 1,148종이고 코드→이름이 함수가 아니다(78 → 1,148). **층화 축으로 못 쓴다.**

> ⚠ **사용자가 "축산·농산"으로 말한 것은 사용자의 말이지 데이터의 말이 아니다.**
> 사용자가 요구한 것은 **"품목별로 나눠 보라"** 이지 특정 어휘가 아니다. **8원자로 그 요구를 만족시키고, 이름 대응표를 화면에 둔다.** 어휘를 억지로 맞추려 `MLFD_CLASS_NM` 을 끌어오면 1,148종 자유 텍스트가 실험에 들어온다.

**🔴 그리고 결측이 결측이 아니다 — 이게 이번 회신에서 가장 중요한 줄이다.**
```
MAIN_ITEMS 채움  ⟺  MN_TRMT_LMT_YN = 'Y'      n=233,380 에서 예외 0건
```
**완전한 결정론적 대응이다.** 그러면:
- ❌ **MAR/MNAR 논쟁이 필요 없다.** 대체(imputation)도 하지 마라. **결측 패턴 자체가 관측된 범주**다
- ✅ **"품목 미표기 85,331" 은 잃어버린 표본이 아니라 제3의 층이다** — *"다품목 제한이 안 걸린 공고"*
- 🔴 **그리고 이건 공짜로 얻은 E6 축이다.** `n=85,331` 대 `n=148,049`. **분포가 갈리는지 재기만 하면 된다** — 갈리면 화면의 첫째 필터가 여기서 나온다

**⚠ 대신 선택 편의를 문서에 박아라.** 품목 축은 **`MN_TRMT_LMT_YN='Y'` 인 공고 안에서만 정의된다.**
그러면 품목별 결론은 *"다품목 제한이 걸린 공고에서의 품목별 결론"* 이지 전체가 아니다.
**화면에서 품목 필터를 열면 사장은 자기 공고 중 63.4% 에만 해당하는 것을 전체로 읽는다.** 이건 설계 문서 §6 이 "표본 충분성"을 지표로 올린 것과 같은 종류의 위험이고, **`n` 만 표시해서는 안 막힌다 — "이 필터는 어떤 공고에 적용되는가"를 같이 놔야 한다.**

**층화 설계 (S1/S2/S3 를 이 위에서 돌린다):**
| 층 | n | 쓸 수 있나 |
|---|---:|---|
| 상위 6품목 × 2024~2026 | 칸당 1,500 이상 | ✅ **여기서만 품목×연도 교차를 한다** |
| 곡류 1,818 · 우유류 1,470 | 합계가 이미 얇다 | ⚠ **연도와 교차하지 마라.** 품목 단독으로만, 또는 계층(S3)으로 흡수 |
| 다품목 30,870 | 2품목이 65% | ✅ **제3 범주.** 2품목만 따로 볼 값어치가 있다 |
| 품목 미표기 85,331 | 36.6% | ✅ **제4 범주이자 E6 축.** 버리지 마라 |

**⚠ `data-inventory` 의 "포함 기준(D표)"을 검정에 쓰지 마라** — 다품목이 각 품목에 중복 계수돼 독립 표본이 아니다. 이미 그쪽에서 경고했고, 여기 한 번 더 박아 둔다.

#### 2-5B. 사다리 — 문헌 근거는 그대로

사용자가 품목별을 명시했고, **"전체 평균이 품목별 신호를 지운다"는 우려는 문헌이 지지한다.** 다만 문헌의 처방은 "따로 학습하라"가 아니다.

**부분집단 문헌의 결론:** 집단별 분리 학습은 **검정력이 낮고 과적합에 취약**하다. 하나의 모형 안에서 **상호작용으로** 다루는 편이 낫고, **계층 모형이 둘의 절충**이다.

**제안 — 3단 사다리. 셋을 다 돌리고, 순서가 판정을 만든다.**
```
S1  풀링 + 품목을 인자로        (기준선)
S2  품목별 완전 분리 학습        (이질성의 상한)
S3  계층 / 다중과제              (공유 + 품목별 편차)
```
| 관측 | 결론 | 화면 판정 |
|---|---|---|
| S2 ≈ S1 | 품목 간 이질성이 없다 | **품목 축을 안 연다.** 이것도 결과다 |
| S2 > S1, S3 ≥ S2 | 이질성 있고 공유도 값을 한다 | **S3 채택. 품목 축을 연다** |
| S2 > S1, S3 < S2 | 품목이 사실상 다른 시장이다 | **품목 축을 열고, 품목별 모형을 따로 둔다** |
| S2 < S1 | 분리하면 표본이 모자란다 | **품목 축을 화면에는 열되 모형은 풀링** |

**🔴 그리고 보고 형식을 규율로 박아라.**
> *"모든 표를 **8원자 + 다품목 + 미표기** 로 쪼개서도 보고한다. 전체 평균만 있는 표는 결과로 인정하지 않는다."*

사용자의 지적이 정확히 이 위험을 가리켰고, 이건 방법이 아니라 **보고 규율**로 막아야 한다.

⚠ **다만 연도 교차는 조건부다** (§2-5A): 상위 6품목만 연도와 교차하고, **곡류·우유류는 품목 단독으로만** 낸다. 얇은 칸을 억지로 채워 보고하면 설계 문서 §6 이 경계한 `1회 중 100%` 를 우리가 표에서 재생산하게 된다.

**⚠ 다품목 공고.** 계획이 "다품목 공고 있음"만 적고 처리를 안 정했다. **다품목은 별도 범주로 두라** — 품목의 혼합이 아니라 **제3의 시장**일 가능성이 높다(참여 가능한 업체 집합이 다르다). 어느 품목에 배분하면 **양쪽 신호가 다 오염된다.** 실측상 2품목이 65%(20,002/30,870)이므로 **2품목만 따로 보는 것부터** 하면 된다.

### 2-6. VoI 를 어떻게 계산할 것인가 — 구체 절차

계획이 모호하다고 스스로 적었다. 여기가 제일 값나가는 부분이므로 절차로 쓴다.

#### (a) 결정 문제를 먼저 못박는다 — VoI 는 결정이 정의돼야 존재한다

```
행동공간   a ∈ A = {불참} ∪ {x 격자: 1.000, 1.0002, …, 1.005}   ← 격자 간격은 창문 폭(0.058%)의 1/5 이하
보수       u(a, ω) = 낙찰 시 (수주금액 − 원가대리값) − 참여비용 c
                     불참 시 0
상태 ω     그 회차의 (R, 경쟁자 전원의 x)   ← 사후에 전부 관측된다
```
⚠ **원가 대리값과 참여비용 c 가 없으면 VoI 를 계산할 수 없다.** 설계 §11 이 이걸 "미정"으로 남겼는데, **VoI 가 중심 지표인 이상 이건 미정으로 둘 수 없다.** 최소한 **"낙찰 자체가 보수 1"** 이라는 축퇴 버전(c=0, 마진 상수)을 기본으로 정의하고, 원가가 생기면 재계산하는 2단으로 가라. 축퇴 버전에서도 VoI 는 잘 정의된다 — **낙찰 수의 개선분**이 된다.

#### (b) 🔴 반사실을 정확히 재생한다 — OPE 가 필요 없다

우리는 회차의 **R 과 경쟁자 전원의 x 를 사후에 안다.** 그래서 임의의 x 에 대해:
```
낙찰(x) ⟺ x ≥ R  ∧  ¬∃j: R ≤ xⱼ < x
```
를 **결정론적으로 판정**할 수 있다. 추정도 가중치도 필요 없다.

**이건 IPS/DR 을 쓰는 것보다 훨씬 강하다** — 분산이 없고 로깅 정책 가정도 필요 없다. **계획 M6 이 "정책 비교"라고만 적었는데, 그것이 결정론적 리플레이임을 명시하라.** 그러지 않으면 누군가 OPE 추정량을 구현하며 없는 문제를 푼다.

**⚠ 이 재생이 기대는 가정은 정확히 하나다: 내 x 가 남의 x 를 바꾸지 않는다(no market impact).**
- 이건 **가정이지 사실이 아니다.** 문서에 명시하라.
- 그리고 **검사 가능하다**: 아버지가 참여한 회차와 참여하지 않은 유사 회차에서 **경쟁자 x 분포가 같은지** 비교. 다르면 진입 효과가 있고, 그때는 VoI 가 상향 편향된다.
- 최소한 **아버지 본인이 낙찰자였던 회차**에서는 그의 투찰을 뺀 나머지로 재생해야 한다(자기 자신과 경쟁시키지 마라).

#### (c) 정책 두 개를 세우고 차이를 잰다

```
π₀(z)      재료 s 없이 학습한 정책      x* = argmax_a Ê[u | z]
π_s(z, s)  재료 s 를 추가해 학습한 정책  x* = argmax_a Ê[u | z, s]

VoI(s) = (1/T) Σ_t [ u(π_s(z_t, s_t), ω_t) − u(π₀(z_t), ω_t) ]
```
**한계 VoI** 는 이미 놓인 재료 집합 S 위에서: `VoI(s | S) = V(S ∪ {s}) − V(S)`.

**⚠ 순서 의존 문제.** 재료 순서마다 값이 다르다. Shapley 식 평균화가 유혹적이지만 **비용이 폭발하고 §1-6 의 비판을 그대로 받는다.**
**처방: 전방 선택(forward selection) 순서를 화면 슬롯 순서와 동일하게 고정하고, 그 순서를 문서에 박아라.** 화면에는 어차피 순서가 있다 — 첫째 칸에 놓을 재료, 둘째 칸에 놓을 재료. **VoI 를 그 순서대로 재면 순서 의존이 결함이 아니라 사양이 된다.**

#### (d) 🔴 max 편향을 막는 장치 — 계획에 없는 조각

Brennan et al. 이 경고한다: **몬테카를로 추정치의 최대값은 위쪽으로 편향된다.** 우리 절차는 `argmax_a` 를 매 회차마다 취하므로 **정확히 이 편향에 걸린다.** 재료 수만큼 최대값을 취하면 **아무 정보 없는 재료도 양의 VoI 를 받는다.**

**방어 장치 셋. 셋 다 하라.**
1. **내부/외부 분할.** 정책 학습(argmax 를 정하는 데 쓰는 모형)은 **학습 분할**에서, VoI 평가는 **평가 분할**에서. 같은 데이터로 argmax 를 정하고 그 argmax 의 성과를 재면 편향이 확정적이다.
2. 🔴 **영점 재료(null floor) — 두 종류를 다 넣어라.**

   | | 재료 | 예측력 | 결정 가치 | 무엇을 시험하나 |
   |---|---|---|---|---|
   | **음성 대조군** | 난수 재료 20개 | 0 | 0 | 절차가 **잡음에 값을 매기는가** |
   | ⚠ **양성 대조군** | **`DRAW_NO` 파생 재료** | **거의 완벽** | ~~정확히 0~~ → **보류** | 절차가 **"맞추지만 쓸모없는 값"을 걸러내는가 |

   > 🔴 **개정 5 — 이 대조군은 보류다** (§0-⚠). "정확히 0"은 슬롯 교환가능성 정리에서 나온 값인데 그 정리가 전수에서 흔들렸다. **§0-D 의 검정이 끝날 때까지 이걸 통과 기준으로 쓰지 마라.**
   >
   > **다만 버리지도 마라 — 검정 결과에 따라 더 좋아질 수도 있다:**
   > - **가격 가시성이 기각되면** → 원래 계획대로 "정확히 0" 양성 대조군으로 복귀
   > - **확정되면** → 결정 가치가 0이 아니라 **계산 가능한 작은 값**(§0-D 의 개인 몫)이 된다. 그러면 이건 대조군으로서 **더 강해진다** — VoI 절차가 "0인지 아닌지"가 아니라 **알려진 작은 값을 맞추는지**를 시험하게 되고, 그건 눈금(calibration) 검사다
   >
   > **그 사이에는 음성 대조군(난수 20개)만으로 간다.**

   난수 재료만으로는 부족하다 — 예측력도 0이라 **"예측력이 없어서 VoI 가 0"인지 "예측력은 있는데 결정과 무관해서 0"인지 못 가른다.** 후자가 우리 설계 문서 §0 이 잡아내겠다고 한 바로 그 경우다.

   **`DRAW_NO` 가 그 시험을 정확히 한다** (§0-A ②): 어느 슬롯이 뽑히는지를 85.6% 맞추면서(N>12, seq3), 결정 가치는 **슬롯 교환가능성에서 나오는 정리로 정확히 0**이다. 근사가 아니라 증명이다.

   **판정:** 진짜 재료의 VoI 가 난수 재료 분포의 95분위를 넘어야 하고, **`DRAW_NO` 파생 재료의 VoI 는 그 분위 아래여야 한다.** 후자가 위로 나오면 **VoI 코드가 고장난 것이다 — 실데이터 순위표를 내지 마라.**
3. **회차 단위 블록 부트스트랩.** 같은 회차의 투찰은 R 을 공유하므로 독립이 아니다(§1-4). **투찰 단위로 부트스트랩하면 신뢰구간이 부당하게 좁아진다.** 반드시 회차 블록으로.

⚠ **판정 기준 문장을 고쳐야 한다.** 설계 §7 의 *"한계 VoI 신뢰구간이 0 을 안 넘는 재료가 하나 이상"* → **"한계 VoI 가 영점 재료 분포의 95 분위를 넘는 재료가 하나 이상"**.

## 3. 우리가 놓친 것 — 문헌에 있는데 계획에 없는 것

### 3-1. 🔴 조건부 밀도 추정으로 재구성 (RTB 문헌)
**왜 맞나.** §2-2 와 §1-7. 우리는 경쟁자를 전수 관측한다 — 표본이 1,058만이고 불균형이 없다. RTB 는 검열까지 안고 이걸 하고 있다.
**계획 어디에 들어가나.** M1 의 `X|z` 추정 부분이 사실상 이것이다. **계획이 이미 절반쯤 적어 놓고 이름을 안 붙였다.** 이름을 붙이면 문헌과 도구가 따라온다.

### 3-2. NNE — 구조 모형 파라미터를 신경망으로 추정
**왜 맞나.** M1 과 M5 를 합치는 정공법. 시뮬레이터가 있고(§4), 미지수가 둘뿐이다 — NNE 의 전제와 정확히 같다.
**어디에 들어가나.** M1 의 추정 절차 대안. 그리고 **§4 의 합성 검증 인프라를 그대로 재사용**한다 — 생성기를 한 번 만들면 검증과 추정에 둘 다 쓴다.

### 3-3. 🔴 Simulation-Based Calibration (SBC) — §3-1 규율의 정식 절차
**왜 맞나.** 계획이 *"합성 데이터로 알려진 파라미터를 복원하는지 본다"* 고만 적었다. SBC 는 **그것보다 강하고, 실패의 종류까지 알려준다.** §4-2 에 절차와 진단표를 적었다.

### 3-4. TabM · RealMLP — 신경망 후보를 정할 때
**왜 맞나.** M5 를 열게 되면 무엇을 쓸지 계획에 없다. FT-Transformer/SAINT 계열이 아니라 **MLP 계열**이 2025 년 결과다. RealMLP 는 **잘 튜닝된 기본값**을 제공하므로 §2-4 의 "축 A(기본값)" 비교에 특히 맞다.

### 3-5. Conformalized Quantile Regression — M2 의 실패 조건을 다시 쓰게 만든다
**왜 맞나.** M2 의 실패 판정이 *"구간 커버리지가 명목치를 벗어나면 화면에 구간을 못 놓는다"* 인데, **CQR 은 그 커버리지를 유한표본에서 보장한다.** 즉 이 실패 조건은 **CQR 을 쓰면 자동으로 충족**되므로 지금 형태로는 무의미하다.
**고쳐 쓸 실패 조건:** *"CQR 보정 후에도 **조건부** 커버리지(품목별·지역별·경쟁밀도별)가 명목치에서 벗어나면"*. 주변부(marginal) 커버리지는 보장되지만 조건부는 안 되고, **화면은 조건부로 쓰인다** — 사장은 자기 품목·자기 지역에서 본다.

### 3-6. NGBoost / 분포 부스팅 — M2 의 자연스러운 상위 버전
**왜 맞나.** 분위 5개를 따로 적합하면 **분위 교차(quantile crossing)** 가 생기고 분포가 일관되지 않는다. 분포 부스팅은 조건부 분포 전체를 한 번에 준다.

### 3-7. 혼합효과 신경망 — M3 과 M5 의 다리
**왜 맞나.** M3 은 계층을, M5 는 유연성을 준다. 우리에게 필요한 건 **"학교/업체별 편차를 축소하면서 비선형인" 모형**이고, 그게 정확히 이 계열이다.

### 3-8. 오라클 시뮬레이션으로 상한 재기 (E3 의 대안 경로)
**왜 맞나.** E3 은 R 분포에서 **해석적으로** 상한을 구하려 한다. 그건 R 만의 상한이고 **경쟁자 불확실성이 빠져 있다.** 합성 데이터에서는 **진짜 파라미터를 아는 오라클**을 돌릴 수 있고, 그 성능이 **모든 지표에 대한 상한**을 준다. §4-3 의 L4.

### 3-9. ✅ 해결됨 — 복수예가 메커니즘 (개정 2에서 확정·정정)

**개정 1에서 나는 이렇게 적었다:**
> *"투표식이면 `R ⊥ N` 이 깨지고 미지수 둘이 결합된다. 손해가 아니라 추가 지렛대일 수도 있다."*

**절반만 맞았다. 정정한다.**

| | 개정 1의 예상 | 실측 결과 |
|---|---|---|
| 메커니즘이 투표식인가 | 그럴 것이다 | ✅ **맞다** — `DRAW_NO` 고유값 정확히 105 = C(15,2), 채움률 100% |
| 낮은 seq 가 과대표집되나 | 그럴 것이다 | ✅ **맞다, 그것도 아주 강하게** — seq3 0.749 vs seq14 0.013 |
| 그 효과가 N 이 작을수록 큰가 | 그럴 것이다 | ❌ **거꾸로다** — N 이 **클수록** 날카로워진다 (측정 3) |
| `R ⊥ N` 이 깨지나 | 깨진다 | ❌ **안 깨진다** — sd(R) 이 N 구간 넷에서 모두 0.0075~0.0079 |
| R 분포가 순수추첨과 달라지나 | 달라진다 | ❌ **구별 안 된다** — KS D=0.0287 < 0.0351 |

**내가 놓친 것은 측정 1이다.** 번호↔가격 배정이 **회차마다 균등 순열**이라는 사실. 그것 하나로 투표 편향이 R 에 전달되지 않는다 — 슬롯이 교환가능하면 **어떤 슬롯 선택 규칙이든 R 은 4개 균등 비복원 추출의 평균**이다.

**교훈 둘을 남긴다.**
1. **메커니즘을 알아낸 것과 그것이 예측에 쓸모 있는 것은 다른 문제다.** 나는 전자를 확인하자마자 후자를 추론했고, 그건 한 단계를 건너뛴 것이었다.
2. **"더 어려워졌다"도 "더 쉬워졌다"도 아니고, 측정해 봐야 알았다.** 대조군(같은 15개에서 4개 균등추출)을 만드는 데 코드 세 줄이 들었다. **구조 주장에는 항상 대조군을 붙여라** — §4-1 의 L0(축퇴 검사)이 이 습관의 일반형이다.

**⚠ 남은 확인 하나.** 이 결론은 **15개 가격이 개찰 전 비공개**라는 가정에 전부 걸려 있다(§0-A 말미). 그 하나만 확인되면 이 항목은 닫힌다.

**부수 확인 — 이 문은 닫혀 있다.** 옛 코퍼스에서 `PLNPRC_TYPE_CD` 분포(`F:/Project/eat-bid/scratch_scope.txt`):
```
'002' 복수예정가격   72,722
'001' 단일예정가격       71     ← 0.1%
```
`001` 은 추첨이 없어 **R = 1.0 확정**이라 커트라인이 투찰 시점에 알려진다 — 원리적으로 예측 가능한 유일한 부분모집단이다. **그런데 0.1% 다.** 화면 재료로도 실험 축으로도 값이 없다. **닫고 기록하라** — 나중에 누가 다시 물을 것이다.

### 3-10. 🔴 M1 재작성 — 실측 후의 구조

미지수가 재배치됐으므로 M1 의 추정 대상이 바뀐다.

```
낙찰 ⟺ x ≥ R  ∧  ¬∃j: R ≤ xⱼ < x

R      ~ 15개 중 4개 균등 비복원 추출의 평균,  15개 ~ U(0.97, 1.03)
       → 🔴 추정 안 한다. 유도한다. 파라미터 0개
       → 회차별로 기초가만 알면 R 의 분포가 완전히 결정된다

N | z  경쟁자 수
       → ⚠ §0-B 가 갈린다. 투찰 시각이 있으면 as-of 관측, 없으면 추정
       → 추정할 경우: 음이항 회귀. 과산포 필수

X | z  경쟁자 위치 분포                    ← 🔴 유일하게 남은 진짜 미지수
       → 투찰 1,058만 전수 관측. 조건부 밀도 추정
       → 여기가 신경망·RTB 문헌·고카디널리티 임베딩이 전부 걸리는 자리

표     → ❌ 추정 대상에서 뺀다. 예측 가능하지만 결정 가치 0 (§0-A ②)
```

**낙찰 확률 = P(x ≥ R) × P(경쟁자 최소 x 가 [R, x) 밖)** — 앞항은 **해석적으로**, 뒷항은 `N|z`·`X|z` 로 합성.

**이 재작성의 효과 셋:**
1. **파라미터 수가 줄었다.** 계획은 미지수 셋(R·N·X), 리더 안은 넷(+표), **실측 후는 하나 반(X, 그리고 조건부 N)**. §1-2 의 식별 가능성 경고가 훨씬 덜 위험해진다.
2. **`P(x ≥ R)` 이 해석적이므로 그 항에는 추정 오차가 없다.** 모든 잔차가 `X` 쪽에서 나온다 — **오차의 출처가 하나로 좁혀진다.** 진단이 쉬워진다.
3. **M4b(경쟁자 최소 x 예측)가 M1 의 정확한 대조군이 된다.** 둘 다 같은 대상(경쟁자 위치)을 다른 방식으로 추정하고, R 항은 공유한다. §2-3 의 공정성 문제가 저절로 해소된다.

**리더 질문에 대한 답 — "표 예측에 회차 임베딩이 필요한가":**
> ❌ **아니다. 그리고 표 예측 자체를 하지 마라.**
>
> 값이 0인 게 첫째 이유이고(§0-A ②), 설령 한다 해도 **고카디널리티 임베딩 문제가 아니다.** 리더가 말한 "회차 공통 충격"은 통계 용어로 **과산포(overdispersion)** 이고, 15칸 카운트 벡터의 과산포에는 **디리클레-다항(Dirichlet-Multinomial) 이라는 닫힌 형태 모형**이 있다. 신경망도 임베딩도 필요 없다. 게다가 **새 회차에는 임베딩이 없으므로** 회차 임베딩은 예측에 쓸 수조차 없다.
>
> **내 판정 2(고카디널리티 임베딩이 신경망의 진짜 자리)는 그대로 유효하지만, 그 자리는 여기가 아니라 `X|z` 안의 학교 ID·업체 ID다.** 표 쪽으로 옮기지 마라.

⚠ **그래서 신경망의 근거는 이번 라운드에서 넓어진 게 아니라 좁아졌다.** 정직하게 적는다 — 남은 자리는 `X|z` 하나이고, 거기서도 GBDT 와 겨뤄야 한다. M5 의 여는 조건(§2-1)은 그대로 둔다.

### 3-11. 조합 예측(M4c) 문헌 — 있다. 그런데 쓸 자리가 없다

리더가 *"표 예측은 15개 중 2개 = 조합 예측이다. 문헌이 있나"* 라고 물었다. **답: 있다. 그리고 이 문제에는 쓰지 마라.** 둘 다 적는다 — 조건이 바뀌면 다시 열어야 하니까.

**문헌은 이런 모양이다** (초록 수준 · 읽은 것 표시):
| 틀 | 무엇 | 우리 문제에 |
|---|---|---|
| **카디널리티 제약 다중라벨** | "정확히 k 개를 고른다" 제약 하의 다중라벨 분류 | 개별 투찰자의 2개 선택을 맞추는 틀 |
| **Plackett–Luce / 순위 모형** | 후보에 효용을 주고 순차 선택으로 부분집합 확률 | 번호 선호 π_k 를 모수화하는 자연스러운 틀 |
| **디리클레–다항(Dirichlet-Multinomial)** | 카운트 벡터의 **과산포**를 닫힌 형태로 | 🔴 **리더가 말한 "회차 공통 충격"의 정확한 이름** |

**그런데 셋 다 쓸 자리가 없다. 이유가 층층이 셋이다:**
1. 🔴 **결정 가치가 정확히 0이다** (측정 6). 표를 완벽히 맞춰도 `R` 의 분포가 안 바뀐다
2. **설령 값이 있어도 신경망이 아니다.** 리더가 지목한 "회차 공통 충격"은 통계 용어로 **과산포**이고, 15칸 카운트에는 **디리클레–다항이라는 닫힌 형태 해**가 있다. 임베딩도 신경망도 필요 없다
3. **회차 임베딩은 예측에 쓸 수조차 없다.** 새 회차에는 임베딩이 없다. 리더가 원한 것은 임베딩이 아니라 **회차 수준 임의효과**이고, 그것이 곧 2번이다

> **내 판정 2(고카디널리티 임베딩이 신경망의 진짜 자리)는 유효하다. 다만 그 자리는 여기가 아니라 `X|z` 안의 학교 ID · 업체 ID 다.** 표 쪽으로 옮기지 마라.

**다시 여는 조건 — 적어 둔다:** §4-4 의 **슬롯↔가격 상관 손잡이가 실데이터에서 0 이 아님이 밝혀지면**, 그때 M4c 가 살아나고 위 세 틀이 전부 후보가 된다. 그 검사는 이미 측정 1·6 이고, 지금은 0이다.

### 3-12. 🔴 우발 계획 — `f_R/g` 진단이 평평하면

리더가 *"평평하면 M1·M2·M4·M5 를 전부 접는다. 그 시나리오를 미리 적어 둬라"* 고 했다. **미리 적는 것이 맞다** — 결과를 보고 적으면 기준이 움직인다(§3-1 규율).

**무엇이 평평하다는 뜻인가.** 낙찰 확률의 `x` 에 대한 기울기가 **커트라인 불확실성에 묻힌다**는 뜻이다. `R` 의 sd 0.0075 가 승부 창문 0.00058 의 **13배**라는 선행 결론의 정밀한 형태다.

**그러면 이렇게 갈린다:**

| 살아남는 것 | 왜 |
|---|---|
| ✅ **L4 오라클 상한** | *"완벽한 정보로도 이만큼뿐"* 을 수치로 준다. **평평함의 증명이 곧 이것이다** |
| ✅ **VoI (M6)** | 재료가 값을 못 한다는 **판정**이 나온다. 화면에서 빼는 근거 |
| ✅ **M3 계층** | 결과와 무관하게 화면에 쓰인다(계획 §2-M3 이 이미 그렇게 적었다). `n=1 중 100%` 문제는 예측 가능성과 무관하다 |
| ✅ **E6 축 · E7 중복** | *"무엇끼리 견줄까"* 는 예측이 아니다. 미표기 36.6% 축(§2-5A)이 여기 있다 |
| ✅ **E5 커버리지 대 위치** | 평평하면 **이게 유일하게 남는 레버다** — 같은 투찰 수를 어디에 뿌리나 |
| ❌ M1·M2·M4·M5 | 조건부 분포를 추정할 이유가 없어진다 |

🔴 **그리고 이 시나리오가 실패가 아니다.** 사용자 원문이 *"안 돼도 프론트엔드 구축 시에 필요한 재료들을 만들 근거를 만드는 거임"* 이었다. **평평함은 그 근거의 가장 강한 형태다:**

> **"투찰 위치로는 못 바꾼다"가 증명되면, 화면은 위치 조언을 그만두고 커버리지·티켓 배치로 옮겨간다.**
> 그건 화면 설계의 **방향 전환이지 중단이 아니다.**

**⚠ 다만 "평평하다"를 어떻게 판정할지 미리 정하라.** 평평함도 **효과 크기와 신뢰구간**으로 말해야 한다.
- ❌ *"기울기가 유의하지 않다"* — n=23만에서는 무의미한 기울기도 유의해진다
- ✅ **"최적 `x` 와 최악 `x` 사이의 기대 낙찰 수 차이가 [구간] 이다"** — 실물 단위로
- 그리고 **품목별로 따로 내라**(§2-5A). **전체가 평평해도 어느 품목은 안 평평할 수 있다** — 사용자가 지적한 바로 그 위험이고, 이 진단에도 그대로 적용된다

## 4. 🔴 "안 됐다"를 세 가지로 가르는 절차

계획의 삼분(① 방법 불일치 ② 구현 오류 ③ 데이터 부족)은 옳지만 **순서가 없다.** 순서 없이 셋을 동시에 물으면 못 가른다. **사다리로 만든다 — 아래 칸을 통과해야 위 칸을 묻는다.**

### 4-1. 사다리 다섯 칸

| 칸 | 검사 | 실패하면 결론 | 통과 못 하면 |
|---|---|---|---|
| **L0** | **축퇴 검사.** 상수 예측기 · 난수 재료 · 라벨 섞기(label shuffle)를 돌린다. 이것들이 이기거나, 라벨을 섞었는데 성능이 남으면 | **파이프라인 버그** (누출·평가 코드 오류) | 위로 못 감 |
| **L1** | **구현 검증.** 합성 데이터에서 알려진 파라미터 복원 + **SBC 균등성** | **② 구현이 틀렸다** | 실데이터 금지 |
| **L2** | **용량 검증.** 합성 데이터의 표본을 실데이터와 같은 크기로 줄여 같은 실험. 여기서 신호가 사라지면 | **③ 데이터(표본)가 모자란다** | — |
| **L3** | **오설정 검증.** 생성기를 우리 가정과 **일부러 다르게** 만들고(경쟁자 상관 · N 내생성 · 투표식 추첨) 방법이 깨지는 **증상의 모양**을 기록. 실데이터에서 같은 모양이 나오면 | **① 방법이 안 맞는다** — 그리고 **어느 가정이 틀렸는지까지** 나온다 | — |
| **L4** | **상한 검증.** 합성 데이터에서 **진짜 파라미터를 아는 오라클**의 성능을 잰다. 실데이터 성능 / 오라클 성능 = 우리가 상한의 몇 %에 있나 | (실패 아님 — 눈금) | — |

**L0 과 L4 가 계획에 없다.**
- **L0 없이는 ②를 ①로 오독한다.** 누출 검사기(계획 §10-1)는 *특징*의 as-of 위반을 잡지만, **평가 코드의 버그나 분할 누출은 못 잡는다.** 라벨 섞기가 그걸 잡는다.
- **L4 없이는 "안 됐다"의 분모가 없다.** *"낙찰 예측이 안 된다"* 와 *"오라클도 못 하는 판이다"* 는 완전히 다른 결론이고, 후자만이 **화면 설계의 근거**가 된다. 사용자가 원한 "안 돼도 프론트엔드 근거"가 정확히 이 지점이다.

### 4-2. SBC — L1 의 정식 절차

Talts et al. 2018 (본문 열람). 절차:
```
N 회 반복:
  1. 사전분포에서 진짜 파라미터 θ̃ ~ π(θ) 를 뽑는다
  2. 그 θ̃ 로 데이터 ỹ ~ π(y | θ̃) 를 생성한다        ← §4-4 의 생성기
  3. 우리 추정 절차로 사후표본 L 개를 뽑는다
  4. 각 1차원 함수 f 에 대해 순위통계량 = (사후표본 중 f(θ̃) 보다 작은 개수)

L+1 개 순위값의 히스토그램이 균등해야 한다. 99% 신뢰띠와 대조.
```
**🔴 히스토그램 모양이 오류의 종류를 알려준다 — 이게 SBC 의 값이다:**

| 모양 | 뜻 | 우리 문제에서 예상되는 원인 |
|---|---|---|
| **U 자** | 사후가 **과소산포** (너무 좁다) | 경쟁자 상관을 무시하고 독립 가정 → 유효표본 과대평가 |
| **∩ 자 (봉우리)** | 사후가 **과대산포** (너무 넓다) | 사전분포가 과도하게 넓거나 정보를 다 못 쓴 것 |
| **한쪽으로 기움** | 사후가 **편향** — 기운 반대쪽으로 | 추첨 메커니즘 오설정(§3-9), 철회 처리 오류 |
| **양끝 스파이크** | 표본 간 **자기상관** | MCMC 수렴 실패 |

**한계도 정직하게 적어라:** ① 실데이터 전에 N 개 복제 데이터셋을 다 적합해야 해서 비싸다 ② **1차원 요약만** 본다 — 다변량 관계는 못 잡는다 ③ 파라미터가 많으면 그림이 감당 안 된다 ④ 작은 오차는 히스토그램 분산에 묻힌다(경험 CDF 로 보완).

⚠ **SBC 는 베이즈 절차용이다.** M4/M5 같은 점 추정 모형에는 그대로 안 쓴다. 거기서는 **L1 을 "합성 데이터에서 오라클 대비 상대 격차가 기준 이내"** 로 대체한다.

### 4-3. 판정을 눈금으로 만든다 — 서로 이기고 지는 게 아니라 오라클까지의 거리

계획의 실패 판정들이 **상대 비교**로 돼 있다("M4 에 크게 지면", "M4 를 못 이기면"). 이건 **둘 다 나쁠 때 못 알아챈다.**

**제안: 모든 방법의 성적을 오라클 대비 상대 격차로 보고한다.**
```
격차(M) = [ score(M) − score(오라클) ] / [ score(B0) − score(오라클) ]

0 이면 오라클과 같다 · 1 이면 아무 정보 없는 기준선과 같다
```
오라클은 합성 데이터에서만 계산 가능하지만, **합성 생성기를 실데이터에 맞춰 보정하면 실데이터 오라클의 근사치가 된다.** 이게 E3(이론 상한)의 실행형이다.

### 4-4. 🔴 합성 데이터 생성기 명세

**설계 원칙 셋을 먼저.**
0. 🔴 **주장의 모양과 검정의 모양을 맞춘다.** (개정 5~7에서 팀이 네 번 틀리고 박는다)
   **네 가지가 전부 같은 실수다:**
   ```
   sd 가 맞으니 무작위다        → 평균을 안 쟀다        (나, 측정 1)
   주변분포가 맞으니 iid 다      → 결합 구조를 안 봤다   (나, 개정 3 생성기)
   옴니버스 χ² 가 통과했다       → 대립가설은 단조 기울기 (data-inventory, 순위 검정)
   집계가 85.8% 다              → 분포의 p10 은 57.1%   (나, 도착 곡선)
   ```
   **평균을 주장하면 평균을, 독립을 주장하면 독립을, 기울기를 의심하면 추세를 검정하라.**
   **집계는 분포가 아니다. 모먼트 일치는 검정이 아니다.**
   🔴 **검정이 기각을 *할 수 있는* 상태인지 먼저 확인하라** (개정 9) — `data-inventory` 의
   재구성 검정은 득표 슬롯이 4개 미만일 때 **4위 임계가 0 이라 어떤 선택도 자동 통과**했다.
   N=1 회차 783건이 전부 그 **공허참**에 걸려 불일치로 안 잡혔고, 그래서 `785 > 300` 이 났다.
   **검정력 0 보다 나쁜 것이 "기각 불가능한 검정"이다. 통과율을 보기 전에 기각 조건이
   발동하는 표본 수를 세라.**

   🔴 **그리고 핵심 변수는 두 경로로 만들어 대조하라** (개정 8) — 리더가 `BID_CALC_AMT` 의
   10¹³ 접두 오염으로 하마터면 **반대 결론**을 낼 뻔했고, `EFT_ALL_AMT` 와 `SAJEONG_PCT`
   두 경로 대조(99.982% 일치)가 그걸 잡았다. **단위가 이상하면 즉시 멈춰라** —
   비율이어야 할 값의 중앙값이 560,048 이었다.
   그리고 **표본으로 못 본 것을 "없다"로 적지 마라** — 내 z=−0.66 은 전수에서 −12.96 이었다.
   🔴 **검정력을 항상 같이 보고한다.** 이건 개인 습관이 아니라 **팀 규율**이다.

   🔴 **그리고 합성 검정은 *내가 정의를 준 곳*을 검정하지 못한다** (개정 22) —
   `L1` 이 `P(승|x,N)` 의 지수 오프바이원을 4라운드 동안 통과시켰다:
   ```
   L1 합성 진실 :  초점 1명 + 경쟁자 n 명을 그린다      ← 내가 정한 정의
   L1 M1 호출  :  win_prob(..., n) → 지수 n           ← 같은 정의
   실데이터    :  win_prob(..., nbid) → 지수 nbid      ← nbid 는 **투찰자 수** = 경쟁자+1
   ```
   **생성기와 추정기가 `N` 의 정의를 공유했다 ⟹ 정의 불일치를 구조적으로 기각할 수 없었다.**
   **L1 이 검증한 건 적분이지 "데이터의 열 → 모형의 인자" 사상이 아니었다.**
   > **⟹ 생성기는 실데이터의 *행 모양*을 만들어야 한다.**
   > **"경쟁자 `n` 명"이 아니라 "투찰 `N` 건짜리 회차". 그래야 사상까지 검정된다.**
   > **⟹ 그리고 정의는 함수 한 곳에 가둔다. 호출자가 단위를 고르게 두지 않는다.**

1. **특징 분포를 지어내지 않는다.** `z` 는 실데이터 경험분포에서 리샘플. 지어내면 L2(용량 검증)가 무의미해진다.
   🔴 **⚠ 단서 (개정 4에서 두 번 틀리고 배웠다): 경험분포 리샘플은 독립을 가정한다.**
   **층화·제약·합 고정이 있으면 주변분포가 맞아도 틀린 세계를 만든다.** 예비가격이 정확히 그랬다 —
   풀링 리샘플이 주변분포를 완벽히 재현하면서 `sd(R)` 을 13% 틀렸다(측정 10).
   **리샘플 전에 "이 15개(또는 n개) 사이에 제약이 있는가"를 먼저 물어라.**
2. **모든 손잡이(knob)는 꺼짐 상태가 우리 가정이다.** 켜면 가정 위반이 된다. L3 이 이걸 쓴다.
3. **생성기는 "투찰 시점에 알 수 있는 것"을 따로 표시해 내보낸다.** 누출 검사기를 이걸로 시험한다.

#### 생성 절차

```
회차 t:

1. 회차 특징        z_t ← 실데이터 회차에서 복원추출
                    (품목·다품목여부·하한율·기초가·시군구·시도·시기·계약형태·
                     학교 이력 요약·투찰기간·재입찰 여부)

2. 기초가           B_t = z_t.기초가
   하한율           f_t = z_t.하한율

3. 예비가격 15개    p_k = B_t · u_k
   🔴 **구간 배분은 고정(아래 8 · 위 7), 각 구간 안에서는 iid** (측정 10 · 12)
        아래 8개  ~ U(0.97, 1.00)      실측 덩어리평균 0.985442 · 내부sd 0.007817
        위  7개  ~ U(1.00, 1.03)      실측 덩어리평균 1.014750 · 내부sd 0.007637
        그 15개를 **무작위 순열로 슬롯 1~15 에 배정**

   ⚠ **개정 13 — 용어 충돌 경고.** `stats-expert` 가 이 모형을 **"IID"** 라 부르고,
      리더의 명세 초안에는 `🔴 IID (층화 아님)` 으로 적혀 있었다. **그대로 읽으면 아래 A 를 짠다.**
      세 모형을 각 20만 회 시뮬해 실측과 대조했다(`tools/mechanism/19_candidate_model_selection.py`):
   ```
   실측                              sd(15개 평균) 0.002166   %<1.0  0.5300

   A  15개 전부 U(0.97,1.03) iid            0.004467  (2.06배)   0.5010   ❌
   B  8~U(.97,1.00) + 7~U(1.00,1.03)        0.002235  (1.03배)   0.5333   ✅ 이것
   C  15구간 계통추출                         0.000298  (0.14배)   0.4998   ❌
   ```
   **`stats-expert` 의 "IID" = 내 "8/7" = B.** 그가 배제한 "층화"는 C(계통추출)이고, 그건

6. 경쟁자 위치      x_j = 1 + s(z_t) · Beta(α(z_t), β(z_t)),  j = 1..N_t

#### 손잡이 표 — 각각이 무엇을 시험하나

| 손잡이 | 기본 | 켜면 | 시험하는 것 | 어느 칸 |
|---|---|---|---|---|
| `φ` (N 과산포) | 실측치 | 크게 | N 추정의 난이도 | L2 |

#### 방법별 L1 통과 기준 — 숫자를 미리 못박는다

| 방법 | 통과 기준 |
|---|---|
| **M1** | `μ, φ, α, β` 의 95% 신뢰구간이 진값을 덮는다 (커버리지 ≥ 90%, 100회 반복) **+ SBC 히스토그램이 99% 띠 안** |
| **M2** | 명목 80% 구간의 실제 커버리지 **78~82%**, 분위 교차 0건 |
| **M3** | `n < 5` 학교에서 **단순평균 대비 예측 오차 감소**, 그리고 축소량이 이론값과 일치 |
| **M4a/M4b/M5** | **오라클 대비 상대 격차 ≤ 0.3** (§4-3 의 눈금). 못 넘으면 구현 실패 |
| **M6 (VoI)** | 🔴 셋 다 통과해야 한다 — ① 진값이 알려진 재료의 VoI 를 절차가 복원한다 ② **난수 재료**(음성 대조군)의 VoI 가 0 근방 ③ 🔴 **`DRAW_NO` 파생 재료**(양성 대조군: 예측력 거의 완벽 · 결정 가치 정확히 0)의 VoI 가 난수 재료 분포 안. **③이 실패하면 실데이터 순위표를 내지 마라** |
| **누출 검사기** | 주입한 누출을 **100% 검출**, 오탐 0 |

**M6 의 L1 이 특히 중요하다.** VoI 절차 자체가 검증된 적 없는 코드다. **진값을 아는 합성 세계에서 VoI 의 정답을 계산할 수 있으므로**(오라클 정책 vs 재료 없는 정책의 실제 차이), 우리 추정 절차가 그걸 복원하는지 반드시 먼저 본다. 안 하면 실데이터 VoI 순위표가 **검증 안 된 숫자**가 된다.

### 개정 22 (🔴 저`N` 미보정의 원인 — 여섯 번째 축이 아니라 지수 오프바이원)

**4라운드 동안 "저`N` 에서 승률을 −20% 과소예측한다"를 쫓았다. 후보 1~5 를 배제하고

```
P(승|x,N) = ∫ w(r)·1{r≤x}·(1 − F_X(x) + F_X(r))^?  dr
?  = 경쟁자 수 = N − 1          내가 쓴 것 = nbid = N   ← 나 자신을 경쟁자로 한 번 더
상대 과대계상 = 1/(N−1)          ⟹ 저N 에서만 크게 보인다.  그 단조 패턴 전부였다
```

| **AE** | 🔴 **합성 검정은 내가 정의를 준 곳을 검정하지 못한다** (§4-4 원칙 0 에 반영). `L1` 은 생성기와 추정기가 `N` 의 정의를 공유해서 사상 오류를 기각할 수 없었다. **L1 을 회차 모양으로 고쳤다** — `N` 건 = 초점 1 + 경쟁자 `N−1`. 그리고 정의를 `win_prob` 한 곳에 가뒀다 |

| **AG** | ⚠ **편향된 상태에서 한 하이퍼파라미터 선택은 우연히 맞아도 근거가 없다.** 지수를 고치자 `h` 스윕이 평평해졌다 — 짝지은 군집 검정 `Brier(0.40)−Brier(0.02) = −4.8e−05 ± 4.5e−05` (`z=−1.08`). **예전에 `h=0.02` 를 "골랐던" 건 −20% 버그가 목적함수를 지배했기 때문이다** |

#### 부수 결과 — `N` 상한 제거

커널을 **연속 함수**로 바꿨다 (`F_X(·|n)` 을 임의 `n` 에서, 표본 얇은 `N` 은 이웃에서 빌린다).
**`N≥60` 경계 자체가 없어졌다.** 60-99 `−0.1±0.1%` · 100-364 `+0.9±0.1%`. 인공물 없음.

#### `h` 를 무엇으로 고르나 — Brier 가 침묵한다

```
Murphy 저N   h=0.02  rel 0.000438  res 0.005776  |  h=0.40  rel 0.000422  res 0.005808
             항등식 잔차 −3.8e−06 / −3.2e−06 (닫힌다)
N 대역 신뢰도  h=0.02  N=3-4 +0.8%   |  h=0.40  N=3-4 −8.8±2.8%
```
**⟹ `h=0.02`. 근거는 Brier 가 아니라 3번이 *사전 등록한 대상*인 `N` 조건부 신뢰도다.**
⚠ **Brier 가 침묵했다는 사실을 수치와 같은 줄에 적는다.**

#### ② 회차 수준은 **마감 전에 관측되는 것으로 40% 넘게 예측된다**

기관·품목·지역·기초금액·낙찰하한·`N` 으로 GBDT `[학습기 156,977 회차 적합 → TUNE 34,895 평가]`:
```
N=3-4    R² 0.287 / 달성상한 0.692   ⟹ 회차 수준의 41.5%
N=5-9    R² 0.349 / 0.813            ⟹ 42.9%
N=10-29  R² 0.402 / 0.881            ⟹ 45.6%
N≥30     R² < 0  — 다만 거기선 잴 게 없다 (sd(r̄_a) 0.001~0.002)
```
🔴 **빠진 층 가설은 절반 맞다. 회차 수준은 실재하고 사전에 관측된다.**
⚠ **상한이 1 이 아니다** — `sd(r̄_a)` 에 회차 내 표본오차 `σ_w/√n` 이 섞여 있다. 같이 적는다.

#### ③ 그런데 `F_X` 에 넣으면 **모든 형태에서 나빠진다**

`F_X(v|N,g) = F_N(v − δ)` 로 넣었다 (기관 CDF 를 직접 쓰면 그 기관의 여러 `N` 을 뭉개므로 위치이동만):
```
기관 수축 δ (κ=1~100)                 저N Brier 0.0776 → 0.0785~0.1008    전부 악화
GBDT 예측 δ (×0.15~1.0)               0.0776 → 0.0781~0.0931              전부 악화
🔴 오라클 δ (그 회차 다른 투찰자들의 실제 값)  0.0776 → 0.1068              가장 나쁨
   + 회차내 폭으로 F_X 를 좁혀도          0.1060                            여전히 나쁨
```
**⟹ δ 가 *정확해질수록 더 나빠진다*. 추정 실패가 아니라 형태가 틀렸다.**

**진단:** 풀링 `F_X` 의 폭에 회차 간 성분이 들어 있고 그게 "회차 수준을 모른다"는 사실의 표현이다.
그 상태의 `P(승|x)` 는 **주변** 확률이라 보정된다. δ 로 중심을 옮기면 조건부 예측이 되는데,
**회차당 낙찰자가 정확히 1명이라는 배타성**을 모형이 안 걸어서 회차별 `Σ_i p_i` 예산이 깨진다.

⚠ 🔴 **그리고 오라클은 깨끗한 천장이 아니다** — 경쟁자의 실현값을 δ 로 한 번, `F` 에서 다시 한 번
쓴다. `N=3` 이면 δ 가 곧 그 경쟁자 자신이라 조건부 분산이 0 이어야 하는데 `σ_w` 를 그대로 쓴다.
**천장으로 인용하면 안 된다.**

> **⟹ 후보 6 판정: 설명 대상이 사라졌고(−17.8% → +4.1%), 자원으로서도 위치이동 형태로는 못 쓴다.**
> **미검정 하나: 회차별 배타성을 건 계층 모형. 남은 `+4.1%` 가 거기 살 수 있다. 지금은 안 판다.**

### 개정 1의 권고 (전부 유효)

1. **Y1 이진 분류를 중심에서 빼라.** 경쟁자 x 의 조건부 밀도 추정으로 재구성하면 표본 1,058만, 불균형 없음.
2. **M5 의 조건 2·3 을 교체하라.** 고차 상호작용은 근거가 없고, "M1/M4 차이 미설명"은 게이트가 아니라 결과다.
3. **M5 를 M1 밖이 아니라 안에 넣어라.** `X|z`·`N|z` 의 신경망 파라미터화. RTB 문헌이 더 어려운 조건에서 검증한 길이다.
4. **M4 를 두 판 돌려라** — M4a(이진) · M4b(경쟁자 최소 x). M1 의 진짜 대조군은 M4b 다.
5. **예산은 "탐색 횟수 동일"이 아니라 "계산 시간 동일"**, 그리고 **기본값 축과 예산 축을 따로 보고**하라. 화면 판정은 기본값 축을 따른다.
6. **리샘플링·클래스 가중치 금지.** 주 지표는 log loss/Brier, ECE 는 단독 근거 금지.
7. **품목은 S1/S2/S3 사다리로 판정하고, 모든 표를 품목×연도로 쪼개 보고**하는 것을 규율로 박아라. 다품목 공고는 제3의 범주.
8. **VoI 는 결정론적 리플레이로 계산하고**(OPE 불필요), **영점 재료 · 내부/외부 분할 · 회차 블록 부트스트랩**으로 max 편향을 막아라. 판정 문장을 "0 을 안 넘는다"에서 "영점 분포를 넘는다"로 고쳐라.
9. **SHAP 은 순위표 근거로 쓰지 말고 절제 결과와의 대조(버그 검출)로만** 쓴다고 명시하라.
10. **사다리 L0~L4 와 합성 생성기(§4-4)를 먼저 만들어라.** 특히 **L0(라벨 섞기)와 L4(오라클)** 가 계획에 없고, 둘 없이는 "안 됐다"가 영영 안 갈린다.
