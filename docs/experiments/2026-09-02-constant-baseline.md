# 상수 기준선 — **모형을 재기 전에 "아무것도 안 하는 전략"부터 재야 했다**

> **2026-09-02 · team-lead 직접 계산 · 자료 `eat-bid/data/mechanism/xcap2.npz`**
> **전수 10,586,855 투찰 · 233,380 회차. 기록된 낙찰자 재현 일치율 99.92%**

## 0. 왜 했나

`M5` 신경망이 **1.25%** 로 제비뽑기(1.87%)보다도 낮게 나왔다.
`ml-expert` 는 예산 부족(M4 150만 행 vs M5 40만 행)을 사유로 신고했다.
⚠ **그런데 예산으로는 "무작위보다 못하다"가 설명되지 않는다.** 그래서 직접 쟀다.

**⟹ 재보니 문제는 신경망이 아니라 *기준선*이었다.**

## 1. 🔴 결론 둘 — 갈라서 읽어야 한다

```
① 전수      상수 전략이 사람 평균을 이긴다.  안정적이다
② 아버지    상수 전략이 아버지를 못 이긴다.  그리고 그의 표본으로는 아무것도 판정 못 한다
```

### ① 전수 — 상수가 이긴다

```
사람 실제 평균                        2.239%
상수 x0 (0.990~1.010 격자 평균)        2.887%
   격자 최저(x0=0.990)                2.462%   ← **최악의 상수도 사람 평균을 이긴다**
   격자 최고(x0=0.996)                3.032%
```
🔴 **정보를 하나도 안 쓰는 고정 숫자가 사람 평균보다 29% 더 낙찰한다.**

### ② 그런데 `N` 이 전부다

| 경쟁자 `N` | 사람 실제 | 상수(격자 평균) | 배수 |
|---:|---:|---:|---:|
| 2–5 | 30.06% | 36.22% | **1.21×** |
| 6–10 | 12.92% | 22.82% | **1.77×** |
| 11–20 | 6.83% | 10.79% | **1.58×** |
| 21–40 | 3.65% | 4.23% | 1.16× |
| 41–80 | 1.70% | 1.59% | **0.93×** ⚠ |
| 81+ | 0.69% | 0.64% | **0.93×** ⚠ |

> **⟹ 경쟁이 적으면 고정 숫자가 낫고, 경쟁이 많으면 못하다. 갈림목은 `N ≈ 30`.**
> **기제: `R` 바로 위에 서는 게 낙찰인데, 경쟁자가 많으면 누군가는 항상 `R` 바로 위에 있다.**

## 2. ⚠ 자기 정정 — 냈으면 틀렸을 수치

**처음 계산에서 이렇게 나왔다:**
```
아버지 자리에 x0=1.0000 고정 → 109 낙찰 (2.776%) vs 실제 74 (1.885%)
McNemar b=105 c=70  p=0.00996        ← "유일하게 아버지를 유의하게 이긴 방법"
```
🔴 **틀렸다. `x0=1.0000` 은 그의 표본에서 곡선의 *최댓값*이다.**
```
x0=0.9950 → 91      x0=1.0000 → 109     ← 최댓값
x0=0.9990 → 57      x0=1.0005 →  29     ← 0.0005 옆에서 급락
격자 전체 평균 1.738%  ·  중앙 1.681%  ·  최저 0.739%  ·  최고 2.776%
그의 실제                                            1.885%
```
> **⟹ 격자 평균으로 보면 상수가 아버지보다 *못하다*. `p=0.00996` 은 86개 격자점 중 최고를 고른 값이다.**
> **⟹ 규율 36(결과로 고른 집단)의 연속 격자판이다. 내가 만든 규율에 내가 걸렸다.**

### 정직한 검정 — 앞 절반에서 고르고 뒤 절반에서 채점

```
앞 절반(202312~202503)에서 최적 상수 x=0.9945 선택  (그 구간 3.311%)
뒤 절반(202503~202608)에서 채점       2.191%   vs  아버지 1.885%
이득 +0.306%p   95% CI [−0.662, +1.326]     ⟹ **0 을 포함한다. 판정 불가**
```

## 3. 🔴 그래서 진짜 결론 — **아버지 한 명으로는 아무것도 못 잰다**

```
상수 전략 하나의 추정치가 x0 를 0.02 움직이는 사이 0.739% ~ 2.776% 로 흔들린다
⟹ 그의 3,926 투찰에서 **잡음 바닥이 약 ±1%p 다**
⟹ 아버지 1.91% / M1 2.11% / M4 2.22% 의 차이는 전부 이 바닥 아래다
```
**⟹ `M1`·`M4` 의 `p=0.575`·`p=0.388` 은 "모형이 나쁘다"가 아니라 "이 자로는 못 잰다"였다.**
**⟹ 전수 평가(10.5M 투찰)로 옮기는 결정이 옳았다. 이 문서가 그 근거다.**

## 4. ⚠ 상수가 기준선이어야 한다 — 제비뽑기가 아니라

```
지금까지 기준선   제비뽑기 1.87%      ← 너무 약하다
🔴 옳은 기준선     최적 상수           ← 전수에서 사람 평균을 이긴다
```
**⟹ 모든 방법은 *상수를 이겼는가*로 다시 채점한다. 제비뽑기를 이기는 건 자격 요건이 아니다.**

## 5. 제품 함의

```

⚠ N>=41 이면    고정은 사람보다 못하다 (0.93배).  여기서 값을 하려면 진짜 모형이 필요하다

🔴 균형 주의     모두가 같은 상수를 쓰면 이 이득은 사라진다.  현 인구에 대한 최적반응이지 균형이 아니다
```

## 🔴 "사람 = 제비뽑기" 는 항등식이다 — 결과가 아니다

```
회차 a · 투찰자 j 의 제비뽑기 승률 = 1/N_a
전 투찰 합 = Σ_a N_a·(1/N_a) = 회차 수
÷ 총 투찰  = 회차수/투찰수 = **사람 낙찰률과 정의상 동일**   (회차당 낙찰자 정확히 1명)
```
⚠ **소수 셋째 자리까지 같은 것이 당연하다. 대수다.**

## ① 항등식이 무엇을 무효화하나 — **풀링만이다**

```
전 투찰 Σ(1/N) = 233,380.0   =   회차 수 233,380   =   실제 낙찰 233,380
⟹ 소수점까지 정확히 같다.  풀링 제비뽑기는 인구 평균과 **항등**이다
```
**그런데 사업자 개인에는 안 걸린다:**
```

|차이| > 5 인 사업자 **1,917명**
⟹ 합만 묶이고 개인은 자유롭다
```
> ✅ **⟹ 부록 AI(전수 `z` 분포 · `sd=2.41` · 상위 1% 2.1배)는 항등식과 무관하다. 그대로 유효하다.**
