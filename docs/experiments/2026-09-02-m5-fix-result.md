> **⟹ 층별 양상은 *다음 가설*이지 이번 결과의 구제가 아니다.**

### 왜 이 모양인가 — 가설 (안 쟀다)

```
고N 에서는 최적 x 가 R 분포의 아래쪽에 몰린다 ⟹ "낮게" 만으로 거의 맞는다
저N 에서는 최적점이 위로 올라가고 **봉우리가 중요해진다** ⟹ 단조 정책이 무너진다
⟹ 신경망이 못 배운 것은 "봉우리의 위치가 N 에 따라 이동한다" 는 상호작용이다
```
⚠ **가설이다. 이번 실행으로 검증하지 않았다.**
