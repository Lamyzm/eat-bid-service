# 재료 값어치 실험 — 설계

**2026-09-01 · 상태: 설계 (실행 전) · 숫자를 보기 전에 못박는다**

---

## 0. 이 문서가 정하는 것

**사용자가 스스로 분석할 수 있는 화면을 만들기 위한 초석이다.**

우리 제품은 답을 주지 않는다. 사장이 재료를 보고 **자기 판단을 세운다.**
그러면 화면이 할 일은 둘이다:

> **① 볼 값이 있는 재료를 놓는다**
> **② 사장이 스스로 잘라 보고 견줄 수 있는 축을 연다**

지금 화면의 재료들(`잘 나온 구간`·`참여 업체 수`·`최근 3회`·`하한율`…)은
**설계자가 값하리라 믿어서** 놓인 것이다. 재본 적이 없다.
그리고 **축**(품목·지역·시기·경쟁밀도)은 아예 안 열려 있다.

**산출물은 둘이다: 재료 순위표 + 축 목록.**

### 🔴 척도를 바꾼다 — "설명력"이 아니라 "결정을 바꾸는가"

제품이 예측기가 아니므로 **"이 재료가 결과를 얼마나 맞추나"는 잘못된 자다.**

- **설명력이 높아도 사장이 못 쓰는 값**이 있다 (바꿀 수 없는 축과 묶여 있으면)
- **설명력이 낮아도 결정을 바꾸는 값**이 있다 (드물지만 결정적인 경우)

→ **중심 지표는 정보의 값어치(Value of Information)다.**
**그 값을 알았을 때 최적 행동이 달라지고, 달라진 행동이 더 나은 결과를 내는 정도.**

VoI 는 세 가지를 저절로 처리한다:
| | |
|---|---|
| 맞추지만 행동과 무관한 값 | VoI = 0 → **안 놓는다** |
| 두 재료가 같은 말을 함 | 둘째의 한계 VoI = 0 → **하나만 놓는다** |
| 특정 상황에서만 결정적 | 조건부 VoI → **그때만 놓는다** |

### 예측은 죽이지 않는다

헌법 1번(예측·추천가 금지)은 **제품에 넣는 것**을 금한다. **조사하는 것**은 금하지 않는다.
분석하다 예측이 실제로 되면 **그게 발견이고 좋은 일이다** — 다만 그때 제품에 넣을지는
따로 판단한다. **실험에서 미리 접지 않는다.**

## 1. 전제 변경 — 사용자는 한 명이 아니다

**엔터프라이즈 목표로 바뀌었다.** 그 결과 앞선 판정 셋이 다시 열린다:

| 앞서 미룬 판정 | 근거였던 것 | 지금 |
|---|---|---|
| `conflict` 101 미룸 | *아버지 지역 넷은 전국 유일 이름* | **무효.** 서구·북구·남구·동구·중구·강서구를 쓰는 802곳이 사용자가 된다 |
| `시군구 미상` 5곳 무시 | *0.08% 라 화면에 거의 안 보임* | **재판정 필요.** 그 지역 사장에게는 100% 다 |
| `PDLC_NM` 79.6% 로 충분 | *아버지 지역 넷이 커버됨* | **무효.** 빠지는 서울 자치구 51종이 곧 사용자다 |

**이 문서의 실험도 같은 규율을 따른다 — 아버지 표본으로 일반 결론을 내지 않는다.**

## 2. 무엇을 재는가

### 2-1. 예측은 목표가 아니지만 문은 열어 둔다

선행 분석이 이미 결론을 냈다(`eat-bid/README.md`):

```
낙찰 ⟺ x ≥ R 이고, R ≤ xⱼ < x 인 경쟁자가 없음
  x = 투찰금액 / (기초가격 × 하한율/100)
  R = 예정가격 / 기초가격     평균 0.99868 · sd 0.00781

커트라인 흔들림(기초가의 0.78%) > 승부가 갈리는 창문 폭(0.058%) 의 13배
```

**예정가는 복수예가 15개 중 4개 추첨 평균이다. 투찰 시점에 원리적으로 알 수 없다.**

→ **주 질문은 "맞출 수 있나"가 아니다.** 다만 재다가 넘으면 그건 발견이다 — 미리 접지 않는다.

> **① 결과의 몇 %가 애초에 설명 가능한가 (상한)**
> **② 그 설명 가능한 몫을 어느 재료가 갖고 있는가 (순위)**
> **③ 나머지는 무엇인가 — 운인가, 우리가 못 본 것인가**

⚠ **이 선행 결론 자체를 재검증한다.** 인용하고 넘어가지 않는다.
`sd 0.00781`·`창문 폭 0.058%`를 새 코퍼스에서 다시 낸다. 다르면 그게 첫 발견이다.

### 2-2. 목표 변수 — 셋을 따로 잰다

한 변수로 뭉치면 어느 재료가 무엇을 설명하는지 안 갈린다.

| | 정의 | 왜 따로 |
|---|---|---|
| **Y1 낙찰 여부** | `won ∈ {0,1}` | 사장이 실제로 겪는 결과 |
| **Y2 커트라인 위치** | `x = 투찰금액 / (기초가 × 하한율/100)` | 사장이 **고르는 값**. 유일한 조작 변수 |
| **Y3 낙찰선** | 그 회차 낙찰 `x` | 사후 관측. **예측 대상이 아니라 벤치마크** |

**Y2 가 실험의 중심이다.** Y1 은 Y2 와 R(추첨)의 함수이고, R 은 우리가 못 건드린다.

## 3. 🔴 정보 집합 동등성 — 이 실험의 유일한 무효 조건

> **모델과 사람에게 투찰 시점에 알 수 있었던 것만 준다.**

이걸 어기면 실험 결과가 **전부 무효**다. 성능이 좋게 나오면 더 위험하다 —
좋아 보이는 이유가 미래를 봤기 때문이라 아무도 안 의심한다.

### 3-1. as-of 절단

각 회차의 기준 시각 = **`BID_END_DT`(투찰 마감)**.
⚠ `OPNG_DT`(개찰)가 아니다. 둘은 같은 적이 0/1,200 이고 최대 18시간 차다.

**그 시각 이후에 생긴 값은 어떤 특징에도 못 들어간다.**
학교 과거 이력도 **그 시각 이전에 개찰된 회차만** 집계한다.

### 3-2. 누출 목록 — 명시로 금지한다

| 값 | 언제 생기나 | 지금 화면에 있나 |
|---|---|---|
| `예정가(PLNPRCE)` | 개찰 | 아니오 |
| `낙찰가·낙찰률` | 개찰 | **예 — `최근 3회`·`잘 나온 구간`의 원천** |
| `참여 업체 수(BID_CNT·nValid)` | 개찰 | **예 — `usualN` 으로 노출 중** |
| `순위(RNK)` | 개찰 | 아니오 |
| `예비가격 15개` | 개찰 | 아니오 |

⚠ **`최근 3회`·`잘 나온 구간`·`참여 업체 수`는 과거 회차의 개찰값이라 누출이 아니다.**
단 **as-of 절단 안에서 집계할 때만** 그렇다. 지금 로더는 전 기간으로 집계한다 —
**미래 회차가 과거 특징에 섞여 있다.** 이 실험에서는 그걸 다시 만든다.

### 3-3. 사람 쪽 정보 집합

아버지와 모델을 비교하려면 **아버지가 실제로 본 것**을 알아야 한다.
**우리는 그걸 모른다.** 그래서:

- **모델에게 상한을 준다** — 원본이 그 시점에 준 것 전부
- **비교는 "모델 > 사람"이 아니라 "정보 상한으로도 이만큼뿐"** 으로 읽는다
- ⚠ **모델이 못 이기면 강한 결론**(정보로 안 되는 판)
  **이기면 약한 결론**(사람이 못 본 정보가 있었을 뿐일 수 있다)

**비대칭을 문서에 박는다. 유리한 쪽으로 읽지 않는다.**

## 4. 실험 두 축 — 표본 크기가 다르다

```
모집단 축   회차 228,564 · 투찰 1,058만 · 2023-09 ~ 2026-08
개인 축     투찰 3,926 · 낙찰 75         2023-12 ~ 2026-08
```

**낙찰 75건이 개인 축의 상한이다.** 이 숫자가 설계를 제약한다:
- 파라미터 수십 개짜리 모델은 **반드시 과적합**한다
- 효과 크기가 크지 않으면 **검출되지 않는다**
- **엔터프라이즈 결론은 개인 축에서 내지 않는다**

### E1 (모집단) 설명 상한
**질문:** 투찰 시점 정보만으로 Y1/Y2 의 몇 %를 설명하나.
**방법:** 시간 분할(2023-09~2025-12 학습 / 2026-01~08 평가). 무작위 분할 금지 — 미래가 샌다.

### E2 (모집단) 재료의 정보 값어치 — **화면 순위표의 원천**
**질문:** 이 재료를 알았을 때 최적 행동이 달라지고, 그 행동이 더 나은 결과를 내나.

**두 층으로 잰다:**
| | 무엇 | 답하는 것 |
|---|---|---|
| **설명력(절제)** | 재료를 뺀 모델의 성능 하락폭 | 이 값에 정보가 있나 |
| **VoI** | 그 재료를 보고 행동을 바꿨을 때의 결과 개선 | **그 정보가 쓸모가 있나** |

**둘이 갈리는 게 핵심이다.** 설명력은 높은데 VoI 가 0 이면 —
**맞추기는 하는데 사장이 그걸로 할 수 있는 게 없다는 뜻**이고, 화면에 놓을 이유가 없다.

**한계 VoI 로 잰다** — 이미 놓인 재료들 위에 이 재료를 더했을 때의 개선.
그래야 **중복이 자동으로 걸러진다.**

### E6 (모집단) 축 실험 — **사용자가 스스로 자를 수 있게**
**질문:** 어떤 차원으로 나누면 결과 분포가 실제로 갈리나.

후보 축: 품목 · 시군구 · 시도 · 하한율 · 기초가 구간 · 경쟁 밀도 · 학교 규모 ·
공고 시기(월·요일) · 단가/총액 계약 · 다품목 여부 · 재입찰 여부

**갈리는 축만 UI 의 필터·비교 대상이 된다.** 안 갈리는 축을 열면 화면만 복잡해지고
사장은 **의미 없는 차이를 의미 있다고 읽는다.**

⚠ **축은 재료와 다르다.** 재료는 "이 회차의 값"이고 축은 "무엇끼리 견줄까"다.
**지금 화면에는 축이 사실상 없다** — 지역 하나뿐이다.

### E7 (모집단) 재료 간 중복
**질문:** 어느 재료들이 같은 말을 하나.

`최근 3회`·`잘 나온 구간`·`학교 중앙값`이 서로 얼마나 다른 말을 하는지 잰다.
**같은 말이면 하나만 놓고, 나머지 자리는 다른 재료에 준다.**

### E3 (모집단) 이론 상한 재검증
`R` 의 분포를 새 코퍼스에서 다시 낸다. **완벽한 정보로도 못 넘는 선**을 긋는다.
E1 이 그 선에 붙으면 **남은 건 운이고, 화면은 더 보탤 게 없다.**

### E4 (개인) 아버지 선택의 개선 여지
**질문:** 같은 정보 집합에서 다르게 골랐으면 결과가 나아졌나.
**⚠ 낙찰 75건이라 결론이 아니라 신호다.** 신뢰구간을 반드시 같이 낸다.

### E5 (개인) 커버리지 대 위치
선행 분석의 가설 — *실효 레버는 투찰 위치가 아니라 커버리지와 티켓 배치*.
**같은 투찰 수를 다른 학교에 배분했을 때** 기대 낙찰이 어떻게 변하나.

## 5. 비교 대상 — 모델만 두면 잘하는지 못하는지 모른다

| | 규칙 |
|---|---|
| B0 | 항상 하한 + ε |
| B1 | 그 학교 과거 낙찰 `x` 의 중앙값 (as-of 절단) |
| B2 | 같은 시군구·품목의 최근 중앙값 |
| B3 | **아버지의 실제 투찰** |
| M | 모델 |

**B1 이 진짜 기준선이다.** 화면이 지금 하는 일이 대략 이것이라 —
**M 이 B1 을 못 이기면 화면을 바꿀 이유가 없다.**

## 6. 평가 — 정확도가 아니라 결정 개선

| 지표 | 무엇 | 쓰는 곳 |
|---|---|---|
| **한계 VoI** | 이 재료를 더했을 때 결정이 나아지는 정도 | **재료 순위표. 중심 지표** |
| **절제 하락폭** | 재료를 뺐을 때 설명력 손실 | VoI 와 갈리는지 보는 대조군 |
| **축 분리도** | 그 축으로 나눴을 때 분포가 갈리는 정도 | **UI 필터·비교 대상** |
| **표본 충분성** | 각 재료·축의 `n` 분포 | **n=1 짜리는 화면에 못 쓴다** |
| 낙찰 수 · 기대 마진 | 같은 투찰 수로 몇 건 · 얼마 | 결정 개선의 실물 |
| Brier · 보정 | 확률이 정직한가 | **보정 안 된 확률은 화면에 못 쓴다** |

⚠ **AUC 를 주 지표로 쓰지 않는다.** 낙찰률 1.9% 에서 실무 의미가 얇다.

⚠ **표본 충분성을 지표로 올린 이유** — 지금 화면이 `1회 중 100%` 같은 구간을 보여준다.
**틀린 값은 아니지만 사장에게 거짓 확신을 준다.** 재료의 값어치는 `n` 과 같이 판정한다.

## 7. 판정 기준 — **숫자를 보기 전에 못박는다**

| | 통과 | 실패 시 |
|---|---|---|
| **누출 검사** | as-of 위반 특징 **0개** | **실험 전체 무효** |
| **E2 재료** | 한계 VoI 신뢰구간이 **0 을 안 넘는 재료가 하나 이상** | 전부 넘으면 → **그 재료들을 화면에서 뺀다** |
| **E6 축** | 분포가 갈리는 축이 **하나 이상** | 없으면 → **필터를 안 연다** |
| **E7 중복** | 같은 말 하는 재료 쌍을 **찾아낸다** | — (찾는 게 목적) |
| E1 상한 | B1 대비 낙찰 수 개선폭을 **수치와 구간으로 제시** | — |
| E3 이론 상한 | E1 이 상한의 몇 %인지 제시 | 상한에 붙으면 → **화면이 더 보탤 게 없다** |
| E4 개인 | 신뢰구간이 0 을 안 넘음 | 넘으면 → **결론 없음** (75건이라 흔한 일) |

**"결론 없음"과 "실패"는 다르다.** 재료가 값을 못 한다는 게 밝혀지면
**화면에서 빼는 근거**이고, 그건 성공한 실험이다.

⚠ **E1 에서 임의의 문턱(`+10%` 같은 것)을 안 쓴다.** 앞선 초안에 그런 숫자를 적었는데
**근거가 없었다.** 개선폭을 구간과 함께 제시하고, **화면을 바꿀지는 그 구간을 보고 정한다.**

## 8. 이 실험이 못 보는 것 — 먼저 적는다

1. **아버지가 실제로 본 정보를 모른다** (§3-3)
2. **원가를 모른다** — 마진은 대리값이다
3. **회차 간 독립을 가정한다** — 실제로는 같은 학교에 반복 참여한다
4. **철회한 낙찰자 6.5%** — `won` 정의가 오염돼 있다(`PLAN-MATERIALS §0-2`). **E1 전에 처리**
5. **우리는 공고의 92.9%만 갖고 있다** — 유찰·취소가 빠졌다. 그쪽에 다른 규칙이 있으면 못 본다
6. **모집단 결론이 개인에게 이전되는지 안 잰다**

## 10. 순서

```
1. 누출 검사기부터 만든다        ← 특징 하나가 as-of 를 넘으면 즉시 실패
2. 새 코퍼스 (raw → 실험 테이블)  레거시 0줄
3. 규모 재측정 · §4 숫자와 대조
4. E3 (이론 상한)               ← 다른 실험의 눈금이 된다
5. E1 · E2 · E7            ← 재료 순위표 (VoI · 중복)
6. E6                       ← 축 목록. UI 필터가 여기서 나온다
7. E4 · E5                  ← 개인 축. 신뢰구간 필수
8. 재료 순위표 + 축 목록 → 화면 판정
```

**1번이 먼저다.** 누출은 나중에 발견하면 그때까지의 결과를 전부 버린다.
