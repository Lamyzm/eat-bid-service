## §0 이 문서가 정하는 것

**사용자가 스스로 분석할 수 있는 화면을 만들기 위한 초석이다.**

우리 제품은 답을 주지 않는다. 사장이 재료를 보고 **자기 판단을 세운다.**
그러면 화면이 할 일은 둘이다:

> **① 볼 값이 있는 재료를 놓는다**
> **② 사장이 스스로 잘라 보고 견줄 수 있는 축을 연다**

**산출물은 둘이다: 재료 순위표 + 축 목록.**

### 0-A 척도 — "설명력"이 아니라 "결정을 바꾸는가"

제품이 예측기가 아니므로 **"이 재료가 결과를 얼마나 맞추나"는 잘못된 자다.**

- **설명력이 높아도 사장이 못 쓰는 값**이 있다 (바꿀 수 없는 축과 묶여 있으면)
- **설명력이 낮아도 결정을 바꾸는 값**이 있다 (드물지만 결정적인 경우)

→ **중심 지표는 정보의 값어치(Value of Information)다.**

| | |
|---|---|
| 맞추지만 행동과 무관한 값 | VoI = 0 → **안 놓는다** |
| 두 재료가 같은 말을 함 | 둘째의 한계 VoI = 0 → **하나만 놓는다** |
| 특정 상황에서만 결정적 | 조건부 VoI → **그때만 놓는다** |

🔴 **VoI 는 max 기반 지표라 Optimizer's Curse 를 정면으로 탄다.** §8 의 게이트 G1 이
이걸 막고, **부수적으로 커스의 크기를 실측해 다른 모든 max 기반 숫자의 눈금이 된다.**

> **이건 가상의 위험이 아니다.** 메커니즘 조사에서 우리가 실제로 밟았다 — 내가 넘긴
> `레버 = (1/4)·[δ상위2 − δ하위2]·π(N)` 인수분해가 max 통계량이라 위로 편향되고,
> `π ≈ 1` 이라 편향이 감쇠 없이 넘어와 **깨끗한 δ 로도 0.32 bp 짜리 가짜 레버**가
> 나왔을 것이다. 직접 계산으로 바꿔서 잡았다. **커스를 문서에 적어 놓고 우리 계산에
> 그 함정을 넣을 뻔했다.**

### 무엇이 살고 무엇이 조건부가 되는가

**✅ 안 바뀐다 — 회차 *내부* 논리라 표본 구성과 무관하다:**
- 추첨 기전 전부 · 회차 내 반사실 **구조** · `BID_DT` 의미 · 미달 처리 · `R` 재계산
- 🔴 **유찰률 · `P(007|N)` 은 전국 API 질의라 영향 없다 — 우리가 가진 유일한 무편향 기준선이다**

**⚠ 조건부로 읽어야 한다:**
- **최적 x · VoI · 층화 결론은 이 지역 집합 조건부다.** 다른 지역에 일반화되는지 **모른다**
- **지역을 축으로 쓴 모든 분포**

✅ **다만 최적 x 뒤집힘은 시도한 세 부분집합에서 전부 동일했다** —
**전체 · 안전집합 · 지역일치.** **뒤집힘 자체는 견고하다.**

🔴 **그런데 `ml-expert` 가 중요한 단서를 붙였다: `F_X`(경쟁자 행동)는 지역 의존이 클 수 있다.**
**지역마다 업체 수·경쟁 구조가 다르면 `F_X` 가 다르고, 그러면 뒤집힘의 *위치* 가 움직인다.**
```
뒤집힘의 존재   구조적이다 (M1 이 메커니즘만으로 재현) → 안 바뀐다
뒤집힘의 위치   F_X 에 의존한다                        → 지역이 바뀌면 움직일 수 있다
```
**⟹ 화면에 `N` 문턱을 박기 전에 지역별 `F_X` 를 확인해야 한다.**

🔴 **`data-inventory` 가 자기 보고 하나를 종류째로 정정했다** — 부록 5.1 의 지역 분포
(경기 25.06% · 서울 20.71% · 전남광주 20.59% · 경남 13.96%)를 **"축"으로 냈는데,
그건 모집단 분포가 아니라 크롤러가 돈 곳의 지도였다.**

## §0-D 🔴 우리 "시간 분할"이 사실은 시간+지역 분할이었다

**지역 구성이 연도마다 다르므로, 등록된 시간 분할이 지역도 같이 갈랐다:**

```
학습(2023~25) → 평가(2026)   구성 변화
  부산          8.8%  →  0.0%
  전북          5.8%  → 18.9%
  9개 신규 시도  0.0%  → 15.0%

🔴 평가셋의 15% 가 학습에 한 회차도 없는 지역이다.
```
**held-out 으로 낸 모든 수치가 이 위에 있었다.**

### ✅ 지역을 맞춰 재실행했다 — 결론이 전부 살아남는다

**학습·평가 양쪽에 있는 지역만**(경기·서울·전남광주·경남·전북):

| | 전체(혼합) | **지역 일치분** |
|---|---|---|
| 학습 / 평가 | 171,730 / 61,392 | 156,601 / 52,236 |
| `N` 단독 VoI | +0.153 %p | **+0.126 %p** |
| **`N×기초` VoI** | +0.199 %p | **+0.168 %p** |
| **기초금액×N 이득** | +0.606 %p (z=+5.18) | **+0.536 %p (z=+4.20)** |

**앵커가 곧 게이트 높이이므로 그 오차가 게이트를 그만큼 높인다 — 통과했어야 할 모형이 떨어진다.**

## §3 🔴 정보 집합 동등성 — 이 실험의 유일한 무효 조건

이걸 어기면 실험 결과가 **전부 무효**다. 성능이 좋게 나오면 더 위험하다 —
좋아 보이는 이유가 미래를 봤기 때문이라 아무도 안 의심한다.

각 회차의 기준 시각 = **`BID_END_DT`(투찰 마감)**.

개정 1은 `참여 업체 수`를 누출로 봤다. **`BID_DT` 가 최초 제출임이 확정되면서 바뀐다:**

LAST_CHG_DT != BID_DT     100%  (한 값에 682행 = 개찰 일괄갱신)
```
**⟹ 과거 회차의 as-of `N(t)` 를 소급 재구성할 수 있다.**

**기준 시각은 T−1h 로 못박는다:**
```
T−6h   중앙 85.5%  ·  p10 57.1%      ← 하위 10% 회차에선 최종의 절반뿐. 못 쓴다

```
⚠ **집계값(85.8%)이 아니라 회차별 분포로 정했다.** 집계는 분포를 가린다.

🔴 **그런데 두 종류의 `N` 을 섞으면 안 된다:**
- **사후분석·상한·replay** → 최종 `N` (개찰 후)
- **화면·실전 규칙** → `N(T−1h)`

**둘의 차이가 곧 "N 을 모르는 값"이고, 그게 우리가 데이터로 처음 채우는 VoI 다.**

### 3-4 사람 쪽 정보 집합

아버지와 모델을 비교하려면 **아버지가 실제로 본 것**을 알아야 한다. **우리는 모른다.** 그래서:

- **모델에게 상한을 준다** — 원본이 그 시점에 준 것 전부
- **비교는 "모델 > 사람"이 아니라 "정보 상한으로도 이만큼뿐"** 으로 읽는다
- ⚠ **모델이 못 이기면 강한 결론**(정보로 안 되는 판) · **이기면 약한 결론**

**비대칭을 문서에 박는다. 유리한 쪽으로 읽지 않는다.**

```

  · 무득표 슬롯은 서버가 채움          2.742%. 슬롯 번호만 보고 가격은 안 본다
재구성 99.18%  ·  R = mean(선택4) 는 99.96%
```

**귀결 셋:**

**① replay 는 추정이 아니라 계산이다.** 경쟁자 `DRAW_NO` 전원과 `ds_pList` 금액을
관측하므로, **내 표만 바꿔 최다득표를 다시 세면 반사실 `R` 이 정확히 나온다.**
→ **행동 공간을 `x` 에서 `(x, 표)` 로 넓힌다.** 안 그러면 지금 replay 가 틀린 `R` 을 쓴다.

**② 동점 재현이 replay 정확도의 절반이다.** 회차의 48.2% 에서 tie-break 가 결과를 정한다.
**반사실은 대부분 동점 경계에서 갈리므로, 여기가 틀리면 반사실만 골라서 틀린다.**

**③ 투찰 시점 예측 불가와 개찰 후 완전 설명이 분리된다.**
> **`R` 은 투찰 시점에 예측 불가이지만 개찰 후에는 100% 분해된다.**
> **투찰 전 화면은 분포를, 개찰 후 화면은 분해를** — 데이터가 실제로 지지하는 구성이다.

**둘이 갈리는 게 핵심이다.** 설명력은 높은데 VoI 가 0 이면 화면에 놓을 이유가 없다.
**한계 VoI 로 잰다** — 이미 놓인 재료들 위에 더했을 때의 개선. 중복이 자동으로 걸러진다.

✅ **첫 VoI 는 끝났다 — 그리고 화면이 `N` 을 말할 자격이 섰다.**
학습 2023~2025 / 평가 2026, **시간 분할, in-sample 숫자 없음:**
```
① 상한 (최종 N 을 앎)      17.712%
② 실전 (N(T−1h))          17.559%      VoI = ① − ② = +0.153 %p  (상한의 0.9%)
③ 기준선 (고정 x=1.0080)   16.616%      ② − ③ = +0.943 %p  (상대 5.7%)
```
🔴 **`N` 예측 모델을 만들지 않는다** — T−1h 에 버킷이 94.2% 맞는다. **방법 하나를 재서 죽였다.**
🔴 **화면이 "지금 8명, 최종은 대개 5~9명 → x 는 이쪽" 을 말할 수 있다.**
손실은 `N=5-9` 경계에만 몰린다(0.44%p). **거기가 유일하게 불확실성을 표시할 자리다.**

### ✅ 갱신됨 — `N × 기초금액` 정책의 VoI `[영향 계산함]`

층화가 바뀌어 다시 냈다. **평가 2026 (61,392 회차), 정책은 2023~2025 에서 학습 — held-out 이다:**

| 정책 | 낙찰률 |
|---|---|
| ① 상한 — `N × 기초금액`, **최종 N** | **18.318%** |
| ② 실전 — `N × 기초금액`, **as-of N(T−1h)** | **18.120%** |
| ③ 상한 — `N` 단독, 최종 N | 17.712% |
| ④ 실전 — `N` 단독, as-of N | 17.559% |
| ⑤ 고정 x = 1.0080 | 16.616% |

```
🔴 새 VoI = ① − ②  =  +0.199 %p  (SE 0.048)   상한의 1.1%      옛 값의 1.30배
   ② − ④          =  +0.560 %p  (z=+4.95)     기초금액을 넣어 버는 것 — 실전 조건에서도 선다
   ② − ⑤          =  +1.503 %p
```

**셀이 5배로 늘었는데 오분류 손실은 30% 만 커졌다. 내가 걱정한 3~4배가 아니다.**

**⟹ 결정 ① "`N` 예측 모델을 만들지 않는다" 는 유효하다** (상한의 1.1%).
**⟹ 결정 ② EIV 재개 문턱만 `0.153 → 0.199 %p` 로 갱신한다.**

### 🔴 그리고 손실을 만드는 건 오분류가 아니다 — 이게 화면 문구를 좁힌다

| 기초금액 분위 | 회차 | VoI | **버킷 오분류율** |
|---|---|---|---|
| **Q1** (~636만) | 13,856 | **0.47 %p** | 6.6% |
| **Q2** | 11,963 | **0.34 %p** | 7.1% |
| Q3 | 11,262 | 0.10 %p | 5.6% |
| Q4 | 11,954 | 0.04 %p | 6.5% |
| **Q5** (3,230만~) | 12,357 | **0.00 %p** | **7.6%** |

🔴 **오분류율은 층마다 거의 같은데(5.6~7.6%) 손실은 Q1·Q2 에만 있다.
`Q5` 는 오분류율이 가장 높은데 손실이 정확히 0 이다.**

### 🔴 그런데 내 첫 읽기는 **동어반복**이었다 — 정정한다

내가 *"손실을 만드는 건 `N` 을 틀리는 게 아니라 셀 간 최적 x 차이다"* 라고 적었다.
**그건 설명이 아니라 VoI 의 정의다:**
```
손실 ≈ P(오분류) × E[후회 | 오분류]
오분류율이 층마다 같다  ⟹  차이가 후회 항에 있다      ← 산술적으로 강제된다
```
**항상 참이므로 아무것도 설명하지 않는다.** 설명은 **"왜 결정이 안 바뀌나"** 에 있고,
**그건 아직 안 쟀다.** 내 뒷문장(*"곡선이 평평해서"*)은 **셋 중 하나를 근거 없이 고른 것**이다.

**`VoI(Q5) = 0` 을 만드는 설명 셋 — 제품 결론이 정반대다:**

| | 설명 | 제품 결론 |
|---|---|---|
| **A** | `w(x)` 곡선이 **평평하다** | 🔴 **큰 금액에 위치 조언을 아예 안 보여준다** |
| **B** | 곡선은 **뾰족한데 `x*` 가 `N` 에 따라 안 움직인다** | 🔴 **위치 조언은 보여주되 `N` 조건화만 뺀다** |
| ~~C~~ | ~~Q5 의 `N` 분포가 좁다~~ | ❌ **기각됨** (아래) |

**C 는 `stats-expert` 가 재서 기각했다** — Q5 의 `log N` sd 가 1.317 로 다른 분위(1.36~1.40)와
사실상 같고, 사전 등록 층 분포도 고르다(S1 24.4% · S2 29.8% · S3 17.4% · S4 25.0%).

### ✅ A/B 판정 규칙 — **숫자를 보기 전에 등록한다**

**① 과 ② 는 대등하지 않다. 순서가 있다:**

| | ② 작다 | ② 크다 |
|---|---|---|
| **① 작다** | **🅰** | **🅰** — ①이 작으면 ②를 못 읽는다 |
| **① 크다** | **🅱** | **🅲 모순** (`VoI>0` 이어야 한다) |

🔴 **①이 작으면 ②는 해석 불가다 — 평평한 곡선의 argmax 는 순수 잡음이라 아무 값이나
나온다.** 둘을 동시에 보면 안 된다.

**문턱을 발명하지 않는다. 둘 다 이미 등록된 눈금에 건다:**

```
① 뾰족함 = max w − median w
   눈금: T2 사업 문턱.   "평평하다"를 통계적으로 정의하면 표본 크기에 끌려간다.
                        결정에 의미 있는 평평함이어야 한다
   문턱: K건/년 ÷ 연간 투찰 수                          🔴 아래 ⚠ 참조

② 봉우리 이동폭 = spread( x*(N) )
   눈금: 승부 창문 5.8 bp.  x* 가 창문 하나 안에서 움직이면
                            틀린 N 의 조언을 따라도 같은 창문에 착지한다 — 선택이 동일하다
   문턱: < 1 창문 (5.8 bp)
```
**눈금 감각:** 앞서 나온 `1.011 → 0.983` 은 spread 0.028 = **280 bp ≈ 48 창문**이다.
**효과가 진짜일 때 이 문턱은 전혀 빡빡하지 않다. 걸리는 건 진짜로 안 움직일 때뿐이다.**

> 🔴 **문턱이 두 번 틀렸다. 두 번째가 훨씬 크다.**
>
> **새 코퍼스 재측정 (투찰 10,586,962 · 업체 5,986 · 37개월):**
> | 기준 | 연간 투찰 | **① 문턱** |
> |---|---|---|
> | **중앙 업체** | **252.6** | **1.979 %p** |
> | 활동 업체(연 12건↑) 중앙 | 376.2 | 1.329 %p |
> | 평균 업체 | 573.6 | 0.872 %p |
> | **p90 업체** | **1,496.3** | **0.334 %p** |
> | *(등록된 값 1,428)* | *1,428.0* | *0.350 %p* |
>
> 🔴 **등록된 1,428 은 p90(1,496)과 거의 같다 — 지금 문턱은 상위 10% 업체를 기술한다.**
> **중앙 업체 기준이면 1.979%p 로 5.7배 커진다.** 내가 걱정한 1.4배가 아니다.
>
> **⟹ 판정이 실제로 뒤집힌다: `Q3 의 ① = 1.96%p` 는 0.35 기준 통과, 1.979 기준 🅰 다.**
>
> **⟹ 그래서 단일 문턱을 등록하지 않는다. 판정을 볼륨의 함수로 보고한다:**
> ```
> "연 250 건 업체 기준 🅰 · 연 1,500 건 업체 기준 🅲"
> ```
> **§1 이 엔터프라이즈 전제를 못박았으므로 사용자가 분포 전체에 걸쳐 있다.**
> **하나를 고르는 것 자체가 근거 없는 선택이고, 곡선으로 내는 게 더 유용하다.**
>
> ⚠ **어느 분위를 제품의 기준으로 삼을지는 제품 결정이지 통계 결정이 아니다.**

> ⚠ **① 문턱 값에 문서 내 불일치가 있어 여기서 확정한다.**
> `stats-expert` 는 `K=5 → 0.25 %p`(연 2,000 투찰 가정), 나는 `0.34 %p`(연 1,450)로 적었다.
> **실측은 투찰 3,926 / 2023-12~2026-08(약 33개월) ≈ 1,428 건/년 이다.**
> **⟹ 문턱은 상수가 아니라 식으로 등록한다: `① < K ÷ 연간 투찰 수`.**
> **현재 최선값 `K=5`, 연 1,428 → `0.35 %p`.**
> ✅ **`stats-expert` 확인: `연 2,000` 은 모집단에서 가장 큰 업체(투찰 2,000·낙찰 38)
> 숫자였지 아버지가 아니었다.**
>
> 🔴 **그런데 문턱이 사용자별이다:**
> | 사용자 | 연 투찰 | `K=5` 등가 문턱 |
> |---|---|---|
> | 소량 | 300 | **1.67 %p** |
> | **아버지(기준)** | **1,428** | **0.35 %p** |
> | 대량 | 5,000 | 0.10 %p |
>
> **§1 이 "아버지 표본으로 일반 결론 내지 않는다"고 못박았는데 문턱이 아버지 볼륨에 걸려 있다.**
> **⟹ 판정문을 반드시 기준 볼륨과 함께 쓴다** — *"연 1,428 기준으로 🅰/🅱.
> 저볼륨 사용자는 🅰 쪽으로 기운다."* **지금 개인화까지 갈 필요는 없고,
> 판정문이 "모든 사용자"로 읽히지만 않으면 된다.**
> ⚠ 개인 축 규모는 옛 테이블 기준이라 재측정 대기다(§10). **재측정되면 문턱이 자동으로
> 따라 움직인다 — 그래서 상수가 아니라 식으로 등록하는 게 맞다.**

### 🔴 ② 에는 잡음 바닥을 반드시 댄다

**argmax 의 산포는 봉우리가 안 움직여도 0 이 아니다.** 추정 잡음이 `x*` 를 흔들고
**그 흔들림은 spread 를 항상 위로 민다 — 즉 🅱 를 거짓으로 보이게 만든다.**
```
❌ spread(x*) 를 0 과 비교
✅ spread(x*) 를 「x* 가 상수라는 귀무 하의 spread」와 비교
    (회차 블록 부트스트랩으로 각 층 x* 를 다시 뽑고 그 spread 분포를 얻는다)
```
**`α` 에 쓴 것과 정확히 같은 절차다**(§8-C 실패 6: 산포를 귀무 산포와 대조 안 함).
**이 문서에서 같은 실수가 두 번 나올 자리라 미리 막는다.**

### 🔴 등록하는 판정 절차 — **점추정이 아니라 신뢰구간 경계로 판정한다**

**초안이 `① < 문턱 → 🅰` 였는데 그건 점추정 판정이고, `stats-expert` 가 잡았다:**

> **①의 검정은 차이검정이 아니라 동등성검정(equivalence)이다.**
> **"평평하다"는 귀무가 아니라 대립가설이어야 한다.**
> **점추정으로 판정하면 ①을 못 재서 작게 나온 경우와 진짜 작은 경우를 못 가르고,
> 표본이 적을수록 🅰 가 잘 나온다 — 정확히 거꾸로다.**

**§8-C 실패 5(공허참)의 사촌이다 — 기각 못 한 것을 "없다"의 증거로 쓰는 것.**

```
전제: ①·② 모두 G1 평가기간 값. ①은 max, ②는 argmax 라 학습기간 값은 둘 다 위로 편향된다.

1단계   ① 의 CI 상한 < K ÷ 연간 투찰 수                →  🅰 확정. 멈춘다
2단계   ② 의 CI 상한 < 1창문  AND  ② < 귀무 spread 95분위  →  🅱 확정
3단계   CI 가 문턱을 걸치면                            →  🅲 무판정
        = "평평함이 확인 안 됨" 이지 "평평함" 이 아니다. 화면 안 바꾼다
```

### 🔴 그리고 T1-b 와 **경계 방향이 반대다**

```
T1-b   "효과가 크다" 를 주장   →   CI 하한 을 본다
①      "효과가 작다" 를 주장   →   CI 상한 을 본다
```
> **주장의 방향이 어느 경계를 보는지 정한다. 같은 문서에서 둘이 섞이면 반드시 틀린다.**

### ⚠ 등록 시점에 검정력을 미리 확인한다 — 사전 등록을 안 깬다

**무판정 띠를 넣으면 표본이 모자랄 때 항상 🅲 가 나와 규칙이 아무 판정도 안 하는 장치가 된다.**
```
Q5 평가기간 표본에서 ① 의 CI '폭' 이 얼마인가?
  폭 ≪ 문턱  →  규칙이 작동한다
  폭 ≳ 문턱  →  이 표본으로는 🅰/🅱 를 못 가른다. 그 사실을 결과로 적고 화면은 안 바꾼다
```
🔴 **이 확인은 ①의 *값* 이 아니라 *폭* 만 본다.** CI 폭은 **표본 크기와 분산에서 나오지
효과 크기에서 안 나온다.** **그래서 지금 재도 사전 등록이 안 깨진다.**

### 🔴 판정 — **🅲. 화면 안 바꾼다. 그리고 ①을 지금 다시 정의하지 않는다**

**등록된 절차의 결과가 🅲 다: `①`도 `②`도 문턱을 못 넘었다.**
**등록된 화면 결정은 "아무것도 안 바꾼다. 재측정"이고, 그대로 한다.**

> 🔴 **"①이 `VoI` 를 예측 못 하니 국소로 다시 정의하자"는 지금 하면 안 된다.**
> **그건 규칙이 실패한 걸 보고 규칙을 고치는 것이다 — 이 문서가 §8-A 부터 막아 온 그것이다.**
> **국소 ①은 *다음 라운드의 새 사전 등록 질문*으로 넘긴다. 사후 동기에서 나왔다는 것을
> 라벨에 붙여서.**

**그리고 이게 사전 등록이 실제로 작동한 사례다** —
**"모르겠다"를 그럴듯한 이야기 대신 내놓게 만들었다.**
**등록 안 했으면 국소 ①을 그 자리에서 만들어 🅰 를 냈을 것이다.**

### 판정별 화면 결정 — 이것도 지금 등록한다

| | 화면 |
|---|---|
| **🅰** | 🔴 **큰 금액에서 위치 조언을 뺀다.** 경고를 붙이는 게 아니라 **조언을 뺀다** |
| **🅱** | 조언은 보여주되 **`N` 조건화를 뺀다.** 참여자 수 경고도 뺀다 |
| **🅲** | **아무것도 안 바꾼다.** 재측정 |

⚠ **🅰 와 🅱 는 "경고를 어디 붙이나"가 아니라 "무엇을 보여주나"를 가른다.**
**그래서 화면 결정을 물린 게 옳았다.**

**사전 등록으로서 유효한 근거 셋:**
1. **문턱 둘 다 이 판정 이전에 존재한다** — T2 는 §8-A, 창문 5.8 bp 는 1차 문서
2. **어느 쪽이 유리한지 아무도 모른다** — 🅰 는 화면을 줄이고 🅱 는 유지한다
3. **모순 분기를 미리 열어 뒀다** — 답이 안 나오는 경우를 결과 보고 만들지 않는다

⚠ **그리고 경고 배치(`작은 금액 × N=5-9`)는 §8-A3 에 격리한 바로 그 사후 관찰에서 나왔다.**
화면 설계용이라 추론 주장은 아니지만, **held-out 에서 같은 자리에 나오는지 확인하고 붙인다.**
비용이 거의 없다.

**⟹ A/B 를 가르기 전에는 화면을 확정하지 않는다.** `N` 별로 `N=5-9` 가 0.44 → **0.76 %p**
로 커진 것은 사실이지만, **그 경고가 "경고"여야 하는지 "조언 제거"여야 하는지가 A/B 에 달렸다.**

⚠ **errors-in-variables 처리는 지금 안 한다. 재개 조건을 숫자로 박는다:**
> **어떤 EIV 처리도 최대 `0.168 %p` 밖에 못 번다** — 그게 as-of `N` 과 최종 `N` 의 전체 격차다.
> **T1 게이트 여유가 `0.168 %p` 미만으로 좁혀지면 그때 연다. 그 전에는 안 연다.**
> ⚠ **지역 일치 기준 갱신값**(혼합 기준 옛 값 0.199). §0-D 참조.
> ⚠ 갱신값이다(옛 0.153 은 `N` 단독 정책 기준). **held-out 이라 커스에 안 물렸다.**

**대조군 둘을 반드시 같이 돌린다:**
- **음성** — 난수 20개. VoI 가 0 이어야 한다
- **양성** — `DRAW_NO`. **예측력은 크고(85.6%) 결정 가치는 알려진 작은 값(≤0.3 bp)** 이다.
  난수보다 강한 시험이다 — "예측력이 없어서 0"과 "쓸모없어서 0"을 가른다

### E6 (모집단) 축 실험 — **후보 열한 개가 하나로 줄었다**

개정 1은 품목·시군구·시도·하한율·기초가·경쟁밀도·학교규모·시기·계약형태·다품목·재입찰
열한 개를 후보로 뒀다. **전수로 재니 최적 위치를 움직이는 건 하나뿐이다:**

| 축 | 최적 x 를 움직이나 |
|---|---|
| **`N` (경쟁자 수)** | 🔴 **뒤집는다.** 1.019 → 0.983 |
| 연도 2023~2026 | 1.013 / 1.011 / 1.008 / 1.008 — 거의 안 움직인다 |
| 하한율 90 / 88 | 1.007 / 1.009 — 안 움직인다 |
| 품목 (8원자) | 0.998 ~ 1.016 — 크기만 바꾸고 모양은 안 바꾼다 |

**⟹ 1차 층화는 `N` 이다. 품목·연도로 쪼개면 표본만 잃는다.**
**그리고 `N ≤ 29` 안에서 기초금액이 2차 축이다(아래).**

### ✅ 품목 × `N` 교차 — 검정했고, 안 갈린다

**주변 최적 x 만으로는 판정할 수 없다**(품목마다 `N` 분포가 다르면 그 차이가 곧 `N` 효과의
그림자다). 그래서 교차로 다시 냈다.

**먼저 표본 게이트(칸당 1,500) — 60칸 중 33칸만 볼 수 있다.**
🔴 **곡류·우유류는 통과 칸이 0개다. `N=1` 도 전 품목 미달이다.**
**이 셋은 "효과가 없다"가 아니라 "못 봤다"로 적는다.**

**판정 — argmax 는 갈리는 것처럼 보이지만 과적합이다:**
```
눈으로:  N=2-4 에서 김치류 0.9980 vs 다품목 1.0160        ← 갈리는 것처럼 보인다
정책으로 만들어 시간분할(학습 2023~2025 / 평가 2026):

  A  N 단독        17.712%
  B  품목 × N      17.761%
  B − A = +0.049 %p   SE 0.098   z = +0.50        ← 사라진다
```
**두 정책이 회차의 51.2%(31,442)에서 서로 다른 x 를 고르는데도, 그 회차만 봐도 SE 안이다.**

**⟹ 화면에 품목 필터를 넣을 근거가 없다.**

### 🔴 기초금액 × `N` — **갈린다. 층화는 `N` 하나가 아니다**

`stats-expert` 가 `α` 축에서 `하한율 88 × 기초금액 2,000만원` 상호작용을 찾았고,
**기초금액이 최적 x 축으로는 검정된 적이 없다**는 게 드러나 같은 절차로 냈다.
**절단점은 고정하지 않고 분위 격자로 열었다.**

| 2026 평가 (학습 2023~2025) | 낙찰률 |
|---|---|
| A: `N` 단독 | 17.712% |
| **B: 기초금액 × `N`** | **18.318%** |
| **B − A** | **+0.606 %p** (SE 0.117, **z = +5.18**) |

| 축 | z | |
|---|---|---|
| 품목 × `N` | +0.50 | ❌ |
| **기초금액 × `N`** | **+5.18** | ✅ |

**해상도를 올릴수록 이득이 커진다 — 구간화 인공물이 아니다:**
3분위 +0.557 (z=4.56) · 5분위 +0.606 (z=5.18) · **10분위 +0.692 (z=5.80)**

### 🔴 그런데 이득이 `N ≤ 29` 에만 있고 `N = 100+` 에서는 **해롭다**

| `N` | 회차 | A | B | 차이 | z |
|---|---|---|---|---|---|
| 2-4 | 10,054 | 47.24% | **48.47%** | **+1.22 %p** | **+4.55** |
| 5-9 | 12,930 | 24.86% | **26.09%** | **+1.23 %p** | **+3.30** |
| 10-29 | 18,957 | 11.77% | **12.44%** | **+0.66 %p** | **+3.12** |
| 30-99 | 11,939 | 2.31% | 2.19% | −0.13 %p | −0.79 |
| **100+** | 7,167 | 1.53% | **1.24%** | **−0.29 %p** | **−2.03** |

**⟹ 전역 필터로 걸면 고경쟁 회차에서 손해다. `N ≤ 29` 조건부로만 건다.**

**방향은 층 안에서 단조다** — `N` 층 안에서 **기초금액이 클수록 최적 x 가 오른다**
(`N=5-9` 에서 Q1 0.9930 → Q5 1.0090).

### ⚠ 그리고 주변으로 봤으면 **반대 결론**이 나왔다 — 실물 두 번째

**기초금액 주변 최적 x 는 단조가 아니다:** Q1 1.0070 · Q2 1.0080 · Q3 1.0130 ·
Q4 1.0110 · Q5 1.0090.

> **초기 스윕에 이 축을 주변으로 넣었으면 "안 갈린다"고 잘못 적었을 것이다.**
> **축이 빠져 있던 게 운이 좋았던 게 아니라, 살아 있던 위험이 우연히 잡힌 것이다.**

**§8-C 의 "주효과로만 검정하면 상호작용 층을 놓친다"가 이 라운드에서 두 번 실물로 나왔다** —
`α` 축(발주기관·품목이 주효과로는 기각되고 기초금액 상호작용이 진짜였다)과 여기.

### ⚠ `α` 절단점을 최적 x 에 전용하면 안 된다 — 재서 확인했다

| | n | 최적 x | 최대 |
|---|---|---|---|
| 하한 88 · <2,000만 | 6,901 | 1.0080 | 16.81% |
| 하한 88 · ≥2,000만 | 75,259 | **1.0090** | 24.15% |

**`α` 에서 6.6배 상호작용을 만드는 2,000만 선이 최적 x 에서는 아무것도 안 가른다**
(1.0080 vs 1.0090). **최적 x 쪽은 분위 전체에 걸쳐 연속이다 — 특정 선이 아니라 연속 축이다.**

> **두 축은 변수를 공유하지만 절단점이 다르다.**
> `α` 의 절단점은 **규칙**에서 나오고, 최적 x 의 절단점은 **`f_R/g` 구조**에서 나온다.
> **같을 이유가 없다.**

⚠ **하한율은 다른 자리에서 축이다** — 최적 x 는 안 움직이지만 **`α` 를 예측한다**
(90 → 3.0% 상수, 88 → 2.87%). **`f_R` 을 만들 때의 층화축이지 위치 선택의 축이 아니다.**

**남은 축 실험은 이것 하나다: 지역·학교·기관이 무언가를 가르나.** 위 넷은 안 갈랐다.
**안 갈리면 필터를 안 연다** — 사장이 의미 없는 차이를 의미 있다고 읽는다.

| | 규칙 |
|---|---|
| B0 | 항상 하한 + ε |

## §8 판정 기준 — **숫자를 보기 전에 못박는다**

### 8-A 🔴 Optimizer's Curse 게이트 G1~G5 — 모든 max 기반 숫자에 적용

**G1. 시간분할 밖에서 값을 보고한다.** 학습기간에서 `x*(N)` 을 고르고 **평가기간에서 그
`x*` 의 승률을 잰다. 학습기간 최댓값은 절대 보고하지 않는다.** argmax 선택이 학습기간 안에서
끝나므로 **편향이 구조적으로 제거된다 — 축소 수식이 필요 없다.**

> 🔴 **부수 효과가 게이트 자체보다 값어치 있다: `학습 max − 평가 값` = 커스의 실측값.**
> **VoI 를 포함한 모든 max 기반 지표의 편향 눈금이 된다. 한 번 재서 문서에 남긴다.**

**G2. max 전에 곡선을 매끄럽게.** `ŵ(x)` 는 이론상 x 에 대해 매끄럽다.
**격자별 원시 추정치의 max 를 쓰지 마라.** 평활 적합 후 그 곡선의 max —
**평활이 이 상황의 shrink-then-max 다.**

**G3. 뒤집힘을 순열 귀무와 대 본다.** 귀무는 "곡선이 N 과 무관".
셀(연월×하한율×품목) 안에서 **N 라벨을 순열** → N구간별 `x*` 재계산 → 통계량 `spread(x*)`.
관측(0.036)이 95분위를 넘는가. ⚠ **회차 블록 단위로, N 은 셀 안에서만** 섞는다.

**G4. argmax 말고 곡선을 보고한다.** `x*` 는 평평한 봉우리 위에서 크게 흔들린다.
**"1.011 을 넣어라"가 아니라 "이 구간이 평평하다 / 이쪽이 낫다"다.**
제품에 필요한 건 봉우리 위치가 아니라 **곡선이 평평한지 여부**다.

**G5. 효과 크기 문턱 — 3중 게이트. 셋 다 통과해야 예측 갈래를 연다.**

> ⚠ **내 초안(`+1.0%p`, 기준 "전체 최적 17.58%")은 커스를 문턱에 구웠다.**
> **`17.58%` 자체가 in-sample max 이고 G5 가 막으려는 바로 그 양이다.**
> **기준점은 반드시 `B1` 이어야 한다.** `stats-expert` 가 잡았고 아래가 서명본이다.

| | 게이트 | 왜 |
|---|---|---|
| **T1** 주 | 아래 8-A2 의 4 요건 (추세 · 수준 · 무해 · 한정) | 🔴 **내 초안의 「≥2 층 통과」는 폐기했다 — 지금 증거를 기각하도록 설계돼 있었다. 8-A2 참조** |
| **T2** 실물 | `Δ(승률) × 연간 투찰 수 ≥ **K = 5 건/년**` (개인 축 ≈ 1,450 투찰/년 기준 → Δ ≥ 0.34%p) | **사장이 판정에 참여할 수 있는 유일한 단위다.** 엔터프라이즈 축은 투찰 수에 비례해 조정 |
| **T3** 앵커 | 모형의 개선폭 > **「`f_R` 중심을 −10.0 bp 로 고치기만 한 것」** 의 개선폭 | **외부 숫자를 안 가져와 임의성이 가장 적다.** 모형이 "`f_R` 을 제대로 놓기"를 못 이기면 만들 이유가 없다. 🔴 **앵커가 곧 게이트 높이라 값이 틀리면 통과했어야 할 모형이 떨어진다** — §2-5 |

**셋 다 통과 → 위치 재료를 화면에 올린다. 못 넘으면 → 위치 조언을 접고 커버리지·티켓
배치로 옮긴다. 그건 "실패"가 아니라 "예측 갈래를 접는 근거"다.**

⚠ **T2 의 `K = 5` 는 사장이 정할 값이다.** 지금은 기본값으로 두고 **데이터를 보기 전에만**
바꾼다. 나중에 "10%는 너무 빡세네"가 되는 게 이 절이 막으려는 실패 그대로다.

> **G1 만으로 대부분 해결된다. G1 을 건너뛰면 나머지를 다 해도 숫자가 위로 편향된 채 남는다.**

### 8-A2 🔴 T1 상세 — 「≥2 층 통과」를 폐기한다

**내가 커밋한 형태가 결함이었다.** `stats-expert` 가 자기 제안의 검정력을 계산해 잡았다
(각 층 α=0.025 단측):

| 층별 검정력 | 효과가 **모든 층**에 있을 때 `P(≥2)` | 효과가 **한 층**에만 있을 때 |
|---|---|---|
| 30% | 0.348 | **0.022** |
| 50% | 0.688 | **0.037** |
| 70% | 0.916 | **0.051** |
| 90% | 0.996 | **0.066** |

🔴 **효과가 한 층에만 있으면 검정력이 2~7% 다. 사실상 항상 실패한다.**
**그리고 우리 증거가 정확히 그 모양이다 — 이득이 `N≤29` 에만 있고 `N=100+` 에서는 해롭다.**

> **그대로 등록하면 "국소적으로 진짜인 효과"를 "전역적으로 없음"으로 판정하게 된다.**
> **복제 조건으로 위양성을 막으려다 위음성을 거의 확실하게 만든 것이다.**

⚠ 「≥2 of K」의 실효 α: **K=4 면 0.0036 · K=5 면 0.0059.** 위 표와 같이 보면
**"보수적"이 아니라 "거의 항상 기각"이다.**

### ✅ 대체 — 추세 요건이 복제 요건을 대신한다

**우연한 한 층은 기울기를 못 만들고, 진짜지만 국소적인 효과는 만든다.** 그게 둘을 가른다.

🔴 **그리고 방향이 데이터를 보기 전에 이미 정해져 있다** — §4-2 의 구조가 예측한다:
```
P(낙찰|x) = f_R(x) / (N · g(x))   →   N 이 크면 영토가 얇아지고 몫이 1/N 로 눌린다
⟹ 위치 선택의 이득은 N 에 대해 감소해야 한다
```
**사후 관찰이 아니라 구조에서 나온 사전 예측이고, `기초금액` 결과보다 먼저 문서에 있었다.**

**등록 형태 — 넷 다 통과해야 한다:**

| | 요건 |
|---|---|
| **T1-a 추세** | 층별 개선폭이 `N` 에 대해 **단조 비증가** (Jonckheere–Terpstra, 단측) |
| **T1-b 수준** | 적어도 한 층에서 `B1` 대비 상대 개선 **CI 하한 > +10%** (G1 평가기간 · 회차 블록 부트스트랩) |
| **🔴 T1-c 무해** | **어느 층에서도 유의한 손해가 없을 것.** `N=100+` 의 −0.29%p(z=−2.03)가 정확히 여기 걸린다 — **각주가 아니라 게이트다** |
| **T1-d 한정** | 통과하면 **제품 주장을 통과한 층으로 한정한다** ("`N ≤ X` 에서") |

**T1-a 가 T1-b 보다 강력하다** — 모든 층의 정보와 순서를 다 쓰고 **우연한 한 층으로는 못 만든다.**

### ✅ 등록하는 `N` 층 — 투표 메커니즘의 구조 경계 (`2N` 표 vs `15` 슬롯)

**근거가 신호 위치와 무관하고, `기초금액` 결과보다 먼저 나왔다:**

| 층 | `N` | 표/슬롯 | n | 구조적 의미 |
|---|---|---|---|---|
| **제외** | 1–2 | ≤0.27 | 16,112 | **마스크가 표로 결정됨** (아래) |
| **S1** | 3–7 | 0.4~0.93 | 51,157 | 표<슬롯 · 채움 · tie-break 지배 |
| **S2** | 8–15 | 1.07~2.0 | 52,598 | 표≥슬롯 · 4/5위 동점 빈발 |
| **S3** | 16–37 | 2.1~4.9 | 37,795 | 득표수 분리 시작 |
| **S4** | 38+ | ≥5.1 | 75,542 | tie-break 희소 |

**`n` 이 3.8만~7.6만으로 고르다 — 층별 검정력이 비슷해 추세 검정이 한 층에 안 끌린다.**

**`N≤2` 제외 근거:**
> **`N≤2` 에서는 선택에 무작위성이 없다. 마스크는 뽑히는 게 아니라 계산된다.**
> **N=1**: 표 2개 → 서버가 2개를 채운다(결정론적, 낮은 번호 3배 선호).
> **N=2**: 표 4개 → 득표 슬롯이 4개면 **마스크 = 득표 집합. 선택 단계가 존재하지 않는다.**
> **N=3** 부터 `2N = 6 > 4` 가 되어 비로소 "고르는" 일이 생긴다.
> **∴ "선택이 가격과 독립인가"라는 귀무가설이 `N≤2` 에서 정의되지 않는다.**
> **실측 뒷받침:** `N≤2` 는 회차의 6.9% 인데 **선택보정 후 결합 z 의 거의 전부를 낸다**
> (z=+6.44 vs `N≥3` 의 +0.6~1.3). **잔여 이상이 정확히 귀무가 성립 안 하는 곳에 몰려 있다.**

### 🔴 8-A3 사후 관찰로 층을 고르지 않는다 — 두 개가 이미 위험이다

**우리는 이제 둘을 안다. 둘 다 층 선택에 쓰면 안 된다:**
```
🔴 "이득이 N≤29 에 있다"           (기초금액 × N 검정 결과)
🔴 "VoI 가 Q1·Q2 에서 크고 Q5 는 0" (VoI 층별 분해 결과)
```
**둘 다 사후 관찰이고, 그걸 보고 층을 고르면 "신호가 있는 곳만 골라 놓고 통과했다"가 된다.**
**등록은 위 구조 경계로만 한다.**

### 🔴 8-A4 `VoI` 자체가 max 기반이다 — G1 을 `VoI` 에도 건다

```
VoI = E_N[ max_x E[보상|N,Z] ]  −  max_x E[보상|Z]
      Z 가 세밀해지면 두 항이 다 커지고, Jensen 으로 첫 항이 더 빨리 커진다
      그리고 셀이 늘면 안쪽 max 의 후보가 늘어 Optimizer's Curse 가 커진다
```
**⟹ 재계산된 `VoI` 의 증가분은 "진짜"와 "커스"가 섞여 있다.**

🔴 **"`VoI` 가 커졌으니 `N` 예측 모델을 다시 연다"가 커스에 속아서 내려질 수 있다.**

> **`VoI` 를 `in-sample` 과 `held-out` 두 벌로 낸다.**
> **둘의 차이가 커스 실측값이고, 그게 그대로 EIV 재개 문턱의 잡음 하한이 된다.**

### ✅ 커스 눈금이 실측됐다 — 그리고 `VoI` 에는 쓰면 안 된다

```
held-out    상한 18.318%   실전 18.120%   VoI +0.199%p
in-sample   상한 20.274%   실전 20.157%   VoI +0.117%p

🔴 커스 = 20.274 − 18.318 = +1.956 %p     max 통계량은 in-sample 에서 약 2%p 부푼다
```

⚠ 🔴 **`VoI` 에 그대로 적용하면 안 된다.** `VoI` 는 **두 max 의 차이**라 커스가 대부분
상쇄된다 — **in-sample VoI 0.117 이 held-out 0.199 보다 오히려 작다.**
**눈금은 상한 · 최적 x · T1 의 *단일* max 에만 쓴다.**

✅ **이번 재계산은 이미 held-out 이다** — 정책을 2023~2025 에서 고르고 2026 에서 평가했다.
**그래서 `0.199 %p` 는 커스에 안 물린 값이다.** `in-sample` 대조는 커스 눈금용으로 따로 낸다.

| 7 | 🔴 **「기록이 처리를 대신함」** | 증상을 적는 행위가 처리했다는 느낌을 주고, 그 위에서 계산을 이어간다 |

**8 은 5(공허참)의 형제다** — 5 는 **기각할 수 없는 검정**, 8 은 **거짓일 수 없는 설명**.
둘 다 **반증 불가능한 것을 증거로 쓴 것**이다.

> **규율: "그럼 이게 거짓이면 무엇이 달라지나"를 물어라. 답이 "아무것도"면 설명이 아니다.**
> **규율: 합성 검증은 반드시 여러 시드로. 단일 실행은 검증이 아니라 추출 하나다.**
> **규율: 검정이 통과했을 때 "무엇이 검사됐나"를 물어라. 통과는 검사됐다는 뜻이 아니다.**
> **규율: 분할을 만들면 *다른* 축들이 양쪽에서 같은 분포인지 확인해라.**
> **한 축으로 자른다고 그 축만 갈리는 게 아니다.**
>
> ✅ **11 은 잡혔고, 검정 결과 결론이 전부 살아남았다** — 그리고 **약화가 아니라 강화**였다.
> **오염된 평가셋이 *더 어려운* 지역을 포함하고 있었으므로, 효과가 그 분포 변화를 뚫고 나온 것이다.**
>
> **10 이 잡힌 경위가 그 규율 자체다** — *"왜 승률이 `N` 과 무관하지?"* 를 물어서 잡혔다.

**단일 시드를 그대로 읽으면 "추정기가 편향돼 있고 실데이터 잔차는 전부 인공물"이 되고,
그건 여러 라운드에 걸쳐 세운 판정을 통째로 뒤집는 결론이다.**
**2분짜리 반복이 잡았다.**

오히려 의심스럽다"* 고 적어 `stats-expert` 에게 확인을 요청했고, 그쪽이 동어반복임을

| 나 | 90 행을 "0.041% 잔차"로 적고 넘어감 | `sd(R)` 이 2.8배 틀린 채 문서에 남음 |
| `data-inventory` | 왜도 −41.2·첨도 +1954 를 **"이상치 오염"이라 이름까지 붙이고** 그 위에서 승률 곡선 계산 | 곡선은 0.04%p 만 움직였다 (아래 ⚠) |
| `stats-expert` | `sd(mean r)=0.001534` 를 유도하며 **"직접 재라"는 경고를 달고, 그 숫자를 표에 넣고, 그 표로 판정** | 참값 0.002166 — **41% 틀렸고 판정이 바뀐다.** 그 값을 쓴 사람은 생성 규칙을 틀리게 동정했을 것이다 |
| `data-inventory` (2차) | *"제 지역 코드 매핑이 틀렸을 수 있습니다"* 를 적고 **그 표를 그대로 보고** | 실제로 틀렸다(코드 11 을 강원으로). **검증 비용이 로컬 계산 한 번, API 호출 0 이었다** |

🔴 **7 번이 세 좌석에서 네 번 나왔다 — 목록에서 가장 재발이 잦다.**
**그리고 마지막 사례가 가장 명확하다: 검증 비용이 거의 0 이었는데도 안 했다.**
> **⟹ 규율을 강하게 고친다: 의심을 적을 때 그 자리에서 검증 비용을 같이 적어라.**
> **비용이 낮으면 적지 말고 그냥 검증해라. "의심을 적었다"가 면죄부가 되는 걸 막는다.**

### 🔴 그래서 처방이 다르다 — "더 조심하기"가 아니라 **검사 규칙**이다

**1~6 은 다시 읽어야 잡히는데 7 은 문서를 자기 자신과 대조하면 기계적으로 잡힌다:**

> **「오염」「이상치」「의심」「미해결」「예외」가 들어간 문장은 반드시 처분 태그로 끝난다:**
> **`[제거함]` `[격리함]` `[영향 계산함]` `[의도적 무시 + 근거]`**
> **태그 없는 증상 문장 = 린트 오류.**
>
> 🔴 **그리고 강한 형태: 처분 태그가 `[영향 계산함]` 이 아니면 그 숫자를 표에 넣지 마라.**
> **경고 문구는 독자를 못 막는다. 표에서 빼는 것만이 막는다.**

### ⚠ 다만 "작은 개수 = 작은 영향"의 역도 참이 아니다

내 초안은 *"작은 개수가 작은 영향을 뜻하지 않는다"* 였는데 **`data-inventory` 가 반례를 냈다:**
```
오염 40 회차 (0.017%)  →  sd(R) 을 2배로 만들었다
                        →  낙찰률 곡선은 0.04 %p 밖에 못 움직였다
```
**낙찰률은 회차별 0/1 의 평균이라 유계여서 40 회차가 못 움직이고,
`sd` 는 제곱편차라 극단값이 지배한다. 통계량마다 답이 다르다.**

### ✅ 정정된 규율 — **영향 = `ε × 영향함수`. 한 줄로 계산된다**

내 1차 정정(*"통계량의 성질이 정한다"*)은 옳지만 **"그럼 어떻게 아느냐"에 답을 안 줘서
'계산하지 말고 생각해라'로 읽힌다.** `stats-expert` 가 이름과 공식을 줬다:

| 통계량 | 영향함수 | 오염의 영향 |
|---|---|---|
| **비율 (0/1 평균)** | 유계, `\|IF\| ≤ 1` | `\|Δ\| ≤ ε` — **개수가 곧 상한** |
| **평균** | `IF ∝ (x−μ)` | `Δ ≈ ε·δ̄` — 편차에 **선형** |
| **분산 · sd** | `IF ∝ (x−μ)²` | `Δ ≈ ε·(δ²−σ²)` — 편차의 **제곱** |
| 상관 · 회귀계수 | 무계 + 지렛대 | 더 나쁘다 |

**우리 90 행으로 검증했다** (`ε = 0.0386%`, 오염값 편차 `δ = 0.998` = 깨끗한 sd 의 **131배**):
```
sd    예측 0.021031  실측 0.021028   비 1.000
평균  예측 −3.85 bp  실측 −3.85 bp
비율  상한 0.0386%p  관측  0.04 %p
```
**같은 오염, 같은 개수. sd 는 2.76배 부풀고, 평균은 3.85 bp 밀리고, 비율은 0.04%p 에 갇힌다.
`data-inventory` 가 관찰한 두 값이 하나의 공식에서 둘 다 나온다.**

> **⟹ 「영향 = `ε` × 영향함수. 개수만으로는 절반이다. 둘 다 재라 — 한 줄이다.」**

### 🔴 그리고 이게 위 린트 규칙을 **실행 가능하게** 만든다

**린트의 진짜 위험은 "지키기 비싸면 무시된다"는 것이다.** `[영향 계산함]` 태그마다 오염 빼고
전체를 다시 돌려야 하면 아무도 안 한다.

**영향함수는 `ε`(오염 비율)과 `δ`(오염값 편차)만 재면 상한이 나오게 만든다 — 재계산 없이 30초.**
**그래야 규칙이 살아남는다.**

**실무 따름정리 — 이게 제일 자주 쓰인다:**
> **오염을 제거할 수 없으면 유계 통계량으로 보고하라.**
> 평균 대신 **중앙값**, 분산 대신 **IQR**, 무계 지표 대신 **비율**.
> **`sd(R)` 이 2.76배 튄 것도 중앙값·IQR 로 봤으면 안 튀었다.**

### ⚠ 그리고 비교 수치는 같은 격자에서 다시 계산한 뒤에 비교한다

`data-inventory` 가 `R` 수정 전후 동적범위를 **28.2 → 414.7** 로 보고할 뻔했다.
**격자를 넓힌 탓이지 `R` 수정 탓이 아니었고, 같은 격자로 맞춰 확인하니 28.1 이었다.**
**"고쳤더니 값이 크게 변했다"는 서사가 가장 잘 만들어지는 자리다.**

**규율으로 박는다:**
> **① 검정력을 항상 같이 보고한다. 표본으로 못 본 것을 "없다"로 적지 않는다.**
> **② 주장의 모양과 검정의 모양을 맞춘다. 모먼트 일치는 검정이 아니다.**
> **③ 집계는 분포가 아니다.**
> **④ 핵심 변수는 두 경로로 만들어 대조한다. 단위가 이상하면 즉시 멈춘다.**
> **⑤ 검정 조건은 그 조건이 만족돼야 하는 자명한 항등식을 같이 출력한다.**

**⑤는 실물로 값을 했다** — `xmax ≥ R` 이 007 전수에서 100% 여야 한다는 게 공짜로 나오는데,
안 찍었으면 0.186% 의 어긋남을 못 봤고 **판정이 내가 원하는 쪽으로 기운 채 나갔다.**

## §8-D ✅ 추정기 L1 — 우리가 판정에 써 온 둘을 뒤늦게 검증했다

**여러 라운드 동안 두 추정기를 판정 근거로 써 왔는데 검증한 적이 없었다.**
합성 세계는 **구성상 슬롯↔가격이 독립**이라 콜라이더 말고 `D` 를 만들 게 없다 — **진실 = 0.**

| 추정기 | 합성 (진실 0) | 실데이터 | 차 |
|---|---|---|---|
| **A** 안전집합 `mean(D)` | **+0.027 ± 0.103** (z=+0.26) | +0.542 ± 0.176 | **+0.515** (z=+2.53) |
| **B** 열거 귀무 잔차 | **−0.051 ± 0.069** (z=−0.74) | +0.375 ± 0.124 | **+0.426** (z=+3.00) |

> **둘 다 진실이 0 일 때 0 을 낸다. 편향이 없다.**
> **⟹ 실데이터 잔차(+0.54 / +0.375)는 구현 인공물이 아니다.**
> **우리 사다리에서 ②(구현이 틀렸다)가 이 주장에 대해 제거된다.**

**⟹ 남은 것은 ①(방법이 안 맞는다) 또는 ③(데이터가 모자란다)이고,
`N≤2` 건은 이미 ③으로 판정됐다(방법론 §3-1b).**

⚠ **늦었다.** 이건 그 추정기를 처음 쓸 때 했어야 하는 검증이다.
**규율로 올린다: 판정에 쓰는 추정기는 쓰기 전에 진실 0 에 대고 편향을 재라.**

## §9 이 실험이 못 보는 것 — 먼저 적는다

1. 🔴 **"왜 유찰되는가"는 이 코퍼스로 원리적으로 못 배운다.** 표본을 아무리 늘려도 못 배운다.
   ```
   이전 회차가 007 낙찰이면 보유 5/5 = 100%
   이전 회차가 009 유찰이면 보유 0/6,099 = 0%
   ```
   끝내 낙찰 안 된 사슬은 이력에도 안 남는다. 실패율 하한 2.5%, **상한은 계산 불가.**
   **⟹ 화면이 "이 공고가 유찰될 확률"도 "재입찰이 될 확률"도 말하면 안 된다.**
2. **아버지가 실제로 본 정보를 모른다** (§3-4)
3. **원가를 모른다** — 마진은 대리값이다
4. **회차 간 독립을 가정한다** — 실제로는 같은 학교에 반복 참여한다
5. **철회한 낙찰자 6.5%** — `won` 정의가 오염돼 있다. **E1 전에 처리**
6. ✅ **`N≤2` 이상 현상 — 원인 확정. 투찰 분포가 `N` 에 의존한다** `[영향 계산함]`
   합성 생성기에 `N` 구간별 실측 `x` 분포를 주니 `N≤2` 의 `D` 가 −8.87 → **−0.91**
   (실측 −1.24)로 맞았다. **경쟁이 적으면 높게 넣는다.**
   ⚠ **다만 크기는 여전히 식별 안 된다** — 실측 `x` 가 007 조건부라 선택이 두 번 적용된다.
   방법론 계획 §3-1b. **`P(007|N)` 이 있으면 풀린다**
10. 🔴 **목록 질의의 날짜 필터가 단순 범위가 아니다 — 우리 코퍼스 완전성에 걸린다**
    ```
    주간 창(2025-06-01~07)  →   111 건
    같은 달 전체            → 15,471 건        주/월 비 139배 (기대 4~5배)
    ```
    **`P_BID_BGNG_DT`/`P_BID_END_DT` 가 겹침이 아니라 더 좁은 조건으로 보인다**
    (투찰기간이 창 안에 온전히 들어가야 하는 형태로 추정). **정확한 의미는 모른다.**
    ⚠ **짧은 창 질의는 편향된 부분집합을 준다.** `[미해결 — 아래 검사 대기]`
    **결정적 검사: `12개 월별 창의 합 == 1개 연간 창` 인가.** 같으면 무해하고,
    다르면 **우리 아카이브가 창 경계에 걸친 회차를 빠뜨리고 있다.**
11. **모집단 결론이 개인에게 이전되는지 안 잰다**
8. 🔴 **투찰 분포와 콜라이더 강도가 007-only 데이터에서 분리 식별되지 않는다.**
   **"모르는 게 있다"가 아니라 "이 데이터로는 알 수 없다"다.** `P(007|N)` 이 있으면 풀린다.
   ⚠ **다만 판정 자체는 구조에 걸려 있어 영향 없다** — 투찰 분포를 어떻게 넣든
   필터를 끄면 `D ≈ 0`, 켜면 음수다
9. ⚠ **하한율 88 (회차의 35.2%) 의 `α` 에 숨은 축이 하나 더 있다** — `발주기관` 으로 추정.
   그 층에서는 `f_R` 이 지금보다 부정확하다

## §11 순서

```
1. 누출 검사기                      ← 특징 하나가 as-of 를 넘으면 즉시 실패
   🔴 검사기 사양 확장: "값이 마감 후에 생겼나"뿐 아니라
      "그 시점 아카이브만으로 재구성할 수 있나"까지 본다 (가용성 누출)
2. as-of N(T−1h) 재구성            ← 3-3. 이게 E2 의 첫 VoI 를 만든다
3. 새 코퍼스 (raw → 실험 테이블)     레거시 0줄 · 규모 재측정
4. E2 첫 VoI: N(T−1h) 대 최종 N     ← G1 을 여기서 처음 집행하고 커스 눈금을 잰다
5. E1 · E2 · E7                     ← 재료 순위표
6. E6 (지역·학교·기관 축만 남았다)   ← UI 필터
7. E4 · E5                          ← 개인 축. 신뢰구간 필수
8. 재료 순위표 + 축 목록 → 화면 판정
```

**~~E3~~ 가 빠져서 하루가 줄었다.** 그리고 **2번이 앞으로 왔다** — as-of `N` 이 없으면
E2·E6 이 전부 개찰 후 `N` 을 쓰게 되고, 그건 화면에 못 옮기는 결과를 만든다.

**1번이 먼저다.** 누출은 나중에 발견하면 그때까지의 결과를 전부 버린다.
