## §0 이 문서가 정하는 것

**사용자가 스스로 분석할 수 있는 화면을 만들기 위한 초석이다.**

우리 제품은 답을 주지 않는다. 사장이 재료를 보고 **자기 판단을 세운다.**
그러면 화면이 할 일은 둘이다:

> **① 볼 값이 있는 재료를 놓는다**
> **② 사장이 스스로 잘라 보고 견줄 수 있는 축을 연다**

**산출물은 둘이다: 재료 순위표 + 축 목록.**

### 0-A 척도 — "설명력"이 아니라 "결정을 바꾸는가"

제품이 예측기가 아니므로 **"이 재료가 결과를 얼마나 맞추나"는 잘못된 자다.**

- **설명력이 높아도 사장이 못 쓰는 값**이 있다 (바꿀 수 없는 축과 묶여 있으면)
- **설명력이 낮아도 결정을 바꾸는 값**이 있다 (드물지만 결정적인 경우)

→ **중심 지표는 정보의 값어치(Value of Information)다.**

| | |
|---|---|
| 맞추지만 행동과 무관한 값 | VoI = 0 → **안 놓는다** |
| 두 재료가 같은 말을 함 | 둘째의 한계 VoI = 0 → **하나만 놓는다** |
| 특정 상황에서만 결정적 | 조건부 VoI → **그때만 놓는다** |

🔴 **VoI 는 max 기반 지표라 Optimizer's Curse 를 정면으로 탄다.** §8 의 게이트 G1 이
이걸 막고, **부수적으로 커스의 크기를 실측해 다른 모든 max 기반 숫자의 눈금이 된다.**

> **이건 가상의 위험이 아니다.** 메커니즘 조사에서 우리가 실제로 밟았다 — 내가 넘긴
> `레버 = (1/4)·[δ상위2 − δ하위2]·π(N)` 인수분해가 max 통계량이라 위로 편향되고,
> `π ≈ 1` 이라 편향이 감쇠 없이 넘어와 **깨끗한 δ 로도 0.32 bp 짜리 가짜 레버**가
> 나왔을 것이다. 직접 계산으로 바꿔서 잡았다. **커스를 문서에 적어 놓고 우리 계산에
> 그 함정을 넣을 뻔했다.**

## §2 무엇을 재는가

### 2-1 선행 결론 재검증 — 끝났다. 셋 중 둘이 바뀌었다

```
낙찰 ⟺ x ≥ R 이고, R ≤ xⱼ < x 인 경쟁자가 없음
  x = 투찰금액 / (기초가격 × 하한율/100)
  R = 예정가격 / 기초가격
```

| | 선행 결론 | **전수 재측정** | |
|---|---|---|---|
| 낙찰 조건식 | 위 식 | **확정** | `xmax ≥ R` 이 100.000%, 예외 0 건 |
| `sd(R)` | 0.00781 | **0.007605** | 🔴 90 행 오염이 2.8배로 부풀리고 있었다 |
| `mean(R)` | 0.99868 | **0.998867** | 원인 확정 — 8/7 생성 규정 |
| 13배 논증 | 흔들림 > 창문의 13배 | **성립** | 그리고 **연도별로 안정 — 유효기간이 없다** |

🔴 **`R` 을 `ELCTRN_BID_PLNPRC / BGNG_PRC` 로 만들지 마라. `mean(CHC_YN='Y' 4개)` 를 써라.**
전자는 90 행이 통째로 깨져 있고, **그게 팀이 오래 끌던 sd 불일치의 정체였다.**

> **교훈을 규율로 올린다: 작은 개수가 작은 영향을 뜻하지 않는다.**
> 나는 이 90 건을 "0.041% 잔차"로 적고 넘어갔다. 90 행이 sd 를 2.8 배로 만들었다.

### 2-2 예측은 죽이지 않는다 — 그리고 이제 죽일 이유가 없다

헌법 1번(예측·추천가 금지)은 **제품에 넣는 것**을 금한다. **조사하는 것**은 금하지 않는다.

**그리고 분기점 판정이 나왔다 — `f_R/g` 는 평평하지 않다.**

비율 근사를 버리고 정의대로 셌다. `R` 도 경쟁자 `x` 전량도 관측되므로 **반사실이 정확히
계산된다** — 내 투찰만 옮겨 `x ≥ R` 이고 `[R,x)` 에 경쟁자 없음을 다시 판정. 근사 0, 가정 0.

```
낙찰률   x=0.980  0.62%    →    x=1.008  17.58%       28배
안전 부분집합에서 다시 재도                            35.9배
```
**⟹ M1·M2·M4·M5 를 접을 근거가 없다.** 개정 1이 걸어 둔 조기 종료 조건은 발동 안 한다.

### 2-3 🔴 이미 확정된 화면 재료 다섯 — 이건 실험 대상이 아니라 결과다

| 재료 | 값 | 성격 |
|---|---|---|
| **`f_R` 중심** | **−10.0 bp = 승부 창문 1.72 개** (해석적) | 🔴 **가장 큰 단일 오차원.** `R` 을 1.0 중심으로 놓고 위치를 잡으면 창문 1.7개만큼 어긋난다. as-of 안전. **007 전수 실측 −11.3 은 콜라이더가 섞인 값이다 — §2-5** |
| **`f_R` 층화축** | **하한율.** `α` 가 이봉(±2.14% / ±3.07%)이고 저모드 비율이 하한율 90→3.56% · 88→16.66% · 84→37.22% | **공고 시점에 알 수 있다.** ❌ 발주기관(between/within 0.795)·품목은 층이 아니다 |
| **최적 x 가 N 에 따라 뒤집힌다** | 1.019 → 0.983 (N=1 → N=100+) | 안전집합에서도 서고 동적범위가 오히려 커진다 |
| **번호 선택** | *"거의 항상 커트라인을 바꾼다. 그런데 어느 쪽인지는 알 수 없다"* | π > 0.94(N≤9) · 레버 0.298 bp < 영분포 0.367. **둘 다 측정값** |
| **오라클 상한** | 가격을 볼 수 있었다면 **89 bp = 창문의 15배** | 제도가 무엇을 막는지. 사장이 왜 이 게임을 하는지의 배경 |

**앞의 셋은 위치 계산에 직접 들어가고, 뒤의 둘은 사장의 세계관을 고친다.**

### 2-5 🔴 사장의 결정은 007 조건부가 **아니다** — 그리고 그게 앵커와 화면 둘 다 바꾼다

`ml-expert` 가 T3 앵커 `−11.3 bp` 에 007 콜라이더가 섞여 있다고 지적하고 분해했다:

```
007 전수    E[R]−1 = −11.332  =  후보생성 −9.332   +  선택 E[D] −2.000
안전집합    E[R]−1 =  −9.485  =  후보생성 −10.027  +  선택 E[D] +0.542
나머지      E[R]−1 = −17.202
```

**판정: 사장의 결정은 007 조건부가 아니다.** 근거 셋 —

1. **결정 시점에 그 회차가 낙찰될지는 미정이고, 그 미정을 좌우하는 게 `R` 자신이다.**
   007 로 조건화하면 **예측하려는 양이 들어간 콜라이더에 조건화**하는 것이다
2. **"아무도 못 땄다"는 사장에게 "남이 땄다"와 똑같은 패배다.** 분모에 남아야 한다
3. **무조건부 값은 추정 오차 0 으로 해석적으로 나온다**

```
E[mean r] = (8 × 0.985 + 7 × 1.015) / 15 = 0.99900   →   −10.00 bp
E[D]      = 0        (선택이 가격 무관 — §4-3b 에서 판정한 것)
E[R] − 1  = −10.00 bp                                     ← 앵커는 이것
```
**안전집합 실측 −10.027 이 0.03 bp 안에서 맞는다 — 독립 확인이다.**

⚠ **안전집합 값(−9.485)도 앵커가 아니다.** 안전집합은 `xmax ≥ Rmax` 로 자르므로
**후보 생성 평균 자체가 조건부다**(−10.027). `E[D]` 는 깨끗하지만 `E[mean r]` 은 아니다.

**⟹ T3 앵커를 `−10.0 bp` 로 확정한다.** 차이 1.3 bp 는 창문의 0.22 이고,
**앵커가 곧 게이트 높이이므로 그 오차가 게이트를 그만큼 높인다 — 통과했어야 할 모형이 떨어진다.**

### 2-6 🔴 같은 논리가 승률 **수준**에도 걸린다 — 그리고 이건 못 고친다

위 판정이 앵커 하나로 끝나지 않는다. **우리가 낸 모든 승률이 `P(낙찰 | 007)` 이다:**
```
17.712%  ·  17.559%  ·  16.616%  ·  최적 17.58%  ·  최악 0.62%      전부 007 조건부
```
사장이 마주하는 건 `P(낙찰)` 이고 `P(낙찰) = P(낙찰|007) × P(007)` 이다.

🔴 **그런데 `P(007)` 을 계산할 수 없다.** §9-1 대로 **끝내 낙찰 안 된 사슬은 이력에도 안 남아
실패율의 하한(2.5%)만 알고 상한이 없다.** 표본을 늘려도 안 된다.

**⟹ 화면 규율 둘:**
> **① 절대 승률을 절대값으로 보여주지 않는다.** `17.6%` 를 그대로 띄우면 사장이
> **실제보다 높은 수를 자기 확률로 읽는다.** 정직한 표시는 **비교·순위·상대 개선**이다
> **② 정책 비교는 유효하다.** 조건화가 두 정책에 공통이라 상쇄된다.
> **T1 을 절대가 아니라 `B1` 대비 상대로 잡은 게 이 이유로도 옳다.**

⚠ **이건 데이터 부족이 아니라 원리적 제약이다.** "나중에 유찰 데이터를 모으면 된다"가 아니다 —
**유찰 후 끝내 성사 안 된 건은 원본에도 흔적이 없다.**

## §3 🔴 정보 집합 동등성 — 이 실험의 유일한 무효 조건

> **모델과 사람에게 투찰 시점에 알 수 있었던 것만 준다.**

이걸 어기면 실험 결과가 **전부 무효**다. 성능이 좋게 나오면 더 위험하다 —
좋아 보이는 이유가 미래를 봤기 때문이라 아무도 안 의심한다.

### 3-1 as-of 절단

각 회차의 기준 시각 = **`BID_END_DT`(투찰 마감)**.
⚠ `OPNG_DT`(개찰)가 아니다. 둘은 같은 적이 0/1,200 이고 최대 18시간 차다.

### 3-2 누출 목록

| 값 | 언제 생기나 | 판정 |
|---|---|---|
| `예정가(PLNPRCE)` · `예비가격 15개` | 개찰 | ❌ 금지 |
| `낙찰가·낙찰률` · `순위(RNK)` | 개찰 | ❌ 금지. 단 **과거 회차의 as-of 집계는 허용** |
| **`참여 업체 수`** | 투찰마다 누적 | ✅ **as-of 로 자르면 허용** (아래) |
| `CHC_YN` · `DRAW_NO` (그 회차) | 개찰 | ❌ 금지. **사후분석·replay 에만** |

### 3-3 ✅ `N` 이 누출에서 특징으로 옮겨졌다

개정 1은 `참여 업체 수`를 누출로 봤다. **`BID_DT` 가 최초 제출임이 확정되면서 바뀐다:**

```
BID_DT == FRST_REG_DT     10,586,853 / 10,586,855
LAST_CHG_DT != BID_DT     100%  (한 값에 682행 = 개찰 일괄갱신)
```
**⟹ 과거 회차의 as-of `N(t)` 를 소급 재구성할 수 있다.**

**기준 시각은 T−1h 로 못박는다:**
```
T−6h   중앙 85.5%  ·  p10 57.1%      ← 하위 10% 회차에선 최종의 절반뿐. 못 쓴다
T−1h   중앙 99.3%  ·  p10 84.0%  ·  회차의 83.5% 가 90%↑
```
⚠ **집계값(85.8%)이 아니라 회차별 분포로 정했다.** 집계는 분포를 가린다.

🔴 **그런데 두 종류의 `N` 을 섞으면 안 된다:**
- **사후분석·상한·replay** → 최종 `N` (개찰 후)
- **화면·실전 규칙** → `N(T−1h)`

**둘의 차이가 곧 "N 을 모르는 값"이고, 그게 우리가 데이터로 처음 채우는 VoI 다.**

### 3-4 사람 쪽 정보 집합

아버지와 모델을 비교하려면 **아버지가 실제로 본 것**을 알아야 한다. **우리는 모른다.** 그래서:

- **모델에게 상한을 준다** — 원본이 그 시점에 준 것 전부
- **비교는 "모델 > 사람"이 아니라 "정보 상한으로도 이만큼뿐"** 으로 읽는다
- ⚠ **모델이 못 이기면 강한 결론**(정보로 안 되는 판) · **이기면 약한 결론**

**비대칭을 문서에 박는다. 유리한 쪽으로 읽지 않는다.**

## §4 메커니즘이 닫혔다 — 이게 실험 설계를 바꾼다

```
R = mean(득표 상위 4개 예비가격)
  · 표는 철회자 포함 전원 2표          회차의 52.67% 에 철회자가 있다
  · 동점은 낮은 번호 우선 (93.4%)      회차의 48.221% 에서 발생 — 예외가 아니라 기본 동작
  · 무득표 슬롯은 서버가 채움          2.742%. 슬롯 번호만 보고 가격은 안 본다
재구성 99.18%  ·  R = mean(선택4) 는 99.96%
```

**귀결 셋:**

**① replay 는 추정이 아니라 계산이다.** 경쟁자 `DRAW_NO` 전원과 `ds_pList` 금액을
관측하므로, **내 표만 바꿔 최다득표를 다시 세면 반사실 `R` 이 정확히 나온다.**
→ **행동 공간을 `x` 에서 `(x, 표)` 로 넓힌다.** 안 그러면 지금 replay 가 틀린 `R` 을 쓴다.

**② 동점 재현이 replay 정확도의 절반이다.** 회차의 48.2% 에서 tie-break 가 결과를 정한다.
**반사실은 대부분 동점 경계에서 갈리므로, 여기가 틀리면 반사실만 골라서 틀린다.**

**③ 투찰 시점 예측 불가와 개찰 후 완전 설명이 분리된다.**
> **`R` 은 투찰 시점에 예측 불가이지만 개찰 후에는 100% 분해된다.**
> **투찰 전 화면은 분포를, 개찰 후 화면은 분해를** — 데이터가 실제로 지지하는 구성이다.

## §5 실험 — 두 축, 표본 크기가 다르다

```
모집단 축   회차 233,204 · 경쟁자 투찰 9,667,069 · 2023 ~ 2026   (전수 재측정 완료)
개인 축     투찰 3,926 · 낙찰 75                                  (옛 테이블 기준. 재측정 대기)
```

**낙찰 75건이 개인 축의 상한이다.** 파라미터 수십 개짜리 모델은 반드시 과적합한다.
**엔터프라이즈 결론은 개인 축에서 내지 않는다.**

### ~~E3 이론 상한~~ — **삭제. 유도로 확정됐다**

```
Var(R) = E[σ_within²]·(1/4)(11/14)  +  Var(mean r)
         sd 0.007447                   sd 0.002166    →  예측 0.007756
                                                          실측 0.007605   비 0.9615
```
분산에서 3.8% 안이고, 실측이 낮은 방향이 007 절단과 부합한다.
**실험 순서에서 하루가 빠지고 다른 실험의 눈금이 정확해진다.**

### E1 (모집단) 설명 상한
투찰 시점 정보만으로 Y1/Y2 의 몇 %를 설명하나.
**시간 분할 고정** — 2023-09~2025-12 학습 / 2026-01~08 평가. **무작위 분할 금지.**

### E2 (모집단) 재료의 정보 값어치 — **화면 순위표의 원천**

| | 무엇 | 답하는 것 |
|---|---|---|
| **설명력(절제)** | 재료를 뺀 모델의 성능 하락폭 | 이 값에 정보가 있나 |
| **VoI** | 그 재료를 보고 행동을 바꿨을 때의 결과 개선 | **그 정보가 쓸모가 있나** |

**둘이 갈리는 게 핵심이다.** 설명력은 높은데 VoI 가 0 이면 화면에 놓을 이유가 없다.
**한계 VoI 로 잰다** — 이미 놓인 재료들 위에 더했을 때의 개선. 중복이 자동으로 걸러진다.

✅ **첫 VoI 는 끝났다 — 그리고 화면이 `N` 을 말할 자격이 섰다.**
학습 2023~2025 / 평가 2026, **시간 분할, in-sample 숫자 없음:**
```
① 상한 (최종 N 을 앎)      17.712%
② 실전 (N(T−1h))          17.559%      VoI = ① − ② = +0.153 %p  (상한의 0.9%)
③ 기준선 (고정 x=1.0080)   16.616%      ② − ③ = +0.943 %p  (상대 5.7%)
```
🔴 **`N` 예측 모델을 만들지 않는다** — T−1h 에 버킷이 94.2% 맞는다. **방법 하나를 재서 죽였다.**
🔴 **화면이 "지금 8명, 최종은 대개 5~9명 → x 는 이쪽" 을 말할 수 있다.**
손실은 `N=5-9` 경계에만 몰린다(0.44%p). **거기가 유일하게 불확실성을 표시할 자리다.**

⚠ **errors-in-variables 처리는 지금 안 한다. 재개 조건을 숫자로 박는다:**
> **어떤 EIV 처리도 최대 `0.153 %p` 밖에 못 번다** — 그게 as-of `N` 과 최종 `N` 의 전체 격차다.
> **T1 게이트 여유가 `0.153 %p` 미만으로 좁혀지면 그때 연다. 그 전에는 안 연다.**

**대조군 둘을 반드시 같이 돌린다:**
- **음성** — 난수 20개. VoI 가 0 이어야 한다
- **양성** — `DRAW_NO`. **예측력은 크고(85.6%) 결정 가치는 알려진 작은 값(≤0.3 bp)** 이다.
  난수보다 강한 시험이다 — "예측력이 없어서 0"과 "쓸모없어서 0"을 가른다

### E6 (모집단) 축 실험 — **후보 열한 개가 하나로 줄었다**

개정 1은 품목·시군구·시도·하한율·기초가·경쟁밀도·학교규모·시기·계약형태·다품목·재입찰
열한 개를 후보로 뒀다. **전수로 재니 최적 위치를 움직이는 건 하나뿐이다:**

| 축 | 최적 x 를 움직이나 |
|---|---|
| **`N` (경쟁자 수)** | 🔴 **뒤집는다.** 1.019 → 0.983 |
| 연도 2023~2026 | 1.013 / 1.011 / 1.008 / 1.008 — 거의 안 움직인다 |
| 하한율 90 / 88 | 1.007 / 1.009 — 안 움직인다 |
| 품목 (8원자) | 0.998 ~ 1.016 — 크기만 바꾸고 모양은 안 바꾼다 |

**⟹ 층화는 `N` 으로 한다. 품목·연도로 쪼개면 표본만 잃는다.**

⚠ **하한율은 다른 자리에서 축이다** — 최적 x 는 안 움직이지만 **`α` 를 예측한다**
(90 → 3.0% 상수, 88 → 2.87%). **`f_R` 을 만들 때의 층화축이지 위치 선택의 축이 아니다.**

**남은 축 실험은 이것 하나다: 지역·학교·기관이 무언가를 가르나.** 위 넷은 안 갈랐다.
**안 갈리면 필터를 안 연다** — 사장이 의미 없는 차이를 의미 있다고 읽는다.

### E7 (모집단) 재료 간 중복
`최근 3회`·`잘 나온 구간`·`학교 중앙값`이 서로 얼마나 다른 말을 하나.
**같은 말이면 하나만 놓고 나머지 자리를 다른 재료에 준다.**

### E4 (개인) 아버지 선택의 개선 여지
같은 정보 집합에서 다르게 골랐으면 나아졌나.
**⚠ 낙찰 75건이라 결론이 아니라 신호다.** 신뢰구간을 반드시 같이 낸다.

### E5 (개인) 커버리지 대 위치
**같은 투찰 수를 다른 학교에 배분했을 때** 기대 낙찰이 어떻게 변하나.

| | 규칙 |
|---|---|
| B0 | 항상 하한 + ε |

## §8 판정 기준 — **숫자를 보기 전에 못박는다**

### 8-A 🔴 Optimizer's Curse 게이트 G1~G5 — 모든 max 기반 숫자에 적용

**G1. 시간분할 밖에서 값을 보고한다.** 학습기간에서 `x*(N)` 을 고르고 **평가기간에서 그
`x*` 의 승률을 잰다. 학습기간 최댓값은 절대 보고하지 않는다.** argmax 선택이 학습기간 안에서
끝나므로 **편향이 구조적으로 제거된다 — 축소 수식이 필요 없다.**

> 🔴 **부수 효과가 게이트 자체보다 값어치 있다: `학습 max − 평가 값` = 커스의 실측값.**
> **VoI 를 포함한 모든 max 기반 지표의 편향 눈금이 된다. 한 번 재서 문서에 남긴다.**

**G2. max 전에 곡선을 매끄럽게.** `ŵ(x)` 는 이론상 x 에 대해 매끄럽다.
**격자별 원시 추정치의 max 를 쓰지 마라.** 평활 적합 후 그 곡선의 max —
**평활이 이 상황의 shrink-then-max 다.**

**G3. 뒤집힘을 순열 귀무와 대 본다.** 귀무는 "곡선이 N 과 무관".
셀(연월×하한율×품목) 안에서 **N 라벨을 순열** → N구간별 `x*` 재계산 → 통계량 `spread(x*)`.
관측(0.036)이 95분위를 넘는가. ⚠ **회차 블록 단위로, N 은 셀 안에서만** 섞는다.

**G4. argmax 말고 곡선을 보고한다.** `x*` 는 평평한 봉우리 위에서 크게 흔들린다.
**"1.011 을 넣어라"가 아니라 "이 구간이 평평하다 / 이쪽이 낫다"다.**
제품에 필요한 건 봉우리 위치가 아니라 **곡선이 평평한지 여부**다.

**G5. 효과 크기 문턱 — 3중 게이트. 셋 다 통과해야 예측 갈래를 연다.**

> ⚠ **내 초안(`+1.0%p`, 기준 "전체 최적 17.58%")은 커스를 문턱에 구웠다.**
> **`17.58%` 자체가 in-sample max 이고 G5 가 막으려는 바로 그 양이다.**
> **기준점은 반드시 `B1` 이어야 한다.** `stats-expert` 가 잡았고 아래가 서명본이다.

| | 게이트 | 왜 |
|---|---|---|
| **T1** 주 | `B1` 대비 **상대** 개선, G1 평가기간, 회차 블록 부트스트랩. **CI 하한 > +10%** 🔴 **그리고 사전 등록한 `N` 층 중 ≥2 개에서 독립 통과** | 절대 문턱은 승률이 `N` 에 따라 크게 달라 엉뚱한 이유로 갈린다. **복제 조건이 핵심이다 — 한 층이 전체를 끌고 가는 걸 실제로 봤다** |
| **T2** 실물 | `Δ(승률) × 연간 투찰 수 ≥ **K = 5 건/년**` (개인 축 ≈ 1,450 투찰/년 기준 → Δ ≥ 0.34%p) | **사장이 판정에 참여할 수 있는 유일한 단위다.** 엔터프라이즈 축은 투찰 수에 비례해 조정 |
| **T3** 앵커 | 모형의 개선폭 > **「`f_R` 중심을 −10.0 bp 로 고치기만 한 것」** 의 개선폭 | **외부 숫자를 안 가져와 임의성이 가장 적다.** 모형이 "`f_R` 을 제대로 놓기"를 못 이기면 만들 이유가 없다. 🔴 **앵커가 곧 게이트 높이라 값이 틀리면 통과했어야 할 모형이 떨어진다** — §2-5 |

**셋 다 통과 → 위치 재료를 화면에 올린다. 못 넘으면 → 위치 조언을 접고 커버리지·티켓
배치로 옮긴다. 그건 "실패"가 아니라 "예측 갈래를 접는 근거"다.**

⚠ **T2 의 `K = 5` 는 사장이 정할 값이다.** 지금은 기본값으로 두고 **데이터를 보기 전에만**
바꾼다. 나중에 "10%는 너무 빡세네"가 되는 게 이 절이 막으려는 실패 그대로다.

> **G1 만으로 대부분 해결된다. G1 을 건너뛰면 나머지를 다 해도 숫자가 위로 편향된 채 남는다.**

근거**이고, 그건 성공한 실험이다.

### 8-C 🔴 검정이 기각할 수 있는 상태인지 먼저 확인한다

메커니즘 조사에서 팀이 **같은 실수를 여섯 번** 했다. 전부 "검정의 모양이 주장의 모양과
안 맞았다"였다:

| # | 형태 | 실물 |
|---|---|---|
| 1 | **sd 만 보고 구조를 선언** | 후보 분포를 균등으로 가정 (sd 차이 2.4%뿐이라 안 걸림) |
| 2 | **주변분포만 보고 결합 구조를 놓침** | 풀링 리샘플이 8/7 층화를 못 담아 sd(R) 13% 과대 |
| 3 | **옴니버스로 단조 기울기를 가림** | df=14 χ² 로 p=0.12 → 전수 추세검정 z=−13.54 |
| 4 | **집계로 분포를 가림** | 도착률 집계 85.8% 인데 하위 10% 회차는 57.1% |
| 5 | **공허참 — 기각 불가능한 검정** | 득표 <4 면 4위 임계가 0 이라 모든 선택이 자동 통과 |
| 6 | **산포를 귀무 산포와 대조 안 함** | 범위통계는 고정 α 라도 퍼진다 |
| 7 | 🔴 **증상을 적어 놓고 그 위에서 계산을 이어감** | `f_R` 왜도 −41.2·첨도 +1954 를 "이상치 오염"이라 적고 그 위에서 승률 곡선을 냄. 나는 같은 90 행을 "0.041% 잔차"로 적고 넘어감 |

**7 은 앞의 여섯과 범주가 다르다.** 앞의 여섯은 **검정의 모양이 주장의 모양과 안 맞은 것**이고,
7 은 **검정이 이미 끝났는데 결과를 안 쓴 것**이다. 규율로 따로 박는다:

> **문서에 "오염"·"이상치"·"의심"이라고 적었으면 그 위에서 다음 계산을 돌리지 않는다.**
> **증상을 적는 것은 처리가 아니다. 적었으면 고치거나, 고칠 때까지 그 위에 아무것도 안 세운다.**

**규율으로 박는다:**
> **① 검정력을 항상 같이 보고한다. 표본으로 못 본 것을 "없다"로 적지 않는다.**
> **② 주장의 모양과 검정의 모양을 맞춘다. 모먼트 일치는 검정이 아니다.**
> **③ 집계는 분포가 아니다.**
> **④ 핵심 변수는 두 경로로 만들어 대조한다. 단위가 이상하면 즉시 멈춘다.**
> **⑤ 검정 조건은 그 조건이 만족돼야 하는 자명한 항등식을 같이 출력한다.**

**⑤는 실물로 값을 했다** — `xmax ≥ R` 이 007 전수에서 100% 여야 한다는 게 공짜로 나오는데,
안 찍었으면 0.186% 의 어긋남을 못 봤고 **판정이 내가 원하는 쪽으로 기운 채 나갔다.**

## §9 이 실험이 못 보는 것 — 먼저 적는다

1. 🔴 **"왜 유찰되는가"는 이 코퍼스로 원리적으로 못 배운다.** 표본을 아무리 늘려도 못 배운다.
   ```

   이전 회차가 009 유찰이면 보유 0/6,099 = 0%
   ```

   **⟹ 화면이 "이 공고가 유찰될 확률"도 "재입찰이 될 확률"도 말하면 안 된다.**

5. **철회한 낙찰자 6.5%** — `won` 정의가 오염돼 있다. **E1 전에 처리**
6. ⚠ **`N≤2` 이상 현상 (회차의 7.8%)** — 관측이 귀무보다 +3.4 bp 위인데 못 풀었다.

   순열 귀무가 성립하지 않는다"** 이지만 확정 못 했다
7. **모집단 결론이 개인에게 이전되는지 안 잰다**
8. ⚠ **하한율 88 (회차의 35.2%) 의 `α` 에 숨은 축이 하나 더 있다** — `발주기관` 으로 추정.

## §11 순서

```
1. 누출 검사기                      ← 특징 하나가 as-of 를 넘으면 즉시 실패
   🔴 검사기 사양 확장: "값이 마감 후에 생겼나"뿐 아니라
      "그 시점 아카이브만으로 재구성할 수 있나"까지 본다 (가용성 누출)
2. as-of N(T−1h) 재구성            ← 3-3. 이게 E2 의 첫 VoI 를 만든다
3. 새 코퍼스 (raw → 실험 테이블)     레거시 0줄 · 규모 재측정
4. E2 첫 VoI: N(T−1h) 대 최종 N     ← G1 을 여기서 처음 집행하고 커스 눈금을 잰다
5. E1 · E2 · E7                     ← 재료 순위표
6. E6 (지역·학교·기관 축만 남았다)   ← UI 필터
7. E4 · E5                          ← 개인 축. 신뢰구간 필수
8. 재료 순위표 + 축 목록 → 화면 판정
```

**~~E3~~ 가 빠져서 하루가 줄었다.** 그리고 **2번이 앞으로 왔다** — as-of `N` 이 없으면
E2·E6 이 전부 개찰 후 `N` 을 쓰게 되고, 그건 화면에 못 옮기는 결과를 만든다.

**1번이 먼저다.** 누출은 나중에 발견하면 그때까지의 결과를 전부 버린다.
