## 0. 한 문장

> 🔴 **신경망은 굶은 게 아니었다. 사람이 안 가는 구간으로 외삽해서 무너졌다.**
> **그리고 그게 `M1`(구조식)이 이기는 이유를 설명한다.**

## 1. 예산 가설이 죽었다

```
1차   40만 행 ·  7 에폭 (상한 40)
🔴 재실행  **150만 행** (M4 와 동일) · **17 에폭에서 수렴** (상한 200)
   상한이 구속했나 → **아니오**
```
**⟹ 두 번 다 조기 종료가 걸렸다. 예산 상한에 부딪힌 적이 없다. `ml-expert` 의 자기 신고는 성실했지만 원인 진단으로는 틀렸다.**

## 2. 🔴 `D1` — 퇴화. 격자 최저점에 60% 가 몰린다

```
선택된 x 의 분포 (평가 표본 20,000)
   x=0.9600   **60.38%**   <- 격자 최저점
   x=0.9620    2.31%
   x=0.9610    2.08%
   x=0.9640    2.08%
   x=0.9650    1.97%
최대 쏠림 60.38%   ⟹ 사전 등록 문턱 20% 초과.  **퇴화 판정**
```
**⟹ 사전 등록 §2 대로 성능 수치를 해석하지 않는다.**

## 3. `D2`·`D3` — 곡선은 살아 있고 확률도 맞다. **방향만 틀렸다**

```
D2  기복 (최대−최소)/최대     M5 0.7878   M1 1.0000   비 0.788  → "평평함" 아님
```
🔴 **평평한 게 아니라 *단조 감소*다. "낮을수록 좋다"만 배웠고 봉우리를 못 배웠다.**

```
D3  보정 — 십분위별 예측 vs 실제
     1   0.2047% → 0.3000%        6   0.9325% → 1.2000%
     2   0.3584% → 0.5000%        7   1.1380% → 1.1000%
     3   0.4783% → 0.5500%        8   1.5721% → 1.6000%
     4   0.6173% → 0.9000%        9   3.4772% → 3.3500%
     5   0.7729% → 1.0500%       10  11.0965% → 12.1000%
```
✅ **보정은 좋다. 상위 십분위 11.10% 예측에 실제 12.10%. 관측 구간에서는 확률을 제대로 낸다.**

## 4. 🔴 진단 — **외삽 실패다**

```
실제 투찰 x 의 1% 분위 = **0.98381**
격자 최저점            = **0.96000**     ← 데이터가 사실상 없는 곳
⟹ 신경망은 거기서 국소 기울기("낮을수록 좋다")를 그대로 연장한다
⟹ **너무 낮으면 예정가 아래라 실격**이라는 걸 배울 데이터가 없다
```

### 그래서 `M1` 이 이긴다 — 구조가 데이터를 대신한다

```
M1 은 P(승|x,N) = ∫ w(r)·1{r<=x}·(1−F(x)+F(r))^(N−1) dr
                        ↑ 이 항이 x 가 R 아래로 내려가면 **스스로 무너진다**
🔴 신경망은 이 항을 **데이터에서 배울 수 없다** — 그 구간에 관측이 없으니까
```
> **⟹ "구조 모형 > 기계학습" 의 이유가 표현력이 아니라 *데이터가 없는 곳의 행동*이다.**
> **⟹ 이건 `M4`(GBDT)에도 걸리는데, 트리는 외삽 시 마지막 구간 값을 유지하므로 덜 극단적이다. 그래서 `M4` 는 퇴화까지는 안 갔다.**

## 5. ⟹ 고치는 법은 예산이 아니라 설계다

```
① 격자를 관측 지지집합으로 제한  (예: x >= 학습기 1% 분위)
② 또는 P(x >= R) 항을 명시로 곱한다     ← M1 이 하는 것
③ 또는 라벨을 "낙찰"이 아니라 "R 통과" + "최저 초과" 로 분해해 각각 학습
```
⚠ **셋 다 새 설계이고 새 사전 등록이 필요하다. 오늘 범위 밖이다.**

## 6. 판정 — 사전 등록대로

```
사전 등록 기준   상수를 이기고(p<0.05) + M4 를 이긴다
🔴 판정          **D1 퇴화로 성능 해석 안 함.**  성공/실패 판정을 내리지 않는다
⟹ 결론은 "이 구성의 신경망은 이 격자에서 못 쓴다" 이지
   **"신경망이 이 문제에 부적합"이 아니다**
```

## 7. 남는 사실

```
✅ 예산 가설 기각 — 두 번 다 수렴했다.  ml-expert 의 자기 신고는 원인이 아니었다
✅ 신경망의 확률 자체는 보정이 좋다 (D3) — 관측 구간에서는 쓸 수 있다
🔴 실패는 argmax 가 관측 밖으로 나가는 데서 생긴다.  격자 설계 문제다
🔴 그리고 이것이 M1 의 우위를 설명한다 — 표현력이 아니라 외삽 안정성
```
⚠ **`D3` 가 좋다는 건 별도로 쓸모가 있다: `ADR 0027` 의 "예측 승률을 재료로 보여준다"는 *argmax 를 안 쓴다*. 사용자가 넣을 금액에서 확률만 내면 되고, 거기서는 신경망이 잘 보정돼 있다.**
