## 0. 무엇을 고치나 — 진단이 지목한 한 곳만

```
확인된 원인   격자 [0.960, 1.045] 이 **관측 지지집합 밖**으로 나간다
             학습기 x 의 1% 분위가 0.98381 인데 격자 최저는 0.96000
             신경망이 거기서 "낮을수록 좋다"를 연장하고 60.38% 가 몰렸다

🔴 수정      격자를 **학습기 x 의 [1%, 99%] 분위**로 제한한다.  그것뿐이다
⚠ 안 바꾸는 것   구조(128,64) · 특징 · 학습 행 수 150만 · 조기종료 · seed · 정보 대칭
```
**⟹ 한 곳만 바꾼다. 여러 개를 같이 바꾸면 무엇이 고쳤는지 모른다.**

## 1. 🔴 이 수정이 실패할 수 있는 방식 — 미리 적는다

```
격자를 좁혀도 **새 하한에 다시 몰릴 수 있다**
⟹ 그러면 신경망이 구간 안에 봉우리를 못 만든 것이고, 실패는 격자가 아니라 구조다
⟹ 그 경우 "격자 문제였다"는 내 진단이 **틀린 것**이고 그렇게 보고한다
```

### 그래서 진단을 먼저 본다 — 성능보다 앞

```
D1'  새 격자에서 선택된 x 의 분포.  **새 하한 쏠림 >= 20% 면 구조 실패**
D2'  p(x) 곡선이 새 구간 **안에서** 봉우리를 갖나
     ⟹ argmax 가 내부점인 행의 비율.  <50% 면 여전히 단조다
D3'  보정 (전과 동일)
```
🔴 **`D1'` 이 걸리면 `M5a` 도 판정하지 않고, "격자 가설 기각 · 원인은 구조"로 닫는다.**

## 2. 민감도 — 격자 폭을 임의로 정하지 않기 위해

```
세 폭을 **전부** 낸다:  [1%, 99%] · [5%, 95%] · [0.5%, 99.5%]
⟹ 결과가 폭에 크게 흔들리면 그 자체가 결론이다 ("격자 선택이 답을 만든다")
⚠ 어느 하나를 골라서 보고하지 않는다.  셋 다 표에 넣는다
```
