## §0 이 문서가 막으려는 것

지난 시도들은 **값만 넣어 보고 "안 되네" 하고 넘어갔다.** 그러면 남는 게 없다:

> **"안 됐다"가 셋 중 무엇인지 안 갈린다.**
> ① 방법이 이 문제에 안 맞는다 ② 우리가 잘못 구현했다 ③ 데이터가 모자란다

### 0-A 이 규율은 이미 값을 했다 — 메커니즘 조사에서 실물로

같은 가설을 세 번 검정했고 **매번 귀무를 더 정확하게 만들었고 매번 답이 바뀌었다:**

```
L1  "선택 4개 = 균등 부분집합"                    z=−12.96 기각
    ↳ 그런데 이 귀무는 애초에 참일 수 없다 (투표가 쏠려 있다). 기각해도 아무 말이 아니다
L2  "선택 슬롯집합 ⊥ 슬롯→가격 배정"               순열로 z=−10.54 기각
    ↳ 그런데 코퍼스가 007 낙찰 전수다. R 이 낮은 회차가 살아남는다
L3  L2 + "mean(뽑힌 4개) ≤ xmax 를 통과해야 관측"   기각 못 함 → 판정
```

**만약 L1 에서 멈췄으면 "투찰자가 가격을 본다"는 결론을 냈을 것이고, 그건 틀렸다.**
그리고 그 결론 위에 세운 경쟁자 행동 모형이 전부 틀렸을 것이다.

> **⟹ 방법이 "안 맞는다"고 말하기 전에, 귀무가 애초에 참일 수 있는 것이었는지 먼저 본다.**

### 0-B 규율 다섯

1. **합성 데이터로 구현을 먼저 검증한다.** 답을 아는 축소 문제를 만들어 그걸 맞추는지 본다.
   **못 맞추면 구현 실패다 — 실데이터로 안 넘어간다.**
2. **인자 목록을 먼저 확정한다.** 돌려 보고 추가하지 않는다.
3. **각 방법에 "이러면 이 방법은 아니다" 를 미리 쓴다.**
4. 🔴 **검정력을 항상 같이 보고한다. 표본으로 못 본 것을 "없다"로 적지 않는다.**
5. 🔴 **주장의 모양과 검정의 모양을 맞춘다. 모먼트 일치는 검정이 아니다.**

**4·5 는 새로 추가됐다.** 메커니즘 조사에서 팀이 **같은 실수를 여섯 번** 했기 때문이다 —
sd 만 보고 구조 선언 · 주변분포만 보고 결합 구조 놓침 · 옴니버스로 단조 기울기 가림 ·
집계로 분포 가림 · 공허참(기각 불가능한 검정) · 산포를 귀무 산포와 대조 안 함.
**전부 "검정의 모양이 주장의 모양과 안 맞았다"였다.** 자세한 것은 설계 문서 §8-C.

## §1 문제의 구조 — 미지수가 하나로 줄었다

```
낙찰 ⟺ x ≥ R  그리고  R ≤ xⱼ < x 인 경쟁자 j 가 없음

x = 내 투찰금액 / (기초가 × 하한율/100)      ← 내가 고르는 유일한 값
R = 예정가 / 기초가                          ← 복수예가 15개 중 4개 추첨 평균
xⱼ = 경쟁자 j 의 같은 값                     ← 내가 못 봄
```

**분류 문제가 아니다.** 결과는 **두 확률변수의 순서**로 정해진다.

### 1-1 개정 1의 "미지수 셋" 이 하나로 줄었다

| | 개정 1 | **개정 2** |
|---|---|---|
| **`R` 분포** | 관측됨. 경험분포 + 유도 대조 | ✅ **파라미터 0개.** 규칙이 전수로 확정됐다 |
| **경쟁자 수 `N`** | 투찰 시점 특징으로 **추정해야 함** | ✅ **as-of 관측 가능.** T−1h 에 중앙 99.3% |
| **경쟁자 위치 `X`** | 개찰 후 관측 | 🔴 **유일한 진짜 미지수** |

**`R` 이 유도로 확정된 것의 값어치는 정확도가 아니라 진단이다:**
> `P(x ≥ R)` 이 해석적으로 나오므로 **잔차의 출처가 `X` 하나로 좁혀진다.**
> M1 이 틀리면 **어디가 틀렸는지 바로 안다.**

### 1-2 확정된 `R` 의 규칙

```
후보 15개   구간 배분은 고정(아래 8 · 위 7), 각 구간 안에서 iid
            아래 8개 ~ U(0.97, 1.00)   ·   위 7개 ~ U(1.00, 1.03)
            → 15개를 무작위 순열로 슬롯 1..15 에 배정
   🔴 15개를 U(0.97,1.03) 에서 통째로 iid 로 뽑지 마라 — sd(mean r) 2.06배
   🔴 15구간 계통추출도 아니다 — 0.14배
표          철회자 포함 전원 2표  (회차의 52.67% 에 철회자가 있다)
선택        득표 상위 4 · 동점은 낮은 번호 우선(93.4%, 회차의 48.221%)
            · 무득표 슬롯은 서버가 채움(2.742%, 슬롯 번호만 보고 가격은 안 봄)
분포        sd 0.007605   N 과 무관   연도별 안정
            mean  🔴 007 전수 실측 0.998867 (−11.3 bp) 은 콜라이더가 섞인 값이다
                  사장이 마주하는 무조건부 값은 해석적으로 −10.0 bp (설계 §2-5)
층화축      하한율 (90 → α 3.0% 상수 · 88 → 2.87%, 숨은 축 하나 더 있음)
```

🔴 **`R` 을 `ELCTRN_BID_PLNPRC / BGNG_PRC` 로 만들지 마라 — 90 행이 통째로 깨져 있고
sd 를 2.8 배로 부풀린다. `mean(CHC_YN='Y' 4개)` 를 써라.**

### 1-3 🔴 `f_R` 은 리샘플하지 않는다 — `α` 하나짜리 모수족이다

규칙이 확정됐으므로 `f_R` 은 **`α` 만 정해지면 완전히 결정된다:**
```
후보 = 아래 8개 iid U(1−α, 1)  +  위 7개 iid U(1, 1+α)
R    = 그중 4개 평균
  → f_R(·|α) 를 α 격자(2.0~3.1%, 0.05% 간격)에 미리 계산해 두면 끝
```
**화면의 문제가 "`f_R` 을 어떻게 만드나"에서 "이 회차의 `α` 가 얼마인가" 하나로 줄어든다.**

리샘플보다 나은 이유 셋: **표본잡음 0**(하한율 84 는 n=1,995 라 리샘플이 거칠다) ·
**as-of 가 깨끗**(과거 후보값을 안 만지고 공고 특징만 쓴다) ·
**꼬리가 정확**(리샘플은 꼬리를 못 채우는데 `f_R` 꼬리가 위치 계산에 중요하다).

**전 기간을 쓴다.** `α` 는 규칙 모수지 행동이 아니다. **대신 `α` 월별 관리도를 붙인다** —
`bid_id` 가 `E230919-…` 형식이라 연월이 거기 들어 있다. 제도가 바뀌면 그때 재적합.

**`α` 는 이봉이고, 규칙은 상호작용이다:**
```
저모드 ±2.14%  회차의 8.55%    ·    고모드 ±3.07%  회차의 91.45%    ·    골 2.00~2.05%

🔴 하한율 88 & 기초금액 < 2,000만원  →  α = 2%
   그 외                            →  α = 3%
```
**2,000만원에서 칼같이 끊기고, 하한율 90 은 같은 구간에서 평평하다(대조군 통과).**
**둘 다 공고에 있어 as-of 안전하다.**

### 🔴 그런데 이 규칙은 **불완전하다** — 정밀도 92.4% · 재현율 24.3%

회차별 `α̂ = (max−min)/1.7639` 로 재니(8/7 구조의 정확한 상수다):

| 구간 | n | `α̂` 중앙 | 규칙값 | |
|---|---|---|---|---|
| 하한 88 · <2,000만 | 6,905 | 0.02126 | 0.020 | ✅ |
| 하한 88 · ≥2,000만 | 75,267 | 0.03016 | 0.030 | ✅ |
| 하한 90 · <2,000만 | 142,779 | 0.03039 | 0.030 | ✅ |
| 하한 90 · ≥2,000만 | 5,898 | 0.03039 | 0.030 | ✅ |
| **기타 하한율** | 2,355 | **0.02716** | — | ⚠ **규칙이 없다** |

**구간 중앙값은 전부 맞는다. 그런데 개체 수준에서는:**
```
α̂ < 0.025 인 회차              11.28%  (26,299 건)
  정밀도  규칙 0.02 중 실제 낮은 비율        92.4%   ✅
  🔴 재현율  실제 낮은 것 중 규칙이 잡는 비율    24.3%   ✗
```
> **`α` 가 낮은 회차가 11.3% 인데 규칙은 그중 1/4 만 잡는다.**
> **나머지 약 8.5% 는 우리가 모르는 조건으로 `α` 가 낮다.**

**그리고 그게 정확히 `sd(R)` 격차를 설명한다** — 역산으로 "약 10% 가 `α=0.02` 여야 `sd` 가
맞는다"가 나왔고 **실측 11.3% 와 일치한다.**

🔴 **그냥 못 넘긴다.** `f_R` 은 M1 의 **눈금 전체**다:
```
회차의 8.5% 에서 커트라인 불확실성을 최대 50% 과대평가한다 (0.03 vs 0.02)
승부 창문이 5.8 bp 인데 sd 를 0.0079 로 쓸지 0.0053 으로 쓸지가 갈린다
⟹ 그 회차들에서 P(win|x) 곡선이 통째로 틀린다
```

### ✅ 해법 — **`α` 를 고르지 않는다. 주변화한다**

**"어느 `α` 인가"를 골라야 한다는 전제가 문제였다.** `f_R` 은 `α` 격자가 둘뿐이라
**가중합이 공짜다:**
```
f_R(r | z)  =  P(α=0.02 | z) · f_R(r | 0.02)  +  P(α=0.03 | z) · f_R(r | 0.03)
               ↑ 예측 확률을 그대로 쓴다. 이진화하지 않는다
```

**이진화를 버리는 이유 넷:**
1. **약한 예측을 이진화하면 정보를 버린다.** 예측이 불확실하면 그 불확실성이 `f_R` 에 반영된다
2. **정밀도/재현율 트레이드오프를 고를 필요가 없다.** 임계가 없다
3. 🔴 **비대칭 비용이 자동 처리된다** — `α=0.03` 인데 0.02 로 쓰면 **과신**(나쁘다),
   반대는 **과소확신**(덜 나쁘다). **주변화는 애매한 회차를 자동으로 넓은 쪽으로 민다**
4. **체제 변화에 강하다**(아래) — `P(α|z)` 를 최근 창으로 갱신하면 되고 절벽이 안 생긴다

**계산 비용 0.** `f_R` 두 개가 이미 격자에 있다.
**그리고 `기타 하한율` 2,355 건 문제도 자동으로 흡수된다.**

⚠ **실패 판정에 영향이 있다** — 보정 곡선이 벗어났을 때 원인 후보가 하나 는다
(`F_X` 냐 `P(α|z)` 냐). **`α` 를 규칙으로 고정한 판과 주변화한 판을 둘 다 돌려 대조한다.**

**이진화를 시도한 결과가 이 결정의 근거다:**
```
현행 규칙                     정밀도 0.751  재현율 0.127
발주기관 과거양성률 > 0.3      정밀도 0.360  재현율 0.308   ← 재현율 2.4배, 정밀도 반토막
발주기관 × 하한율 × 기초5분위   정밀도 0.473  재현율 0.123   ← 조합이 오히려 나쁘다
```
**발주기관에 강한 신호는 있다**(기관별 양성률 p10 0.026 / p50 0.070 / **p90 0.972**,
66개 중 25개가 0.5 초과). **그런데 임계로 자르면 정밀도를 잃는다.**

### 🔴 그리고 제도가 2025Q3 에 바뀌었다 — 정적 규칙이 이 경계를 못 넘는다

```
분기별 α<0.025 비율
2023Q3 .091 → 2024 .132~.138 → 2025Q1 .155 → 2025Q2 .164
                                        ↓ 절반으로 떨어진다
2025Q3 .096 → Q4 .083 → 2026Q1 .080 → Q2 .074 → Q3 .073
```
**`α̂` 중앙값은 0.0299~0.0304 로 그대로다 — 낮은 밴드 회차의 *비율*만 줄었다.**

⚠ **최근 12개월만 학습하면 오히려 나빠진다**(정밀도 0.345 / 재현율 0.185).
**체제 변화와 표본 부족이 상충한다.** 주변화가 이걸 피하는 이유이기도 하다.

### 🔴 그리고 이게 `sd(R)` 연도별 변동을 정확히 설명한다 — 두 좌석의 교차검증

`sd(R|α=0.02) = 0.005281` · `sd(R|α=0.03) = 0.007937` 로 혼합분산을 계산하면:

| | `α<0.025` 비율 | **예측 `sd(R)`** | **실측 `sd(R)`** | 차 |
|---|---|---|---|---|
| 2025 | 0.164 | **0.007566** | **0.007571** | **0.07%** |
| 2026 | 0.076 | **0.007767** | **0.007695** | 0.9% 낮음 |

⚠ **실측이 예측보다 약간 낮은 건 007 절단 방향과 일치한다**(절단은 분산을 줄인다).

> 🔴 **`sd(R)` 시계열을 "단조 축소 없음 · 잡음"으로 읽었던 것이 정정된다.**
> **그 변동은 잡음이 아니라 `α` 혼합비 변화의 신호였고, 두 좌석이 독립으로 잰
> 양이 공식으로 1% 안에서 이어진다.**

⚠ **그런데 이건 우리 시간분할에 걸린다.** 등록된 분할이
`학습 2023-09~2025-12 / 평가 2026-01~08` 인데 **체제 전환점(2025Q3)이 학습 기간 안에 있다.**
```
학습 세트는 두 체제가 섞여 있다   →  모형이 불리해진다
평가 세트는 전부 새 체제다        →  ✅ 평가는 현재 체제에서 이뤄진다
```
**⟹ 분할을 바꾸지 않는다.** 평가가 **우리가 실제로 쓸 체제**에서 이뤄지는 게 더 중요하고,
**학습 세트가 섞인 비용은 정직하게 문서에 적는다.** `[영향 계산함 — 분할 유지]`

⚠ **이건 "규칙이 틀렸다"가 아니라 "규칙이 불완전하다"다.** 네 구간의 중앙값이 전부 맞으므로
**주변 분석은 옳았고 개체 분산을 못 잡을 뿐이다.**

❌ **발주기관은 층이 아니다** (between/within = **0.795**).
❌ **품목도 아니다** — **품목은 절단선의 대리변수였다**(품목마다 기초금액 분포가 달라
2,000만 선을 다르게 걸친다).
⚠ **연월은 추세가 있다.** 안정된 층이 아니라 움직이는 설정이므로 층으로 쓰지 말고
**관리도로 감시한다** — `asof.npz` 의 `ym` 필드를 쓴다
(⚠ `plist.npz` 의 `bid_id` 는 순수 숫자라 연월이 안 들어 있다).

> **교훈: "층이 있나"를 주효과로만 검정하면 상호작용 층을 놓친다.**
> **§0-B 규율 5(주장의 모양과 검정의 모양을 맞춘다)의 한 형태다.**

## §2 방법 가족

### M1. 구조 모형 (mechanism-based) — **주력**

**왜 이 문제에 맞나**
구조가 알려져 있고 **`R` 이 파라미터 0개다.** 미지수를 하나로 줄인다.

**추정 대상**
```
X | 회차특징, 🔴 N     경쟁자 위치 분포 (하한 대비 x 의 분포)   ← 유일한 미지수
N | as-of              T−1h 관측값 + 잔여 도착 보정            ← 추정이 아니라 보정
```

### 🔴 `X` 는 `N` 에 의존한다 — 세 좌석이 다른 경로로 같은 곳에 왔다

**`X | z` 에 `N` 을 안 넣으면 M1 이 구조적으로 틀린다.** 근거 셋이 독립이다:

| 경로 | 발견 |
|---|---|
| 반사실 승률 곡선 | **최적 x 가 `N` 에 따라 1.019 → 0.983 으로 뒤집힌다** |
| 정책 검정 | **층화는 `N` 이 1차, `기초금액` 이 2차(`N≤29`)** |
| **합성 생성기** | **`N` 무관 투찰 분포로는 `N` 양 끝이 재현이 안 된다** |

**생성기 쪽 논증이 제일 뾰족하다:**
```
실측 xmax/R 중앙   N≤2 1.0894  →  N=3-9 1.076  →  N=30-99 1.042

🔴 N 이 커질수록 내려간다. 그런데 xmax 는 N 개의 최댓값이라
   투찰 분포가 고정이면 N 이 커질수록 반드시 올라가야 한다. 부호가 반대다.
⟹ 경쟁이 적으면 높게 넣는다. 행동이 N 에 의존한다.
```
**`N=3-9` 는 `N` 무관 가정으로도 거의 정확히 재현되고**(합성 −4.709 vs 실측 −4.868,
−2.343 vs −2.371) **양 끝만 어긋난다 — 그리고 두 끝이 같은 하나로 설명된다.**

> **⟹ 우리가 못 풀던 `N≤2` 이상 현상은 데이터 문제가 아니라 행동이다.**
> 설계 문서 §8-C 의 미해결 항목에서 **원인이 밝혀진 항목**으로 옮긴다.

⚠ **그 분포를 실측 `xmax` 로 보정하면 순환이다** — `xmax` 자체가 007 조건부이고,
**생존 조건이 `xmax ≥ R` 이라 `xmax` 는 최대로 오염된 통계량이다.**

**⟹ 유계 통계량으로 보정한다**(설계 §8-C 따름정리). **실측됐다:**

| `N` | 회차 | **median(x)** | **IQR(x)** | (대조) median(xmax) |
|---|---|---|---|---|
| 1 | 1,694 | **1.07053** | 0.07396 | 1.07053 |
| 2 | 16,507 | **1.07552** | 0.08881 | 1.08996 |
| 3-4 | 24,327 | **1.01628** | 0.07543 | 1.07506 |
| 5-9 | 44,812 | **1.00819** | 0.04745 | 1.07339 |
| 10-29 | 67,063 | **1.00281** | 0.01260 | 1.06015 |
| 30-99 | 47,017 | **1.00014** | 0.00986 | 1.03847 |
| 100+ | 31,702 | **1.00006** | 0.00932 | 1.05684 |

**`median(x)` 1.0755 → 1.0001 단조 하락 · `IQR` 0.089 → 0.009 붕괴.**
**`xmax` 로 얻은 결론(행동이 `N` 에 의존)이 오염이 훨씬 덜한 몸통에서 재확인된다.**

> 🔴 **`median(xmax)` 열은 맞출 값이 아니라 결과로 나와야 하는 값이다.**
> **몸통으로 보정한 생성기가 그 열을 재현하면 그게 검증이다.**
**낙찰 확률 = P(x ≥ R) × P(경쟁자 최소 x 가 [R, x) 밖)**
— 앞 항은 **해석적**, 뒤 항만 `X` 에 의존한다.

**인자 (투찰 시점에 아는 것만)**
```
공고     기초가 · 하한율 · 품목(다품목 여부 포함) · 단가/총액 · 계약형태
         투찰기간 길이 · 마감 요일/시각 · 재입찰 여부 · 지역제한 폭
학교     as-of 절단 과거 회차 수 · 과거 참여자 수 분포 · 과거 낙찰 x 분포
지역     시군구 · 시도 · 해당 시군구의 최근 경쟁 밀도
시기     연 · 월 · 학기 · 방학 여부
경쟁     🔴 N(T−1h)  ← 새로 들어왔다. 개정 1은 이걸 누출로 분류했다
```
⚠ **개찰 후 값 금지** — 이 회차의 최종 참여자 수·낙찰가·예정가·순위·`CHC_YN`·`DRAW_NO`.

**측정**
`P(낙찰)` 의 **보정(calibration)** 이 1차 지표. 맞추는 것보다 **정직한 확률**이 먼저다.

**실패 판정 — 이러면 M1 은 아니다**
- 합성에서 **알려진 `X` 를 복원 못 하면** → 구현 실패. 실데이터로 안 감
- 보정 곡선이 대각선에서 크게 벗어나면 → **구조 가정이 틀렸다.** 그런데 `R` 은 확정이므로
  **틀린 곳은 `X` 다** — 개정 1보다 진단이 훨씬 좁다
- **M4 에 크게 지면** → `X` 모형이 못 잡는 신호가 있다

### ✅ M1 L1 통과 — 그리고 **뒤집힘을 구조만으로 재현한다**

```
P(win | x, N, z) = ∫_{r ≤ x} f_R(r) · (1 − F_X(x) + F_X(r))^N dr
```

**합성 진실 대조:**

| `N` | M1 최적 x | 진실 최적 x | M1 승률 | 진실 승률 | 상대오차 |
|---|---|---|---|---|---|
| 3 | 1.0200 | 1.0200 | 0.2340 | 0.2384 | −1.9% |
| 5 | 0.9952 | 0.9958 | 0.1760 | 0.1787 | −1.5% |
| 10 | 0.9925 | 0.9925 | 0.1210 | 0.1205 | +0.4% |
| 30 | 0.9895 | 0.9892 | 0.0654 | 0.0655 | −0.1% |
| 100 | 0.9870 | 0.9862 | 0.0321 | 0.0321 | 0.0% |

### 🔴 그리고 이게 진짜 결과다

```
M1 (구조만)            1.0200  →  0.9870
data-inventory (실측)   1.019   →  0.983
```
**경험적 반사실 승률 곡선으로 찾은 뒤집힘을, M1 이 메커니즘 + 경쟁자 분포만으로 재현한다.**
🔴 **그 사실에 맞춘 파라미터가 하나도 없다** — `f_R` 은 파라미터 0개고 `F_X` 는 합성 진실이다.

**그리고 *왜* 인지도 나온다:**
> **경쟁자가 적으면 아무도 나를 안 밟으니 높게 넣어 `P(x ≥ R)` 를 키우는 게 이득이고,
> 많으면 밟힐 확률이 지배해 낮게 내려가야 한다.**
> **`N×x` 상호작용의 구조적 정체가 이것이다.**

**⟹ 독립 경로 표에 네 번째 줄이 생겼다 — 반사실 곡선 · 정책 검정 · 합성 생성기 · 구조 모형.**

🔴 **그리고 이건 M5 여는 조건 4번에 대한 답이다:**
**뒤집힘이 `N` 조건부화로 설명되므로 신경망이 필요한 자리가 아니다.**

⚠ `N=3` 의 1.0200 은 격자 상단이라 잘렸을 수 있다. 실데이터 적합 때 격자를 넓힌다.

| [0.0000, 0.0042) | 233,964 | 0.0031 | 0.0035 | 0.0001 |

**문턱 초과 십분위 0 / 10 (판정 문턱 3) → 통과.**

🔴 **예측이 0.3% 부터 13% 까지 두 자릿수 배율에 걸쳐 관측을 따라간다.**
**자유 파라미터는 층별 경험 `F_X` 하나뿐이고 `f_R` 은 0 개다.**

> **⟹ 설계 문서 §5-E1(설명 상한)의 전제가 섰다.**
> **"구조 모형이 정직한 확률을 낸다"가 실데이터에서 확인됐고,**
> **화면에 확률을 놓을 수 있는 조건이 처음으로 충족됐다.**

### ✅ 그리고 남은 미보정이 `α` 문제와 방향이 같다 — 사전 등록한다

```
상위 두 십분위에서 체계적 과소예측:   0.0353 → 0.0385 (+9%)   ·   0.1182 → 0.1330 (+13%)
```
**적합에 `α = 0.03` 을 전 회차에 강제했다. 그런데 회차의 11.3% 는 `α` 가 낮고,
`α` 가 낮으면 `R` 이 좁아 최적 x 근처에서 승률이 더 높다.**
**⟹ `α=0.03` 강제는 그 회차들에서 승률을 과소예측한다. 부호와 위치가 일치한다.**

> 🔴 **사전 등록: `α` 주변화를 넣으면 상위 두 십분위의 미보정이 줄어야 한다.**
> **안 줄면 원인이 `α` 가 아니라 `F_X` 다.** 결과 보기 전에 못박는다.

### 🔴 시험 결과 — **예측이 틀렸다. 범인은 `F_X` 로 확정된다**

```
                      α=0.03 고정    α 주변화
D10 (상위)             −11.1%       −11.1%    🔴 변화 없음
D9  (상위 두 번째)      −8.2%        −8.4%     🔴 안 줄었다

[대조] 중간 구간은 실제로 움직였다
D2                     −4.3%        +0.1%     주변화가 고쳤다
D4                     −3.4%        −1.5%
```

**주변화는 작동한다 — 중간 구간에서 미보정을 줄인다. 그런데 상위 두 십분위를 전혀 안 건드린다.**

> **⟹ 사전 등록한 대로 판정한다: 원인은 `α` 가 아니라 `F_X` 다.**

✅ **이게 틀린 예측이 맞은 예측보다 값어치 있는 사례다** —
**"`α` 를 고치면 된다"로 끝났으면 `F_X` 를 안 봤을 것이다.**
**그리고 대조군(중간 구간이 실제로 움직임)이 있어서 "주변화가 아예 작동 안 한다"와
"작동하는데 이 구간을 못 건드린다"를 가를 수 있었다. 대조군이 없었으면 못 갈랐다.**

### `F_X` 의 어느 부분인가 — 후보 셋

```
1. F_X 도 체제 변화를 겪었나
   α 에서 통한 처방을 그대로 시험한다. 통하면 "체제 변화가 경쟁자 행동에도 있었다"는 더 큰 결론
2. 007 조건부 F_X 의 편향
   ⚠ 방향 확인 필요 — 아래
3. 층화가 거칠다 (N 6버킷 × 기초금액 5분위. 지역이 빠져 있다)
   코퍼스 지역 편향을 생각하면 유력하다
```

🔴 **후보를 고르기 전에 한 줄 진단이 먼저다 — 상위 십분위가 *무엇*으로 이뤄져 있나:**
```
Q5 곡선 기준 승률:  N=3-4 에서 0.34   ·   N=100+ 에서 0.012      약 28배 차이
⟹ 상위 십분위는 "낮은 x" 가 아니라 거의 전부 "낮은 N" 회차일 가능성이 높다
```
**⟹ 상위 두 십분위를 `N` 층으로 분해해라. 전부 저`N` 이면 후보 순서가 바뀐다.**
**그리고 저`N` 은 `P(007|N)` 상 선택이 가장 강한 구간이다**(`N=2-4` 93.17%, `N=1` 11.55%).

### 🔴 진단 결과 — **십분위 현상이 아니라 `N` 현상이다.** 원인 진단이 틀렸다

**십분위 구성표:**

| 십분위 | N=3-4 | N=5-9 | N=10-29 | N=30-99 | N=100+ |
|---|---|---|---|---|---|
| D8 | 0.000 | 0.011 | 0.030 | **0.937** | 0.022 |
| D9 | 0.009 | 0.030 | **0.530** | 0.430 | 0.000 |
| D10 | 0.083 | **0.280** | **0.638** | 0.000 | **0.000** |

**십분위가 사실상 `N` 을 재배열한 것이다. `D10` 에 `N=100+` 이 0 건이다.**

**그리고 미보정이 `N` 에 단조다:**
```
N=3-4     −18.7%   (n=   21,822)
N=5-9     −12.7%   (n=   86,041)

```
**같은 `N` 층 안에서는 상위 십분위든 전체든 미보정이 같다**(`N=3-4` 는 둘 다 −18.7%).

> **⟹ "상위 십분위 = 낮은 `x` 에서 `F_X` 가 틀렸다"는 틀렸다.**
> **`x` 는 상관없다. 저`N` 층의 `F_X` 가 틀렸고, 십분위가 저`N` 으로 채워져 있어서 그렇게 보였다.**

### ✅ 후보 2 를 내린다 — 부호가 반대다

```
생존 필터가 "모두 낮게 넣은 회차"를 뺀다  →  관측 F_X 가 위로 치우침
→ 경쟁자를 실제보다 높게 봄  →  나를 밟을 확률을 낮게 봄  →  승률 **과대**예측
관측은 **과소**예측이다.  부호가 반대다.
```
**⟹ 후보 2(007 조건부 편향)는 단독으로는 이 미보정을 못 만든다.**

**그리고 부호를 앞으로 밀면 방향이 나온다:**
**과소예측을 만들려면 `F_X` 가 아래로 치우쳐야 한다 = 경쟁자를 실제보다 낮게 봄
= 학습기(2023-2025) 경쟁자가 평가기(2026)보다 낮게 넣었다.**
**⟹ 후보 1(체제 변화)의 방향과 맞는다.**

### ⚠ 후보 4 를 추가한다 — 층 내 이질성 (풀링)

**저`N` 층에서 `F_X` 를 회차들 위로 풀링하면 *회차 간* 변동이 분포에 섞인다.**
**층이 거칠수록(지금은 `N` 6버킷 × 기초금액 5분위) 그 몫이 크고,
`N` 이 작을수록 회차당 관측 경쟁자가 적어 층 내 이질성을 개별 회차로 못 나눈다.**
**⟹ 미보정이 `N` 에 단조인 것과 모양이 맞는다.**

⚠ **다만 부호를 계산 안 했다.** 풀링이 `F_X` 를 넓히는데,
**넓은 `F_X` 가 좁은 `[R,x)` 구간에 넣는 질량이 늘어나는지 주는지는 구간 위치에 달렸다.**
**후보 2 를 부호로 내린 것과 같은 기준을 적용해야 한다 — 계산 전에는 채택 안 한다.**

### ✅ 후보 1 과 3·4 를 가르는 검사 — 저`N` 층 안에서 `A`/`B`

**지역 교란 때문에 후보 1 로 바로 못 간다. 그래서:**
```
저N 층 안에서 A(기존 기관) / B(신규 기관) 로 미보정을 가른다

A 와 B 가 같다   → 지역/기관이 아니다 → 시간(체제) 효과.  후보 1
B 에서만 크다    → 신규 지역의 경쟁자 행동이 다르다.      후보 3
A 에서도 크다    → 둘 다이거나 제3 원인 (후보 4 포함)
```
**`A`/`B` 라벨은 이미 있고(학습 기간 기관 집합으로 고정) 같은 스캔에서 공짜다.**

### 🔴 결과 — 두 후보 어느 쪽도 아니다. **기존 지역이 4배 나쁘다**

| `N` 층 | 지역 | n | 상대오차 |

### ❌ 그런데 경쟁 설명이 하나 있다 — **시간이 다르다** `[반증됨 — 아래]`

🔴 **그리고 두 시간짜리 스윕이 월 단위 루프를 돌다 멈췄으면, 우리가 가진 신규 지역 회차는

## §2-FX 후보 판정 — 부호·`N` 패턴·크기 셋으로 거른다

### ✅ 규율 (`ml-expert` 제안 + 확장)

> **후보는 *부호*와 *변수 의존 패턴* 둘 다 맞아야 채택한다.**
> **부호만 보면 후보 4 를 채택했을 것이고 틀린 처방(M3 도입)으로 갔다.**
>
> 🔴 **확장: 크기는 *실제 조건부*로 계산한다. 주변 확률을 대리로 쓰지 않는다.**
> **후보 5 가 정확히 여기서 걸렸다 — 아래.**

### 후보 판정표

| | 후보 | 부호 | `N` 패턴 | 크기 | 판정 |
|---|---|---|---|---|---|
| 1 | `F_X` 체제 변화 | ✅ | — | — | ⏳ 미검정 (지역 통제 필요) |
| 2 | `F_X` 의 007 편향 (학습 쪽) | ❌ 반대 | — | — | **단독 원인 아님** — 단, 존재는 한다 |
| 3 | 층화가 거칠다 | — | ❌ | — | 세분화가 안 도움. ⚠ 교란 있음 |
| 4 | 층 내 이질성 (풀링) | ✅ | ❌ 반대 | — | **기각** |
| 5 | 007 조건부 (평가 쪽) | ✅ | ✅ | ❌ | **크기 미달** — 아래 |

### 후보 4 — 부호는 해석적으로 통과, `N` 패턴에서 기각

```
q_i = P(회차 i 경쟁자가 [R,x) 밖).  풀링 F̄ 를 쓰면 우리는 (E[q])^N 을 계산한다
진실은 E[q^N] 이고 x^N 이 볼록 ⟹ Jensen:  E[q^N] ≥ (E[q])^N
⟹ 풀링은 반드시 **과소**예측.  관측 부호와 일치  ✅
```
**그런데 `N` 의존이 정반대다:**
```
합성 (h=0.004)  N=3 −15.9%  N=10 −40.0%  N=100 −59.7%   → N 클수록 **심해짐**
실측            N=3-4 −18.7%  N=10-29 −8.7%  N=100+ −0.5%  → N 클수록 **약해짐**
```
**⟹ 단독 원인이면 `N=100+` 이 최악이어야 한다. 실측 −0.5%. 기각.**

⚠ **세분화 시험은 교란이라 판정에 못 쓴다** — 잘게 쪼개니 오히려 나빠졌다(−14.6%→−18.7%→−20.1%).
**이질성은 줄지만 층당 표본이 줄어 `F_X` 가 잡음해진다. 두 효과가 반대로 걸린다.**
**⟹ 합성으로 간 판단이 옳다. 이 상충 자체를 규율로 남긴다: 층을 쪼개서 나빠졌다고 "층화 문제 아님"으로 못 읽는다.**

### 🔴 후보 5 (평가 집합의 007 조건부) — 부호 ✅ `N` 모양 ✅ **크기 ❌**

**주장:** 코퍼스가 007 전수이고 `낙찰 ⊂ 007` 이므로
`P(낙찰|007) = P(낙찰)/P(007) > P(낙찰)` ⟹ 관측이 예측보다 높다 ⟹ **과소**예측. 부호 ✅
그리고 `P(007|N)` 이 저`N` 93.17% · 고`N` ~100% 라 **`N` 모양도 정확히 맞는다.** ✅

🔴 **그런데 팽창 배수의 조건부가 틀렸다. `1/P(007|N)` 이 아니라 `1/P(007|xᵢ)` 다:**
```
관측 = P(승 | xᵢ, 007) = P(승|xᵢ) / P(007|xᵢ)          [승 ⟹ 007]

007 ⟺ max_j x_j ≥ R.   내 xᵢ ≥ R 이면 나 혼자로 007 성립
⟹ 승률 질량을 지는 높은 x 구간에선  P(007|xᵢ) ≈ 1  ⟹ 팽창이 거의 사라진다
```
**`P(007|xᵢ) ≥ P(007|N)` 이므로 `7.3%` 는 과대추정이다. 관측 `18.7%` 와의 간극이 더 벌어진다.**

🔴 **그리고 후보 2 가 반대 부호로 살아 있어 상쇄한다:**
```
후보 2 (학습 쪽 007)  →  F_X 위로 치우침  →  과대예측  (+)
후보 5 (평가 쪽 007)  →  관측 팽창        →  과소예측  (−)
관측 −18.7% 는 이 둘의 **차**다
⟹ 후보 5 단독은 18.7% 보다 **더 커야** 한다.  간극이 두 방향에서 나빠진다
```
**⟹ 후보 2 를 "단독 원인 아님"으로 기각한 것을 "존재하지 않음"으로 읽으면 안 된다. 판정표에 그대로 반영했다.**

### 🔴 그래서 — 재판을 그만두고 **쪼개서 각각 크기를 붙인다**. 새 데이터 0건

**007 회차는 낙찰자가 반드시 정확히 한 명이다. 분자에 표집오차가 없다.**
**그리고 `x` 벡터 전체에 조건 걸면 승 확률이 닫힌 형태다 — `f_R` 만 있으면 되고 `F_X` 가 필요 없다:**
```
P(승_i | x 전부) = P(R ≤ x_i,  x_j ∉ [R, x_i) ∀ j≠i)
Σ_i P(승_i | x 전부) = P(R ≤ x_max) = F_R(x_max)     ← 항등식
                                    (승 사건은 배반, 합집합이 007)
```
🔴 **`F_R(x_max)` 이 곧 후보 5 의 크기다 — 회차마다, 주변 확률이 아니라 그 회차의 실제 조건으로.**

**사전 등록:**
> **후보 5 가 전부라면 `E[F_R(x_max) | N 층] ≈ 1 + 관측미보정` 이어야 한다.**
> **`N=3-4 → 0.813` · `N=100+ → 0.995`. 맞으면 후보 5 확정, 잔차가 남은 원인의 크기다.**

**필요한 건 전부 있다:** `xmax` 는 `bids.npz` (`b_xmax`, 철회 포함·비포함 둘 다), `f_R` 도 있다.

**그리고 이게 미보정을 통째로 두 조각으로 나눈다:**
```
(a) P(승_i | x 전부)   실제 경쟁자에 조건.  f_R 만 씀
(b) P̂(승_i | x_i)      배포 모형.  F_X 로 경쟁자 주변화

(a) vs 관측   =  f_R + 007 선택의 몫     ← 후보 5 의 진짜 크기
(b) vs (a)    =  F_X 의 몫               ← 후보 1·3·4 가 사는 자리
```
⚠ **(a)는 입찰 시점에 없는 정보를 쓰므로 배포 못 한다. 천장 모형으로서만 유효하다.**

### 🔴 그 전에 — 후보 5 와 후보 1 을 가르는 한 줄. **사전 등록**

**후보 5 는 *모든 시기*에 있는 선택 효과다. 후보 1 은 시간 효과다.**
```
학습 기간(2023-2025)에 대해 **표본 내** 보정을 잰다.  그 코퍼스도 007 전수다

저N 미보정이 표본 밖과 비슷   →  후보 5 (선택).  체제 아니다
표본 내에서 ≈ 0              →  후보 1 (체제).  선택 아니다
```
**새 데이터 0건. 제일 싸고 제일 결정적이라 이것부터 돌린다.**

### 실행 순서

```
1. 🔴 표본 내 저N 미보정            후보 5 vs 후보 1
2. 🔴 E[F_R(x_max) | N 층]          후보 5 의 크기를 실제 조건부로
3.    (b) vs (a) 로 F_X 몫 분리     남은 후보들의 크기
4.    그 다음에 체제 검정 (필요하면)
```
⚠ **`P(007|N)` 은 요청 보류.** 주변 확률이라 우리가 쓸 값이 아니고, 위 셋이 같은 걸 더 정확하게 공짜로 준다.
`data-inventory` 에는 **목록 종단에 입찰자 수 필드가 있는지** 스키마 확인만 걸어뒀다 (크롤 아님).

✅ **답: 있다.** `ds_list` 38컬럼에 `BID_CNT` 가 **100% 채워져 있다**(고유값 230). 그리고 **기존 `P(007|N)` 값이 이미 그 필드로 만든 것**이고 상세를 안 썼다. 원본이 `failcount/` 에 보존돼 재계산에 호출 0회다.
**⟹ 내 반박은 그 값의 *생산*이 아니라 *환산*을 향한 것이었다. 값 자체는 맞다.** 근거를 안 밝히고 "잘못된 조건부"라고만 쓴 게 내 잘못이다.

## §2-FX-N `N` 버킷 경계 톱니 — **후보 3 이 맞았다. 틀린 축을 세분했을 뿐**

### 🔴 정확한 `N` 으로 재니 톱니가 나온다

```
기존 지역, 정확한 N 별 미보정
N=3 −29.3  N=4 −14.8  N=5 −16.1  N=6 −16.5  N=7 −13.4  N=8 −12.6  N=9 −6.8
N=10 −22.9  N=11 −17.4  N=12 −15.5  N=13 −14.2  N=14 −9.8  N=15 −7.7   N=16-29 −1.6

층 경계가 정확히 N = 5, 10, 30, 100 이다
```

**기제:** `F_X` 는 **버킷 전체로 풀링**되는데 승률 계산은 **정확한 `N`** 으로 한다.
```
저N 회차는 경쟁자가 더 높게(R 에서 멀게) 넣는다
⟹ 버킷의 낮은 N 에서 풀링된 F_X 에 고N 회차의 **낮은 x** 가 섞인다
⟹ [R, x) 구간 질량 과대  →  밟힐 확률 과대  →  **과소예측**
⟹ 버킷 끝(높은 N)으로 갈수록 자기 회차와 가까워져 완화된다
```
**관측된 버킷 내 단조 개선이 정확히 그 모양이다.** 부호 ✅

### 🔴 그런데 증거는 원시 차가 아니라 **기울기 보정 점프**로 읽는다

**경계 가설과 "미보정이 `N` 에 매끄럽게 단조" 가설은 *버킷 안에서 똑같은 예측*을 한다.**
**둘 다 `N` 이 커지면 개선된다. ⟹ 증거는 전부 *경계*에 있고, 국소 기울기 대비 편차로 재야 한다.**

### ✅ 실측 확정 — 세 경계 전부 같은 부호·비슷한 크기·유의

| 경계 | 외삽 예측 | 관측 | **편차** | `z` |
|---|---|---|---|---|
| `N=5` | +5.1% | −15.5% | 🔴 **−20.6 %p** | **−17.0** |
| `N=10` | −2.2% | −22.8% | 🔴 **−20.6 %p** | **−11.4** |
| `N=30` | +8.2% | −6.4% | 🔴 **−14.6 %p** | −2.3 |
| `N=100` | — | — | ⏳ **미확인** | 표본 부족 (`N=70~99` 가 150 투찰) |

> **⟹ 버킷 경계 가설 확정.** `N=30` 의 `z=−2.3` 은 약하지만 방향이 맞고 표본이 얇아서다.
> ⚠ **`N=100` 은 "미확인"으로 남긴다 — 표본 부족을 통과로 읽지 않는다.**

**`N` 별 `n`·`SE` (규율 18, 세 번째 만에):**
```
N=3   8,034  −28.1  SE 1.14      N=10  16,440  −22.8  SE 1.81
N=4  13,788  −11.5  SE 1.31      N=15  24,855   −7.9  SE 2.19
N=5  19,240  −15.5  SE 1.22      N=16  18,400   −9.7  SE 2.58
N=9  17,865   −4.9  SE 2.01      N=30   6,120   −6.4  SE 6.45
```
**표본 충분. `−28.1%`·`−22.8%` 는 확실히 유의하다.**

✅ **그리고 `15→16` 은 실측으로 점프가 아니었다** — `N=15 −7.9` · `N=16 −9.7`, 매끄럽다. **없는 점프였음이 확인됐다.**

🔴 **두 경계 모두 15~18 %p, 같은 부호, 예측한 방향.**
**원시 차(`−14.8→−16.1`)만 보면 `N=5` 가 미미해 보이는데 기울기를 빼면 `N=10` 만큼 크다 — 증거가 두 배다.**

⚠ **`15→16` 은 점프가 아니다.** 앞은 단일 `N`, 뒤는 14개 `N` 의 집계이고 `N=16` 은 버킷 `[10,30)` **안쪽**이다. **단일 값과 집계를 나란히 놓아 없는 점프를 본 것 — 실패 13 의 또 한 겹이다.**

⚠ **남은 것: `N` 별 `n`·`SE`, 그리고 경계 30·100.** 넷 중 넷이면 확정이다.

### ✅ 후보 3 을 잘못 기각했었다 — 세분화 시험의 함정

```
세분화에서 추가한 것   기초금액 · 지역      →  효과 없음 (그건 맞다)
안 한 것              🔴 N 을 잘게         →  이게 원인이었다
```
> 🔴 **규율: 세분화 시험은 "어느 축을 세분하나"를 정하고 돌린다.**
> **축이 틀리면 기각이 나오고, 그 기각이 진짜 원인을 가린다.**

### ⚠ 처방의 성공은 진단의 증거가 아니다

```
경계 가설이 맞다     →  정확한 N 조건부화가 고친다
매끄러운 N 가설      →  정확한 N 조건부화가 고친다 (진짜 F_X 가 N 에 매끄러우니까)
```
**⟹ 처방은 두 가설에서 같으므로 먼저 돌려도 된다. 다만 "고쳐졌으니 경계 가설이 맞았다"로 읽으면 안 된다.**
**진단의 증거는 위 기울기 보정 점프뿐이고, 그건 따로 낸다.**

### ✅ 지역 효과도 실재한다 — 저`N` 에서만

```
정확한 N 에서 기존−신규 차
N=3-9    −5 ~ −18 %p    크다
N=10-15  −4 ~ +8 %p     작고 부호가 섞인다
N≥16     ±2 %p          사실상 0
```
**⟹ 두 원인이 겹쳐 있다: `N` 버킷 경계(전 구간) + 지역(저`N` 만).**

### M3 가 여기서 필요해진다 — 다만 수축량은 **학습**한다

`N=3` 기존이 7,002 투찰이라 `N` 하나당 `F_X` 적합은 얇다. **이웃 `N` 부분 풀링(계층)이 필요하다.**
⚠ **그런데 부분 풀링은 결국 *부드러운 경계의 버킷*이다. 수축량을 손으로 정하면 같은 인공물을 다른 모양으로 다시 넣는 것이다. 반드시 학습한다.**

## §2-FX-V 진단 종결 — 사전 등록 두 개가 다 판정됐다

### ✅ 검정 1 (사전 등록) — **후보 1 기각.** 표본 내에서도 그대로 남는다

| | N=3-4 | N=5-9 | N=10-29 | N=30-99 | N=100+ |
|---|---|---|---|---|---|
| **표본 내**(학습) | **−22.1%** | −13.8% | −7.7% | −2.1% | −0.7% |
| 표본 밖(평가) | −18.7% | −12.7% | −8.7% | −2.3% | −0.5% |
| 차 (밖−안) | 3.4 %p | 1.1 %p | −1.0 %p | −0.2 %p | 0.2 %p |

🔴 **`F_X` 를 *같은 데이터*로 적합했는데 `−22.1%` 가 남는다.**
**⟹ 사전 등록한 판정대로 후보 1(체제 변화) 기각. `F_X` 추정 오차도 시간 변화도 아니고 모형 *구조*다.**

⚠ **"오히려 표본 내가 더 나쁘다"는 아직 아무 뜻도 아니다.**
`N=3` 이 `−29.3` · `N=4` 가 `−14.8` 이라 **`N=3-4` 버킷의 내부 구성이 두 기간에서 다르면 그 3.4 %p 는 통째로 구성 차다.**
**⟹ 판정은 `−22.1%` 가 *크다*는 데 걸려 있으므로 그대로 선다. 3.4 %p 만 구성표 없이는 못 읽는다.** (규율 18 승격 직후의 보고다)

### ✅ 검정 2 — 007 조건부는 **실재하되 5분의 1**

```
E[F_R(xmax)]     N=3-4 0.9589  N=5-9 0.9766  N=10-29 0.9813  N=100+ 0.9963
후보 5 만이라면   −4.1%        −2.3%        −1.9%         −0.4%
실측 미보정       −22.1%       −13.8%       −7.7%         −0.7%
설명 비율         19%          17%          25%           57%
```
**부호 ✅ · `N` 패턴 ✅ · 크기 ❌ — 약 20% 만 설명한다.**
**⟹ `1/P(007|N)` 을 대리로 쓴 게 5배 과대였다. 실제 조건부(`F_R(x_max)`)로 재니 작다. 규율 15 가 값을 했다.**

### 🔴 그런데 잔차 귀속은 무효다 — 후보 목록이 전수가 아니다

```
"1·2·4·5 가 아니니 남은 80% 는 3 이다"   ⟹ 목록이 전수라는 전제가 필요하다
```

**후보 6 — 회차 내 경쟁자 상관.** 우리 모형은 경쟁자 `x` 를 `F_X` 에서 **IID** 로 뽑는다.
```
K = [R, x_i) 안의 경쟁자 수.   우리는 IID 로 P(K=0) 을 계산
회차 내 양의 상관(같은 기초금액·하한율·원가구조) ⟹ K 과산포 ⟹ P(K=0) **증가**
   (혼합이항의 P(0) > 같은 평균 이항의 P(0).  p ↦ (1−p)^N 볼록, Jensen)
⟹ 진짜 승률 > 예측  ⟹  **과소예측**      부호 ✅
```
🔴 **그런데 후보 4 와 *같은 볼록성 가족*이다** — 후보 4 는 층 내 *회차 간* 이질성, 후보 6 은 *회차 내* 상관. **둘 다 `(1−p)^N` 의 Jensen 이라 후보 4 를 죽인 `N` 패턴을 물려받는다.**

> **⟹ 후보 3 결론은 아마 맞다. 다만 근거가 "잔차라서"가 아니라
> "잔차의 최유력 대안이 이미 죽은 것과 같은 가족이라서"다.**
> ⚠ **예외: 상관 자체가 `N` 에 따라 줄면**(소규모 지역 시장은 상관이 높고 큰 시장은 낮다) **`N` 패턴이 뒤집힌다. 배제 안 됐다.**

### 🔴 사전 등록 (처방 돌리기 전)

> **정확한 `N` 조건부화 후 잔차가 007 바닥(`N=3-4` 에서 `−4.1%`) 근처로 내려가야 한다.**
> **내려가면 후보 3 이 80% 를 가져간 게 확정.**
> **안 내려가면 남는 건 층화가 아니고, 후보 6 을 `N` 의존 상관으로 다시 연다.**

**⟹ 후보 3 을 지탱하는 건 톱니(실물 증거)지 잔차가 아니다.**

### ⚠ 바닥 `−4.1%` 는 숫자가 아니라 **구간**이다

```
후보 2(F_X 의 007 편향)도 못 고친다 — F_X 를 007 회차에서만 관측하는 건 구조다
⟹ 바닥 = (못 고치는 −4.1%) − (못 고치는 후보 2 몫)
⟹ 둘 중 하나만 쟀다.  바닥은 [0, 4.1%] 구간이다
```
🔴 **"천장이 더 낮다(고칠 여지가 더 크다)"가 아니라 "천장을 아직 모른다"다.**

**상한은 잴 수 있다 — 새 수집 없이:** `P(007|N)`(저`N` 93.17%)이 **빠진 회차의 질량**을 준다. 빠진 회차는 전원 `x < R` 이다. **질량과 방향을 아니 최악 배치로 상한이 나온다.**
⚠ **그리고 `F_X` 를 바꾸면 후보 2 의 크기도 바뀐다. 바닥은 고정 상수가 아니다.**

### ✅ (b) vs (a) — 진단으로는 접고, **정보 천장**으로 살린다

**진단은 불필요해졌다(①이 `F_X` 확정, ②가 007 정량화).**
🔴 **대신 `(a) = P(승_i | x 전부)` 를 정보 천장으로 남긴다** — `f_R` 을 알고 실제 경쟁자를 아는 모형의 최선. 배포는 못 하지만 **"정확한 `N` 조건부화가 어디까지 갔나"를 재는 자다.**
```
(a) 에 근접  →  경쟁자 정보 부족분을 거의 회수.  더 짜낼 게 없다
멀다        →  남은 건 층화가 아니라 F_X 형태의 문제
```

**⟹ 셀을 늘리면 in-sample 은 계속 좋아지고 held-out 은 안 좋아진다. 실용점을 내린 판단이 옳다.**

### 🔴 지표가 틀렸다 — 우리는 `N` 을 **맞힐** 필요가 없다

```
P(승 | x) = Σ_N  P̂(N | 공고) · P(승 | x, N)
```
**⟹ 필요한 건 argmax 정확도가 아니라 *보정된 예측 분포* `P̂(N|공고)` 다.**
`68.6%` 는 "3분의 1은 틀린다"로 들려 실제보다 나빠 보이고, `sd(log N)` 도 대리값이다.

🔴 **진짜 지표는 하나다:**
```
N 을 알 때 미보정        ← 천장 (−22.1% → −4.1% 를 노리는 그 좌표계)
N̂ 로 주변화한 미보정      ← 실적
낙차                     ← 제품이 N 을 모르기 때문에 잃는 값
```
⚠ **`P(승|x,N)` 이 `N` 에 비선형이라 점추정 `N̂` 을 꽂으면 안 된다. 반드시 분포로 적분한다** — 후보 4·6 을 죽인 그 볼록성이 여기서 세 번째로 나온다.
⚠ **`P̂(N|공고)` 의 보정 검사도 같이 건다.** 셀당 중앙 `n`=3 이면 경험분포가 심하게 과신할 수 있다.

### 🔴 이득과 손실이 같은 자리에 있다

```
처방(§2-FX-N):   저N 에서 F_X 를 정확한 N 에 조건부화  →  −22.1% → −4.1%
                 **이득이 전부 저N 에 있다**

N̂ 의 한계:       코퍼스가 007 전수라 저N 이 과소 대표 (P(007|N=1)=11.55%)
                 N̂ 가 저N 에서 가장 낙관적 = 가장 못 맞힌다
                 **손실도 전부 저N 에 있다**
```
🔴 **따로 보면 둘 다 좋은 소식인데 겹치면 상쇄될 수 있다.**
> **⟹ 낙차를 재기 전에는 `−4.1%` 를 제품 수치로 인용하지 않는다.**
> **3번(정확한 `N` 조건부화)이 끝나도 4번(낙차) 전에는 개선폭을 발표하지 않는다.**

### ❌ `N̂` 을 `F_X` 해상도의 게이트로 두자는 제안 — **반려. 전제가 틀렸다**

`ml-expert` 제안: *"`N̂` 이 ±3 이면 정확한 `N` 조건부화가 무의미하다. `N̂` 정확도를 먼저 재고 그 해상도에 맞추자."*

🔴 **두 연산이 다르다:**
```
지금 (틀림)   F_X 를 버킷으로 풀링 → 그 F_X 로 승률 계산      = 비선형성 **안쪽** 평균
옳음          F_X(·|N) 정확히 → 승률 → P̂(N|공고) 로 주변화     = 비선형성 **바깥쪽** 평균
```
**`Σ_N P̂(N)·P(승|x,N)` 은 `P̂(N)` 이 아무리 넓어도 *편향이 없다*.**
**버킷 풀링은 `P̂(N)` 이 완벽해도 `−22%` 편향이 남는다.**

> **⟹ `N̂` 이 넓으면 예측이 *덜 날카로워*질 뿐이고, 지금 문제인 *편향*은 그대로 제거된다.**
> **⟹ `F_X` 의 `N` 해상도는 `N̂` 이 아니라 *표본*이 정한다 — 그게 M3 의 학습된 수축량이 하는 일이다.**
> **`N̂` 은 주변화 시점에 들어오지 적합 시점에 안 들어온다.**

⚠ **다만 점추정 `N̂` 을 꽂으면 제안자 말이 맞아진다** — 그건 다시 안쪽 평균이고, §2-FX-0 의 **다섯 번째 축**이다. **분포로 적분한다.**
**`N̂` 정확도 측정은 병행하되 3번의 게이트가 아니다.**

### 실시간 `N` 이 있으면 예측이 필요 없다 — **제품 설계 질문**

```
마감 1시간 전 목록 조회   94.2%   ⚠ 출처 검증 중

🔴 **⟹ 제품이 투찰 시점에 목록 종단을 부를 수 있으면 예측 모델이 불필요해진다.**
**그리고 그 경로를 택하면 수집기의 *운영 신뢰성*이 차단 의존성이 된다** — 미해결인 `_warmup()` 멈춤이 "나중에 고칠 것"에서 "제품 전제"로 승격된다.
**⟹ 사용자 결정 대기 항목 3번의 우선순위가 올라간다.**

### 🔴 검증 ② — `94.2%` 의 출처는 밝혀졌다. **그런데 제품이 쓸 수 있는 값이 아직 아니다**

`data-inventory` 정정: **앞선 "과거분으로 못 만든다"가 틀렸다.** 상세의 `BID_DT` 가 100% 있어 **회차마다 `N(T−1h)` 를 복원할 수 있다. `n = 233,122`**(지역 일치 평가셋만으로도 93.3%, `n=52,236`). **006 목록 442행과 무관하다.**
✅ **"두 출처가 있다"로 봉합하지 않고 "내 문장이 틀렸다"로 정정한 처리, 옳다.**

🔴 **그런데 잰 것과 제품이 할 일이 다르다:**
```
잰 것      상세의 BID_DT 로 N(T−1h) 를 **복원**
제품       마감 1시간 전에 **목록 종단을 불러 BID_CNT 를 읽는다**

eaT 가 마감 전에 입찰자 수를 공개하면 그게 곧 우리가 모형화하는 그 전략 정보다

**⟹ 결정적 확인을 걸었다 — 진행중(006) 목록 442행의 `BID_CNT` 를 본다.** `[미해결]`

⚠ **갈리기 전까지 `94.2%` 는 "상세로 복원한 *상한*"으로만 표기한다.**

⚠ **다만 남은 질문이 있다: `T−1h` 의 값이 최종 `N` 에 얼마나 근접하나.** `[미해결]`

## §2-FX-3 3번 설계 — `F_X(·|N)` + M3. **목적함수를 고치고 돌린다**

```
F_X(·|N) = Σ_N' w(N,N') · F̂_N'        w ∝ n_N' · exp(−|log N' − log N| / h)
h 를 학습한다 (스윕 0.02~0.80, TUNE Brier 최소).  손으로 안 고른다
N ≥ 60 은 하나로 묶는다
기준선으로 6버킷 풀링을 같은 스캔에서.  (2) 무조건부 주변화도 같이
```
**`TUNE` 에서만. 봉인 미접촉.**

### 🔴 결함 ① — `h` 스윕의 목적함수가 **고`N` 에 지배된다**

```
전역 Brier 로 h 를 고른다.  그런데 표본이 N 에 극단적으로 쏠려 있다
   N=3-4      21,822 투찰
   N=100+  1,145,454 투찰        ← 52배
```
🔴 **전역 `Brier` 의 98%가 고`N` 에서 오고, 고`N` 은 이미 `−0.5%` 로 멀쩡하다.**
**⟹ *안 고쳐도 되는 구간*이 목적함수를 정하고, 전부인 저`N` 이 2% 지분으로 끌려간다.**

**예측되는 결과: `h` 가 넓게 학습 → 저`N` 개선 미미 → "정확한 `N` 조건부화가 생각보다 안 통한다"는 *잘못된* 결론.**

### 🔴 결함 ② — 가중치의 `n_N'` 인자가 같은 방향으로 샌다

**정밀도 가중(`n` 비례) 자체는 표준이다. 그런데 우리 `n` 이 `N` 에 단조 증가한다:**
```
저N 을 목표로 커널을 걸어도  n_N' 인자가 고N 쪽으로 질량을 끌어온다
⟹ h 가 아주 작지 않으면 저N 의 F_X 가 다시 고N 경쟁자로 오염된다
⟹ **제거하려는 그 오염을 커널이 되넣는다**
```
⚠ **①과 결합하면 최악이다 — 전역 스윕이 큰 `h` 를 고르고, 큰 `h` 에서 `n_N'` 가 저`N` 을 삼킨다.**

### ✅ 처방 — 1번 채택

```
1. 🔴 h 를 N 의 함수로.  h(N).  저N 은 좁게 고N 은 넓게
      미보정이 N=3 에서 40배 큰데 단일 h 가 양쪽을 못 섬긴다
      최소 형태: 저N(<30)·고N(≥30) 에 h 를 따로 스윕
2.    목적함수를 저N 부분집합(N<30)에서만 — 1번의 특수형. 지금 바로 됨
3.    N 층 균등 가중 Brier   ⚠ 층 간 중요도를 손으로 정하는 것이라 열등
```
🔴 **`h` 를 전역으로 하나 뽑았으면 그 수치는 못 쓴다. 목적함수를 고치고 다시 돌린다.**
⚠ **①②는 "학습한다"가 아니라 *무엇에 대해 학습하나*의 문제다. `h` 를 손으로 안 고르는 원칙 자체는 맞다.**

### 🔴 결함 ③ — `N ≥ 60` 은 **새 경계**다. 검사한다

**전체 발견이 "버킷 경계가 인공물을 만든다"인데 거기 `60` 이라는 새 경계를 넣고 있다.**

| 100+ | 4,019 | 78.9% | 68.4% | *76.9%* |

**예상대로 창 하나로 안 뒤집혔다. 정본으로 채택한다.**
⚠ **"겹침 우려 해소"는 여전히 `ml-expert` 의 `N` 층별 회수율 뒤다.**

⚠ **⟹ "겹침 우려는 `N=1` 에만"은 격려는 되지만 확정 아니다. 확정은 회수율을 `N` 층별로 낸 뒤다.**

### ✅ 회수율 — `N̂` 의 값어치를 비율로 낸다

```
(1) N 을 알 때 미보정          −22.1% (N=3-4)   ← 천장. 있다
(2) N 을 아예 안 쓸 때 미보정    ?               ← 🔴 바닥. 안 쟀다
(3) N̂ 분포로 주변화한 미보정     ?               ← 실적

회수율 = (2 − 3) / (2 − 1)      "N 정보의 몇 %를 N̂ 이 회수하나"
```
**(2)가 없으면 "(3)이 (1)보다 나쁘다"만 알고 얼마나 나쁜지 모른다. `P̂(N)` 없이 지금 낼 수 있다.** 승인함.

### 🔴 다만 `(2)` 의 정의를 고쳤다 — 층 평균 `N` 을 꽂으면 다섯 번째 축이 **분모**에 들어간다

```
❌  P(승 | x, N̄)                점추정.  Jensen 격차가 붙는다
✅  Σ_N P(N) · P(승 | x, N)      **무조건부** 주변분포로 주변화
                                 (공고 정보를 안 쓴다는 뜻이지 N 을 안 쓴다는 뜻이 아니다)
```
**부호가 유리한 쪽으로 틀려서 더 위험하다:**
```
나쁨을 b 라 하면  b1 < b3 < b2      회수율 = (b2 − b3)/(b2 − b1)
b2 를 Δ 부풀리면 → (b2+Δ−b3)/(b2+Δ−b1)  →  Δ 가 클수록 **1 에 수렴**
⟹ 바닥을 나쁘게 잡을수록 N̂ 이 좋아 보인다
```

### 🔴 제대로 잡으면 실험의 *의미*가 달라진다 — 이쪽이 더 중요하다

```
Σ_N P(N)·P(승|x,N) = E_N[P(승|x,N)] = P(승|x)      ← 정의상 **무조건부 승률 그 자체**
```
**⟹ 제대로 주변화한 바닥은 *편향이 0* 이다. 그냥 덜 날카로울 뿐이다.**

| | 편향 | 분해능 |
|---|---|---|
| (1) `N` 을 알 때 | 0 | 최대 |
| (2) 무조건부 주변화 | **0** | 최소 |
| (3) `N̂` 주변화 | 0 | 중간 |

> 🔴 **⟹ 3번은 *편향*을 없애고, 4번은 *분해능*을 잰다. 다른 양이고 한 숫자에 섞으면 안 된다.**
> **현재 `−22.1%` 는 편향(버킷 풀링)이다. 회수율은 분해능 회수율이다.**
> **⟹ 회수율을 "미보정 몇 %"로 재지 마라 — 미보정은 3번이 0 으로 만든다.**
> **분해능은 `Brier` 의 `res` 항이나 `f_R` 기준 이득으로 잰다.**

⚠ **3번 후에도 미보정이 안 사라지면 `(2)` 도 편향을 갖는다는 뜻이고, 그건 §2-FX-0 에 *여섯 번째 축*이 있다는 신호다. 그 경우 사전 등록한 대로 후보 6 을 다시 연다.**

### 🔴 `P(α|z)` 보정 게이트 — 신뢰도만 보면 안 된다

**주변화가 이진화보다 나은 건 확률이 보정됐을 때뿐이다.**
**보정 안 된 확률로 주변화하면 이진화보다 나쁠 수 있다 — 그래서 이건 선택이 아니라 게이트다.**

```
Murphy 분해:   Brier = 신뢰도(Reliability) − 분해능(Resolution) + 불확실성
```
🔴 **신뢰도만 게이트로 걸면 "항상 기저율을 예측하는 모형"이 만점을 받는다.**
**완벽히 보정돼 있고 완전히 쓸모없다 — 주변화가 아무 일도 안 하게 된다.**

🔴 **그리고 이게 `M3` 사용처에 직접 걸린다. 계층 축소는 보정을 좋게 만들고 분해능을 죽인다.**
**발주기관 사후확률을 세게 축소하면 `P(α|z) → 기저율` 이 되고, 신뢰도 게이트는 통과하면서
제품 가치가 0 이 된다.**
> **⟹ `M3` 의 축소 강도를 "신뢰도"가 아니라
> **"신뢰도 게이트를 통과하는 범위에서 분해능 최대"** 로 정한다.

**🔴 기저율 이동을 반드시 처리한다 — 크기가 실측됐다:**
```
학습기 0.164  →  평가기 0.073   (2.25배)      로그오즈 이동 = −0.913
```
**학습기 평균으로 적합한 `P(α|z)` 는 평가기에서 체계적으로 과대예측한다.**
**절편 재보정 없이는 보정 검사를 통과 못 하고, 통과 못 하는 이유가 모형이 나빠서가 아니다.**

**등록할 절차:**
```
1. 보정은 평가기간에서 검사한다 (풀링 금지 — 기저율이 다르다)
2. 🔴 선택 규칙 = Brier 최소.  (게이트+분해능 최대에서 바뀌었다 — 아래 참조)
3. 절편 재보정을 명시적 단계로 허용하되 문서에 적는다.
   🔴 기울기까지 재적합하면 그건 재학습이지 보정이 아니다. 절편만.
   🔴 그리고 평가 기저율로 맞추면 미래를 보는 것이다 — 각 평가 월에 대해
      그 이전 월들의 기저율만 쓴다(전진 검증). 서빙 시점에 아는 것과 같다.
4. 신뢰도 곡선도 같이 그린다 — 분해를 못 읽는 사람이 볼 그림이 필요하다
```

### 🔴 선택 규칙 정정 — "게이트 + 분해능 최대"가 `Brier` 하나보다 나쁘다

**내가 등록한 규칙이 틀렸다. `ml-expert` 가 대수로 보였다:**
```
Brier = rel − res + unc      ⟹   min Brier   ≡   max (res − rel)

"항상 기저율" 모형:   res = 0,  rel = 0   →   Brier = unc   →   최악. 자동 배제된다
```
> **`Brier` 하나가 이미 그 트레이드오프를 정확히 담고 있다.**

**`stats-expert` 의 우려는 유효했고 대상이 달랐다** — *신뢰도만* 걸면 항상-기저율이 만점이지만,
**`Brier` 는 그렇지 않다.** 걱정은 맞았고 해법이 과했다.

**그리고 게이트+분해능 규칙이 실제로 더 나빴다:**
```
신뢰도 게이트(rel ≤ 0.1·unc) 가 s ≤ 30 전부를 통과시켜 한 번도 안 물렸다
그 위에서 분해능 곡면이 평평(0.0157~0.0179)해서 사실상 잡음으로 골랐다
```
**⟹ 선택 규칙을 `Brier` 최소로 바꾼다.** ✅ `stats-expert` 서명 — **자기 게이트를 철회했다.**

### ⚠ 다만 `rel` 에 남는 일이 하나 있다 — 선택이 아니라 **진단**으로

```
res 낮다  →  회차마다 같은 f_R      →  개별 위치 조언이 무뎌진다
rel 크다  →  f_R 이 체계적으로 치우친다  →  집계 주장이 틀어진다 ("f_R 중심 −10.0 bp")
```
> **선택은 `Brier` 하나로. `rel` 은 별도 진단으로 계속 보고한다.**
> **크면 모형을 바꿀 이유는 아니지만, `f_R` 기반 *집계 수치*에 그 편향폭을 같이 적을 이유다.**

### 🔴 그리고 Murphy 분해에 함정이 하나 — 항등식이 닫히는지 먼저 봐라

**10구간으로 계산했더니 항등식이 안 닫혔고, 그 오차가 `s` 마다 달라 순서가 뒤집혔다:**

| | bins | Brier(raw) | rel−res+unc | 차 |
|---|---|---|---|---|
| s=3 | 10 | 0.055153 | 0.065851 | **+0.010698** ← 안 닫힌다 |
| s=3 | 50 | 0.055153 | 0.056290 | +0.001136 |
| s=3 | **200** | 0.055153 | 0.055147 | **−0.000006** ← 닫힌다 |

```
        10구간                    200구간
s=3    res 0.005736           res 0.017319 · rel 0.002447
s=30   res 0.005834 ← 최대     res 0.015706 · rel 0.005925
```
**10구간에서는 구간 내 분산이 `res` 로 안 잡혀 분해능이 과소평가된다.**
**200구간으로 보면 `s=3` 이 신뢰도·분해능 *둘 다* 낫다 — 거친 분해가 지배당하는 선택지를 골랐다.**

> **규율: Murphy 분해를 쓰기 전에 항등식이 닫히는지 확인하라.**
> **안 닫히면 분해능 비교가 무효다.**

### ✅ 지역 구성 처리 — **자르지도 두지도 말고 층으로 가른다**

**공변량 이동 문제이고 표준 처방은 절단이 아니라 층화다:**
```
❌ 절단   지역 일치분만        →  표본 감소 + 평가 집합이 배포 모집단을 대표 안 함
❌ 방치   전부                →  낙관이 얼마인지 모른다
✅ 층화   평가 집합을 둘로
            A. 학습에 있던 지역        →  내삽 성능. 정직한 추정치
            B. 2026 에만 있는 9개 시도  →  외삽 성능. 별도 보고
          전체 = 두 성능의 가중 평균 (가중치 = 평가기 회차 비율)
```

**두 선택지보다 나은 이유 셋:**
1. **표본을 안 버린다** — B 도 평가하되 따로 읽는다
2. 🔴 **낙관의 크기가 계산된다. 추정이 아니라 계산이다:**
   `낙관 상한 ≤ (B 의 회차 비율) × (A 성능 − B 성능)`. **지금 데이터로 바로 나온다**
3. **B 가 A 만큼 잘 나오면 걱정 자체가 실증적으로 소멸한다.** 가정하지 말고 잰다

🔴 **A/B 분류는 *학습 기간*의 지역 목록으로 정한다. 평가 기간을 보고 정하면 순환이다.**
**학습 세트에 등장한 시도 집합을 먼저 확정하고 그걸로 평가 회차를 라벨링한다.**

> **⟹ `+21.4%` 가 "A 에서 얼마 · B 에서 얼마 · 전체 얼마"로 갈라지고,
> 낙관 여부가 추측이 아니라 수치가 된다.**

### ✅ 실행 결과 — 낙관 상한이 **계산됐다**

| | n | Brier | vs 전역 | 신뢰도 | 분해능 |
|---|---|---|---|---|---|
| 전체 | 61,392 | 0.055153 | **+21.4%** | 0.002447 | 0.017319 |
| **A 내삽** (84.2%) | 51,690 | 0.055434 | **+24.3%** | 0.002923 | 0.020637 |
| **B 외삽** (15.8%) | 9,702 | 0.053656 | **+0.6%** | 0.000777 | **0.000048** |

```
🔴 낙관 상한 = 0.158 × 23.7 %p = 3.74 %p
```

### 🔴 그런데 `B` 의 분해능 `0.000048` 이 더 중요한 발견이다 — **안전한 실패**다

**신규 기관에서 `P(α|z)` 가 전역 기저율로 떨어진다**(학습에 없으니 당연하다).
**⟹ 주변화가 사실상 `α=0.03` 고정과 같아진다.**

> **외삽 구간에서 모형이 *틀린 확신을 주는 게 아니라 아무 말도 안 한다.***
> **우리 문서 전체가 "과신을 피한다"로 일관돼 있는데, 주변화가 외삽에서 자동으로 그렇게 동작한다.**
> **⟹ `+0.6%` 는 "쓸모없다"가 아니라 "해롭지 않다"로 읽는다. 그게 배포 안전성이다.**

**그래서 낙관 상한 `3.74 %p` 의 성격도 달라진다:**
**배포 시 신규 기관 비율이 15.8% 보다 높으면 이득이 줄지만 **손해로 뒤집히지 않는다**
(`B` 가 `+0.6%` 로 음수가 아니다). **상한이지 위험이 아니다.**

### ⚠ `rel` 도 층마다 다르다 — 집계 수치에 층을 밝힌다

**외삽에서 오히려 더 잘 보정돼 있다** — 전역값을 내니 당연하다.

✅ **그리고 분해능은 max 가 아니라 평균 기반이라 커스를 안 탄다 — `G1` 이 필요 없는 드문 항목이다.**

### 🔴 `P(α|z)` 판정 — 전기간 학습은 **아무것도 안 하는 것보다 나쁘다**

발주기관별 경험 베이즈 축소(`M3` 첫 실물 사용)로 냈다:
```

        → 전역상수 대비 −8.2%  ·  규칙 대비 −9.3%      🔴 둘 다 진다

보정 곡선   예측 0.0095 → 관측 0.0466 (5배 과소)  ·  0.3378 → 0.1534 (2.2배 과대)
```
**원인 둘:**
1. **체제 변화** — 학습 양성률 0.126 vs 평가 0.076. **수준이 통째로 밀려 있다**
2. **축소 강도가 거의 0** (`s=1.3`) — **기관 간 이질성이 커서 "축소를 안 하는 것"이 경험
   베이즈의 답**이었고, 그래서 소표본 기관 잡음이 그대로 들어왔다

> 🔴 **`stats-expert` 의 경고가 실물로 나왔다** — *"주변화가 이진화보다 나은 건 확률이

> **"나쁠 수 있다"가 아니라 실제로 나빴다.**

**⟹ 사전 등록한 예측("주변화하면 상위 두 십분위 미보정이 준다")은 시험 자체가 불가능했다.**
**전제(보정된 `P(α|z)`)가 안 섰다. 그건 예측의 실패가 아니라 전제의 실패다.**

### ✅ 판정 — **B. 그리고 이건 등록된 규칙과 충돌하지 않는다**

|---|---|
| A | 분할 고정 · `P(α|z)` 포기 · `α=0.03` 고정으로 M1 |

| C | 전체 분할을 체제 후로 옮긴다 |

> 인자 문제가 아니라 *대상이 다른* 문제다.**
> **반면 `F_X`(경쟁자 행동)는 체제 변화와 무관하므로 전기간이 맞다.**
> **학습 대상의 안정성이 다르면 학습 창도 달라야 한다.**

🔴 **이 검정 없이 최근성 가중을 넣으면 그것도 결과를 보고 모형을 고치는 것이다.**

  통합 z (역분산 가중)      −51.48

### M2. 분위 회귀 — **화면에 가장 가까움**

**왜**
사장이 실제로 묻는 건 *"얼마를 넣어야 하나"* 이고, 그건 **낙찰선의 조건부 분위**다.
지금 화면의 `잘 나온 구간` 이 이것의 조잡한 버전이다.

**대상** `Y3 = 그 회차 낙찰 x` 의 조건부 분위 (10·25·50·75·90%)

**인자** M1 과 동일

🔴 **`N` 을 반드시 조건에 넣는다.** 전수로 재니 **최적 x 가 N 에 따라 뒤집힌다.**
N 을 빼면 두 반대 체제를 평균 내서 **아무에게도 안 맞는 구간**이 나온다.

🔴 **그리고 `N(T−1h)` 에 직접 조건화한다. 최종 `N` 을 추정해서 대입하지 않는다.**
```
❌  g(·|N_final = n) 을 추정  →  그 n 자리에 N(T−1h) 를 대입
✅  g(·|N(T−1h) = n) 을 과거 회차의 「최종 투찰 분포」에서 직접 추정
```
**✅ 쪽은 최종 N 의 사후분포로 이미 적분돼 있다** — 과거에 `N(T−1h)=n` 이었던 회차들이
각자 다른 최종 N 으로 끝났고 그 평균이 곧 적분이다. **명시적 적분을 코딩할 필요가 없다.**

**❌ 쪽 오차를 쟀다.** `P ≈ f_R/(N·g)` 라 Jensen 부등식(`E[1/N] > 1/E[N]`)이 걸린다:
```
N(T−1h)=5  → 최종 평균 9    승률 −49.5%
N(T−1h)=10 → 최종 평균 18   승률 −58.5%
N(T−1h)=80 → 최종 평균 144  승률  −8.5%
```
**저경쟁 회차에서 승률을 절반 가까이 과소평가한다. 우리가 쫓던 어떤 효과보다 크고
고치는 비용이 0이다.**
⚠ 다만 편향이 x 에 대해 대체로 곱셈 상수라 **뒤집힘이라는 정성적 결론은 견고하고,
보고되는 승률 수치가 아니다.**

**측정** pinball loss · 구간 커버리지(80% 구간이 실제로 80%를 덮나)

**실패 판정**
- 구간 커버리지가 명목치에서 크게 벗어나면 → **화면에 구간을 못 놓는다**
- **`N` 조건부 분위가 `N` 무조건 분위와 다르지 않으면** → 위 뒤집힘이 재현 안 되는 것이고,
  그건 **분위 회귀 구현이 틀렸다는 뜻이다** (뒤집힘은 이미 전수로 확인됐다)

### M3. 계층 모형 — **`n=1` 문제의 정석 해법**

**왜**
지금 화면이 `1회 중 100%` 같은 구간을 보여준다. **틀린 값은 아니지만 거짓 확신을 준다.**
계층 모형은 **표본이 적은 학교를 전체 평균 쪽으로 자동으로 끌어당긴다.**

**구조** 학교 ⊂ 시군구 ⊂ 시도, 그리고 품목 축

**측정** 표본이 적은 학교에서 **예측 오차가 단순 평균보다 줄어드는가**

**실패 판정**
- shrinkage 후에도 `n` 이 적은 구간의 오차가 안 줄면 → 계층 구조가 잘못 잡혔다
- 모든 학교가 사실상 같으면 → **학교별 재료를 화면에 놓을 이유가 없다.** 이것도 결과다

⚠ **M3 은 결과와 무관하게 화면에 쓰인다.** 표본이 적은 값을 어떻게 보여줄지가
지금 화면의 실제 결함이고, 이 방법이 그 답을 준다.

---

### M4. 판별 모델 (GBDT) — **상한 재기용**

**왜** 구조를 안 쓰고 낼 수 있는 최대 성능. **M1 의 대조군이다.**

**인자** M1 과 동일 — **반드시 같아야 대조가 성립한다**

**측정** M1 과 같은 지표. 그리고 **재료 절제·VoI(설계 문서 E2)를 여기서 낸다**

**실패 판정**
- **B1(학교 과거 중앙값)과 B2n(같은 N 구간의 최적 x)을 둘 다 못 이기면**
  → **인자에 신호가 없다.** 화면을 바꿀 근거 없음

⚠ **B2n 이 새 기준선이다.** 규칙 한 줄(`N` 보고 표에서 x 고르기)로 얼마나 되는지가
모델의 값어치를 정한다. **M4 가 B2n 을 못 이기면 모델이 아니라 표를 화면에 놓는다.**

---

### M5. 신경망 — **여는 조건이 좁아졌다**

**왜 기본이 아닌가**
표 형태 데이터에서 GBDT 를 이기기 어렵다는 게 정설이고, 우리 문제는 구조가 알려져 있다.

> **⚠ "안 되네" 하고 넘어갔던 게 아마 여기다. 이번엔 조건을 미리 정한다.**

🔴 **그리고 개정 1 이후 근거가 넓어진 게 아니라 좁아졌다.**
- `R` 예측이 빠졌다 (파라미터 0개)
- `N` 예측이 빠졌다 (as-of 관측)
- 분기점의 뒤집힘이 **`N` 하나로 설명된다** — `g` 의 모양에서 나오는 구조적 현상이다
- **남은 자리는 `X | z` 하나이고, 거기서도 GBDT 와 겨뤄야 한다**

**여는 조건 (넷 다 충족해야 시작)**
1. **M4 가 B1 과 B2n 을 둘 다 유의미하게 이긴다**
2. **M4 의 상호작용 진단에서 고차 상호작용이 검출된다**
3. **M1 과 M4 의 차이가 설명 안 된다**
4. 🔴 **그 차이가 `N` 조건부화로 사라지지 않는다** — 새 조건. 뒤집힘이 `N` 으로 설명되므로,
   `N` 을 넣은 뒤에도 남는 비선형이어야 신경망의 자리다

**넷 중 하나라도 안 되면 M5 를 안 만든다. 그 사실을 결과로 적는다.**

**실패 판정**
- 같은 인자·같은 분할·같은 예산에서 M4 를 못 이기면 → **이 문제에 신경망은 아니다.** 닫는다
- 이기는데 보정이 나쁘면 → 화면엔 못 쓴다

⚠ **하이퍼파라미터 탐색 예산을 M4 와 같게 준다.** 안 그러면 "덜 튜닝해서 진 것"과
"방법이 안 맞는 것"이 안 갈린다.

### M6. 정책 비교 (replay) — **VoI 의 근거. 그리고 이제 추정이 아니라 계산이다**

**왜**
설계 문서의 중심 지표가 VoI 인데, VoI 는 *"이 값을 알면 행동이 달라지고 결과가 나아지나"* 다.

### 🔴 6-1 off-policy evaluation 이 아니다

경쟁자 `DRAW_NO` 전원과 `ds_pList` 금액과 경쟁자 `x` 전량(9,667,069)을 **관측한다.**
그래서 반사실이 **추정되는 게 아니라 계산된다:**

```
내 투찰을 x 로 옮긴다  →  x ≥ R 이고 [R, x) 에 경쟁자 없음 을 다시 판정
내 표를 c 로 바꾼다    →  득표 재집계 → 동점 낮은 번호 우선 → R 을 다시 계산
```
**가정 0, 근사 0.** 중요도 가중도, 성향점수도, 신뢰구간 확장도 필요 없다.

**⟹ 행동 공간을 `x` 에서 `(x, 표)` 로 넓힌다.** 안 그러면 지금 replay 가 틀린 `R` 을 쓴다.

### ✅ 실행됨 — 표 레버는 실재하지만 창문의 0.07 배다

**105쌍 전수 열거 · 동점 규칙 실측치 재현 · 233,122 회차:**
```
최소 ΔR  +0.021 bp (쌍 10,14)      최대 ΔR  +0.399 bp (쌍 4,8)
레버 폭  0.378 bp = 승부 창문(5.8bp)의 0.07 배
선택이 실제로 바뀌는 회차  15.3% ~ 32.8%      ← 기전은 작동한다
🔴 105쌍 전부에서 ΔR > 0  — 내 2표는 평균적으로 R 을 조금 올린다
```
**낙찰률 환산:**

| | 최대 낙찰률 | 최적 x |
|---|---|---|
| 표 효과 무시 (현재 곡선) | 17.65% | 1.0080 |
| `ΔR` 최대 쌍 | **17.84%** | 1.0110 |

**⟹ 쌍 선택으로 버는 것은 최대 0.19 %p.** 위치 선택(28배 · 280 bp)에 견주면 무시할 수준이다.
✅ **`ml-expert` 의 0.298 bp 와 같은 자릿수다 — 두 경로가 맞는다.**
✅ **반사실 곡선이 표 효과를 무시한 것은 안전했다.**
⚠ **다만 0 은 아니므로 생성기와 replay 정확도에는 넣는다.**

**부수로 나온 것:** `R` 이 오르면 **최적 위치도 함께 오른다**(1.0080 → 1.0110).
**둘이 상충하는 게 아니라 같이 움직인다.**

### 🔴 `N`+1 은 이 데이터로 식별되지 않는다

**같은 회차를 `N` 과 `N+1` 로 동시에 관측할 수 없다.** 관측되는 건 "내가 없었을 때"뿐이다.

**`N` 버킷 간 차이는 상한처럼 보이지만 깨끗한 상한이 아니다** —
**경쟁자의 투찰 행동 자체가 `N` 에 따라 달라진다**(`median(x)` 1.0755 → 1.0001).
**`N` 효과와 행동 효과가 섞여 있다.**

**가르려면 준실험이 필요하다** — 같은 학교·같은 품목·인접 월에서 `N` 만 다른 회차 쌍 매칭.
**안 했다. `[미해결 — 대리값으로 대체하지 않았다]`**

> ✅ **대리값을 내놓는 대신 "못 낸다"고 말한 것이 옳다.**
> **`N`+1 은 저경쟁에서 효과가 클 텐데, 거기가 정확히 위치 조언이 값을 하는 구간이다.**
> **틀린 대리값을 넣으면 그 구간의 조언이 틀린다.**

### 6-2 동점 재현이 replay 정확도의 절반이다

회차의 **48.221%** 에서 tie-break 가 결과를 정한다.
**반사실은 대부분 동점 경계에서 갈리므로, 여기가 틀리면 반사실만 골라서 틀린다.**

### 6-3 첫 VoI 는 이미 정해져 있다

```
상한 = 최종 N 을 알았을 때의 낙찰률
실전 = N(T−1h) 로 고른 x 의 낙찰률
차이 = "N 을 모르는 값"
```
**화면이 "지금 N=8 이니 이쪽" 이라고 말할 자격이 있는지가 여기서 정해진다.**

**대조군 둘을 반드시 같이 돌린다** — 음성(난수 20개, VoI=0 이어야) ·
양성(`DRAW_NO`, 예측력 85.6% 인데 결정 가치 ≤0.3 bp). **양성이 난수보다 강한 시험이다.**

**실패 판정**
- 정책 차이의 신뢰구간이 0 을 넘으면 → **그 재료의 VoI 는 "결론 없음"**
- **대조군 둘 중 하나라도 어긋나면 → VoI 계산이 틀렸다. 실험 중단**

실측 리샘플   필터 끄면 D = +0.007 bp   켜면 음수
```
**투찰 분포를 어떻게 넣든 필터를 끄면 `D ≈ 0`, 켜면 음수다.**

> **⟹ 콜라이더 인과 구조 자체는 투찰 분포 가정과 무관하게 선다. 크기만 식별이 안 된다.**
> **판정("투찰자는 가격을 못 본다")은 크기가 아니라 구조에 걸려 있으므로 영향받지 않는다.**

### 🔴 식별을 푸는 데 필요한 것은 정확히 하나다

```
P(007 | N)   —  N 구간별 유찰률
```
그게 있으면 선택 강도가 `N` 별로 고정되고, **실측 `x` 에서 선택을 되돌려 무조건부 투찰
분포를 복원할 수 있다.** 그러면 ④가 판정 가능해진다.

### ✅ 왔다 — `P(007|N)` 실측. ④가 다시 열린다

```
N=0   0.00%      N=2-4   93.17%      N=10-29  98.59%      N=100+  99.88%
N=1  11.55%      N=5-9   97.28%      N=30-99  99.26%
```
🔴 **선택은 거의 전부 `N=1` 현상이다. `N≥5` 면 3% 미만이다.**

**⟹ 선택 강도가 `N` 별로 고정됐으므로 실측 `x` 에서 선택을 되돌릴 수 있다.**
**④가 "판정 불가"에서 "판정 가능"으로 바뀐다.**

⚠ **다만 `N=1` 은 11.55% 생존자라 복원 배율이 8.7배다.** 거기서는
**복원 자체의 분산이 커서 결과를 그대로 못 믿는다.** `N=1` 은 계속 분리해 둔다 —
**T1 층 제외 · SBC 제외 · 순열 귀무 제외에 이어 네 번째 같은 제외다.**

### 3-2 인자는 한 벌이다

**M1·M2·M4·M5 가 같은 인자 집합을 쓴다.** 다르면 비교가 성립하지 않는다.

🔴 **`N(T−1h)` 과 `N×x` 상호작용은 넷 전부에 들어간다.** 어느 하나가 빠지면 비교가 무효다 —
뒤집힘이 곧 `N×x` 상호작용이므로, 그걸 못 받는 모형은 **설계상 질 수밖에 없다.**

### 3-3 분할은 시간 기준 하나로 고정

```
학습 2023-09 ~ 2025-12   ·   평가 2026-01 ~ 2026-08
```
**무작위 분할 금지.** 그리고 **모든 max 기반 숫자는 평가기간에서만 보고한다**(설계 §8-A G1).

### 3-4 예산을 미리 정한다

방법마다 **탐색 횟수·시간 상한**을 적는다. 예산을 다 쓰고도 안 되면 그게 결과다.

## §4 순서와 정지 조건

```
0. 누출 검사기                             ← 이게 없으면 아래 전부 무효
   🔴 사양 확장: "값이 마감 후에 생겼나" + "그 시점 아카이브만으로 재구성 가능한가"
                                             (가용성 누출 — 시각이 아니라 가용성)
1. ✅ R 분포 — 끝났다                       파라미터 0개로 확정. 정지 조건 통과
2. ✅ 합성 생성기 — 완성                    ①②③⑤⑥ 통과 · ④ 판정 불가(식별)
3. ✅ as-of N(T−1h) — 끝났다                VoI 0.153%p (상한의 0.9%). 아래 참조
4. M3 계층 모형                            ← 결과와 무관하게 화면에 쓰인다
5. M1 구조 모형                            ← 주력. 잔차 출처가 X 하나로 좁혀져 있다
6. M4 판별 모델                            ← M1 의 대조군 · VoI 산출
7. M2 분위 회귀 (N 조건부)                 ← 화면의 구간
8. M6 정책 비교                            ← VoI 확정
9. M5 신경망                               ← §2-M5 의 네 조건을 충족할 때만

⚠ **L1(SBC) 은 5번 M1 직후에 붙는다.** 생성기가 입력, M1 의 추정기가 대상이다.
**M1 없이 SBC 를 돌릴 수 없다.**
```

**개정 1의 1번(R 분포 대조)이 정지 조건이었고, 통과했다.** 관측 분포와 유도가 3.8% 안에서
맞고 분해가 닫힌다. **그 위의 모형들이 틀린 전제에 서 있지 않다.**

**새 정지 조건은 2번이다.** 생성기가 관측 필터를 켜고도 `mean(D)` 를 재현 못 하면
**우리 인과 이해에 아직 빠진 게 있다는 뜻이고, 그걸 모른 채 M1 을 세우면 안 된다.**

### 4-1 ✅ as-of `N` 의 첫 VoI — 끝났고, 방법 하나를 죽였다

학습 2023~2025 (171,730) / 평가 2026 (61,392). **시간 분할. in-sample 숫자 없음.**

| 2026 평가 | 낙찰률 |
|---|---|
| ① 상한 — 최종 `N` 을 앎 | **17.712%** |
| ② 실전 — `N(T−1h)` | **17.559%** |
| ③ 기준선 — 고정 `x = 1.0080` | 16.616% |

```
VoI = ① − ②  =  +0.153 %p   (상한의 0.9%)     ← N 을 모르는 값
      ② − ③  =  +0.943 %p   (상대 5.7%)       ← N 으로 x 를 고르는 값
```

🔴 **⟹ `N` 예측 모델을 만들지 않는다.** `T−1h` 에 **버킷이 94.2% 맞는다.** 관측으로 충분하다.
**계획에서 방법 하나가 사라졌고, 그건 재서 죽인 것이다.**

🔴 **⟹ 그리고 화면이 `N` 을 말할 자격이 섰다.** 고정 x 보다 상대 5.7% 낫다.

**손실은 `N=5-9` 경계에만 몰린다**(0.44%p). 나머지 버킷은 0.00~0.16%p.
⚠ **이게 `ml-expert` 의 우려("뒤집힘 근처에서 N 오차의 손실이 비대칭적으로 커진다")에 대한
답이다 — 방향은 맞았고 크기는 0.44%p 다.** 화면에 불확실성을 표시할 자리는 거기 하나다.

**화면 문구 근거:** 정확 일치는 50.4% 뿐이지만 **최종/as-of 비의 중앙이 전 버킷 1.00~1.03**
이라 편향이 없다. **"지금 8명, 최종은 대개 5~9명"** 을 띄울 수 있다.

## §5 안 쓰는 방법과 이유 — 나중에 다시 안 묻게

| | 왜 안 쓰나 | 다시 여는 조건 |

| 협업 필터링 | 업체×학교 행렬이 극도로 희소하고, 답할 질문이 추천이 아니다 | 헌법 1번이 바뀌면 |
