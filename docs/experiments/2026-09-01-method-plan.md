> **개정 1은 "미지수가 셋"이라고 적었다. 지금은 하나다.**
> 메커니즘을 전수로 닫으면서 `R` 은 파라미터 0개가 됐고 `N` 은 as-of 로 관측 가능해졌다.

## §0 이 문서가 막으려는 것

지난 시도들은 **값만 넣어 보고 "안 되네" 하고 넘어갔다.** 그러면 남는 게 없다:

> **"안 됐다"가 셋 중 무엇인지 안 갈린다.**
> ① 방법이 이 문제에 안 맞는다 ② 우리가 잘못 구현했다 ③ 데이터가 모자란다

### 0-A 이 규율은 이미 값을 했다 — 메커니즘 조사에서 실물로

같은 가설을 세 번 검정했고 **매번 귀무를 더 정확하게 만들었고 매번 답이 바뀌었다:**

```
L1  "선택 4개 = 균등 부분집합"                    z=−12.96 기각
    ↳ 그런데 이 귀무는 애초에 참일 수 없다 (투표가 쏠려 있다). 기각해도 아무 말이 아니다
L2  "선택 슬롯집합 ⊥ 슬롯→가격 배정"               순열로 z=−10.54 기각
    ↳ 그런데 코퍼스가 007 낙찰 전수다. R 이 낮은 회차가 살아남는다
L3  L2 + "mean(뽑힌 4개) ≤ xmax 를 통과해야 관측"   기각 못 함 → 판정
```

**만약 L1 에서 멈췄으면 "투찰자가 가격을 본다"는 결론을 냈을 것이고, 그건 틀렸다.**
그리고 그 결론 위에 세운 경쟁자 행동 모형이 전부 틀렸을 것이다.

> **⟹ 방법이 "안 맞는다"고 말하기 전에, 귀무가 애초에 참일 수 있는 것이었는지 먼저 본다.**

### 0-B 규율 다섯

1. **합성 데이터로 구현을 먼저 검증한다.** 답을 아는 축소 문제를 만들어 그걸 맞추는지 본다.
   **못 맞추면 구현 실패다 — 실데이터로 안 넘어간다.**
2. **인자 목록을 먼저 확정한다.** 돌려 보고 추가하지 않는다.
3. **각 방법에 "이러면 이 방법은 아니다" 를 미리 쓴다.**
4. 🔴 **검정력을 항상 같이 보고한다. 표본으로 못 본 것을 "없다"로 적지 않는다.**
5. 🔴 **주장의 모양과 검정의 모양을 맞춘다. 모먼트 일치는 검정이 아니다.**

**4·5 는 새로 추가됐다.** 메커니즘 조사에서 팀이 **같은 실수를 여섯 번** 했기 때문이다 —
sd 만 보고 구조 선언 · 주변분포만 보고 결합 구조 놓침 · 옴니버스로 단조 기울기 가림 ·
집계로 분포 가림 · 공허참(기각 불가능한 검정) · 산포를 귀무 산포와 대조 안 함.
**전부 "검정의 모양이 주장의 모양과 안 맞았다"였다.** 자세한 것은 설계 문서 §8-C.

## §1 문제의 구조 — 미지수가 하나로 줄었다

```
낙찰 ⟺ x ≥ R  그리고  R ≤ xⱼ < x 인 경쟁자 j 가 없음

x = 내 투찰금액 / (기초가 × 하한율/100)      ← 내가 고르는 유일한 값
R = 예정가 / 기초가                          ← 복수예가 15개 중 4개 추첨 평균
xⱼ = 경쟁자 j 의 같은 값                     ← 내가 못 봄
```

**분류 문제가 아니다.** 결과는 **두 확률변수의 순서**로 정해진다.

### 1-1 개정 1의 "미지수 셋" 이 하나로 줄었다

| | 개정 1 | **개정 2** |
|---|---|---|
| **`R` 분포** | 관측됨. 경험분포 + 유도 대조 | ✅ **파라미터 0개.** 규칙이 전수로 확정됐다 |
| **경쟁자 수 `N`** | 투찰 시점 특징으로 **추정해야 함** | ✅ **as-of 관측 가능.** T−1h 에 중앙 99.3% |
| **경쟁자 위치 `X`** | 개찰 후 관측 | 🔴 **유일한 진짜 미지수** |

**`R` 이 유도로 확정된 것의 값어치는 정확도가 아니라 진단이다:**
> `P(x ≥ R)` 이 해석적으로 나오므로 **잔차의 출처가 `X` 하나로 좁혀진다.**
> M1 이 틀리면 **어디가 틀렸는지 바로 안다.**

### 1-2 확정된 `R` 의 규칙

```
후보 15개   구간 배분은 고정(아래 8 · 위 7), 각 구간 안에서 iid
            아래 8개 ~ U(0.97, 1.00)   ·   위 7개 ~ U(1.00, 1.03)
            → 15개를 무작위 순열로 슬롯 1..15 에 배정
   🔴 15개를 U(0.97,1.03) 에서 통째로 iid 로 뽑지 마라 — sd(mean r) 2.06배
   🔴 15구간 계통추출도 아니다 — 0.14배
표          철회자 포함 전원 2표  (회차의 52.67% 에 철회자가 있다)
선택        득표 상위 4 · 동점은 낮은 번호 우선(93.4%, 회차의 48.221%)
            · 무득표 슬롯은 서버가 채움(2.742%, 슬롯 번호만 보고 가격은 안 봄)
분포        sd 0.007605   N 과 무관   연도별 안정
            mean  🔴 007 전수 실측 0.998867 (−11.3 bp) 은 콜라이더가 섞인 값이다
                  사장이 마주하는 무조건부 값은 해석적으로 −10.0 bp (설계 §2-5)
층화축      하한율 (90 → α 3.0% 상수 · 88 → 2.87%, 숨은 축 하나 더 있음)
```

🔴 **`R` 을 `ELCTRN_BID_PLNPRC / BGNG_PRC` 로 만들지 마라 — 90 행이 통째로 깨져 있고
sd 를 2.8 배로 부풀린다. `mean(CHC_YN='Y' 4개)` 를 써라.**

### 1-3 🔴 `f_R` 은 리샘플하지 않는다 — `α` 하나짜리 모수족이다

규칙이 확정됐으므로 `f_R` 은 **`α` 만 정해지면 완전히 결정된다:**
```
후보 = 아래 8개 iid U(1−α, 1)  +  위 7개 iid U(1, 1+α)
R    = 그중 4개 평균
  → f_R(·|α) 를 α 격자(2.0~3.1%, 0.05% 간격)에 미리 계산해 두면 끝
```
**화면의 문제가 "`f_R` 을 어떻게 만드나"에서 "이 회차의 `α` 가 얼마인가" 하나로 줄어든다.**

리샘플보다 나은 이유 셋: **표본잡음 0**(하한율 84 는 n=1,995 라 리샘플이 거칠다) ·
**as-of 가 깨끗**(과거 후보값을 안 만지고 공고 특징만 쓴다) ·
**꼬리가 정확**(리샘플은 꼬리를 못 채우는데 `f_R` 꼬리가 위치 계산에 중요하다).

**전 기간을 쓴다.** `α` 는 규칙 모수지 행동이 아니다. **대신 `α` 월별 관리도를 붙인다** —
`bid_id` 가 `E230919-…` 형식이라 연월이 거기 들어 있다. 제도가 바뀌면 그때 재적합.

**`α` 는 이봉이고, 하한율이 가른다:**
```
저모드 ±2.14%   회차의  8.55%       고모드 ±3.07%   회차의 91.45%      골은 2.00~2.05%
저모드 비율:  하한율 84.245 → 37.22%   ·   88 → 16.66%   ·   90 → 3.56%      10배 차이
```
❌ **발주기관은 층이 아니다** (50회차↑ 1,826곳에서 between/within = **0.795**).
❌ **품목도 아니다** (8원자 전부 2.44~2.64%).
⚠ **연월은 추세가 있다** — 2023-09 6.5% → 2025-04 15.7% → 2026-08 4.27%.
**안정된 층이 아니라 움직이는 설정이다.** 층으로 쓰지 말고 관리도로 감시한다.

## §2 방법 가족

### M1. 구조 모형 (mechanism-based) — **주력**

**왜 이 문제에 맞나**
구조가 알려져 있고 **`R` 이 파라미터 0개다.** 미지수를 하나로 줄인다.

**추정 대상**
```
X | 회차특징     경쟁자 위치 분포 (하한 대비 x 의 분포)      ← 유일한 미지수
N | as-of        T−1h 관측값 + 잔여 도착 보정               ← 추정이 아니라 보정
```
**낙찰 확률 = P(x ≥ R) × P(경쟁자 최소 x 가 [R, x) 밖)**
— 앞 항은 **해석적**, 뒤 항만 `X` 에 의존한다.

**인자 (투찰 시점에 아는 것만)**
```
공고     기초가 · 하한율 · 품목(다품목 여부 포함) · 단가/총액 · 계약형태
         투찰기간 길이 · 마감 요일/시각 · 재입찰 여부 · 지역제한 폭
학교     as-of 절단 과거 회차 수 · 과거 참여자 수 분포 · 과거 낙찰 x 분포
지역     시군구 · 시도 · 해당 시군구의 최근 경쟁 밀도
시기     연 · 월 · 학기 · 방학 여부
경쟁     🔴 N(T−1h)  ← 새로 들어왔다. 개정 1은 이걸 누출로 분류했다
```
⚠ **개찰 후 값 금지** — 이 회차의 최종 참여자 수·낙찰가·예정가·순위·`CHC_YN`·`DRAW_NO`.

**측정**
`P(낙찰)` 의 **보정(calibration)** 이 1차 지표. 맞추는 것보다 **정직한 확률**이 먼저다.

**실패 판정 — 이러면 M1 은 아니다**
- 합성에서 **알려진 `X` 를 복원 못 하면** → 구현 실패. 실데이터로 안 감
- 보정 곡선이 대각선에서 크게 벗어나면 → **구조 가정이 틀렸다.** 그런데 `R` 은 확정이므로
  **틀린 곳은 `X` 다** — 개정 1보다 진단이 훨씬 좁다
- **M4 에 크게 지면** → `X` 모형이 못 잡는 신호가 있다

### M2. 분위 회귀 — **화면에 가장 가까움**

**왜**
사장이 실제로 묻는 건 *"얼마를 넣어야 하나"* 이고, 그건 **낙찰선의 조건부 분위**다.
지금 화면의 `잘 나온 구간` 이 이것의 조잡한 버전이다.

**대상** `Y3 = 그 회차 낙찰 x` 의 조건부 분위 (10·25·50·75·90%)

**인자** M1 과 동일

🔴 **`N` 을 반드시 조건에 넣는다.** 전수로 재니 **최적 x 가 N 에 따라 뒤집힌다.**
N 을 빼면 두 반대 체제를 평균 내서 **아무에게도 안 맞는 구간**이 나온다.

🔴 **그리고 `N(T−1h)` 에 직접 조건화한다. 최종 `N` 을 추정해서 대입하지 않는다.**
```
❌  g(·|N_final = n) 을 추정  →  그 n 자리에 N(T−1h) 를 대입
✅  g(·|N(T−1h) = n) 을 과거 회차의 「최종 투찰 분포」에서 직접 추정
```
**✅ 쪽은 최종 N 의 사후분포로 이미 적분돼 있다** — 과거에 `N(T−1h)=n` 이었던 회차들이
각자 다른 최종 N 으로 끝났고 그 평균이 곧 적분이다. **명시적 적분을 코딩할 필요가 없다.**

**❌ 쪽 오차를 쟀다.** `P ≈ f_R/(N·g)` 라 Jensen 부등식(`E[1/N] > 1/E[N]`)이 걸린다:
```
N(T−1h)=5  → 최종 평균 9    승률 −49.5%
N(T−1h)=10 → 최종 평균 18   승률 −58.5%
N(T−1h)=80 → 최종 평균 144  승률  −8.5%
```
**저경쟁 회차에서 승률을 절반 가까이 과소평가한다. 우리가 쫓던 어떤 효과보다 크고
고치는 비용이 0이다.**
⚠ 다만 편향이 x 에 대해 대체로 곱셈 상수라 **뒤집힘이라는 정성적 결론은 견고하고,
보고되는 승률 수치가 아니다.**

**측정** pinball loss · 구간 커버리지(80% 구간이 실제로 80%를 덮나)

**실패 판정**
- 구간 커버리지가 명목치에서 크게 벗어나면 → **화면에 구간을 못 놓는다**
- **`N` 조건부 분위가 `N` 무조건 분위와 다르지 않으면** → 위 뒤집힘이 재현 안 되는 것이고,
  그건 **분위 회귀 구현이 틀렸다는 뜻이다** (뒤집힘은 이미 전수로 확인됐다)

### M3. 계층 모형 — **`n=1` 문제의 정석 해법**

**왜**
지금 화면이 `1회 중 100%` 같은 구간을 보여준다. **틀린 값은 아니지만 거짓 확신을 준다.**
계층 모형은 **표본이 적은 학교를 전체 평균 쪽으로 자동으로 끌어당긴다.**

**구조** 학교 ⊂ 시군구 ⊂ 시도, 그리고 품목 축

**측정** 표본이 적은 학교에서 **예측 오차가 단순 평균보다 줄어드는가**

**실패 판정**
- shrinkage 후에도 `n` 이 적은 구간의 오차가 안 줄면 → 계층 구조가 잘못 잡혔다
- 모든 학교가 사실상 같으면 → **학교별 재료를 화면에 놓을 이유가 없다.** 이것도 결과다

⚠ **M3 은 결과와 무관하게 화면에 쓰인다.** 표본이 적은 값을 어떻게 보여줄지가
지금 화면의 실제 결함이고, 이 방법이 그 답을 준다.

### M4. 판별 모델 (GBDT) — **상한 재기용**

**왜** 구조를 안 쓰고 낼 수 있는 최대 성능. **M1 의 대조군이다.**

**인자** M1 과 동일 — **반드시 같아야 대조가 성립한다**

**측정** M1 과 같은 지표. 그리고 **재료 절제·VoI(설계 문서 E2)를 여기서 낸다**

**실패 판정**
- **B1(학교 과거 중앙값)과 B2n(같은 N 구간의 최적 x)을 둘 다 못 이기면**
  → **인자에 신호가 없다.** 화면을 바꿀 근거 없음

⚠ **B2n 이 새 기준선이다.** 규칙 한 줄(`N` 보고 표에서 x 고르기)로 얼마나 되는지가
모델의 값어치를 정한다. **M4 가 B2n 을 못 이기면 모델이 아니라 표를 화면에 놓는다.**

### M5. 신경망 — **여는 조건이 좁아졌다**

**왜 기본이 아닌가**
표 형태 데이터에서 GBDT 를 이기기 어렵다는 게 정설이고, 우리 문제는 구조가 알려져 있다.

> **⚠ "안 되네" 하고 넘어갔던 게 아마 여기다. 이번엔 조건을 미리 정한다.**

🔴 **그리고 개정 1 이후 근거가 넓어진 게 아니라 좁아졌다.**
- `R` 예측이 빠졌다 (파라미터 0개)
- `N` 예측이 빠졌다 (as-of 관측)
- 분기점의 뒤집힘이 **`N` 하나로 설명된다** — `g` 의 모양에서 나오는 구조적 현상이다
- **남은 자리는 `X | z` 하나이고, 거기서도 GBDT 와 겨뤄야 한다**

**여는 조건 (넷 다 충족해야 시작)**
1. **M4 가 B1 과 B2n 을 둘 다 유의미하게 이긴다**
2. **M4 의 상호작용 진단에서 고차 상호작용이 검출된다**
3. **M1 과 M4 의 차이가 설명 안 된다**
4. 🔴 **그 차이가 `N` 조건부화로 사라지지 않는다** — 새 조건. 뒤집힘이 `N` 으로 설명되므로,
   `N` 을 넣은 뒤에도 남는 비선형이어야 신경망의 자리다

**넷 중 하나라도 안 되면 M5 를 안 만든다. 그 사실을 결과로 적는다.**

**실패 판정**
- 같은 인자·같은 분할·같은 예산에서 M4 를 못 이기면 → **이 문제에 신경망은 아니다.** 닫는다
- 이기는데 보정이 나쁘면 → 화면엔 못 쓴다

⚠ **하이퍼파라미터 탐색 예산을 M4 와 같게 준다.** 안 그러면 "덜 튜닝해서 진 것"과
"방법이 안 맞는 것"이 안 갈린다.

### M6. 정책 비교 (replay) — **VoI 의 근거. 그리고 이제 추정이 아니라 계산이다**

**왜**
설계 문서의 중심 지표가 VoI 인데, VoI 는 *"이 값을 알면 행동이 달라지고 결과가 나아지나"* 다.

### 🔴 6-1 off-policy evaluation 이 아니다

경쟁자 `DRAW_NO` 전원과 `ds_pList` 금액과 경쟁자 `x` 전량(9,667,069)을 **관측한다.**
그래서 반사실이 **추정되는 게 아니라 계산된다:**

```
내 투찰을 x 로 옮긴다  →  x ≥ R 이고 [R, x) 에 경쟁자 없음 을 다시 판정
내 표를 c 로 바꾼다    →  득표 재집계 → 동점 낮은 번호 우선 → R 을 다시 계산
```
**가정 0, 근사 0.** 중요도 가중도, 성향점수도, 신뢰구간 확장도 필요 없다.

**⟹ 행동 공간을 `x` 에서 `(x, 표)` 로 넓힌다.** 안 그러면 지금 replay 가 틀린 `R` 을 쓴다.

⚠ **표 축은 정확도를 위해 필요하지 레버로는 아니다.** 전수 측정 결과 **표 레버는 검출
한계 아래다**(0.298 bp < 영분포 0.367). **화면에 표 추천을 올리지 않는다.**

### 6-2 동점 재현이 replay 정확도의 절반이다

회차의 **48.221%** 에서 tie-break 가 결과를 정한다.
**반사실은 대부분 동점 경계에서 갈리므로, 여기가 틀리면 반사실만 골라서 틀린다.**

### 6-3 첫 VoI 는 이미 정해져 있다

```
상한 = 최종 N 을 알았을 때의 낙찰률
실전 = N(T−1h) 로 고른 x 의 낙찰률
차이 = "N 을 모르는 값"
```
**화면이 "지금 N=8 이니 이쪽" 이라고 말할 자격이 있는지가 여기서 정해진다.**

**대조군 둘을 반드시 같이 돌린다** — 음성(난수 20개, VoI=0 이어야) ·
양성(`DRAW_NO`, 예측력 85.6% 인데 결정 가치 ≤0.3 bp). **양성이 난수보다 강한 시험이다.**

**실패 판정**
- 정책 차이의 신뢰구간이 0 을 넘으면 → **그 재료의 VoI 는 "결론 없음"**
- **대조군 둘 중 하나라도 어긋나면 → VoI 계산이 틀렸다. 실험 중단**

## §4 순서와 정지 조건

```
0. 누출 검사기                             ← 이게 없으면 아래 전부 무효
   🔴 사양 확장: "값이 마감 후에 생겼나" + "그 시점 아카이브만으로 재구성 가능한가"
                                             (가용성 누출 — 시각이 아니라 가용성)
1. ✅ R 분포 — 끝났다                       파라미터 0개로 확정. 정지 조건 통과
2. 합성 생성기 + L1(SBC)                   ← §3-1. 통과 기준 ①이 핵심
3. ✅ as-of N(T−1h) — 끝났다                VoI 0.153%p (상한의 0.9%). 아래 참조
4. M3 계층 모형                            ← 결과와 무관하게 화면에 쓰인다
5. M1 구조 모형                            ← 주력. 잔차 출처가 X 하나로 좁혀져 있다
6. M4 판별 모델                            ← M1 의 대조군 · VoI 산출
7. M2 분위 회귀 (N 조건부)                 ← 화면의 구간
8. M6 정책 비교                            ← VoI 확정
9. M5 신경망                               ← §2-M5 의 네 조건을 충족할 때만
```

**개정 1의 1번(R 분포 대조)이 정지 조건이었고, 통과했다.** 관측 분포와 유도가 3.8% 안에서
맞고 분해가 닫힌다. **그 위의 모형들이 틀린 전제에 서 있지 않다.**

**새 정지 조건은 2번이다.** 생성기가 관측 필터를 켜고도 `mean(D)` 를 재현 못 하면
**우리 인과 이해에 아직 빠진 게 있다는 뜻이고, 그걸 모른 채 M1 을 세우면 안 된다.**

### 4-1 ✅ as-of `N` 의 첫 VoI — 끝났고, 방법 하나를 죽였다

학습 2023~2025 (171,730) / 평가 2026 (61,392). **시간 분할. in-sample 숫자 없음.**

| 2026 평가 | 낙찰률 |
|---|---|
| ① 상한 — 최종 `N` 을 앎 | **17.712%** |
| ② 실전 — `N(T−1h)` | **17.559%** |
| ③ 기준선 — 고정 `x = 1.0080` | 16.616% |

```
VoI = ① − ②  =  +0.153 %p   (상한의 0.9%)     ← N 을 모르는 값
      ② − ③  =  +0.943 %p   (상대 5.7%)       ← N 으로 x 를 고르는 값
```

🔴 **⟹ `N` 예측 모델을 만들지 않는다.** `T−1h` 에 **버킷이 94.2% 맞는다.** 관측으로 충분하다.
**계획에서 방법 하나가 사라졌고, 그건 재서 죽인 것이다.**

🔴 **⟹ 그리고 화면이 `N` 을 말할 자격이 섰다.** 고정 x 보다 상대 5.7% 낫다.

**손실은 `N=5-9` 경계에만 몰린다**(0.44%p). 나머지 버킷은 0.00~0.16%p.
⚠ **이게 `ml-expert` 의 우려("뒤집힘 근처에서 N 오차의 손실이 비대칭적으로 커진다")에 대한
답이다 — 방향은 맞았고 크기는 0.44%p 다.** 화면에 불확실성을 표시할 자리는 거기 하나다.

**화면 문구 근거:** 정확 일치는 50.4% 뿐이지만 **최종/as-of 비의 중앙이 전 버킷 1.00~1.03**
이라 편향이 없다. **"지금 8명, 최종은 대개 5~9명"** 을 띄울 수 있다.
