# 방법론 계획 — 무엇을, 어떤 인자로, 어떻게 잴 것인가

**2026-09-01 · 상태: 계획 (구현 전) · 짝 문서: `2026-09-01-material-value-design.md`**

---

## 0. 이 문서가 막으려는 것

지난 시도들은 **값만 넣어 보고 "안 되네" 하고 넘어갔다.** 그러면 남는 게 없다:

> **"안 됐다"가 셋 중 무엇인지 안 갈린다.**
> ① 방법이 이 문제에 안 맞는다 ② 우리가 잘못 구현했다 ③ 데이터가 모자란다

**셋을 가르는 장치를 방법마다 미리 붙인다.** 그리고 **구현 전에 정한다.**
만들면서 정하면 결과를 보고 기준을 움직이게 된다.

### 규율 셋

1. **합성 데이터로 구현을 먼저 검증한다.** 답을 아는 축소 문제를 만들어 그걸 맞추는지 본다.
   **못 맞추면 구현 실패다 — 실데이터로 안 넘어간다.**
2. **인자 목록을 먼저 확정한다.** 돌려 보고 추가하지 않는다. 추가하려면 왜인지 적고 다시 돌린다.
3. **각 방법에 "이러면 이 방법은 아니다" 를 미리 쓴다.**

## 1. 문제의 구조 — 이것이 방법 선택을 결정한다

```
낙찰 ⟺ x ≥ R  그리고  R ≤ xⱼ < x 인 경쟁자 j 가 없음

x = 내 투찰금액 / (기초가 × 하한율/100)      ← 내가 고르는 유일한 값
R = 예정가 / 기초가                          ← 복수예가 15개 중 4개 추첨 평균
xⱼ = 경쟁자 j 의 같은 값                     ← 내가 못 봄
```

**분류 문제가 아니다.** 결과는 **두 확률변수(R, 경쟁자 최소값)의 순서**로 정해진다.

### 🔴 그리고 R 은 관측된다 — 가정하지 않아도 된다

`ds_pList` 에 후보 예비가격 15개와 `CHC_YN`(추첨 여부)이 회차마다 들어 있다.
**추첨 결과가 원본에 있다.** 그래서:

- R 의 분포를 **경험적으로** 추정할 수 있고
- 추첨 메커니즘에서 **해석적으로** 유도한 것과 **대조**할 수 있다
- **둘이 다르면 우리가 메커니즘을 잘못 안 것이다** — 그 자체가 발견

**이게 이 문제의 가장 강한 지렛대이고, 일반 분류기는 이걸 못 쓴다.**

### 미지수는 셋뿐이다

| | 아는가 | 어떻게 |
|---|---|---|
| **R 분포** | ✅ 관측됨 | 경험 분포 + 해석적 유도 대조 |
| **경쟁자 수** | ⚠ 개찰 후 관측 | **투찰 시점 특징으로 추정해야 함** |
| **경쟁자 위치 분포** | ⚠ 개찰 후 관측 | 같음 |

**→ 우리가 추정할 게 둘뿐이다.** 나머지는 구조가 준다.
**표본 효율이 일반 모델보다 훨씬 높다.**

## 2. 방법 가족 — 각각 왜, 무엇으로, 어떻게

### M1. 구조 모형 (mechanism-based) — **주력**

**왜 이 문제에 맞나**
구조가 알려져 있고 R 이 관측된다. 미지수를 둘로 줄인다.

**추정 대상**
```
N | 회차특징     경쟁자 수 분포
X | 회차특징     경쟁자 위치 분포 (하한 대비 x 의 분포)
```
**낙찰 확률 = P(x ≥ R) × P(경쟁자 최소 x 가 [R, x) 밖)** — 합성으로 계산.

**인자 (투찰 시점에 아는 것만)**
```
공고     기초가 · 하한율 · 품목(다품목 여부 포함) · 단가/총액 · 계약형태
         투찰기간 길이 · 마감 요일/시각 · 재입찰 여부 · 지역제한 폭
학교     as-of 절단 과거 회차 수 · 과거 참여자 수 분포 · 과거 낙찰 x 분포
지역     시군구 · 시도 · 해당 시군구의 최근 경쟁 밀도
시기     연 · 월 · 학기 · 방학 여부
```
⚠ **개찰 후 값 금지** — 이 회차의 참여자 수·낙찰가·예정가·순위.

**측정**
`P(낙찰)` 의 **보정(calibration)** 이 1차 지표. 맞추는 것보다 **정직한 확률**이 먼저다.
(화면에 확률을 놓으려면 보정이 전제다.)

**실패 판정 — 이러면 M1 은 아니다**
- 합성 데이터에서 **알려진 파라미터를 복원 못 하면** → 구현 실패. 실데이터로 안 감
- 실데이터 보정 곡선이 **대각선에서 크게 벗어나면** → 구조 가정이 틀렸다
- **M4(판별 모델)에 크게 지면** → 구조에 없는 신호가 있다. 그게 무엇인지 찾는 게 다음 일

**구현 검증 (합성)**
알려진 N·X·R 로 회차를 생성 → M1 이 그 파라미터를 복원하는가.

---

### M2. 분위 회귀 (quantile regression) — **화면에 가장 가까움**

**왜**
사장이 실제로 묻는 건 *"얼마를 넣어야 하나"* 이고, 그건 **낙찰선의 조건부 분위**다.
지금 화면의 `잘 나온 구간` 이 이것의 조잡한 버전이다 — **같은 것을 제대로 만든다.**

**대상** `Y3 = 그 회차 낙찰 x` 의 조건부 분위 (10·25·50·75·90%)

**인자** M1 과 동일

**측정** pinball loss · 구간 커버리지(80% 구간이 실제로 80%를 덮나)

**실패 판정**
- 구간 커버리지가 명목치에서 크게 벗어나면 → **화면에 구간을 못 놓는다**
- 조건부 분위가 무조건 분위와 다르지 않으면 → **인자가 아무것도 안 한다**

---

### M3. 계층 모형 (hierarchical / partial pooling) — **`n=1` 문제의 정석 해법**

**왜**
지금 화면이 `1회 중 100%` 같은 구간을 보여준다. **틀린 값은 아니지만 거짓 확신을 준다.**
계층 모형은 **표본이 적은 학교를 전체 평균 쪽으로 자동으로 끌어당긴다(shrinkage).**

**구조** 학교 ⊂ 시군구 ⊂ 시도, 그리고 품목 축

**측정** 표본이 적은 학교에서 **예측 오차가 단순 평균보다 줄어드는가**

**실패 판정**
- shrinkage 후에도 `n` 이 적은 구간의 오차가 안 줄면 → 계층 구조가 잘못 잡혔다
- 모든 학교가 사실상 같으면 → **학교별 재료를 화면에 놓을 이유가 없다.** 이것도 결과다

⚠ **M3 은 결과와 무관하게 화면에 쓰인다.** 표본이 적은 값을 어떻게 보여줄지가
지금 화면의 실제 결함이고, 이 방법이 그 답을 준다.

---

### M4. 판별 모델 (gradient boosting 등) — **상한 재기용**

**왜**
구조를 안 쓰고 낼 수 있는 최대 성능. **M1 의 대조군이다.**
M4 가 M1 을 크게 이기면 **우리 구조 이해에 빠진 게 있다는 신호.**

**인자** M1 과 동일 — **반드시 같아야 대조가 성립한다**

**측정** M1 과 같은 지표. 그리고 **재료 절제·VoI(설계 문서 E2)를 여기서 낸다**

**실패 판정**
- B1(학교 과거 중앙값)을 못 이기면 → **인자에 신호가 없다.** 화면을 바꿀 근거 없음

---

### M5. 신경망 — **조건을 만족할 때만 연다**

**왜 기본이 아닌가**
표본은 크지만(투찰 1,058만) **표 형태 데이터에서 GBDT 를 이기기 어렵다는 게 정설**이고,
우리 문제는 구조가 알려져 있어 구조 모형이 유리하다.

> **⚠ "안 되네" 하고 넘어갔던 게 아마 여기다. 이번엔 조건을 미리 정한다.**

**여는 조건 (셋 다 충족해야 시작)**
1. **M4 가 B1 을 유의미하게 이긴다** — 인자에 신호가 있음이 먼저 확인돼야 한다
2. **M4 의 상호작용 진단에서 고차 상호작용이 검출된다** — 신경망이 이길 여지가 거기 있다
3. **M1 과 M4 의 차이가 설명 안 된다** — 구조로 못 잡는 무언가가 있다

**셋 중 하나라도 안 되면 M5 를 안 만든다. 그 사실을 결과로 적는다.**

**실패 판정**
- 같은 인자·같은 분할에서 M4 를 못 이기면 → **이 문제에 신경망은 아니다.** 확정하고 닫는다
- 이기는데 보정이 나쁘면 → 화면엔 못 쓴다

⚠ **하이퍼파라미터 탐색 예산을 미리 정한다.** 안 그러면 "덜 튜닝해서 진 것"과
"방법이 안 맞는 것"이 안 갈린다. **M4 와 같은 예산을 준다.**

---

### M6. 인과·개입 관점 — **VoI 의 근거**

**왜**
설계 문서의 중심 지표가 VoI 인데, VoI 는 *"이 값을 알면 행동이 달라지고 결과가 나아지나"* 다.
**상관만으로는 못 답한다.**

**방법** 정책 비교 — 재료를 보는 정책 vs 안 보는 정책의 결과 차이를 과거 데이터로 평가

**실패 판정**
- 정책 차이의 신뢰구간이 0 을 넘으면 → **그 재료의 VoI 는 "결론 없음"**

## 3. 공통 규율

### 3-1. 합성 데이터 검증을 먼저 통과해야 실데이터를 준다

각 방법마다 **알려진 답이 있는 축소 문제**를 만든다.
**못 맞추면 구현 실패로 확정하고 실데이터로 안 넘어간다.**

> 이 단계가 없으면 "안 되네"가 영원히 셋 중 무엇인지 모른다.

### 3-2. 인자는 한 벌이다

**M1·M2·M4·M5 가 같은 인자 집합을 쓴다.** 다르면 비교가 성립하지 않는다.
인자를 바꾸면 **전부 다시 돌린다.**

### 3-3. 분할은 시간 기준 하나로 고정

```
학습 2023-09 ~ 2025-12   ·   평가 2026-01 ~ 2026-08
```
**무작위 분할 금지.** 같은 학교의 미래 회차가 학습에 들어간다.

### 3-4. 예산을 미리 정한다

방법마다 **탐색 횟수·시간 상한**을 적는다. 예산을 다 쓰고도 안 되면 그게 결과다.
**예산을 안 정하면 "더 해보면 될지도"가 영원히 남는다.**

## 4. 순서와 정지 조건

```
0. 누출 검사기                        ← 이게 없으면 아래 전부 무효
1. R 분포 (관측 + 해석 유도 대조)      ← 안 맞으면 여기서 멈추고 원인부터
2. M3 계층 모형                        ← 결과와 무관하게 화면에 쓰인다
3. M1 구조 모형                        ← 주력
4. M4 판별 모델                        ← M1 의 대조군 · VoI 산출
5. M2 분위 회귀                        ← 화면의 구간
6. M6 정책 비교                        ← VoI 확정
7. M5 신경망                           ← §2-M5 의 세 조건을 충족할 때만
```

**1번에서 멈출 수 있다.** R 이 우리가 아는 메커니즘과 다르면 그 위의 모든 모형이 틀린 전제 위에 선다.

## 5. 안 쓰는 방법과 이유 — 나중에 다시 안 묻게

| | 왜 안 쓰나 |
|---|---|
| 시계열 예측(ARIMA 등) | 회차가 시계열이 아니다. 학교·품목별 독립 사건에 가깝다 |
| 협업 필터링 | 업체×학교 행렬이 극도로 희소하고, 우리가 답할 질문이 추천이 아니다 |
| 강화학습 | 환경과 상호작용할 수 없다. 과거 로그만 있고 탐색이 불가능하다 |
| 딥러닝 표현학습 | 인자가 이미 구조화돼 있다. 학습할 표현이 뭔지 불분명하다 |

**⚠ 이 표는 "지금 안 쓴다"이지 "영원히"가 아니다.** 조건이 바뀌면 다시 연다 — 조건도 적어 둔다.
