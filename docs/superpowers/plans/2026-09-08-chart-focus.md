# 차트 크게보기 수정 — 2026-09-08

## 문제와 범위

기존 집중 배치는 1280×850 이상에서만 켜지고 과거 회차에 높이 34%를 배분한다.
실제 Chrome에서 1280×800 확대 상태의 차트는 304px, 문서는 1248px였다.
1422×889에서는 오히려 차트가 175px까지 줄었다. 버튼의 확대 의미와 실제 결과가 다르다.

사용자가 승인한 전체 폭·전역 우측 패널·같은 차트 유지 원칙을 적용한다.
현재 작업은 EAT-111 dev 통합 브랜치의 확대 동작 수정이며 API·DB·수집 실행은 바꾸지 않는다.

실제 34건 명단에서 전역 panel의 portal mount에 높이가 없어 문서가 2608px로 늘어나는 결함도 재현했다.
소유 경로에 `apps/web/src/shell/layout/workspace-layout.css`의 높이 전달 규칙을 포함한다.

## 동작 결정

- 크게보기는 같은 중앙 지면에서 차트가 남은 높이를 사용한다. 모달을 만들지 않는다.
- 현재 공고 제목과 필터는 남기고 상세 배너·요약 및 과거 회차 표는 접는다.
  표와 차트 DOM을 다시 만들지 않아 선택·확대 범위를 유지한다.
- 전역 공고/기록 패널은 기존 320px 공간과 좁은 화면 Sheet를 그대로 사용한다.
- 좁은 화면에서도 확대는 동작한다. 아주 낮은 창은 조작부·날짜축을 자르는 대신 최소 높이의 문서 스크롤을 허용한다.
- 작게보기·Escape로 돌아오면 조건과 회차 선택을 유지한다. 열린 메뉴/Sheet의 Escape 처리를 먼저 존중한다.
- 일반 보기의 페이지 이동, 확대 보기의 휠 날짜 확대를 구분한다.
