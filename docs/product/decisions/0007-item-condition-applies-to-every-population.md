# PDR-0007 — 품목 조건은 비교하는 모든 집단에 같게 적용한다

- Status: Active
- Date: 2026-09-18
- Supersedes: [PDR-0006](0006-institution-and-regional-analysis.md)
- Superseded-by: 없음
- Linear: EAT-176, EAT-216

## 결정

분석판의 품목 조건은 **비교하는 세 집단 전부**에 같게 적용한다. 기관의 낙찰점, 지역·전국의 관측
구름, 그리고 겹쳐 찍은 다른 기관의 점이 모두 같은 품목 조건을 쓴다. PDR-0006이 정한 "기관에만
품목 필터, 비교군은 전체 품목"을 대체한다.

PDR-0006의 나머지 판단은 **그대로 이어받는다.** 기관과 선택 eaT 공고지역/전국을 같은 기간·하한율·
낙찰방식·관측 명단 범위로 비교한다. 지역 전체는 대상 기관의 조건에 맞는 기록도 포함하며 겹침 수를
따로 낸다. 현재 공고 상세의 attempt는 양쪽에서 빼고 기관 상세에서는 빼지 않는다. 관측 명단은 네 밴드로
근사하지 않고 양끝 포함 최소/최대다. 기간은 KST 날짜 직접 입력과 프리셋이며 개찰일/공고일 기준을
구분한다. 추이·분포·전체 이력은 같은 관측 집합과 snapshot을 소비한다. 예측·추천은 하지 않는다.

품목은 여러 개를 고를 수 있고 `품목 미확인`도 **고를 수 있는 값**이다. 아무것도 고르지 않은 상태가
전체이며, 그때만 미확인이 함께 들어간다. `품목 미확인`은 그 회차에 품목 다리 행이 없다는 뜻이다.

**이것은 가장자리 사례가 아니라 3분의 1이다.** 2026-09-18 운영 실측에서 활성 빌드 929의 회차
320,039개 중 106,755개(33.4%)에 품목 다리 행이 없었고, 열린 공고 스냅샷도 33.0%로 같았다. 연도별로
2024년 34.0%·2025년 33.5%·2026년 32.9%라 백필 구간의 결손이 아니라 상시다. 원인은 우리 투영이
아니라 원천이다 — `item_label`이 비었는지와 다리 행이 없는지가 교차표에서 완전히 일치해, 품목
표시가 없는 공고에만 행이 없다. 같은 실측에서 `mart.build_vocabulary_gap`은 전 빌드 0행이었다.
우리가 받은 품목 문자열은 전부 어휘로 닫혔다는 뜻이므로, 미확인의 원인은 매핑 실패가 아니라
**공고가 품목을 말하지 않은 것**이다.

그래서 품목을 하나라도 고르면 비교군이 3분의 1 줄어든다. 이 감소를 조용히 두지 않는다 —
`품목 미확인`을 값으로 노출해 사용자가 포함 여부를 정하게 하고, 표본 수는 언제나 화면에 함께 낸다.

비교 지역은 전국·시도·시군구 중 **하나**다. 여러 지역을 동시에 비교하지 않는다.

겹쳐 찍는 기관은 최대 여섯 곳이며 비교조건이 아니라 표시 축이다. 고른 기관은 모집단을 바꾸지
않고 같은 그림 위에 점으로만 더해진다.

## 배경

2026-09-18 사용자가 "품목 필터 정할 수 있게 했잖아 전부 필터대로 동작하게 해 줄래 / 걍 전부
필터대로"라고 지시했다. PDR-0006의 되돌리기 조건이 **"품목 비교 자체가 사용자의 필수 질문으로
검증되면 별도 변경으로 비교군 품목 축을 검토한다"**였고, 이 지시가 그 검증이다.

PDR-0006이 비교군을 전체 품목으로 둔 이유는 "기관 품목을 지역 전체 분포에 견주어 보는 질문"을
지키기 위해서였다. 그 질문은 유효하지만, 지금 화면은 조건 막대가 `축산`이라고 말하면서 구름은
전체 품목을 그린다 — 화면이 말하는 것과 그리는 것이 다르다. 두 집단이 다른 질문에 답하고 있는데
사용자는 그것을 화면에서 알 수 없다. 조건을 비우면 언제든 예전 질문으로 돌아갈 수 있으므로,
기본을 "조건대로"에 두고 전체 비교는 조건을 비워서 얻는 쪽이 설명 가능하다.

## 대안과 기각 이유

- **기관에만 적용(PDR-0006 유지)**: 조건 막대가 말하는 조건과 그린 그림이 어긋난 채로 남는다.
  사용자가 직접 뒤집었다.
- **비교군만 따로 품목 축을 둔다(두 벌의 품목 조건)**: 조건이 두 배가 되고, 어느 쪽이 어느 집단에
  걸렸는지 조건 막대에서 읽을 수 없다. 화면의 1차 질문이 둘로 갈라진다.
- **미확인을 자동으로 포함**: 품목을 고른 사용자가 고르지 않은 것까지 받는다.
- **미확인을 자동으로 제외**: 표본이 조용히 준다. 얼마나 줄었는지도 화면이 말하지 않는다. `unknown`은
  유효한 상태이므로 값으로 고르게 한다(AGENTS 3).
- **여러 지역 동시 비교**: 구름이 겹쳐 어느 지역의 밀도인지 읽을 수 없다. 지역을 나란히 보려는
  질문은 화면을 나누는 문제이지 조건의 문제가 아니다.
- **고른 기관을 비교조건에 넣는다**: 기관을 고를 때마다 모집단이 바뀌어 표본 수가 흔들린다.
  사용자가 원한 것은 "그 점을 찍을 수 있게"이지 비교 대상을 바꾸는 것이 아니다.
- **기관을 여섯 곳 전부 진하게**: 시안 루프 실측에서 174개의 고리가 기관 점을 덮었다. 기본은 흐리게
  두고 하나를 집었을 때만 진해지며 번호 배지를 붙인다.

## 되돌리기 조건

`mart.build_vocabulary_gap`에 조각이 쌓이기 시작하면 미확인의 뜻이 바뀐다 — 그때부터는 "공고가 말
안 한 것"과 "우리가 못 읽은 것"이 한 값에 섞이므로 둘을 갈라야 한다. 지금은 0행이라 갈라 둘 이유가
없다.

원천이 품목을 주기 시작해 미확인 비율이 크게 떨어지면 `품목 미확인` 값 자체의 자리를 다시 본다.
반대로 비율이 더 오르면 품목 필터의 기본값을 다시 논의한다.

## 영향

공통 계약은 [상세 MVP 공통 분석 계약](../analysis-common-contracts.md)이 소유하며 품목 필터의
wire 형태와 적용 범위가 바뀐다. EAT-216의 시간축, EAT-217의 분포, EAT-218의 전체 이력이 같은 필터를
소비하므로 셋이 같은 회차 집합을 보게 된다.
