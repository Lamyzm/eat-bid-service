# PDR-0006 — 기관과 지역 전체를 같은 조건으로 비교한다

- Status: Active
- Date: 2026-09-14
- Supersedes: [PDR-0005](0005-cohort-axis-is-floor-rate-and-list-size.md)
- Superseded-by: 없음
- Linear: EAT-213, EAT-176

## 결정

기관과 선택 eaT 공고지역/전국을 같은 기간·하한율·낙찰방식·관측 명단 범위로 비교한다.
기관 쪽에만 검증된 품목 코드 필터를 제공하고 비교군은 전체 품목으로 유지한다.
관측 명단은 네 고정 밴드로 근사하지 않고 양끝 포함 최소/최대 조건을 지원한다.
기간은 KST 날짜 직접 입력과 프리셋이며 개찰일/공고일 기준을 구분한다.

지역 전체는 대상 기관의 조건에 맞는 기록도 포함한다. 현재 공고 상세의 attempt는 양쪽에서 제외하고
기관 상세에서는 제외하지 않는다. 추이·분포·전체 이력은 같은 관측 집합과 snapshot을 소비한다.
분포 MVP는 실제 건수·집단 내 비중이고 작은 표본도 관측으로 보여 준다. 예측·추천은 하지 않는다.

## 배경

2026-09-14 사용자가 지역 전체와 한 기관을 나란히 보고, 긴 보유 기간을 월 범위까지 좁히는 흐름을
확정했다. 기관 품목을 제한하는 것과 지역 전체의 분포를 품목별로 해석하는 것은 다른 사용자 질문이다.
PDR-0005의 하한율·명단 규모 구분 근거는 유지하되 기관에까지 품목 필터를 금지한 범위는 대체한다.
이 결정은 예측력이 새로 검증됐다는 뜻이 아니다. 과거 실측 수치를 현재 총량으로 재사용하지 않는다.

## 대안과 기각 이유

- 지역 비교에서 기관을 자동 제외: 사용자가 요청한 지역 전체의 뜻이 달라진다. 겹침 수를 따로 제공한다.
- 모든 품목 조건을 양쪽에 적용: 지역 전체를 기준으로 기관 품목을 보고자 하는 질문을 바꾼다.
- 명단 네 밴드 합산: 12~24명 같은 임의 입력을 정확히 재현하지 못한다.
- 모든 점을 클라이언트로 전송: 넓은 비교군은 전체 관측의 밀도로 제공하고 실제 점·원자료는 좁혀 조회한다.
- 동일 buildId 강제: 서로 다른 mart 정체성을 위조한다. 실제 입력 조합을 확인해야 한다.

## 되돌리기 조건

관측 정책을 맞췄는데도 추이·분포·이력의 회차 수가 다르면 공통 발급을 중단하고 집합 차이부터 조사한다.
품목 비교 자체가 사용자의 필수 질문으로 검증되면 별도 변경으로 비교군 품목 축을 검토한다.
서버가 정확한 명단/날짜 조건을 처리하지 못하면 조용히 근사하지 않고 미지원 상태를 제공한다.

## 영향

공통 계약과 공급자 인수 기준은 [상세 MVP 공통 분석 계약](../analysis-common-contracts.md)에 둔다.
EAT-215~219의 UI/조회, EAT-198의 집계, EAT-220/221의 발행·캐시가 이 계약을 소비한다.
구형 spec-cohort-v3의 행안부 비교·품목 공통 적용·고정 표본 숨김 정책을 새 슬라이스에 적용하지 않는다.
