## 결정

1. **화면 이름은 "넣을 공고"다.** 주소는 `/work` 그대로이고 지금처럼 운영자 권한 계정에만 열린다.
2. **한 사람이 사업장 여럿을 가진다. N번 값은 등록 순서 N번째 사업장의 값이다.** 1·2번은 맞춤의 두 장 자리, 3~5번은 응답의 예비
   순위다. 사업장이 하나면 혼자 넣을 때의 값이다. 사업장마다 넣는 사람 계정을 나누지 않는다.
3. **하한율마다 값은 하나다.** 90% 공고는 이번 달 맞춤 값이 공고마다 같으므로 사업장 카드에 한 번 둔다. 88% 공고는 전국 공식이
   참여 수 구간마다 달라 그 묶음의 줄마다 사업장별 값을 둔다. 아침 갱신과 방법 이름은 이 화면에 보이지 않는다(계산과 화면
   장부 기록은 그대로).
4. **카드의 "넘겨주기"는 그 사업장에 보낼 글을 복사한다.** 업체 이름, 달, 90% 값, 그 사업장의 88% 공고와 값이다. 다섯 곳을 한
   덩어리로 복사하지 않는다 — 받는 사람마다 남의 값까지 받는다.
5. **목록은 열린 공고(30일)를 KST 마감일로 묶고, 날마다 하한 88% 묶음을 먼저, 90% 묶음을 다음에 둔다.** 88%와 90%를 한 목록에
   섞으면 카드의 90% 값을 88% 공고에 잘못 부르기 쉽다. 줄은 마감 시각·학교·공고번호(복사)다. 9·10시가 아닌 마감은 색으로 띄운다.
6. **두지 않는 것:** 넣음 체크 칸(손으로 찍지 않아 결국 빈칸), 방법 비교와 성적, 하한선 자리 입구 줄, 품목 칩·학교 검색·조건 요약,
   설명·안심 문장. 분석은 심화 분석(#226)으로 간다.
7. **아직 정하지 않은 것:** 예비 3~5순위의 표본 밖 검증(후속 조각), 개찰 뒤 eaT 명단으로 넣은 값을 자동 표시하는 일, 사업장마다
   참가 자격이 없는 공고를 끄는 일.

## 배경

- 2026-11-17 독립 리뷰 둘(반증 담당, 사업장 다섯 가진 사장님 역할)이 4판 시안을 직접 눌러 보고 같은 결함을 짚었다: 넣음 칸 95개는
  쓰이지 않고, 88% 공고가 섞이면 값을 잘못 부르고, 다섯 곳 한 번에 복사는 쓰지 않는다. 시안:
  https://claude.ai/code/artifact/3842e80e-6009-4f3e-889d-66f2674f8d40 (비공개).
- 값의 표시 형식은 [ADR 0074](../../adr/0074-bid-value-shows-base-relative-percent.md)가 정한다.

## 다시 볼 조건

- 예비 3~5순위가 표본 밖에서 1·2번보다 확실히 못하면, 셋째 사업장부터 값을 비우거나 다른 규칙으로 바꾼다.
- 사장님이 넘겨주기 대신 다른 방식(사업장별 계정)을 원하면 결정 2를 다시 본다.
