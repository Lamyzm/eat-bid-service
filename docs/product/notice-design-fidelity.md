# 공고 분석 시안과 dev의 차이 — 2026-09-08

## 현재 판정과 문서 역할

**dev는 실제 자료를 연결한 중간 구현이며 시안 재현을 완료하지 않았다.** 전체 가용 폭과 전역
오른쪽 상세를 적용한 것, 차트 크게보기의 결함을 수정한 것은 화면 전체의 완료와 다르다.
이 문서는 시안 인수의 현재 차이와 수정 순서만 소유한다. 제품 범위·데이터 계약·전역 화면 규칙은
기존 PDR, 아키텍처와 [화면 체계](screen-system.md)가 소유한다.

[기존 통합 작업 기록](notice-dev-cohort-integration.md)의 날짜별 측정·제안은 당시 기록이다.
현재 시안과 dev의 적용 여부는 아래 표를 갱신하며, 완료 범위를 설명하는 표를 추가로 쌓지 않는다.

## 재현 기준

1. 최신 사용자 결정이 우선한다. 그날 하한·낙찰 업체 제거 요청을 별도 탭 제거로 좁히지 않는다.
   기관별 흐름이라는 별도 메뉴의 정리와 핵심 추이 차트 삭제도 같은 뜻이 아니다.
2. 최종 v7은 현재 공고·비교 기관·선택 과거 회차의 분리, 기관 체크, 차트와 이력의 읽는 순서,
   오른쪽 참여 기록을 판단하는 기준이다. 오래된 하단 참여 기록 탭으로 되돌리지 않는다.
3. 후속 [shell A 시안](prototypes/shell-comparison-2026-09-08/README.md)은 기존 왼쪽 탐색 재사용,
   전역 오른쪽 도구, 화면별 폭과 밀도에 대한 비교 자료다. 예시 회사·새 메뉴·사업자 전환까지
   구현 승인되거나 실제 데이터가 있는 것으로 간주하지 않는다.
4. 사용자가 선호한 dev 과거 회차의 숫자 정렬·소수 정밀도·행 밀도는 보존한다. 이것은 모든 열을
   보존하라는 뜻이 아니다. 실제 API 연결과 기존 shadcn·차트 컴포넌트를 재사용한다.
5. 고정 시안의 기관 표본과 연결선을 API의 전체 데이터나 코드 관계로 복제하지 않는다.

최종 v7 소스는 `codex/eat-111-floor-cohorts` 작업본의
`docs/product/prototypes/notice-mvp-2026-09-08`에 있고, 검토 주소는
<http://127.0.0.1:8767/v7/>다. 파일을 새로 복제해 또 다른 디자인을 시작하지 않는다.
이번 대조에서는 이 소스를 독립 빌드해 제공 중인 v7과 같음을 확인했다. 이미 열려 있던 브라우저
탭에는 이전 bundle의 하단 기록 탭이 남아 있었다. 시안 검토 전에 최신 문서를 다시 불러온다.

## 다시 두 번 만들지 않기 위한 수정 순서

### 1. 기존 자료만으로 시안의 화면 구성을 복원한다

- DecisionHeader와 기존 공고 상태 표시를 정리해 제목·마감·기초금액·하한·공고 정보 진입이
  한 공고 문맥으로 읽히게 한다. 상세 수치는 오른쪽 현재 공고 패널에서 계속 읽는다.
- EvidenceTabs·FlowLegend·FlowChart의 기존 조작을 재배치한다. 필수 낙찰값/2등값·축 확대·기본
  범위·크게보기를 우선하고, 후속 표시 설정을 별도 기능처럼 먼저 완성한 것으로 취급하지 않는다.
- HistoryTable과 이력 확대 표의 그날 하한·낙찰 업체 열 제거는 적용했다. 참여 기록 안의 실제
  업체 정보, 숫자 정렬·정밀도는 유지했다. 확대 표에서 기록을 열고 복귀하는 동작은 남아 있다.
- 현재 기관의 확인된 ID 관계와 관측 이름을 사용할 수 있는지 확인하고, 보이는 비교 대상 문맥을
  복원한다. 이름을 공고 제목에서 추정하거나 선택할 수 없는 가짜 다기관 메뉴를 만들지 않는다.

### 2. 기관 비교의 실제 자료 연결을 별도 단위로 완성한다

- 공고 이력이 있는 기관 후보 계약, 지역·품목 코드 관계, 기간·하한 적용 범위를 함께 구현한다.
  시안 표본을 전국 기관 목록으로 사용하지 않는다.
- 비교 체크가 기관 이력을 합치거나 강조해도 현재 공고와 상세로 선택한 회차를 몰래 교체하지 않는다.
  차트·표·분포·건수에 같은 조회 조건이 적용되는지를 확인한다.
- 기관 전용 진입·영속 관심/최근 본·지도·드로잉은 첫 공고 조회 화면의 복원과 구별해 추적한다.

### 3. 기능 검사와 별도로 시안 인수를 한다

- 동일 공고·조건·테마·CSS viewport로 시안과 dev를 함께 캡처한다. 일반 보기, 차트 확대,
  현재 공고 상세, 과거 회차 상세, 패널 접힘을 각각 확인한다.
- 1440×1000·1920×1080에서 가독성과 공간 배분을 보고, 1280×800·1024×768·375×812에서
  넘침·스크롤 소유권·날짜축·명시적 접기와 기록 접근을 확인한다.
- 회차를 고르면 공고 머리글과 과거 목록이 유지되고 오른쪽 기록만 바뀌어야 한다. 확대 복귀는
  같은 캔버스·선택·조건·이전 페이지 위치를 유지해야 한다.
- 기능 테스트가 통과해도 위 표의 미재현·미구현을 완료로 바꾸지 않는다. 다음 변경은 이 표를
  고치고 같은 화면 증거를 갱신한다. 시안 버전을 추가하는 작업부터 시작하지 않는다.

  유지되며 공고 제목은 바뀌지 않는다. 기간을 3개월로 바꾸면 그 회차가 조회에서 빠져 기록이 닫힌다.
- 넓은 화면에서는 Tab만으로 `이 공고 정보`에 닿아 Enter로 열고, 보이는 닫기 버튼으로 닫으면 초점이
  그 버튼으로 돌아온다. 좁은 화면의 Sheet는 Escape로 닫히고 초점도 같은 버튼으로 돌아온다.

검증 표면도 함께 고쳤다. 기관 회차 fixture가 `floorRate`·`awardMethod`·개찰월을 실제로 거르고
`meta.cohort`를 서버와 같은 규칙으로 되돌리도록 바꿨다. 이전에는 조건을 무시하고 코호트도 싣지 않아
web wrapper가 "요청한 비교 조건의 적용 여부를 확인할 수 없습니다"로 거절했고, 화면은 이력 없음으로
보였다. production 코호트 검증은 완화하지 않았다. 회차 명단 fixture를 새로 두어 오른쪽 기록이 빈
패널이나 오류가 아니라 관측 행으로 열리는지 본다.

### 이번에도 남은 한계

- 흐름 차트는 Lightweight Charts 캔버스라 계열·축을 DOM으로 물을 수 없다. 예전 SVG 시절의 계열·축·
  내 값 선 e2e 단언은 현재 구현에 맞지 않아 걷어냈고, 그 규칙은 `flow-series` 표시 모델 단위 검사가
  소유한다. 캔버스 픽셀로 실제 렌더는 확인했지만 계열별 e2e 회귀는 없다.
- `decideMyRateLine`이 만드는 "왜 이 값을 긋지 않는지" 문구를 차트가 화면에 그리지 않는다. 모델과
  단위 검사에는 있고 사용자에게는 보이지 않는 상태다.
- 넓은 화면의 현재 공고 상세는 modal이 아니라 옆 영역이라 Escape로 닫히지 않는다. 닫기는 보이는
  버튼이며 좁은 화면 Sheet만 Escape로 닫힌다.
- 기관 비교·관심·최근 본·내 공고와 전체 화면 시안 인수, 운영 배포는 이번 변경 범위가 아니다.
