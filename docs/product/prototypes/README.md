# 분석 화면 프로토타입

`analysis-hybrid-v1`은 Sites가 만든 로컬 검증 작업공간이다. 화면 구조와 상호작용을 빠르게 비교하기
위한 산출물이며 제품 계약이나 구현 source의 권위가 아니다.

로컬 작업공간은 embedded Git repository와 build artifact를 포함해 약 545MB이므로 이 저장소에
포함하지 않는다. clean checkout의 새 세션은 다음 자료를 권위 순서대로 사용한다.

1. [`../screen-system.md`](../screen-system.md) — 화면 역할과 정보 구조
2. [`../decision-support.md`](../decision-support.md) — 분석 수치와 cohort 의미
3. [`../mockups/analysis-detail-v1.png`](../mockups/analysis-detail-v1.png) — 리뷰 가능한 정적 화면
4. [`../mockups/analysis-detail-v1.svg`](../mockups/analysis-detail-v1.svg) — 편집 가능한 정적 원본

현재 공개된 검토 링크는
[eatbid analysis workbench](https://eatbid-analysis-workbench-v1.huntington59.chatgpt.site)다. 이 링크의
fixture 값과 가용성은 제품 효능, production API 또는 데이터 계약의 근거가 아니다.
