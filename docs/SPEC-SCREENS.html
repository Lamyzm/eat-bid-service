입찰 인텔리전스 — 7화면 명세

기획자 A(아버지 실전파)와 B(유료전환 상품파)의 독립 명세를 대조·판정해 종합했다. 양쪽이 일치한 결론: 승부처는 ② 공고 상세 하나다. 나머지 여섯은 그 화면에 사람을 데려다 놓거나 재료를 쌓는다.

제품 헌법 — "판단은 당신이, 재료는 전부 우리가."
사용자가 스스로 추측할 수 있게 재료를 최대로 제공한다. 아버지가 차트를 응시해 자기 위치를 찾았듯이. 면책 문구는 설정 구석의 한 줄이 전부("저희는 값을 골라드리지 않습니다. 재료를 다 보여드리고, 판단은 사장님이 합니다"). 금지는 둘 — ① 우리가 특정 금액을 추천·예측으로 출력하는 것 ② 해석 라벨(강자 배지·공고 점수·별점) — 재료 맥시멀과 해석 라벨링은 다르다. 사실은 전부 깐다, 딱지는 안 붙인다. 공통 푸터 한 줄(면책이 아니라 셀링 라인): "예정가는 추첨입니다. 그래서 추천가는 없습니다 — 판단 재료는 전부 있습니다." 그리고 아버지 툴 복제 금지(n=1 상품) — 재료는 맥시멀하되 구조는 표준 스택(몰림→착지→흐름→단골→나)으로, 아버지의 읽는 법은 배치가 아니라 카피에 이식한다.

§0.5

지속 결제 엔진 — 왜 "매달" 내는가

일회성 감탄("내 기록이 있네")은 첫 결제까지만 간다. 구독을 유지시키는 건 끊기는 순간 낡아버리는 것들이다:

① 시장의 리듬이 곧 갱신 주기학교 77%가 월간 발주 — 매달 새 판이 열린다. 이번 달 재료로 다음 달을 읽을 수 없다. 구독 해지 = 다음 달 판을 못 본다.
② 매일 아침 채점[투찰함] → 익일 결과·차이. 끊으면 채점이 멈춘다 — 습관이 든 뒤에는 이게 제일 아프다.
③ 자격 레이더는 실시간 자산열린 공고·마감·자격은 오늘만 유효한 정보. 김해 밖 연 20건+ 같은 발견은 끊기면 다시 놓친다.
④ 학교 상세는 쌓이는 자산매 회차 새 점이 찍히고 내 기록이 겹쳐 쌓인다. 6개월 쓴 사람의 ③은 처음 온 사람의 ③보다 "내 판"이다 — 갈아타기 비용이 매달 커진다.
⑤ 예보 → 준비 → 투찰 → 채점 루프"다음 주 장유고 유력" → 미리 학교 상세 응시 → 공고 뜨면 ② → 다음날 채점. 이 루프가 월 사이클로 돈다.
⑥ 월간 정산 문장"이번 달 12투찰 1낙찰, 밀림 차이 중앙값 +0.15 — 지난달보다 승자 구간에 가까워졌습니다." 내 추측이 나아지는 걸 매달 확인.

유료 코어 = ② 공고 상세 + ③ 학교 상세 (재료 스택·전 회차 기록·로스터·예보 알림). 무료 = ①(습관 형성)·⑤(진단 문장·기본 KPI, 단 나vs승자 도트와 차이 분포는 유료). 데이터 신선도 자체가 구독 상품이다 — 매일 크롤·익일 채점의 원가가 여기서 회수된다.

§0.6

인식 설계 — "없으면 투찰 못 하겠다"

발주자 직언: 이 툴의 하드한 효용은 제한적일 수 있다(승률은 수학적으로 못 올림). 그래서 상품의 본체는 의존 인식이다 — 아버지가 차트 없이 투찰 못 하듯, 사용자에게 "이거 없이 쓰는 건 눈감고 쓰는 것"이라는 감각을 설계한다. 단, 현혹은 진짜 데이터의 밀도로 연출한다 — 거짓 주장은 한 줄도 없이.

의존 ① 결정의 장소 독점투찰 결정이 일어나는 물리적 장소를 이 툴로 만든다: 값 입력→차트에 ▼ 박힘→투찰함 기록. 결정의 근육기억이 여기 생기면, 다른 데서 쓰는 투찰은 "허전한" 투찰이 된다.
의존 ② 기록의 인질투찰함 기록·관심 학교·메모·채점 이력이 쌓일수록 떠나는 비용 증가. 내 반년치 결정의 흔적이 여기 있다.
의존 ③ 불안 해소 담당"자격 되는 공고를 놓친 게 없나"(레이더) · "내가 요즘 너무 높게 쓰나"(진단) — 이 불안 둘을 이 툴만 꺼준다. 없으면 불안해지는 게 의존이다.
의존 ④ 아침 의식(ritual)채점 확인→오늘 공고→값 놓아보기→투찰함. 4단계 의식이 매일 반복되면 툴은 도구가 아니라 습관이 된다.
현혹 ① 스케일 과시"전국 9.6만 공고 · 630만 투찰 위에서 계산됩니다" — 화면 곳곳에 진짜 규모를 명시. 혼자서는 못 모으는 물량임을 체감시킴.
현혹 ② 실지도·밀도 연출지도(⑥)·꽉 찬 재료 스택(②)은 "있어 보이는" 표면 담당 — 첫인상에서 "이건 물건이다"를 만든다. 장식이되, 내용물이 진짜인 장식.
§0.7

품목 필터 — 전역 요구사항

축산/수산/농산/공산/김치/기타 — 사용자마다 자기 품목이 기본, 다른 품목도 전환해 볼 수 있다.

  • 온보딩(⑦): 참여 이력에서 내 품목 자동 추정 → 확인 한 번 ("주로 축산 공고에 참여하셨습니다. 맞습니까?").
  • 전역 헤더: 품목 스위처 상시 노출 — ①②③④⑥ 전 화면이 선택 품목 기준으로 필터.
  • 데이터: v1 = 공고명 키워드 분류(축산·육류·정육 / 수산 / 농산 / 공산 / 김치). v2 = 원본 아카이브의 품목분류 코드(MLFD_CLASS_NM) 재파싱으로 정밀화.

제목 = 답하는 질문"회차별 낙찰률" ❌ → "이 학교 승자는 어디에 착지했나" ⭕. 질문을 못 쓰면 차트 탈락.
하한 기준선 항상모든 이야기가 하한선 위 0.10폭에서 벌어진다. 기준선 없는 차트는 좌표 없는 지도.
값은 마크 위에 직접툴팁은 보조. 범례 색 대조로 읽게 하는 차트 금지.
n 명시 의무"14번 중 11번" — 표본을 숨기면 가짜 예측 장사와 같아진다. 4회 미만이면 차트 숨기고 문장으로.
노안 기준본문 16px+, 축 라벨 13px+, 터치 44px+. 1차 고객이 못 읽는 차트는 0원.
패턴 유도 금지난수(예정가 추첨)·판두께 추이(CV 0.85) 시각화 금지 — 없는 패턴을 읽게 만드는 건 거짓말 유도.
①

오늘 (홈)

무료

아침에 열면 3분 안에 "어느 공고에 들어갈지" 고르고 ②로 넘어간다. 첫 10초: "어제가 채점돼 있고, 오늘 할 일이 골라져 있다."

  1. 어제 개찰 결과 (있을 때만): 낙찰 / 밀림 / 무효 3분류 — 숫자까지: "장유고 — 밀림. 사장님 90.31, 낙찰 90.05 — 0.26 차이." 이 숫자가 다음 투찰의 재료다. 제목은 "어제 개찰 결과" — 알림처럼 꾸미지 않는다(실시간 아니므로). 클릭 → 해당 공고 상세.
  2. 지금 열려 있는 공고 (자격 통과분만, 마감 임박순): 학교명·소재지 / 기초금액(크게) / 하한율 / 개찰일 / "자격 됩니다" 배지 / 내 전적 뱃지("7번 투찰·1번 낙찰") + 재료 미리보기 한 줄 "최근 낙찰 90.03 · 90.11 · 90.05 (잘 나온 구간 90.00~90.10)" — 카드 단계에서 이미 감이 오게. 카드 클릭 = ② 공고 상세로 이동.
  3. 곧 나올 학교 (3~5곳): 근거 붙은 한 문장 — "장유고 — 보통 한 달마다 냅니다. 지난 발주 7/29 → 이번 주 유력. 지난 회 낙찰 90.03." — 예보에도 낙찰값을 붙여 미리 감 잡게. 면책 대신 근거가 신뢰다.
차트 0개 — 홈은 리스트다. 문장·숫자·배지로 충분.
  • 버림: 공고→학교 이동(② 신설로 대체) · 알림풍 빨간 점 · 밋밋한 예보 날짜 나열
"어제 개찰 3건 — 1건 낙찰, 2건은 더 낮게 쓴 업체에 밀렸습니다." (미로그인 배너) "사업자번호 10자리를 넣으면 이 화면이 당신 것이 됩니다."
②

공고 상세 (신설)

앱의 심장 결정블록 유료

"이 공고, 얼마 쓸까"를 이 화면 안에서 끝내고 투찰 표시까지 남긴다. 첫 10초: "엑셀에 손으로 모으던 게 전부 정리돼 있다."

공고 사실 → 이 학교의 과거 → 경쟁 상황 → 내 과거 → 결정(계산) → [투찰함]
  1. 헤더: 학교명 / 기초금액(화면 최대 숫자) / 하한율 / 개찰일·마감 / 허용지역 + "참여 가능" 배지 / (확장 후) 품목.
  2. 이 학교의 과거 — 잘 나온 구간: 현재 공고와 같은 하한율 회차만 집계. "최근 14회 중 11회가 90.00~90.10 사이에서 낙찰" + 이번 기초금액 기준 원화 환산 병기 ("41,850,000~41,897,000원").
  3. 자주 걸린 값 (2회 이상 전부 나열): "90.03 ×6 · 90.07 ×3 · 90.12 ×2".
  4. 최근 흐름: 최근 5회를 시간순 그대로 "90.11 → 90.03 → 90.05 → 90.03 → 90.07" — 오르는지 몰리는지는 사용자 눈이 판단한다. 우리는 순서대로 놓기만 한다.
  5. 누가 오나 (로더 확장 필요): "보통 7곳이 들어옵니다(최근 10회)" + 단골 로스터 이력 전부 — "○○축산: 참여 9회, 낙찰 2회 (90.03·90.15), 보통 90.0X대에 씀(투찰 중앙값)" — 참여·낙찰·낙찰값·착지 자리까지. 딱지만 안 붙인다. 사실 문장 병기: "이 학교에서 두 번 연속 낙찰한 업체는 최근 3년간 없었습니다." + "회차마다 들쭉날쭉합니다"(CV 0.85).
  6. 내 전적: "12번 — 낙찰 2 / 밀림 8 / 무효 2" + 밀림 과반이면 "이 학교에선 대체로 높게 쓰셨습니다."
  7. 결정 — 금액 계산기: 투찰률 입력 ↔ 금액 자동 (양방향). 하한 미만 즉시 빨간 경고 "이 금액은 무효입니다(하한 아래)". 입력하는 순간 위 차트에 내 값이 실시간 마커(▼)로 박힌다 — 과거 분포 위 어디 놓이는지 눈으로 확인. 그림이 말하게 두고 평가 문구는 안 붙인다.
  8. [이 공고에 투찰함] + 쓴 투찰률 기록 → 익일 채점의 연료. 하단에 "이 학교 다음 공고 알림 받기" 토글(결정 직후가 승낙율 최고).
차트 1: "이 학교 승자들은 하한선 위 어디에 착지했나?"
가로 1차원 도트 스트립 (x=낙찰 투찰률, 하한~하한+0.15). 하한선 굵은 수직선 + 0.10폭 음영. 자주 걸린 값은 점 쌓기+"90.03 ×6" 라벨. 음영 위 "14번 중 11번". 점=n. 최근성 인코딩: 최근 3회 진한 색+테두리, 오래될수록 옅게 — 몰림과 최근 흐름을 한 그림에. 과거 내 투찰 점은 △, 입력 중인 값은 실시간 ▼. 현재 하한율 회차만, 다른 하한은 접힘 영역.
  • 넣지 않음: 학교 산점도 재탕(링크로) · 예정가 추첨 시각화(난수에 패턴 유도=소음) · "비슷한 공고" 추천 · 강자 배지·점수·별점(해석 라벨) · 영역마다 붙는 면책 문구
"누가 이길지는 아무도 모릅니다. 누가 오는지는 보여드립니다." · "그 안의 어디가 이길지는 예정가 추첨입니다 — 저희는 찍어드리지 않습니다." (미로그인, 내 전적 자리) "이 학교에서의 당신 기록이 여기 나타납니다. 이미 저장돼 있습니다 — 사업자번호만 넣으세요."
③

학교 상세

유료 코어

공고가 없을 때 이 학교를 미리 파악한다 — 쌓이는 자산: 매 회차 새 점이 찍히고 내 기록이 겹쳐, 오래 쓸수록 "내 판"이 된다(지속 결제 엔진 ④). 간판 = 다음 발주 예보. 열린 공고가 있으면 예보 자리에 ②로 가는 버튼.

  1. 헤더: 학교명·소재지 / 연 공고 수 / "보통 31일 간격" / 다음 발주 예보 카드 ("지난 발주 8/1 → 9월 초 예상. 확정 아닙니다").
  2. 잘 나온 구간 — 하한별 분리 (90/88 절대 안 섞음): 카드 2장, 각 "N회 중 M회가 {구간}".
  3. 자주 걸린 값 (2회+).
  4. 회차 기록 표 (화면의 몸통): 날짜/기초금액/하한/낙찰률/낙찰 업체명/참여 수/내 참여(내 값·결과·낙찰과 차이). 최신 위 — 낙찰 업체명도 사실이니 싣는다.
  5. 차트(아래) → 단골 참여 업체(② 컴포넌트 재사용) → 내 전적 상세.
  6. 기준금액 입력 계산기 — 맨 아래 강등(공고 없는 날의 시뮬레이션).
차트 1: "착지 구간이 회차마다 유지되는가, 그리고 내 점은 어디 있었나?"
시간축 도트 (x=개찰일, y=투찰률). 하한선+음영, 하한율 변경 시 배경 밴드("이때부터 하한 88"). 내 투찰 점은 △ — 내 점이 늘 위에 떠 있으면 말보다 눈이 먼저 안다. 각 점 아래 작은 숫자로 그 회 참여 업체 수 병기(추이선은 금지, 점별 사실 표기는 재료). 최근 3점 값 라벨, 점 탭→표 행 하이라이트.
  • 버림: 기초가 추이 차트(표 숫자로 충분, 결정에 무영향) · 업체 수 추이선(CV 0.85 노이즈에 패턴 유도 — 유해)
④

학교 찾기

"내 자격으로 갈 수 있는데 몰랐던 학교" 발견. 첫 10초: 검색 전에 이미 제안이 와 있다.

  1. 제안 스트립: "당신 자격으로 참여 가능 · 발주 잦은 순" 상위 5곳 — 소재지 밖(진해용원고류) 우선 노출.
  2. 검색창 + "내 자격 되는 학교만" 토글 (기본 켜짐, 허용지역 기준) — 소재지 필터는 쓰지 않는다(연 20건+ 놓침 증명).
  3. 표 (7열): 학교명/지역/연 공고/보통 업체 수(10곳 이하 강조)/최근 낙찰값 3개("90.03 · 90.11 · 90.05" — 이 열이 있어야 훑기만 해도 궁금증이 생긴다)/마지막 발주/다음 예보. 기본 정렬 = 예보 임박순.
차트 0개 — 지도 시각화 기각. 위치는 납품업자가 안다. 모르는 건 "저 학교가 우릴 받아주는가"고 그건 배지 하나로 답한다.
"김해 밖에도 당신 자격으로 들어갈 수 있는 공고가 연 20건 넘게 있습니다. 소재지만 보면 놓칩니다."
⑤

내 성적표

무료

"내가 대체로 높게 쓰나"를 인정하게 만든다 — 유일하게 행동을 바꾸는 화면. 리텐션(해지 방어) 담당.

  1. 진단 문장 (최상단, 최대 글씨): "최근 3달, 24번 중 15번 밀림 — 대체로 높게 쓰셨습니다." + 차이 분포 병기: "밀린 15번의 차이: 중간값 +0.21, 가장 아까웠던 건 +0.02(○○초)." — 얼마나 내릴지를 스스로 가늠하게. 무효 多면 "하한 계산부터 확인하십시오."
  2. KPI 3장 (5장→3장): 투찰 / 낙찰(율) / 진 것 분해("밀림 15 · 무효 3"). "평균 투찰률" 삭제(하한 섞여 오염).
  3. 사업자 탭: 합산(기본) | 개별. 토글 옆 "합치면 낙찰 기회가 1.9배였습니다 — 두 개 모두 등록하세요."
  4. 차트(아래).
  5. 최근 결과 표: 날짜/학교/내 투찰률/낙찰률/결과/차이("+0.31 높게 씀") — 버릇의 증거물.
  6. 월별 요약은 표 두 줄(투찰/낙찰)로. ComposedChart 탈락.
차트 1: "나는 승자들이 서는 자리 대비 어디에 쓰고 있나?"
하한 기준 정규화 축 하나에 내 투찰(회색 점) vs 그 회차 승자(색 점) 도트 플롯. 진단 문장을 눈으로 재확인시키는 유일한 그림 — 진단과 그림이 같은 말을 하면 신뢰가 생긴다. 내 평균 위치·승자 밀집 구간 직접 라벨.
"'밀림'은 남이 더 낮게 쓴 것, '무효'는 하한 아래로 써서 무효 처리된 것입니다. 무효는 고칠 수 있는 실수입니다." 부제 "어제 개찰분까지"
⑥

시장 지도

"어디로 넓힐까" — 월 1회 전략 화면임을 인정, 그 이상 키우지 않는다. 개발 우선순위 최하.

  1. 실지도 (화면의 히어로 — 발주자 지시): 전국 지도 위 시군구 버블 — 크기 = 연간 공고량, 색 = 업체당 기대낙찰(진할수록 빈 판) + 지금 열린 공고 핀(개수 배지) + 내 지역 ★. 버블 클릭 → 지역 상세. 질문: "어느 권역이 비어 있고, 지금 어디에 공고가 열려 있나."
    기술: v1 = react-leaflet + OSM 타일 + 시군구 중심좌표 번들(API 키 불필요). v2 = 학교 단위 점(주소 지오코딩, VWorld/카카오 키 필요 — 로더 1회 캐시). 카카오맵 교체는 키 발급 후 옵션.
  2. 내 지역 카드 (지도 아래 고정): 업체 수/연 공고/업체당 연 공고 수(핵심 숫자). 남의 랭킹부터 보여주지 않는다.
  3. 지역 표: 지역/업체 수/연 공고/업체당 + "김해의 1.6배" 배수 표기. '랭킹' 프레임 아닌 '내 지역 대비'.
  4. 지역 클릭 → 판두께 분포 차트(아래) + 학교 목록 → ④로 연결.
  5. 한계 문구: "저희가 수집한 범위 안의 숫자입니다."
차트 2개 (지역 상세에서만) — ⓐ "이 지역 판은 얇은가?" ⓑ "이 판이 커지나, 마르나?"
ⓑ = 연도별 공고량 막대 + 참여 업체수 선 — 통영 72→4곳 붕괴를 발견한 바로 그 차트. 확장 판단의 핵심 흐름 재료. 값 직접 라벨.
ⓐ = 공고별 참여 업체 수 분포 막대. 근거: 승률차의 97%가 판두께(지속성 0.97) — 지역 선택의 검증된 유일 변수. "업체 10곳 이하" 구간 비율 직접 라벨. 막대 탭→해당 두께 학교 목록.
  • 버림: '승자 칩' 이름(→ "이 지역 활동 업체"로 개명, 참여·낙찰 건수 유지) · 월별 차트(계절성은 예보가 소화) · '랭킹' 프레임
"통영은 업체 5곳이 연 176건을 나눕니다. 한 곳당 35건 — 김해(21건)의 1.6배. 판이 얇은 곳이 유리한 건 예측이 아니라 나눗셈입니다."
⑦

내 사업자 (온보딩)

전환의 심장 2

번호 10자리 → 3초 뒤 "당신 기록이 이미 있다." 첫 10초: "가입이 아니라 확인이구나."

입력창 1개 → 즉시 조회("OO축산 — 투찰 1,847건") → 진단 문장 하나 맛보기 → 2번째 사업자 제안(1.9배) → 알림 채널(문자/카카오) → 홈
  1. 입력창 하나. 이름·이메일·비밀번호 선요구 금지 — 단계 하나마다 60대 이탈률로 갚는다.
  2. 조회 지연 시 스피너 대신 문장: "공개 입찰 기록을 찾는 중입니다."
  3. 확인 직후 맛보기: 진단 문장 1개 + ⑤의 나vs승자 도트 축소판 1장("회색이 당신입니다") — ⑤ 컴포넌트 재사용, 그 이상 그림은 입장 지연이라 금지.
  4. 가격은 1일차 고지, 과금은 나중: "14일 무료. 이후 월 3만원."
차트 0개 — 설득 도구는 그림이 아니라 "1,847건"이라는 본인의 숫자.
"사업자등록번호 10자리. 그게 전부입니다." · "찾았습니다. 투찰 3,925건, 낙찰 75건. 가장 최근 낙찰: 7월 12일 가락중, 90.07." — 최근 한 건까지 짚어주면 신뢰가 박힌다. · "월 3만원 — 낙찰 한 건 마진의 20분의 1입니다."
