# eaT 목록 창 의미와 코퍼스 규모 실측 (2026-09-03)

## 1. 결론

`P_BID_BGNG_DT`와 `P_BID_END_DT`는 공고일 범위가 아니라 **입찰기간 겹침 필터**다. 그래서 인접한
창은 같은 공고를 다시 돌려준다. 전량 수집은 `ETN_BID_ID` 중복 제거 없이는 성립하지 않는다.

## 2. 관측 방법

저장소의 `EatHttpClient`와 검토된 `bid-list` 계약으로만 호출했다. 재현 명령은
`apps/dataplane/scripts/probe_eat_list.py`이며 읽기 전용이라 R2와 PostgreSQL을 건드리지 않는다.

```powershell
uv run --project apps/dataplane python apps/dataplane/scripts/probe_eat_list.py dates `
  --start-date 20260825 --end-date 20260825 --page-size 200
```

## 3. 창 의미는 겹침이다

세 창에서 반환 행의 날짜 범위를 확인했다. 모든 행이 `BID_STRT_DT <= 창끝` 이고
`BID_END_DT >= 창시작` 이다.

| 창 | 반환 | `BID_STRT_DT` 최대 | `BID_END_DT` 최소 |
|---|---|---|---|
| `20260825..20260825` | 200 | `20260825` | `20260825` |
| `20260828..20260828` | 200 | `20260828` | `20260828` |
| `20260903..20260903` | 85 | `20260903` | `20260903` |

`PBANC_YMD`(공고일)는 창 밖 값이 다수다. 하루 창의 `20260903` 조회에서 공고일이 `20240725`인 행이
나왔다. 공고일 기준으로 자른다는 가정은 기각한다.

**따라서 인접 창은 결과가 겹친다.** 월 단위로 backfill을 쪼개면 경계에 걸친 공고가 두 창 모두에
나타난다.

## 4. 페이지 계약

`20260901..20260903`(`TOT_CNT=115`)에서 측정했다.

| `PAGE_SIZE` | 반환 행 | `RN` 연속 |
|---|---|---|
| 1 | 1 | 예 |
| 10 | 10 | 예 |
| 100 | 100 | 예 |
| 500 | 115 | 예 |
| 1000 | 115 | 예 |

`min(TOT_CNT, PAGE_SIZE)`를 돌려주고 `RN`은 `(page-1)*PAGE_SIZE + 1`부터 연속이다. 1000까지 거부되지
않았다. 상한 자체는 더 확인하지 않았다.

## 5. 물량은 학기 주기로 몰린다

단일 날짜 창의 `TOT_CNT`, 즉 그날 입찰기간이 열려 있던 공고 수다.

| 날짜 | 열린 공고 |
|---|---|
| 2026-08-25 | 7,231 |
| 2026-08-26 | 4,020 |
| 2026-08-27 | 1,708 |
| 2026-08-28 | 568 |
| 2026-08-31 | 146 |
| 2026-09-01 | 88 |
| 2026-09-02 | 83 |
| 2026-09-03 | 85 |

8월 25일 창의 `DLVRY_STRT_DT`가 `20260831`~`20261001`이다. 9월 급식 물량이 8월 말에 한꺼번에
공고된다. 피크와 저점의 차이가 85배다.

**수집 설계 함의.** 피크일에는 한 번의 폴링이 `PAGE_SIZE=1000` 기준 8페이지다. 목록은 감당되지만
그날 신규 공고 7,000건의 상세를 부르는 것은 별개 부하다. 폭을 semaphore와 재개 가능성으로 흡수해야
한다.

## 6. 전량 규모

연 단위 창의 `TOT_CNT`다. 창이 겹치므로 연 경계 공고는 두 해에 중복 계수된다.

| 연도 | `TOT_CNT` |
|---|---|
| 2014 | 186,826 |
| 2015 | 188,578 |
| 2016 | 211,094 |
| 2017 | 207,851 |
| 2018 | 205,659 |
| 2019 | 201,928 |
| 2020 | 137,121 |
| 2021 | 174,194 |
| 2022 | 179,552 |
| 2023 | 173,452 |
| 2024 | 168,098 |
| 2025 | 163,589 |
| 2026 (9월 3일까지) | 106,828 |

2014년에도 18만건대가 나오므로 코퍼스 시작 연도는 더 이르다. 확인하지 않았다.

2020년의 하락은 코호트 해석에서 다뤄야 한다. 학교 휴업 기간이므로 다른 해와 같은 모집단으로 볼 수
없다.

**사용자가 정한 수집 순서 기준.** 최근 1년은 약 16만건, 전량은 2014년 이후만 해도 230만건 규모다.

## 7. 확인하지 않은 것

- `BID_CNT`가 같은 공고에서 시간에 따라 오르는지. 기준 스냅샷만 확보했고 재관측이 필요하다.
- `PAGE_SIZE` 상한값.
- 코퍼스 시작 연도.
- 재공고와 차수가 목록에서 어떻게 구분되는지.
