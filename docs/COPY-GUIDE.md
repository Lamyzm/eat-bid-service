# UI 카피 가이드 (보이스 & 톤)

AI 생성 카피 특유의 문체를 제거하기 위한 규칙. 모든 화면 문구는 이 문서를 따른다.

## 원칙
1. **섹션 제목 = 명사구.** 질문·문장·은유 금지.
   - ❌ "보통 몇 곳이 옵니까" → ✅ "참여 업체"
   - ❌ "착지 구간이 회차마다 유지되는가" → ✅ "회차별 낙찰률"
2. **표준 조달 용어 사용.** 사용자는 나라장터·eaT 용어에 이미 익숙하다. 발명한 은유 금지.
   - 투찰, 개찰, 기초금액, 낙찰하한율(하한), 참가자격, 낙찰률
   - ❌ "잘 나온 구간" → ✅ "주요 낙찰 구간" / ❌ "곧 나올 학교" → ✅ "발주 예정"
3. **1문장 1정보, 능동형.** 설명은 '~합니다' 평서문 한 문장. 수사·감탄·비유 금지.
4. **구체적 사실만.** 숫자·기간·건수로 말한다. 추상 효익("현혹", "당신 것") 금지.
5. **금지 목록**: 수사의문문 제목, 문장 중간 em-dash(—) 수사, "~드립니다/~보세요" 서비스체,
   "당신", 이모지 문구, 따옴표 강조.
6. **구분자**: 나열은 `·` 사용. 설명 부연은 괄호.
7. **예외**: "밀림"(순위 밀림 무효)은 사용자 실사용 어휘라 유지. 판단 문장(진단)은
   '~한 편입니다'까지 허용, 추천·지시("~하세요")는 금지.

## 근거
- 토스 UX 라이팅: 1문장 1메시지, 능동형, 가이드 문서화
- Unslop/anti-slop 방법론: AI티는 "지정 안 한 기본값" — 문구마다 제품 고유의 이유가 있어야 함,
  추상 수사 대신 기능 서술
- NN/g UX copy: 마이크로카피는 기능을 이름으로 부른다 (label = what it does)

## v2 확정 (2026-08-27) — 원본 입찰판 보이스 + AI tells 제거
**canon 어휘 (아버지 입찰판 원본 — 바꾸지 않는다):**
잘 나온 구간 · 자주 걸린 값 · 밀림 · 하한미달 · 내 투찰 버릇 · 내 성적 ·
기초가 · 하한율 · 투찰 · 개찰 · "예측하지 않는다" · 표본 부족 · 판(시장)

**원본 보이스 특징 (따를 것):**
- 제목: 명사형 ("오늘 열린 공고", "과거 기록 전체", "회차별 낙찰률 흐름")
- 설명: 합니다체 1문장 1정보 ("실제 하한 금액은 개찰 때 추첨으로 정해집니다.")
- 진단: 건조한 단정 ("대체로 너무 높게 쓴다")
- 조작 안내: "~하면 ~보입니다" ("학교를 누르면 자세히 보입니다")

**제거 대상 (im-not-ai 한국어 AI tells 중 UI 해당분):**
- A 번역투: "~를 통해", "~에 있어서", 이중 피동
- C/J 구조: 문중 대시(—) 수사, 볼드·이모지 남용
- D 관용구: "결론적으로", 과장 수식("혁신적인")
- I 형식명사: "~할 필요가 있다", "~것입니다"
- 추가: 수사의문문 제목, "드립니다/보세요" 서비스체, "당신"

## 차트 방법론 (NN/g Clutter-Free + small multiples)
1. 하한(그룹)이 섞이면 겹치지 말고 **패널 분리** (small multiples, 공유 시간축)
2. 값이 중요하면 **직접 라벨** (최근 3회), 그러면 그리드·y눈금 최소화
3. 범례 대신 **데이터 옆 직접 라벨** (하한선 위에 "하한 90")
4. 보조 수치(참여수)는 잉크 경쟁 시 툴팁으로
