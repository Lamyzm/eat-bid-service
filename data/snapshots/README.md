# 스냅샷 — 되돌릴 수 없는 시점의 값

여기 있는 파일은 **다시 뜰 수 없는 것**이다. 지우지 마라.

## `schools-id-before-reparse.txt`

**뜬 시각**: 2026-08-28 15:46:16 UTC (재파싱 직전)
**행 수**: 5,596
**그중 주소 파싱 쓰레기로 시작하는 id**: 53 (`급식실|…` 등)

**왜 이게 필요한가.** 이 시점까지 발급된 분석판 URL 이 `{시군구}|{학교명}` 형식이고,
그 값이 **여기 적힌 그대로**다. 재파싱이 시군구를 코드에서 다시 만들면
**DB 에서 이 id 들이 사라진다.** 그러면 사람이 북마크한 링크와 우리가 만든 링크가 죽는다.

**재파싱 후에 뜨면 늦다** — 그때는 이미 다른 값이다. 그래서 직전에 떴다.

**쓰는 곳**: `apps/web/src/lib/school-id.ts` 의 별칭 조회.
이 목록과 재파싱 후 목록을 합성해 `{옛키: 새키}` 를 만든다.
**둘 다 관측된 값 목록이지 규칙이 아니다** — 조회는 되고 비교는 안 된다.

**갱신하지 않는다.** 표가 자라면 그건 다시 규칙이 된다.

## 다시 뜨는 법

```
kubectl -n eatbid exec deploy/postgres -- psql -U eatbid -qtA -c "select id from schools order by id"
```
**단, 지금 뜨면 지금 값이 나온다. 이 파일의 값은 저 시각의 것이고 되돌릴 수 없다.**
